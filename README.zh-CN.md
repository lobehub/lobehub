## 🧩 市场

在 [lobehub.com][official-site] 上找 Agent、MCP 服务器和技能，添加到你的工作空间，也可以发布你自己的。

| 市场                                     | 内容                                                                                       |
| :--------------------------------------- | :----------------------------------------------------------------------------------------- |
| [**🤖 Agent 助理**][market-agents]       | 可直接使用的 AI 助理，覆盖写作、问答、图像、视频、语音与工作流，添加到空间后可以按需调整。 |
| [**🔌 MCP 服务器**][market-mcp]          | 按活跃度、稳定性与社区反馈筛选 MCP 服务器，帮你找到可信的服务。                            |
| [**🧠 技能**][market-skills]             | 采用开放的 `SKILL.md` 格式，同样可以在 Claude Code、Codex CLI 和 ChatGPT 里使用。          |
| [**🎨 AI / LLM 模型图标**][market-icons] | 免费的 AI 品牌与模型图标库，支持下载 SVG、PNG 与矢量文件。                                 |

**发布你自己的**

- **Agent**：在 LobeHub 里打开它的设置即可提交。[创作者奖励计划][creator-program]每两周精选一个社区 Agent。

- **MCP 服务器**：让你的 agent 执行 `Read https://lobehub.com/publish-mcp/skill.md and follow the instructions to publish my MCP server to the LobeHub Marketplace`，或者用命令行：

  ```bash
  npx -y @lobehub/market-cli login
  npx -y @lobehub/market-cli plugin submit https://github.com/OWNER/REPOSITORY
  ```

- **技能**：在[技能市场][market-skills]提交 GitHub 仓库。

## 🛳 开箱即用

在自己的服务器上运行 LobeHub，数据留在你手里。完整教程见 [📘 构建属于自己的 LobeHub][docs-self-hosting]。

### `A` 使用 Docker Compose 部署（推荐）

[![][docker-release-shield]][docker-release-link]
[![][docker-size-shield]][docker-size-link]
[![][docker-pulls-shield]][docker-pulls-link]

一起启动 LobeHub、PostgreSQL、Redis、RustFS 文件存储、SearXNG 搜索和 Agent Gateway。支持 Linux 和 macOS，Windows 请通过 [WSL 2](https://aka.ms/wsl) 运行。

```bash
mkdir lobehub && cd lobehub
bash <(curl -fsSL https://lobe.li/setup.sh) -l zh_CN
docker compose up -d
```

然后打开 <http://localhost:3210>。端口、局域网与域名模式，以及升级方法，见 [📘 使用 Docker Compose 部署][docs-docker]。

### `B` 一键部署

在 Vercel 上部署前，需要准备 PostgreSQL 数据库、S3 兼容存储和几个密钥，[📘 在 Vercel 上部署][docs-vercel] 里有每一项的说明。

## ⌨️ 本地开发

可以使用 GitHub Codespaces 进行在线开发：

[![][codespaces-shield]][codespaces-link]

或者使用以下命令进行本地开发：

```fish
$ git clone https://github.com/lobehub/lobehub.git
$ cd lobehub
$ pnpm install
$ bun run dev          # 全栈开发（Next.js + Vite SPA）
$ bun run dev:spa       # 仅 SPA 前端（端口 9876）
```

> **Debug Proxy**：运行 `dev:spa` 后，终端会输出代理 URL，如
> `https://app.lobehub.com/_dangerous_local_dev_proxy?debug-host=http%3A%2F%2Flocalhost%3A9876`。
> 打开此链接可在线上环境中加载本地开发服务器，支持 HMR 热更新。

如果你希望了解更多详情，欢迎可以查阅我们的 [📘 开发指南][docs-dev-guide]
