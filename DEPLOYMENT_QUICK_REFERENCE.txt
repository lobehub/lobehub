TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

❌ Docker build fails
   → Ensure 10GB+ free disk space: df -h
   → Check network connectivity: ping 8.8.8.8
   → Check Docker version: docker --version

❌ Container won't start
   → Check logs: docker compose logs app
   → Verify environment variables: cat .env
   → Check DATABASE_URL is set correctly

❌ Application not responding
   → Wait 2-3 minutes for full initialization
   → Check port is open: netstat -tulpn | grep 3210
   → Verify network connectivity: curl http://localhost:3210

❌ Audio generation fails
   → Verify SUNO_API_KEY is set: docker exec <id> env | grep SUNO
   → Check Suno API credentials are valid
   → Check network connectivity to Suno API

❌ File uploads fail
   → Verify S3_* env vars: docker exec <id> env | grep S3
   → Check S3 bucket permissions
   → Verify available storage: df -h
