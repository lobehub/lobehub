# 🤯 LobeHub 桌面應用程式

LobeHub Desktop 是 [LobeChat](https://github.com/lobehub/lobe-chat) 的跨平臺桌面應用程式，使用 Electron 構建，提供了更加原生的桌面體驗和功能。

## ✨ 功能特點

- **🌍 跨平臺支援**：支援 macOS (Intel/Apple Silicon)、Windows 和 Linux 系統
- **🔄 自動更新**：搭載更新機制，確保您始終使用最新版本
- **🌐 多語言支援**：完整的 i18n 支援，包含 18+ 種語言的懶載入
- **🎨 原生整合**：與作業系統深度整合，提供原生選單、快捷鍵和通知
- **🔒 安全可靠**：macOS 公證認證，加密令牌存儲，安全的 OAuth 流程
- **📦 多管道發佈**：提供穩定版、測試版和每日構建版本
- **⚡ 高級視窗管理**：多視窗架構，支援主題同步
- **🔗 遠端伺服器同步**：與遠端 LobeChat 實例的安全資料同步
- **🎯 開發者工具**：搭載開發面板和全面的除錯工具

## 🚀 開發環境設定

### 前提條件

- **Node.js** 22+
- **pnpm** 10+
- **Electron** 相容的開發環境

### 快速開始

```bash
# 安裝依賴
pnpm install-isolated

# 啟動開發伺服器
pnpm dev

# 類型檢查
pnpm type-check

# 執行測試
pnpm test
```

### 環境變數設定

複製 `.env.desktop` 到 `.env` 並根據需要設定：

```bash
cp .env.desktop .env
```

> \[!WARNING]
> 在進行更改之前請備份您的 `.env` 檔案，避免丟失設定。

### 構建命令

| 命令                       | 描述                               |
| -------------------------- | ---------------------------------- |
| `pnpm build:main`          | 構建 main/preload（僅產出 dist）   |
| `pnpm package:mac`         | 打包 macOS (Intel + Apple Silicon) |
| `pnpm package:win`         | 打包 Windows                       |
| `pnpm package:linux`       | 打包 Linux                         |
| `pnpm package:local`       | 本地打包（不打 ASAR）              |
| `pnpm package:local:reuse` | 本地打包複用已有 dist              |

### 開發工作流

```bash
# 1. 開發
pnpm dev # 啟動熱重載開發伺服器

# 2. 程式碼品質
pnpm lint       # ESLint 檢查
pnpm format     # Prettier 格式化
pnpm type-check # TypeScript 驗證

# 3. 測試
pnpm test # 執行 Vitest 測試

# 4. 構建和打包
pnpm build:main    # 生產構建（僅 dist）
pnpm package:local # 本地測試打包
```

## 🎯 發佈管道

| 管道                     | 描述                   | 穩定性 | 自動更新 |
| ------------------------ | ---------------------- | ------ | -------- |
| **穩定版**               | 經過充分測試的正式版本 | 🟢 高  | ✅ 是    |

## 🛠 技術棧

### 核心框架

- **Electron** `37.1.0` - 跨平臺桌面框架

- **依賴注入** - 基於裝飾器註冊的 IoC 容器

- **Vitest** - 單元測試框架

- **Electron Safe Storage** - 加密令牌存儲

## 🏗 架構設計

### 📁 核心結構

```
src/main/core/
├── App.ts                    # 🎯 主應用程式協調器
├── IoCContainer.ts           # 🔌 依賴注入容器
├── window/                   # 🪟 視窗管理模組
│   ├── WindowThemeManager.ts     # 🎨 主題同步
│   ├── WindowPositionManager.ts  # 📐 位置持久化
│   ├── WindowErrorHandler.ts     # ⚠️  錯誤邊界
│   └── WindowConfigBuilder.ts    # ⚙️  設定構建器
├── browser/                  # 🌐 瀏覽器管理模組
│   ├── Browser.ts               # 🪟 單個視窗實例
│   └── BrowserManager.ts        # 👥 多視窗協調器
├── ui/                       # 🎨 UI 系統模組
│   ├── Tray.ts                  # 📍 系統托盤整合
│   ├── TrayManager.ts           # 🔧 托盤管理
│   ├── MenuManager.ts           # 📋 原生選單系統
│   └── ShortcutManager.ts       # ⌨️  全域快捷鍵
└── infrastructure/           # 🔧 基礎設施服務
    ├── StoreManager.ts          # 💾 設定存儲
    ├── I18nManager.ts           # 🌍 國際化
    ├── UpdaterManager.ts        # 📦 自動更新系統
    └── StaticFileServerManager.ts # 🗂️ 本地檔案服務
```

### 🔄 應用程式生命週期

`App.ts` 類通過幾個關鍵階段協調整個應用程式的生命週期：

#### 1. 🚀 初始化階段

- **系統訊息記錄** - 捕獲作業系統、CPU、記憶體和區域設定詳細資訊
- **存儲管理器設定** - 初始化持久設定存儲
- **動態模組載入** - 通過 glob 導入自動發現控制器和服務
- **IPC 事件註冊** - 設定製程間通訊通道

#### 2. 🏃 引導階段

- **單實例檢查** - 確保只執行一個應用程式實例
- **IPC 伺服器啟動** - 啟動通訊伺服器
- **核心管理器初始化** - 按順序初始化所有管理器：
  - 🌍 國際化管理器
  - 📋 原生選單系統
  - 🗂️ 本地資源伺服器
  - ⌨️ 全域快捷鍵註冊
  - 🪟 瀏覽器視窗管理
  - 📍 系統托盤（僅 Windows）
  - 📦 自動更新系統

#### 🔧 服務模式

### 🔗 製程間通訊

#### 📡 IPC 系統功能

- **雙向通訊** - Main↔Renderer 和 Main↔Next.js 伺服器
- **類型安全事件** - 所有事件參數的 TypeScript 接口
- **上下文感知** - 事件包含用於視窗特定操作的發送者上下文
- **錯誤傳播** - 具有適當狀態碼的集中錯誤處理

##### 🧩 渲染器 IPC 助手

渲染端通過 `src/utils/electron/ipc.ts` 提供的 `ensureElectronIpc` 獲得一個執行時代理，無需在 preload 中暴露 Proxy 對象即可獲得類型安全的調用體驗：

```ts
import { ensureElectronIpc } from '@/utils/electron/ipc';

const ipc = ensureElectronIpc();
await ipc.windows.openSettingsWindow({ tab: 'provider' });
```
