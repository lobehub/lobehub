# 如何在 LobeHub 中更换订阅方案

<CloudOnlyAlert />

你可以在应用设置中比较套餐，并将当前订阅更换为更高级的方案。如果想使用较低方案，需要先取消当前订阅，等待本次方案到期后再重新订阅。

## 打开套餐页面

<Steps>
  ### 打开应用设置

  点击首页左上角的个人头像，然后点击**应用设置**。

  ### 进入套餐页面

  在左侧导航的**套餐**分组中点击**套餐**。

  页面会显示当前套餐、可选套餐、每月积分、存储空间和其他权益。你可以切换**按月**或**按年**查看对应价格。
</Steps>

## 升级方案

<Steps>
  ### 选择更高级的方案

  找到需要升级到的方案，点击页面显示的购买或升级按钮。

  ### 确认方案变化

  确认目标方案、付款周期、生效时间和应付金额。当前方案的剩余价值可能会抵扣新方案费用；实际金额以确认页面为准。

  ### 完成升级

  根据页面提示完成付款。页面会显示升级结果和生效时间。
</Steps>

升级通常在付款成功后生效。如果页面允许从月付更换为年付，确认页面会显示需要支付的金额和生效时间。

<Callout type="info">
  如果当前订阅有未支付账单，需要先支付欠款或取消该订阅，才能升级方案。
</Callout>

## 更换为较低方案

当前订阅有效期内不能直接更换为较低方案。你可以先在**当前套餐**区域点击**管理订阅**，取消当前订阅，然后等待本次方案到期。

当前方案到期并降为免费版后，回到套餐页面，重新订阅需要的较低方案。到期前仍可继续使用当前套餐权益。

如果取消尚未生效，也可以在到期前点击**恢复订阅**继续自动续订。

## 移动端购买的订阅

如果订阅通过移动端应用购买，网页端会提示前往移动设备管理。你可以在原购买平台更换或取消订阅。
