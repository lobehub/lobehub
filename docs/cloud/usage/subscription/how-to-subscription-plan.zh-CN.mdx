# 如何在 LobeHub 中订阅方案

<CloudOnlyAlert />

LobeHub 有三种个人付费套餐：

- **基础版（Starter）**：适合偶尔使用 AI 的用户。
- **进阶版（Premium）**：适合频繁使用 AI 的专业用户。
- **专业版（Ultimate）**：适合需要复杂 AI 对话的重度用户。

档位越高，包含的月度积分、文件存储和向量存储额度越多。各套餐的实时价格、完整权益和可用计费周期以 **套餐** 页面显示为准。

<Steps>
  ### 进入 **应用设置**

  在 LobeHub 首页点击左上角的个人头像，然后点击 **应用设置**。

  ### 打开 **套餐** 页面

  在应用设置左侧导航栏的 **套餐** 分组中，点击 **套餐**。

  ### 选择套餐和计费周期

  比较三个套餐包含的积分、文件与知识库容量等权益，然后选择按月或按年计费。

  ### 完成订阅

  点击所选套餐的订阅或升级按钮，再根据页面提示完成支付。支付成功后，新套餐会显示为当前计划。
</Steps>
