# 如何在 LobeHub 中查看账单历史

<CloudOnlyAlert />

在**账单**页面，你可以查看当前计划的有效期和套餐权益，进入支付管理，并查看历史订单。

## 打开账单页面

<Steps>
  ### 打开应用设置

  点击首页左上角的个人头像，然后点击**应用设置**。

  ### 进入账单

  在左侧导航的**套餐**分组中点击**账单**。
</Steps>

## 查看账单摘要

页面顶部的**账单摘要**会显示当前计划的有效期。你还可以：

- 点击**查看本月使用情况**，前往用量页面。
- 点击**升级计划**，查看其他订阅方案。
- 点击**支付管理**，管理支付相关信息。

如果当前方案为一次性付款，页面会说明该计划不会自动续费扣款。

## 查看当前套餐

**当前套餐**区域会显示正在使用的方案、到期时间和包含的主要权益，例如每月积分、文件存储、向量存储及可用功能。

到期提醒会显示当前订阅何时结束，方便你在到期前安排使用或选择其他方案。

## 查看账单历史

页面下方的**账单历史**会列出：

| 项目 | 说明 |
| --- | --- |
| **订单编号** | 当前交易的订单标识 |
| **交易状态** | 例如已支付、未支付或已关闭 |
| **金额** | 该笔订单的实际金额 |
| **付款日期** | 订单完成付款的日期 |

点击订单右侧的**查看**，可以打开该笔账单的详细信息。
