# 如何充值积分

<CloudOnlyAlert />

LobeHub Cloud 用户可以购买额外积分，继续使用内置模型服务。免费用户和付费订阅用户都可以充值，无需先升级套餐。

## 购买积分

<Steps>
  ### 打开应用设置

  点击首页左上角的个人头像，然后点击**应用设置**。

  ### 进入积分页面

  在左侧导航的**套餐**分组中点击**积分**。

  页面顶部会显示充值积分余额和订阅积分。点击**查看使用情况**可以打开用量页面；点击**充值记录**可以查看购买记录。

  ### 选择积分数量

  在**购买积分**区域选择页面显示的积分包，也可以选择**自定义**并输入数量。自定义购买从 10M 积分起。

  页面会显示积分数量、价格、赠送积分和有效期。不同套餐对应的积分单价可能不同，以购买页面显示为准。

  ### 完成购买

  确认总价后，点击**立即购买**，根据结账页面的提示完成付款。
</Steps>

## 自动充值

自动充值可以在余额较低时自动购买积分。启用前，点击**添加支付方式**并保存银行卡，再按页面提示设置自动充值规则。

## 查看积分包

页面下方的**我的积分包**会列出积分包的剩余额度、来源、获得时间和到期时间。你可以在**有效、已用尽、已过期**之间切换，也可以按来源和时间排序筛选。

## 常见问题

### 积分的有效期是多久？

每个积分包的有效期以购买页面和**我的积分包**中显示的日期为准。当前购买页面显示充值积分的有效期为 **6 个月**。

### 积分包如何消耗？

系统优先使用订阅积分，再使用充值积分。多个充值积分包的到期时间分别计算。

### 免费用户可以充值和使用积分吗？

可以。免费用户和付费订阅用户都可以购买并使用充值积分。

### 不同套餐的积分价格有区别吗？

不同套餐对应的积分单价可能不同。购买区域会显示当前账号适用的单价、赠送积分、有效期和总价，你可以在付款前确认。
