# 如何在 LobeHub 中查看计算用量

<CloudOnlyAlert />

LobeHub 有两个用量入口：

- 在**应用设置 → 用量**中查看账号整体用量，包括积分、返利积分、文件使用量、向量存储和用量明细。
- 在单个 Agent 的**助理档案 → 统计**中查看该 Agent 的费用、缓存节省、Token 用量和模型明细。

## 查看账号整体用量

<Steps>
  ### 打开应用设置

  点击首页左上角的个人头像，然后点击**应用设置**。

  ### 进入用量页面

  在左侧导航的**套餐**分组中点击**用量**。

  页面顶部显示当前方案，以及积分、返利积分、文件使用量和向量存储的使用情况。下方的明细表会列出每次调用的时间、类型、触发方式、模型、Token 使用量、计费时长和积分消耗。

  你可以按模型、类型和日期筛选明细。
</Steps>

## 查看单个 Agent 的用量

<Steps>
  ### 打开 Agent 的助理档案

  进入需要查看的 Agent，在左侧边栏点击**助理档案**。

  ### 点击统计

  在助理档案顶部点击**统计**。

  你可以按天或按周查看最近 7 天、30 天或 90 天的数据。页面会显示费用、缓存节省和 Token 汇总，并通过趋势图和模型明细展示该 Agent 的用量变化。
</Steps>

<Callout type={'info'}>
  账号用量页汇总你的整体使用情况；Agent 的统计页只显示当前 Agent 的数据。
</Callout>
