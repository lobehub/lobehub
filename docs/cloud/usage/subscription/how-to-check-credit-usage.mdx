# How to View Usage in LobeHub

<CloudOnlyAlert />

LobeHub has two usage views:

- Open **App Settings → Usage** to review account-wide usage, including credits, rebate credits, file storage, vector storage, and usage details.
- Open an individual agent's **Agent Profile → Stats** to review that agent's cost, cache savings, token usage, and model breakdown.

## View Account-Wide Usage

<Steps>
  ### Open App Settings

  Click your profile avatar in the top-left corner of the homepage, then click **App Settings**.

  ### Open Usage

  In the left navigation, find the **Plans** section and click **Usage**.

  The overview shows your current plan and usage for credits, rebate credits, file storage, and vector storage. The details table lists each request's time, type, trigger, model, token usage, billable duration, and credit consumption.

  You can filter the details by model, type, and date.
</Steps>

## View Usage for an Individual Agent

<Steps>
  ### Open the Agent Profile

  Open the agent you want to review, then click **Agent Profile** in the left sidebar.

  ### Open Stats

  Click **Stats** at the top of Agent Profile.

  Group the data by day or week and select the last 7, 30, or 90 days. The page shows cost, cache savings, and token totals, followed by a trend chart and model-level details for that agent.
</Steps>

<Callout type={'info'}>
  The account usage page summarizes your overall usage. The agent Stats page includes data only for the current agent.
</Callout>
