# 邀请好友获取积分

<CloudOnlyAlert />

邀请好友注册 LobeHub。好友通过你的邀请完成首次真实付费并通过审核后，你和好友各得 **2M 积分**。

## 找到邀请页面

<Steps>
  ### 打开应用设置

  点击首页左上角的个人头像，然后点击**应用设置**。

  ### 进入推荐奖励

  在左侧导航的**套餐**分组中点击**推荐奖励**。

  页面会显示你的邀请链接、邀请码、推荐概览、推荐记录和活动规则。
</Steps>

## 邀请好友

你可以复制**邀请链接**并分享给好友，也可以复制**邀请码**，让好友在注册时填写。

一次有效邀请需要满足以下条件：

1. 好友通过你的邀请链接注册，或在注册页面填写你的邀请码。
2. 好友完成首次真实付费，例如订阅套餐或购买个人积分。
3. 付费通过审核后，你和好友各得 **2M 积分**。

<Callout type="info">
  奖励会在好友完成真实付费并通过审核后发放，不会在注册完成时立即到账。
</Callout>

## 忘记填写邀请码

好友注册后 **7 天内**可以补填邀请码：

- 如果好友已经完成真实付费并通过审核，绑定邀请码后会发放奖励。
- 如果好友尚未付费，奖励会在首次真实付费并通过审核后发放。

## 查看邀请结果

**推荐概览**会显示：

- 邀请总数
- 已奖励邀请数
- 累计奖励
- 可用余额

你还可以在**推荐记录**中查看每次邀请的状态和奖励情况。

## 积分使用与有效期

推荐奖励积分的使用顺序为：**免费积分 → 订阅积分 → 返利积分 → 充值积分**。

如果账号连续 **100 天**没有活动，返利积分会被清除。

## 活动规则

- 只有好友通过邀请注册并完成真实付费，才会计为有效邀请。
- 临时邮箱批量注册等作弊行为可能导致相关账号被永久封禁。
- 奖励金额和活动规则可能调整，以推荐奖励页面显示为准。
