# 命令選單

命令選單是 LobeHub 的快捷操作中心。通過鍵盤快捷鍵快速呼出，你可以搜尋和執行各種操作，無需在界面中逐層點擊。這讓導航和操作更快速、更高效。

命令選單支援模糊搜尋，不需要輸入完整名稱，輸入部分關鍵詞即可匹配。例如輸入 "編程" 可以找到 "Python 編程助理"。頻繁切換助理時，使用命令選單比在側邊欄中查找更快。

## 開啟命令選單

使用鍵盤快捷鍵開啟命令選單：macOS：Cmd + K Windows/Linux：Ctrl + K 命令選單會以浮層形式出現在螢幕中央。

## 搜尋和導航

在命令選單中輸入關鍵詞，系統會即時搜尋匹配的內容。你可以搜尋助理名稱快速切換會話，輸入話題關鍵詞跳轉到歷史對話，快捷存取設定、文稿、資源庫等板塊，或者搜尋插件、檔案等。命令選單還支援搜尋操作命令，快速執行建立助理、與 AI 對話等操作。

在命令選單中使用鍵盤快速導航。用 ↑ 和 ↓ 鍵在搜尋結果中移動，按 Enter 執行選中的操作，按 Esc 關閉命令選單。

## 問 Agent

與助理對話 Cmd + K 呼出命令選單後，輸入想發送的話題，按 Tab 並選擇助理，可以實現快捷對話。

選中「新建助理」或「新建助理團隊」，按 Enter 即可建立。

## 快捷導航

選中想存取的板塊，例如「文稿」、「資源」等，按 Enter 即可存取。

## 搜尋內容

輸入關鍵詞，可以搜尋歷史訊息、助理、MCP 插件等。搜尋結果分類顯示，便於快速查找。
