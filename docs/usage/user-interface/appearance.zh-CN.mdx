# 界面外观

外观设置让你自定义 LobeHub 的视觉风格与对话阅读体验。你可以切换主题、选择强调色、设置助理回复的默认语言，调整字体、代码和图表样式，以及动画效果和对话行为。

除了外观设置，你还可以直接在首页调整侧边栏布局和首页内容。本篇分别介绍这些入口及其可配置项。

**外观设置入口：** 点击右上角用户头像 → **应用设置** → **外观**。侧边栏和首页的自定义入口见下方对应章节。

## 语言

切换界面语言。LobeHub 支持多语言，选择适合你工作流的语言即可。

## 助理语言

设置 **助理回复的默认语言**。选择后，助理会优先使用该语言回复，除非你在对话中明确要求使用其他语言。

**示例：** 若设置为「中文」，助理默认用中文回复。你仍可在某条消息中说「用英文回复」。

## 主题模式

三种模式：

| 模式       | 最适合         |
| -------- | ----------- |
| **浅色**   | 明亮环境、白天使用   |
| **深色**   | 弱光环境、减轻眼疲劳  |
| **自动** | 与系统偏好一致（默认） |

**自动** 会根据操作系统设置自动切换亮色 / 深色。适合在不同时段或环境下使用 LobeHub 时使用。

## 主题色彩

除了明暗模式，你还可以设置 **强调色** —— 用于按钮、高亮、链接等交互元素的颜色。LobeHub 提供多种预设主题色和中性色。点击色卡即可应用，界面会立即更新。

**使用场景：** 匹配品牌色、用中性色减少视觉干扰、或选择有助于专注的颜色。

## 字体

分别设置界面字体与代码使用的等宽字体，并调整消息文字的大小。

| 设置 | 用途 |
| --- | --- |
| **界面字体** | 为整个界面选择本机已安装的字体。选择「跟随系统」时，使用当前语言对应的内置字体方案。 |
| **回退字体** | 当界面字体缺少某些字形时，按配置顺序逐个尝试其他字体。需先选择具体的界面字体，再配置回退字体。 |
| **等宽字体** | 用于代码块与内置终端，可选择本机已安装的等宽字体，或保留「跟随系统」。 |
| **等宽回退字体** | 用于代码块与内置终端，在所选等宽字体之后按顺序尝试。需先选择具体的等宽字体，再配置等宽回退字体。 |
| **字体大小** | 调整消息字体大小。拖动滑块，并通过下方的示例文字预览效果；「标准」标记可作为调整时的参考。 |

**搭配建议：** 中英文混排时，可以将偏好的西文字体设为界面字体，再将中文字体放入回退列表。这样，当界面字体不包含中文字形时，会尝试使用配置的中文字体。

## 代码高亮

当对话或文稿中包含代码块时，可以选择 **代码高亮主题**。选择与整体主题协调的方案 —— 亮色主题配亮色代码、深色配深色。

**使用场景：** 提升代码审查时的可读性、与 IDE 配色保持一致、或在长代码会话中减轻眼疲劳。

## Mermaid 主题

Mermaid 是一种用文本描述图表的工具。当对话或文稿中包含 Mermaid 图表（流程图、时序图等）时，可选择 **Mermaid 主题**。与整体主题协调，让图表与界面风格一致。

## 响应动画

选择应用程序操作响应动作（如消息流式输出、界面过渡）的动画速度。

| 模式     | 说明        |
| ------ | --------- |
| **关闭** | 关闭响应动画    |
| **敏捷** | 动画速度更快、更轻 |
| **优雅** | 动画速度更慢、更柔 |

## 过渡动画

选择消息内容呈现时的过渡效果，并通过设置项下方的示例预览。

| 模式 | 说明 |
| --- | --- |
| **无** | 不使用过渡动画。 |
| **淡入** | 使用淡入效果呈现内容。 |
| **平滑** | 使用平滑过渡效果呈现内容。 |

此项用于选择过渡效果，与「响应动画」的动画速度设置不同。

## 对话行为

调整 AI 回复时的滚动方式、工具步骤展示，以及消息链接的图标显示。

| 设置 | 说明 |
| --- | --- |
| **AI 回复时自动滚动** | 开启后，在 AI 回复过程中自动滚动以跟随新内容；关闭后，可自行控制阅读位置。 |
| **运行中展开工具步骤** | 开启后，在工具运行时展开步骤，方便查看执行过程；关闭后，不自动展开运行中的工具步骤。 |
| **在消息链接中显示图标** | 开启后，在消息中的链接旁显示图标，便于识别链接来源；关闭后，不显示这些图标。 |

如果你习惯在 AI 回复时回看前文，可以关闭自动滚动；如果需要关注工具执行过程，可以开启运行中展开工具步骤。

## 右键菜单方案

选择是否为部分列表项启用右键菜单。

| 模式      | 说明            |
| ------- | ------------- |
| **不使用** | 支持的列表项不显示右键菜单 |
| **默认**  | 为支持的列表项启用右键菜单 |

## 自定义侧边栏

调整首页侧边栏的功能顺序与显示状态，让常用入口更容易找到。

**如何进入：** 在 LobeHub 首页点击侧边栏的 **三个点（…）** 按钮 → **自定义侧边栏**。

1. **调整顺序：** 拖动条目左侧的拖拽手柄，将功能移动到合适的位置。
2. **显示或隐藏：** 对带有眼睛图标的条目，点击右侧图标切换显示状态。
3. **确认修改：** 调整完成后，点击 **确认**。

面板中的「下方条目锚定到底部」分隔线标明底部固定区域，位于其下方的条目会锚定在侧边栏底部。调整顺序时，可以结合这一标记安排入口位置。

如需重置布局，点击 **恢复默认**，再点击 **确认**。

## 自定义首页

选择首页展示的内容模块，并调整最近话题和最近任务的列表条数。

**如何进入：** 在 LobeHub 首页右上角选择 **自定义首页**。此入口与侧边栏的「自定义侧边栏」以及「应用设置 → 外观」相互独立。

### 预设与内容模块

可以先选择 **精简**、**适中** 或 **全部** 预设，再按需调整各项开关。

| 分组 | 可调整的内容 |
| --- | --- |
| **形象装饰** | 是否在首页顶部旁显示你的智能体形象。 |
| **Agent** | 未读、需要你处理、进行中、最近话题。 |
| **任务** | 最近任务、定时任务。 |
| **侧边栏** | 目标、今日简报、推荐。这里控制的是首页侧边区域的内容，不是全局侧边栏的功能顺序。 |

使用各项右侧的开关选择是否在首页展示对应内容。若某个控件呈灰色且无法操作，则当前不可调整。

### 列表条数

在面板下方的 **列表条数** 区域，使用 **− / +** 分别调整 **最近话题** 和 **最近任务** 的显示条数。

如果希望首页更简洁，可以减少展示模块和列表条数；如果希望集中查看待处理事项，可以保留「需要你处理」「进行中」等模块。

如需撤销个性化配置，点击面板底部的 **恢复默认**。
