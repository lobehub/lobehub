# 界面外觀

在首頁右上角點擊使用者頭像，在下拉選單中選擇「應用程式設定」，點擊「外觀」，進入自訂頁面。這裡彙集了所有視覺相關的設定選項。\[Image]

## 語言

你可以在設定中切換語言。

## 主題模式

LobeHub 支援三種主題模式：

- 亮色模式
- 深色模式
- 跟隨系統（預設）

## 主題色彩

除了明暗模式，你還可以自訂主題色彩，打造個性化的視覺風格。LobeHub 提供多種預設主題色和中性色，點擊色卡即可應用程式，界面的按鈕、高亮等元素會立即切換為選中的主題色。

## 助手語言

設定 AI 助手回覆的預設語言。選擇後，助手會優先使用該語言回答問題，除非你在對話中明確要求使用其他語言。

## 動畫效果

當對話或文稿中包含程式碼時，可以選擇程式碼高亮的配色方案。選擇與整體主題協調的程式碼高亮方案，讓程式碼更易讀、更美觀。

## Mermaid 主題

Mermaid 是一種用文字描述圖表的工具。當對話或文稿中包含 Mermaid 圖表時，可以選擇圖表的主題樣式。選擇與整體主題協調的 Mermaid 主題，讓流程圖、時序圖等圖表更美觀。

## 模式選擇

- 專業模式
- 精簡模式
