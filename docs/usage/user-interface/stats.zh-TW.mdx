# 資料統計

LobeHub 提供資料統計功能，讓你瞭解自己的使用情況。你可以查看使用天數、助手數量、對話統計，以及過去一年的活躍度和模型使用情況。

## 查看資料統計

在首頁右上角點擊使用者頭像，在下拉選單中選擇「應用程式設定」，點擊「資料統計」即可查看。

![資料統計](/blog/assetse6139c4d5b1b26b05f41a579d98fc6f3.webp)

## 統計內容

### 基礎資料

- 使用天數：從首次使用到現在的總天數
- 助手數：建立和使用的助手總數
- 話題數：與助手的對話話題總數
- 訊息數：發送和接收的訊息總數
- 累計字數：所有對話的累計文字數量

### 活躍度日曆

頁面中部顯示過去一年的活躍度 "瓷磚牆"。每個方塊代表一天，顏色深淺表示當天的活躍程度。通過活躍度日曆，你可以直觀地看到自己的使用習慣和活躍時段。

### 使用率統計

頁面下方顯示詳細的使用率統計：

- 模型使用率統計：展示你使用不同 AI 模型的頻率和佔比，瞭解自己最常用的模型。
- 助理使用率統計：展示你使用不同助手的頻率和佔比，瞭解哪些助手最常用。
- 話題內容量統計：展示不同話題的內容量分佈，瞭解對話的內容規模。

## 分享使用資料

你可以將資料統計生成可分享的圖片。

![clipboard-1769050808722-bd6e724a5b54b.png](/blog/assets55bea1dc3e938580591d75d72908835a.webp)

點擊資料統計頁面右上角的分享按鈕，系統會生成一張包含你使用資料的圖片。你可以選擇圖片格式：JPG/PNG/SVG/WEBP。選擇格式後點擊下載，即可儲存圖片並分享到其他平臺。
