# 快捷鍵

LobeHub 提供豐富的鍵盤快捷鍵，讓你能快速執行各種操作，提升使用效率。熟練使用快捷鍵，可以大幅減少鼠標操作，讓工作流更流暢。

## 進入設定

在首頁右上角點擊使用者頭像，在下拉選單中選擇「應用程式設定」，點擊「快捷鍵」即可查看已有快捷鍵。

## 基礎快捷鍵

- 開啟全域命令面板快速存取功能：⌘ + K（Mac）或 Ctrl + K（Windows/Linux
- 喚起當前頁面主要搜尋框：⌘ + J（Mac）或 Ctrl + J（Windows/Linux）
- 快捷切換助理：通過按住 Ctrl 加數位 0-9 切換固定在側邊欄的助理：^ + 1-9（Mac）或 Ctrl + 1-9（Windows/Linux）
- 切換至預設會話：^ + 0（Mac）或 Ctrl + 0（Windows/Linux）
- 顯示 / 隱藏左側面板：⌘ + \[（Mac）或 Ctrl +\[（Windows/Linux）
- 顯示 / 隱藏右側面板：⌘ + ]（Mac）或 Ctrl + ]（Windows/Linux）
- 開啟快捷鍵幫助：^ + ⇧ + ?（Mac）或 Ctrl + Shift + ?（Windows/Linux）查看所有快捷鍵的使用說明。
- 切換專注模式：⌘ + \（Mac）或 Ctrl + \（Windows/Linux）專注模式下，只顯示當前會話，隱藏其他 UI。
- 儲存文件：⌘ + S（Mac）或 Ctrl + S（Windows/Linux）

## 會話快捷鍵

- 開啟會話設定：⌘ + ,（Mac）或 Ctrl + ,（Windows/Linux
- 重新生成訊息：⌘ + R（Mac）或 Ctrl + R（Windows/Linux）
- 刪除最後一條訊息：⌘ + D（Mac）或 Ctrl + D（Windows/Linux）
- 刪除並重新生成：⌘ + ⇧ + R（Mac）或 Ctrl + Shift + R（Windows/Linux）
- 刪除最後一條訊息並重新生成：⌘ + ⇧ + R（Mac）或 Ctrl + Shift + R（Windows/Linux）
- 儲存當前話題並開啟新話題：⌘ + N（Mac）或 Ctrl + N（Windows/Linux）
- 新增一條使用者訊息：⌘ + ↵（Mac）或 Ctrl + Enter（Windows/Linux）將當前輸入內容新增為使用者訊息，但不觸發生成。
- 編輯訊息：⌘ + ⌥（Mac）或 Ctrl + Alt（Windows/Linux）通過按住 Alt 並雙擊訊息進入編輯模式。
- 清空會話訊息：⌘ + ⇧ + ⌫（Mac）或 Ctrl + Shift + Backspace（Windows/Linux）

## 自訂快捷鍵

大部分快捷鍵可以根據你的使用習慣自訂。根據自己的使用頻率和習慣，自訂最常用操作的快捷鍵，讓操作更順手。在快捷鍵設定界面，找到可點擊的快捷鍵按鈕，按下按鍵即可錄製自訂快捷鍵。
