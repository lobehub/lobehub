# 在 LobeHub 中使用多模型服务商

<Image alt={'多模型服务商支持'} borderless cover src={'/blog/assets17870709/1148639c-2687-4a9c-9950-8ca8672f34b6.webp'} />

你可以为不同助理选择模型服务商，也可以接入本地推理服务。本页提供分组教程入口，完整服务商卡片保留在页面末尾。

## 为什么支持多模型服务商？

- **统一入口** — 在同一界面选择不同服务商支持的模型与模态。
- **成本比较** — 根据任务质量、延迟和预算选择服务商。
- **减少单一依赖** — 当某家服务不可用时，可选择已配置且兼容的替代服务，并非保证自动故障切换。
- **按助理配置** — 为不同职责设置不同的默认模型。
- **本地推理** — 通过 Ollama 或 LM Studio 运行本地模型。本地推理通常不产生云端模型 API 费用，但仍有硬件和运行成本。

本地模型不代表整个工作流完全私密或离线。云端同步、搜索和其他连接器仍可能传输数据。

## 配置提供商

打开 **应用设置 → AI 服务商**，然后选择要配置的服务商。不同服务商显示的配置项可能不同：

1. 从列表中选择服务商，并打开右侧开关
2. 按页面填写凭据。大多数云端服务使用 API Key；Amazon Bedrock、Azure OpenAI 等服务商还会显示区域、端点或其他专用字段
3. 如果页面显示 **代理地址**，可以填写服务商 API 的 Base URL 或兼容接口地址。本地服务可填写 Ollama、vLLM 等运行地址
4. 点击 **检查** 测试连接
5. 在下方模型列表中启用已有模型，也可以根据页面选项获取或添加模型
6. 配置会自动保存。之后可在助理设置中选择该服务商及模型

自托管部署的环境变量配置，请参见[模型提供商环境变量](/zh/docs/self-hosting/environment-variables/model-provider)参考文档。

模型选择原则见[助理指南](/zh/docs/usage/getting-started/agent)。Cloud 与 Desktop 的区别见[功能状态与可用性](/zh/docs/usage/feature-status)。

## 故障排查

**连接错误 / API Key 无效** — 检查 API Key 是否包含多余的空格。确认你使用的 Key 类型与该提供商的要求匹配。

**模型不可用** — 该模型可能不在你的账户套餐中，或已被弃用。请查看提供商的模型可用性说明页面。

**速率限制错误** — 你已达到提供商的请求速率上限。考虑将请求分散到多个提供商，或升级账户套餐。
