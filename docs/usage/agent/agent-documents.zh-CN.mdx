# 助理文档库

助理文档库保存助理创建的笔记、报告和参考资料。文档默认可在同一助理的不同话题中使用，你也可以要求将文档关联到当前话题。上传的文件则单独保存在资源库中。

## 内容应该存在哪里

| 位置 | 范围 | 适合保存 |
| --- | --- | --- |
| **助理文档库** | 助理级，或关联当前话题 | 可复用的说明、笔记、报告和参考资料 |
| [文稿](/zh/docs/usage/getting-started/page) | 独立文档 | 长文写作与协作 |
| [资源库](/zh/docs/usage/getting-started/resource) | 上传资源和知识库 | 供助理搜索、引用的源文件 |

文稿也可以出现在资源管理视图中。

## 查看与创建文档

1. 打开与该助理的会话。
2. 展开右侧工作面板中的文档区域。
3. 选择文档，阅读或编辑内容。

需要保存长期笔记时，可以说：「把这些项目约定保存为助理级文档，标题为『项目约定』。」需要关联本次会话时，可以说：「把这次会议纪要保存为文档，关联当前话题。」在其他话题使用文档前，检查保存内容与所属范围。

你可以在文档面板管理文档、查看历史。可用操作取决于版本和权限。

## 助理如何读取文档

助理会按需查找和读取相关文档，而不是在每次对话中完整读取所有文档。

执行具体任务时，可以告诉助理文档名称，让它先阅读。如果面板中找不到文档，可以检查当前账号、助理和文档范围。上传的 PDF 可以在资源库中查找。

## 修改与删除

可以让助理修改指定文档，也可以在面板中直接编辑。复用其中的操作说明前，先检查改动。删除前，为仍然需要的内容保留副本。
