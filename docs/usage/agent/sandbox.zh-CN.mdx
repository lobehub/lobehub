# 云沙箱

云沙箱让助理在服务端运行代码、执行命令和处理文件。本地执行则让助理在连接的电脑上处理真实项目文件。开始任务前，请检查任务在哪里运行，以及会使用哪些文件。

本页重点介绍云沙箱，并与本地执行对照。设备连接、选择和工作目录设置见[执行设备](/zh/docs/usage/agent/execution-devices)。

## 云端沙箱与本地执行

| 维度 | 云端沙箱 | 本地执行／本地沙箱 |
| --- | --- | --- |
| 执行位置 | 服务端的沙箱环境 | 已连接的电脑 |
| 文件访问 | 沙箱中存在或已传入沙箱的文件 | 设备工具和运行进程有权访问的真实文件 |
| 权限边界 | 沙箱提供方的限制与 LobeHub 工具权限 | 工具、运行进程和操作系统权限；工作目录不会限制所有文件访问 |
| 运行时与依赖 | 取决于提供方和镜像，使用前检查所需运行时与库 | 取决于电脑已有环境，任务开始前检查缺少的依赖 |
| 安装依赖 | 取决于运行环境、安装权限和网络条件 | 会改变执行设备上的环境，应先明确安装位置和所需批准 |
| 联网 | 取决于提供方与部署配置 | 取决于设备网络、代理和权限 |
| 文件持久性 | 临时存储，请及时保存重要文件 | 文件按设备文件系统规则保存，聊天结束后文件改动仍会保留 |
| 获取产物 | 导出结果后取得下载链接 | 按设备路径查找文件，分享时使用可用的上传或导出工具 |

云沙箱内的操作使用沙箱中的文件。另行调用设备工具或使用本地执行时，可能修改或删除电脑上的真实文件。

## 云沙箱能做什么

### 执行代码

在运行时可用时，助理可以运行 Python、JavaScript 或 TypeScript，并返回实际输出。例如，可计算数据统计值或运行一段测试代码。

语言、库和系统工具的可用性取决于当前环境。可以要求助理在运行任务前检查所需依赖。

### 生成文件

具备所需工具和依赖时，助理可以生成 PDF、Excel、Word、图片或图表。生成后，还需要成功导出文件，你才能下载。

### 处理数据

助理可以清洗、统计、转换 CSV、JSON 等数据。在聊天中上传文件后，先确认所选执行环境能读取该文件，再开始处理。

### 运行命令

助理可以执行 Shell 命令，组合脚本、文件操作和系统工具。实际可执行的命令取决于环境与权限。可以通过命令输出和退出码检查运行结果。

## 启用与检查执行位置

1. 打开助理档案中的工具／连接器设置。
2. 找到并启用当前版本中的云沙箱工具。
3. 检查该工具的运行批准方式。
4. 如当前界面有执行设备选择器，检查所选位置。
5. 要求助理在修改文件前报告实际执行位置、工作目录和输入文件路径。

较早版本可通过 **+ 添加技能 → 云沙箱**，或聊天输入框下方的技能图标找到该工具。

自托管环境还需配置沙箱提供方。配置要求见[云沙箱配置](/zh/docs/self-hosting/environment-variables/cloud-sandbox)。

## 使用云沙箱

### 让助理执行代码

- 「在云沙箱中计算这组数据的平均值和标准差。」
- 「运行这个 JavaScript 排序算法，并展示测试结果。」
- 「读取这个 CSV，显示收入最高的 5 行。」

### 让助理生成文档

- 「生成包含这份分析结果的 PDF，并导出供我下载。」
- 「把这段内容转换为 Word，说明文件保存在哪里。」
- 「用这份销售数据生成柱状图，并导出 PNG。」

### 让助理处理数据

- 「把这个 JSON 转换为 CSV，保留原文件。」
- 「删除数据中的重复行，将结果保存为新文件。」
- 「按 id 列合并这两个 CSV，并报告输入和输出路径。」

这些任务也可以在有相应工具的本地环境完成，但会使用该设备的文件和运行环境。

## 保存与获取结果

**云端产物**：让助理导出文件并提供下载链接。打开链接，及时保存重要文件。

**本地产物**：让助理提供文件路径。需要分享时，使用能够访问本地设备的上传或导出工具。

**持续迭代**：对话可以保留讨论内容，文件和进程则可能已经结束或清除。继续任务前，检查原始文件和结果是否仍可访问。
