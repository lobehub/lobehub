# Agent Documents

Agent Documents contain notes, reports, and reference material that an Agent creates. By default, documents are available across topics with that Agent. You can also ask to link a document to the current topic. Files you upload are stored separately in the Resource Library.

## Choose Where to Save Content

| Location | Scope | Use it for |
| --- | --- | --- |
| **Agent Documents** | Agent-level or linked to the current topic | Reusable instructions, notes, reports, and reference material |
| [Pages](/docs/usage/getting-started/page) | An independent document | Long-form writing and collaboration |
| [Resource Library](/docs/usage/getting-started/resource) | Uploaded resources and knowledge bases | Source files that Agents search and reference |

Pages can also appear in resource management views.

## Find and Create Documents

1. Open a conversation with the Agent.
2. Open the document area in the right-side working panel.
3. Select a document to read or edit it.

For a reusable note, ask: “Save these project conventions as an Agent-level document titled Project Conventions.” For conversation notes, ask: “Save these meeting notes as a document linked to the current topic.” Before you use a document in another topic, check its content and scope.

You can manage documents and view their history in the panel. Available controls depend on your version and permissions.

## How the Agent Reads Documents

The Agent finds and reads relevant documents as needed, rather than loading every document in full for each conversation.

For a specific task, name the document and ask the Agent to read it first. If the document is absent from the panel, check the current account, Agent, and document scope. Uploaded PDFs belong in the Resource Library, not this list.

## Update or Delete Content

Ask the Agent to revise a named document, or edit it in the panel. Review changes before you reuse instructions. Before deletion, save a copy of content that you still need.
