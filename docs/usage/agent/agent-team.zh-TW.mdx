# Agent 團隊

有時候，一個助理的視角是不夠的。複雜問題需要多角度思考，創意項目需要不同專業背景的碰撞，學習討論需要多方辯論。Agent 群聊讓多個專業助理聚在一起，像真實群聊一樣協作 —— 翻譯助理、編程助理、產品經理助理圍坐一起，各自發揮專長，共同解決你的問題。你不再是獲得一個答案，而是參與一場對話。不同觀點在這裡碰撞，專業知識在這裡互補，AI 助理協同工作時產生的洞察，遠超任何單一助理所能提供的。

Agent 群聊是多個專業助理的協作空間。你提出一個問題或任務，不同助理從各自的專業角度給出見解，它們之間可以互相討論、補充、甚至辯論。

## 單個助理的侷限

- 只能從一個角度分析問題
- 專業領域受限於預設角色
- 缺少多元視角的碰撞

## Agent 群聊的優勢

- 多個助理各取所長，協同工作
- 不同專業背景帶來全面的解決方案
- 助理之間的討論激發更深入的洞察
- 搭載主持人確保討論有序進行

## 關於主持人

每個 Agent 群聊都有一個搭載的主持人。它負責：

- 理解你的需求，分配討論任務
- 協調各個助理的發言順序
- 總結討論結果，提煉關鍵結論
- 確保對話圍繞主題有序展開

## 建立 Agent 群聊

在左側邊欄選擇「建立群組」即可進入建立。

![clipboard-1768907980491-9cc0669fc3a38.png](/blog/assets8be3a46c8f9c5d3b61bc541f44b7f245.webp)

建立群聊時，你可以使用現有模版，也可以選擇自己的 AI 助理組建群聊。同時，你可以選擇是否使用主持人，併為主持人選擇模型。

![clipboard-1768908081787-ed9eb1cb78bdb.png](/blog/assetsab009b79dd794f02aec24b7607f342e8.webp)

## 設定 Agent 群聊

在群聊會話左側邊欄，選中助理，可以便捷更換助理的模型和移除助理。

![clipboard-1768908121691-b3517bf882633.png](/blog/assetsd3cae44cba0d3f57df6440b46246e5e7.webp)

同樣在左側邊欄，點擊新增成員按鈕可以新增需要的助理到群聊中。

![clipboard-1768908209289-9d3ecff50142f.png](/blog/assets75a5cf08b3e432d2477899d30acc9d47.webp)

在左側邊欄進入「群聊檔案」，你可以編寫群聊提示詞，為群聊新增插件，更換主持人模型。你也可以使用右側面板的 Agent Builder 進行智慧建立。Agent Builder 是 LobeHub 的搭載助理，只需與 Agent Builder 對話，描述你的需求，它就能理解並自動生成完整的群聊設定 —— 包括群聊設定、系統提示詞、插件設定。

![clipboard-1768908230723-3fce0ae5baf9b.png](/blog/assets8e9b164fa30c795850ce8fa8ef7e7c24.webp)
