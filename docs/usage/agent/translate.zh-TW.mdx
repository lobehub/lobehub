# 翻譯會話記錄

## 翻譯對話中的內容

LobeHub 支援使用者一鍵將對話內容翻譯成指定語言。選擇目標語言後，LobeHub 將調用預先設定的 AI 模型進行翻譯，並將翻譯結果即時顯示在聊天視窗中。

<Image alt={'顯示會話翻譯結果'} src={'/blog/assetsf3ccd42bf36b1c75f06f925ffe049f0c.webp'} />

## 翻譯模型設定

你可以在設定中指定您希望使用的模型作為翻譯助手。

<Image alt={'設定翻譯模型'} src={'/blog/assets6541bab7e0047f9c5dbad98dc272d64d.webp'} />

- 開啟`設定`面板
- 在`系統助手`中找到`翻譯設定`選項
- 為你的`翻譯助手`指定一個模型
