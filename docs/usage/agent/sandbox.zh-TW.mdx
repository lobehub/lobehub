# 雲沙箱

LobeHub 支援 Cloud Sandbox ，讓 AI 助理能在安全隔離的雲端環境中執行程式碼、處理檔案。不只是給出程式碼片段，助理可以直接執行程式碼、生成文件、建立圖表 —— 你能立即獲得可下載的成果，即時迭代調整。雲沙箱突破了傳統對話的限制，將 AI 的輸出從建議擴充功能到執行。從資料分析到文件生成，從程式碼除錯到檔案轉換，雲沙箱讓 AI 真正成為你的執行助手。

## 理解 Cloud Sandbox

Cloud Sandbox 是一個安全隔離的雲端執行環境。當你需要的不只是程式碼片段，而是實際執行結果時，助理會在 Cloud Sandbox 中執行程式碼並返回輸出。

## Cloud Sandbox 能做什麼

### 執行程式碼

助理可以執行 Python、JavaScript、TypeScript 程式碼，在沙盒中執行並返回結果。你能看到真實的執行輸出，而不只是程式碼文字。

### 生成檔案

助理可以建立各種檔案 ——PDF 文件、Excel 表格、Word 文件、圖片、圖表等，並提供下載連結。你能直接下載使用。

### 資料處理

助理可以讀取、分析、轉換資料檔案。上傳 CSV、JSON 等資料，助理能幫你清洗、統計、視覺化。

### 執行命令

助理可以執行 Shell 命令，安裝依賴包、處理檔案、執行復雜操作。

### 啟用 Cloud Sandbox

Cloud Sandbox 是搭載插件，需要為助理啟用後才能使用雲沙箱功能。你可以在「助理檔案」頁面新增插件處啟用 Cloud Sandbox 插件，也可以進入會話，在對話框勾選插件處啟用 Cloud Sandbox 插件。

### 使用 Cloud Sandbox

### 讓助理執行程式碼

直接描述你想完成的任務，助理會編寫程式碼並在雲沙箱中執行：

- 「幫我寫個 Python 腳本，計算這組資料的平均值和標準差」
- 「用 JavaScript 實現一個快速排序算法，執行測試一下」
- 「幫我跑一下這段程式碼，看看輸出是什麼」

### 讓助理生成文件

描述你需要的文件內容，助理會生成並提供下載：

- 「幫我生成一份 PDF 報告，包含這些資料的分析結果」
- 「把這段內容做成 Word 文件」
- 「建立一個 Excel 表格，整理這些資訊」

### 讓助理處理資料

提供資料或檔案，助理會處理並返回結果：

- 「分析這份銷售資料，畫個趨勢圖」
- 「把這個 JSON 轉換成 CSV 格式」
- 「幫我清洗這份資料，去除重複項」

### 瞭解雲沙箱環境

隔離的雲端環境雲沙箱執行在安全隔離的雲端伺服器上，與你的本地電腦完全分離。助理在雲沙箱中的所有操作都不會影響你的本地檔案系統。

### 會話級檔案存儲

雲沙箱中的檔案是臨時的，與當前對話會話綁定。會話結束或長時間不活動後，沙箱中的檔案可能會被清理。如果你需要保留檔案，請及時下載助理提供的導出連結。自動導出成果當助理在雲沙箱中生成檔案時，會自動導出並提供下載連結。你無需額外操作，即可獲得程式碼執行產生的文件、圖表、資料檔案等成果。
