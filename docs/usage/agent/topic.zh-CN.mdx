# 话题

在 LobeHub 中，与助理的对话以话题的形式组织。你可以搜索和整理历史对话，在保留原内容的基础上探索新方向，也可以导出内容或通过只读链接分享给他人。

## 话题面板

侧边栏的话题列表适合快速切换。需要总览某个助理的全部话题、按条件筛选或批量整理时，在助理会话页面的左侧导航点击**话题**，进入话题面板。

你可以在面板中浏览、筛选和批量整理话题；针对单个话题的重命名、导出、删除等操作，请在侧边栏话题列表中使用话题的操作菜单（见下文）。

### 浏览与筛选

- **状态标签** — 顶部的**全部 / 活跃 / 运行中 / 已归档**标签显示各类话题的数量，点击即可切换。
- **筛选条件** — 点击 **Add filter** 添加筛选条件，例如按**时间**筛选相应时间的话题。
- **搜索** — 使用右上角的搜索框可以搜索当前助理的话题。
- **视图** — 在**卡片**和**列表**两种视图之间切换。卡片视图显示标题、首条消息预览、消息数、更新时间和状态。列表视图显示标题、所属项目、状态、来源和更新时间。
- **排序** — 通过**排序**按更新时间、创建时间或标题排列话题。
- **分组** — 让话题按时间段或按项目分组显示。

### 批量操作

勾选卡片右上角的复选框选中一个或多个话题，底部会出现批量操作栏，显示**已选 N 项**和以下操作：

- **收藏** — 批量收藏选中的话题。
- **归档** — 批量归档，不删除对话内容。
- **移动到助手** — 选择目标助理，把选中的话题一起移动过去。
- **删除** — 批量删除。操作前需要确认，删除后无法撤销。
- **×** — 取消选择，退出批量操作。

点击面板中的任意话题，即可进入对应会话继续对话。

## 话题列表操作菜单

在侧边栏的话题列表中，点击话题右侧的 **···** 按钮（或右键点击话题）展开操作菜单，即可管理该话题。

| 操作 | 用途 |
| --- | --- |
| **归档** | 收起暂时不需要处理的话题 |
| **收藏 / 取消收藏** | 标记常用话题，方便快速访问 |
| **智能重命名 / 重命名** | 根据内容自动生成标题，或手动设置标题 |
| **检查消息链路** | 检查消息隐藏、分支断开等问题，并修复可恢复的问题 |
| **在新标签页中打开** | 在桌面客户端的新标签页中打开话题 |
| **在右侧打开** | 在右侧面板查看话题，便于对照阅读 |
| **打开独立窗口** | 在桌面客户端的独立窗口中打开话题 |
| **复制会话 ID** | 复制话题标识，便于定位记录或排查问题 |
| **复制链接** | 复制话题的应用内访问链接，不改变访问权限 |
| **复制** | 创建新的话题副本，保留原话题 |
| **转发给其他助手** | 将对话内容发送给其他助理，在新话题中继续处理 |
| **移动到其他助手** | 将原话题移到另一位助理下管理 |
| **导出** | 打开导出窗口，选择图片、文本、PDF 或 JSON |
| **删除** | 永久删除话题，操作前需确认 |

菜单会随话题状态、客户端和权限变化。**在新标签页中打开**和**打开独立窗口**属于桌面客户端操作；没有创建或编辑权限时，相关菜单项可能不可用。

## 搜索和整理话题

在话题列表打开搜索入口，输入关键词查找历史对话。

![在对话中搜索话题](/blog/assets3cdf933016e6f53bca12b8cedb17061f.webp)

在列表的整理和筛选菜单中，可以切换分组方式：

- **按状态** — 按进行中、等待处理、已失败、已归档等状态分组。
- **按时间阶段** — 按今天、昨天、本周、本月等时间段分组。
- **按项目** — 按话题所属项目或目录分组，未关联目录的话题单独归组。
- **平铺** — 不分组，在同一个列表中显示话题。

还可以选择**按创建时间**或**按更新时间**排序，并通过**显示已归档**控制是否显示已归档的话题。

### 归档

不再需要经常查看、但仍想保留的话题，优先选择**归档**，而不是删除。归档不会删除对话内容。

### 收藏和取消收藏

选择**收藏**，将重要或常用的话题标记到收藏区域，方便快速返回。再次打开菜单选择**取消收藏**即可移除标记，不会删除话题。

![收藏话题](/blog/assets04d6fae3d9aa3c33697028f1cc9f4706.webp)

### 重命名

- **重命名** — 输入便于识别的新标题并保存。
- **智能重命名** — 根据对话内容自动生成标题；生成后仍可手动修改。

例如，将笼统的标题改成「客户 A · 合作方案讨论」，比逐条打开对话更容易查找。

## 检查消息链路

如果对话中的消息没有正常显示、顺序异常，或一段对话与前文断开，可以选择**检查消息链路**。

1. 打开话题菜单，选择**检查消息链路**。
2. 查看检查结果，了解是否存在隐藏的消息或断开的对话分支。
3. 如果显示**修复**按钮，点击后修复可恢复的消息关联，再回到话题查看结果。

这项功能用于处理消息的显示和连接关系，并不是检查回答是否正确。原本没有成功保存的消息正文无法通过此功能恢复；检查失败时，可以重试。

## 在其他位置打开话题

- **在新标签页中打开** — 在桌面客户端新增标签页，方便在多个话题间切换。
- **在右侧打开** — 在右侧面板打开话题，便于一边查看当前内容，一边参考另一段对话。
- **打开独立窗口** — 将话题放到单独的桌面窗口中，适合多窗口或多屏工作。若主窗口提示话题已在独立窗口打开，请前往该窗口继续对话。

这些操作只是改变查看位置，不会创建话题副本。

## 复制会话 ID 和链接

- **复制会话 ID** — 将当前话题的唯一标识复制到剪贴板，用于准确定位话题或向支持人员提供排查信息。
- **复制链接** — 复制指向当前话题的应用内链接，适合保存书签或返回原对话。

**复制链接不等于公开分享。** 它不会改变话题的访问权限，也不会让原本无权访问的人获得权限。若要让他人通过只读页面阅读内容，请使用下方的[分享链接](#分享链接)。

## 复制、转发和移动

### 创建话题副本

选择**复制**，创建一个新的话题副本。你可以在副本中继续讨论，原话题仍然保留。

适合从同一段讨论出发尝试不同方案，例如保留原架构设计，再在副本中讨论替代方案。这里的**复制**是创建话题，不是把对话文字复制到剪贴板；复制文字请使用导出功能。

### 转发给其他助手

需要其他助理基于这段对话继续处理时，选择**转发给其他助手**：

1. 搜索并选择一位或多位目标助理。
2. 按需补充说明，例如「请根据这段讨论整理行动项」。
3. 确认转发。

对话内容会整理成一条新消息，发送到目标助理的新话题中，并触发后续处理；原话题保留在原助理下。转发不是完整克隆话题，也不是向外部用户公开分享。请留意目标助理的模型、工具及相应使用费用。

### 移动到其他助手

如果只是想更换话题归属，选择**移动到其他助手**，选定目标助理并确认移动。

移动后，原话题从当前助理的列表移到目标助理下，可通过完成提示前往查看。移动不会在原助理下再保留一个副本；如果两边都要保留，可以先复制或使用转发。

## 导出与分享

在话题菜单选择**导出**，打开导出窗口。也可以从会话窗口右上角的**分享**入口进入；如果先显示链接分享面板，点击其中的**导出**。

| 格式 | 适合场景 |
| --- | --- |
| **截图** | 在聊天工具或社交媒体中直观展示对话 |
| **文本** | 编辑、摘录、引用和整理笔记 |
| **PDF** | 工作报告、学习笔记和阅读存档 |
| **JSON** | 保存结构化消息数据、数据分析或系统集成 |

导出前检查预览，确认是否包含系统提示词、用户消息、工具调用和其他敏感内容。导出文件不是完整账号备份，也不等于打包所有附件或助理配置。

### 截图分享

将对话导出为图片，可以选择：

- **宽度模式** — 宽屏适合电脑阅读，窄屏适合手机阅读。
- **包含助理档案** — 按需包含系统提示词等角色设定内容。
- **包含页脚** — 控制是否显示底部信息。
- **图片格式** — JPG、PNG、SVG 或 WEBP。

设置完成后，复制图片到剪贴板，或下载到本地。

<Image alt={'截图分享'} src={'/blog/assets196d679bc7071abbf71f2a8566f05aa3.webp'} />

### 文本分享

将对话导出为文本，方便复制、编辑或作为 Markdown 笔记使用。可以选择是否包含：

- **助理档案** — 系统提示词等角色设定内容。
- **消息角色** — 标明每条消息的发送者。
- **用户消息** — 保留或排除用户发送的消息，而不只是隐藏用户姓名。
- **技能消息** — 包含相关工具消息及调用信息。

设置完成后，复制到剪贴板，或下载文本文件。

![文本导出选项](/blog/assetsa8e173bec038d1d21d413f6fa0ace342.webp)

### PDF 分享

将对话导出为 PDF，适合阅读、发送报告或存档。与文本导出一样，可以选择是否包含助理档案、消息角色、用户消息和技能消息。

选择所需内容后，点击**生成 PDF**；生成完成后查看预览，并点击**下载 PDF**保存文件。更改选项后，需要重新生成 PDF。

<Image alt={'PDF 分享'} src={'/blog/assets7dccdd4df55aede71001da649639437f.webp'} />

### JSON 分享

JSON 导出有两种模式：

- **默认** — 保存 LobeHub 的结构化话题与消息数据，包括消息标识、时间、角色和相关元数据。
- **OpenAI 兼容** — 以简化的消息格式导出，便于开发者进一步处理。接入其他系统前，应检查目标接口的字段要求。

可以选择是否包含助理档案中的系统提示词。JSON 可能包含工具调用与工具消息，分享前应检查实际内容。设置完成后，复制 JSON 到剪贴板，或下载文件。

## 分享链接

如果当前账号和助理允许链接分享，可以通过会话窗口右上角的**分享**入口设置话题的可见性：

- **私密** — 仅你自己可以访问此分享链接。
- **有链接即可访问** — 任何拿到链接的人都可以阅读分享的会话，不要将链接当作仅限指定收件人的邀请。

### 创建和撤回公开链接

1. 打开**分享**面板。
2. 将可见性设为**有链接即可访问**。
3. 阅读隐私提示，检查整段对话中是否有凭证、密钥、工具调用详情、图片或上传文件等不宜公开的内容，再确认分享。
4. 使用**复制链接**获取分享地址，发送给他人。
5. 不再希望公开时，将可见性切回**私密**。这不会收回他人已经保存的截图、文本或文件副本。

如果公开选项不可用，请查看界面中的权限提示。能够导出内容，并不一定代表能够发布公开链接。

分享页用于只读阅读对话，不会让访问者直接运行你的助理工具。页面中即使有探索或体验助理的入口，也不同于继续操作你的原话题。发布助理配置可参阅[成为创作者](/zh/docs/usage/community/become-a-creator)。

## 删除话题

在话题菜单选择**删除**，阅读提示后确认。**删除为永久操作，无法撤销**；仍需保留的内容应提前导出。如果只是想整理列表，请使用归档。

确认窗口如果显示**同时删除此话题中上传的图片和文件**，请检查勾选状态，确认是否也要删除这些资料。

### 删除前检查文档和浏览器状态

[助理文档库](/zh/docs/usage/agent/agent-documents)统一管理助理创建的文档。文档可以保存在助理级范围，也可以关联当前话题。删除前检查文档所属范围，并为仍然需要的内容保留副本。

[内置浏览器](/zh/docs/usage/agent/built-in-browser)让你在会话旁打开并操作网页。关闭或删除话题不等于退出网站账号；需要退出时，应在网站中退出登录。
