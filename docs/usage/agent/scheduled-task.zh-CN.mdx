# Agent 任务

**任务（Tasks）**用于将工作交给 Agent 执行，并跟踪进度、查看结果。在 Agent 页面，你可以集中管理该 Agent 的任务，按需执行一次性工作，或配置定时计划让任务重复运行。

## 打开任务页面

在 Agent 页面点击**任务（Tasks）**，查看当前 Agent 的任务。这里仅显示该 Agent 的任务，新建任务也直接归属当前 Agent。

## 创建任务

1. 在 Agent 页面点击**任务（Tasks）**。
2. 在页面最上方的 **Add task instruction...** 输入框中，描述希望 Agent 完成的工作。
3. 根据需要设置优先级，或通过附件图标添加相关文件。
4. 点击 **Create task** 创建任务。

描述任务时，写清目标、所需背景和期望的输出。例如：

> 阅读附件中的客户反馈，按问题类型归类，列出出现最多的三个问题，并为每个问题给出改进建议。以表格形式输出。

输入框下方显示当前 Agent。创建前，确认该 Agent 可以访问任务所需的工具和资料。

## 查看任务进度

创建后，在输入框下方的任务列表中查看任务。列表按状态分组，例如 **Pending review**（待审核）和 **Backlog**（待办），便于找到需要关注的工作。

点击任务打开详情，查看具体进度、运行记录和输出。需要检查交付内容时，打开关联的话题或产出物。

## 配置定时执行

需要让 Agent 按计划重复执行工作时，可以在任务详情中配置自动化，设置执行频率、时间和运行次数上限。

1. 在当前 Agent 的**任务（Tasks）**页面打开目标任务。
2. 进入**任务详情 → 自动化（Automation）→ 定时（Scheduled）**。
3. 配置频率、时间、时区和运行次数上限。
4. 启用自动化。
5. 按界面提示启动调度。
6. 核对任务状态和下次运行时间。

### 配置字段

- **任务名称与指令**：写明目标、数据来源、输出格式和交付要求。将之前聊天中与任务有关的背景写入指令。
- **频率**：支持**每天、每周**（可选多个星期）和**每小时**（整数范围为 **1–24**）。
- **时间**：使用 24 小时制，以半小时为单位；分钟选项为 **00** 或 **30**。
- **时区**：选择目标时区并检查预览。未保存时区时，表单使用 **UTC**。
- **运行次数限制**：设置执行次数上限，或选择持续执行。每天一次且按预期运行时，30 次对应 30 天；其他频率覆盖的时长会有所不同。

### 定时与固定间隔

**定时（Scheduled）**按设定的时钟时间运行。**固定间隔**按指定间隔重复执行，最小值为 **10 分钟**或 **1 小时**。需要在一天中的特定时间执行时，选择定时。

定时执行支持每天、每周和每小时，**不支持每月或自定义 cron 表达式**。修改计划后，请核对保存的配置和下次运行时间。

### 计划示例

| 工作 | 计划 | 指令要点 |
| --- | --- | --- |
| 每日晨报 | 目标时区每天 08:00 | 总结昨日指标，注明来源并列出缺失数据。 |
| 竞品复盘 | 每周一 09:00 | 检查指定竞品，附链接说明价格变化。 |
| 监控摘要 | 每小时模式，每 2 小时 | 检查已配置的数据源，汇总新增告警。 |

先按需测试一次指令，再启用重复执行。确认被指派的 Agent 拥有所需工具、权限和可访问的执行环境。

## 管理任务

### 查看结果

在当前 Agent 的任务列表中点击目标任务，在详情中查看运行记录、输出、错误及交付检查报告。打开关联的话题或产出物，检查实际结果。

### 编辑计划

回到**自动化**修改频率、时间、时区或运行次数上限，并核对保存的配置和下次运行时间。已经在执行的工作，请单独查看其运行状态。

### 关闭自动化

关闭自动化可停止后续自动运行，同时保留任务及已保存的配置。重新启用前，请确认运行模式、频率和下次运行时间符合预期。已经在执行的任务，请单独查看其运行状态。

### 删除任务与关闭自动化

**只有确实要移除工作记录时才删除任务**，不要用删除代替暂停计划。

删除任务会移除任务本身及评论、活动、依赖、话题和文档关联等任务级记录。关联内容和子任务的删除范围需分别检查。

删除前保存需要的结果，并检查当前操作是否包含子任务。关联的话题、文档和文件也请单独检查。

## 交付检查与可用范围

为输出要求配置[交付检查](/zh/docs/usage/agent/gtd#交付检查与验收)。每次运行后，查看结果和检查报告。

启用自动化前，先试运行一次，检查所需文件、服务和执行设备是否可访问。定时运行期间，请保持执行环境可用。需要发送邮件或消息时，配置并授权相应工具。

## 故障排查

- **未按预期执行**：检查自动化是否启用、调度是否启动、运行次数是否达到上限，以及时区是否正确；查看任务状态和错误。
- **时间不符合预期**：核对 24 小时制、时区，以及选择的是定时还是固定间隔。
- **缺少上下文或输出不佳**：在任务指令中补齐背景、数据来源和输出标准；检查 Agent 是否可以访问所需工具和数据。
- **执行过多或费用过高**：先关闭自动化，再调整频率和次数上限。
