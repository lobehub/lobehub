# 分享會話記錄

通過會話視窗右上角的`分享`按鈕，您可以將當前會話記錄分享給其他人。LobeHub 支援兩種分享方式：`截圖分享`和 `生成分享連結`。

LobeHub 支援將會話內容分享給他人。你可以將對話導出為截圖、文字、PDF 或 JSON 格式，方便儲存、分享。

## 截圖分享

將會話導出為圖片格式。可選顯示模式：

- 寬屏模式：適合電腦螢幕查看
- 窄屏模式：適合手機螢幕查看

可選內容選項：

- 是否包含助手角色設定：顯示助手的系統提示詞等設定資訊
- 是否包含頁腳：顯示頁面底部資訊
- 可選圖片格式：JPG/PNG/SVG/WEBP
- 可選分享方式：複製圖片：複製到剪貼簿，可以直接貼上到其他應用程式下載截圖：儲存圖片檔案到本地

## 文字分享

將會話導出為純文字格式。可選內容選項：

- 是否包含助手角色設定：包含助手的系統提示詞等設定是否包含訊息角色
- 顯示每條訊息的發送者
- 是否包含使用者資訊：包含使用者相關資訊
- 是否包含插件資訊：包含插件調用的相關資訊
- 可選分享方式：複製文字：複製到剪貼簿下載檔案：儲存為文字檔案

## PDF 分享

將會話導出為 PDF 文件。可選內容選項：

- 是否包含助手角色設定：包含助手的系統提示詞等設定
- 是否包含訊息角色：顯示每條訊息的發送者
- 是否包含使用者資訊：包含使用者相關資訊
- 是否包含插件資訊：包含插件調用的相關資訊生成方式：選擇完選項後，點擊生成按鈕，直接生成 PDF 檔案並下載。

## JSON 分享

將會話導出為 JSON 格式，適合開發者或需要在其他系統中使用。可選導出模式：預設：LobeHub 的標準 JSON 格式 OpenAI 相容：相容 OpenAI API 格式的 JSON 可選內容選項：是否包含角色設定：包含助手的角色設定資訊可選分享方式：複製：複製 JSON 內容到剪貼簿下載檔案：儲存為 JSON 檔案 \[Image] 使用場景截圖分享：適合在社交媒體、聊天工具中分享對話內容，直觀易讀。文字分享：適合需要編輯或引用對話內容的場景，檔案體積小。PDF 分享：適合正式場合，如工作報告、學習筆記、存檔記錄。JSON 分享：適合開發者，可以導入到其他系統或進行資料分析。
