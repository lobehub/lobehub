# 终端（Terminal）

在助理页面右上角打开**终端（Terminal）**，即可直接输入命令并查看输出，无需切换到独立的终端应用。你可以用它检查项目文件、运行脚本，或验证助理完成的修改。

## 打开终端

1. 在 LobeHub 桌面端打开一位助理的聊天页面。
2. 点击页面右上角的**终端（Terminal）**入口，展开终端面板。
3. 检查当前目录，必要时切换到要操作的项目目录。
4. 输入命令并按回车，在面板中查看输出。

例如，在 macOS 或 Linux 的 Shell 中，可以先查看当前目录和文件：

```bash
pwd
ls
```

需要进入项目时，运行 `cd /path/to/project`，将示例路径替换为实际路径。运行项目脚本前，请先阅读项目说明，确认所需命令和依赖。

## 管理终端会话

终端支持多个会话，通过标签页切换。你可以将不同工作分开，例如在一个会话中运行开发服务，在另一个会话中检查文件或运行测试。

右键点击终端标签页，可以关闭当前会话或其他会话。关闭前，请检查相应会话中是否还有需要保留的运行进程。

## 与助理配合使用

终端适合需要你直接操作的步骤；聊天则适合向助理描述目标、请求分析或安排任务。

例如：

1. 请助理修改项目中的一处问题。
2. 打开终端，进入对应的项目目录。
3. 按项目说明运行测试，检查输出。
4. 如果测试失败，将相关错误信息发给助理继续处理。

需要助理分析终端输出时，可以把相关内容发到聊天中。分享日志前，先移除密码、令牌和其他敏感信息。

## 使用注意事项

- **确认运行位置。** 不要仅凭聊天所在的设备判断命令在哪里执行。涉及多台设备时，先检查终端中的环境与路径；助理工具的执行位置见[执行设备](/zh/docs/usage/agent/execution-devices)。
- **手动命令会产生实际影响。** 删除文件、安装依赖或修改配置前，请检查命令和目标路径。
- **区分终端与云沙箱。** 打开终端面板不等于创建云端隔离环境。需要在云端运行任务时，参阅[云沙箱](/zh/docs/usage/agent/sandbox)。
- **找不到入口时。** 可以先确认正在使用桌面端，并检查应用版本。本机终端入口会在桌面端具备相应访问权限时显示。
