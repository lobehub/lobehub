# 助理档案

你可以在助理档案中配置 Agent，设置它的工作方式。你可以为它起名、定制形象，选择模型与工具，编写核心指令，也可以查看它的消息频道和使用情况。

## 打开助理档案

选择一位助理进入会话，点击左侧边栏的**助理档案**。页面顶部有三个标签：

| 标签 | 用途 |
| --- | --- |
| **基础档案** | 设置助理的名称、形象、模型、工具与核心指令 |
| **消息频道** | 将助理连接到外部聊天应用 |
| **统计** | 查看这位助理的费用、Token 消耗与模型使用情况 |

## 基础档案

### 名称与身份

档案顶部展示助理的头像、名称和身份信息。为助理设置一个容易辨认的名字，方便在助理列表与会话中找到它。尚未命名时，可以点击名称旁的**一键起名**，让 AI 帮你命名。

名称用于辨认助理；如果希望它按照特定职责和风格工作，还需要在下方的**核心指令**中写明要求。

### 定制形象

点击助理头像旁的**自定义形象**按钮，打开 **Agent 形象 Studio**。你可以在这里为助理设置头像与全身形象，上传已有图片，或使用 AI 生成形象。

| 形象 | 图片要求 |
| --- | --- |
| **头像** | 1:1，PNG 或 JPG，不超过 1 MB |
| **全身形象** | 3:4，透明底 PNG，不超过 1 MB |

**使用已有头像：** 在头像区域点击**上传**，选择符合要求的图片。需要移除当前头像时，点击该区域的删除图标。

**使用 AI 生成：**

1. 在 **AI 一键生成**区域选择风格：**Lobe 风格、二次元、线条手绘、像素风**或**手绘油画**；也可以选择**参考图**，提供视觉参考。
2. 按需补充形象描述，例如「戴眼镜的研究员，蓝色外套，亲切的表情」。描述为选填，可用于说明角色特征、服饰与配色。
3. 点击头像区域的**生成**来生成头像，或点击**同时生成两个形象**，一起生成头像与全身形象。
4. 生成完成后检查效果，不满意时可以调整风格或描述，再次生成。

形象决定助理的视觉外观，不会改变它的模型、工具权限或核心指令。

### 模型与推理强度

在**模型与推理强度**区域选择助理使用的模型。对于支持调节推理强度的模型，还可以通过旁边的选项调整推理投入。

- **日常问答、改写与摘要**：优先考虑响应速度和成本。
- **复杂分析、规划与代码任务**：可以尝试更高的推理强度，再比较实际效果、耗时与用量。
- **图片、音频或视频任务**：确认所选模型与接入方式支持所需的输入或输出类型。

可选模型和推理档位取决于模型及服务商。更高的推理强度可能增加耗时与消耗，效果因任务而异。你可以打开模型配置区域的**运行优先级**信息入口，了解当前运行规则。

关于模型的接入与可用性，参阅[模型服务商](/zh/docs/usage/providers)。

### Agent 工具与用户工具

模型下方列出助理可用的工具，并分为两个区域：

- **Agent 工具**：面向这位助理配置的专属工具。点击**添加工具**，按工作需要添加工具。
- **用户工具**：展示连接到你账户的工具。通过**集成技能**入口添加所需工具。

可以先为研究助理添加检索与文档工具，再按任务需要连接外部服务。使用列表中的工具前，请按提示完成所需的账号授权、资源访问或执行环境配置。

关于添加工具、使用模式与权限，参阅[连接器](/zh/docs/usage/agent/connectors)；关于可复用的工作方法与技能包，参阅[Skills 市场](/zh/docs/usage/community/skills-market)。

### 核心指令

**核心指令**定义助理的角色、任务范围、工作方法与回复要求。与某次对话中的临时请求不同，这里适合放置希望这位助理持续遵循的规则。

你可以直接在编辑器中输入内容，按 `/` 打开斜杠菜单，也可以通过右上角的按钮切换富文本与源码编辑视图。

一份实用的核心指令可以包含：

- **角色与目标**：助理为谁工作，主要解决什么问题。
- **工作方法**：先收集哪些信息，如何处理缺失资料。
- **回复要求**：语言、篇幅、格式与引用方式。
- **边界**：哪些内容不能猜测，哪些操作需要先确认。

例如，为研究助理设置：

```text
你是一位公司研究助理，帮助我整理企业资料和撰写内部简报。

工作要求：
- 优先使用公司官网、财报与监管披露。
- 区分事实、公开表述与分析判断，不编造数据。
- 信息不足时指出缺口，不以猜测补齐。

输出要求：
- 先给摘要，再展开分析。
- 使用清晰的小标题和简洁段落。
- 关键数据注明时间、单位与来源。
```

核心指令用于指导助理行为，不会自动安装工具或授予权限。需要检索、读文件或操作外部服务时，请先配置相应工具。

## 使用助理构建专家完善配置

不确定如何写核心指令，或希望调整已有助理时，点击档案页右上角的**助理构建专家（Agent Builder）**按钮，打开右侧对话面板。

你可以直接描述使用场景，也可以从面板中的建议开始，例如：

- **设定系统角色**：明确助理的专业领域与职责。
- **补充助手简介**：说明助理能做什么、适合谁使用。
- **编写开场白和引导问题**：帮助使用者快速开始第一次对话。

例如：

> 帮我把这位助理配置成面向产品团队的用户反馈分析助手。它需要先归类反馈，再提炼问题和改进建议。请完善核心指令，并编写一条简短的开场白和三个引导问题。

完成后，检查生成的内容与配置，再用一项真实任务测试效果。你可以继续与 Agent Builder 对话，也可以回到基础档案手动调整。

## 消息频道

**消息频道**让你在外部聊天应用中与这位助理互动，例如 Discord、Telegram、Slack、飞书、Lark、QQ、微信和 LINE。

切换到**消息频道**标签，选择平台，按提示完成接入与访问范围配置。不同平台的接入要求、可用功能与套餐限制不同；标记为**即将上线**的平台暂不可用。

详细设置步骤与各平台说明，请参阅[Channels 总览](/zh/docs/usage/channels/overview)。

## 统计

**统计**标签展示当前助理的用量，帮助你了解成本来自哪里，以及不同模型的使用情况。它与账号级的[数据统计](/zh/docs/usage/user-interface/stats)不同，这里的查看对象是这位助理。

### 选择统计范围

- **维度**：按天或按周查看。
- **时间范围**：选择最近 **7 天、30 天或 90 天**。

### 查看汇总指标

| 指标 | 说明 |
| --- | --- |
| **费用** | 所选时间范围内记录的使用费用 |
| **缓存节省** | 缓存带来的费用节省，并显示命中率与缓存读取量 |
| **Token** | Token 总用量，同时列出输入与输出用量 |

缓存节省用于了解缓存效果，不是账户返现或余额。统计费用也不等同于订阅套餐价格；具体计费以所用服务的规则和账单为准。

### 查看趋势与模型明细

**Agent 用量趋势**支持在**费用**与 **Token** 之间切换，并区分输入、缓存输入、输出与缓存写入，便于定位用量变化。

下方的**按模型统计**表格列出各模型的**请求数、Tokens 和费用**。如果发现某段时间消耗明显上升，可以结合趋势与模型明细，回顾当时的任务，再判断是否需要调整模型、推理强度或任务中的上下文长度。

## 更多操作

点击助理档案右上角的**更多**按钮（`···`），可以使用以下功能：

### 进阶配置

选择**进阶配置**，可以设置这位 Agent 的**开场消息**和**开场问题**：

- **开场消息**：用户打开新会话时显示，用于介绍助理的功能和使用方式。
- **开场问题**：会话开始时展示的引导性问题，帮助用户快速发起任务。输入一个问题后点击 **+**，可以继续添加更多问题。

完成编辑后，点击**确认**保存设置。

### 发布

选择**发布**，可以将当前 Agent 提交到社区。提交后，Agent 将进入审核流程；通过审核后会显示在助理市场中。

首次发布前，请先完善社区创作者资料。完整的准备事项与发布说明，请参阅[成为创作者](/zh/docs/usage/community/become-a-creator)。

### 导出

选择**导出**，再从子菜单选择导出格式或目标。你可以用它备份、分享或复用当前 Agent Profile；实际可用选项以页面显示为准。

### 移动到

选择**移动到…**，可以将当前 Agent 移动到其他可用位置。移动后，原位置不再保留该 Agent；实际可选位置取决于你的账户权限。

### 复制到

选择**复制到…**，可以将当前 Agent 复制到你有权限创建助理的目标位置，包括个人账户或工作区。原 Agent 会保留；实际可选位置取决于你的账户权限。

### 删除

选择**删除**，可以删除当前 Agent。删除属于破坏性操作，请在确认前检查目标 Agent；如果希望保留副本，可先使用**导出**或**复制到…**。

菜单底部还会显示该 Agent 的创建时间，便于核对当前操作的对象。
