# 把助手嵌入你的网站

已分享的助手可以放到你自己的网站上：一行 script 标签就会在页面角落加一个对话按钮，点开即可在面板里和助手对话。

<Callout type={'info'}>
  嵌入功能正在逐步开放。如果分享设置里看不到「嵌入到网站」，说明你的账户暂时还不能使用。
</Callout>

## 设置

1. 打开助手，进入「分享」，开启分享链接。嵌入使用的就是这个链接。
2. 在「嵌入到网站」中填写允许显示对话的网站，每行一个源，例如 `https://docs.example.com` 或 `https://*.example.com`。只能填源，不能带路径。
3. 复制嵌入代码，粘贴到这些网站页面的 `</body>` 之前：

```html
<script src="https://app.lobehub.com/embed.js" data-agent="your-share-link" async></script>
```

## 哪些网站能显示

浏览器只会在你列出的网站上显示对话，其他网站上的面板是空白的。关闭分享链接，或把某个网站从列表中删掉，嵌入会立即失效。

## 访客能做什么

访客和通过分享链接对话时完全一样：需要登录 LobeHub（从面板里打开新窗口登录），对话只有自己能看到，每次运行都计入这个分享的限额 —— 每位访客的话题数、每个话题的轮数、每月花费和文件存储。

## 当前限制

只有当你的网站与 LobeHub 属于同一站点（例如 `docs.example.com` 与 `chat.example.com`）时，访客在面板里才能保持登录。其他网站上，浏览器不会把 LobeHub 的登录状态交给面板，访客会被反复要求登录。更广泛的支持在规划中。

## 可选参数

| 属性              | 含义                               |
| --------------- | -------------------------------- |
| `data-agent`    | 分享链接后缀或分享 ID。                    |
| `data-theme`    | `light`、`dark` 或 `auto`（跟随访客系统）。 |
| `data-position` | `right`（默认）或 `left`。             |
| `data-open`     | `true` 时页面加载后直接打开面板。             |
| `data-locale`   | 界面语言，例如 `zh-CN`。                 |

如果需要用代码控制 —— 从页面切换主题、用自己的按钮打开面板、监听 `messageSent` 事件 —— 请参考 `@lobechat/embed` 包的 README。
