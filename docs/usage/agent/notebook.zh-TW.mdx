# 筆記本

LobeHub 支援筆記本功能（Notebook），讓你在對話中隨時儲存和管理文件。不再擔心重要內容被遺忘，助理可以幫你記錄筆記、儲存報告、整理研究資料 —— 所有內容都留存在當前話題中，隨時查閱。Notebook 突破了對話內容轉瞬即逝的限制，將有價值的資訊沉澱為可管理的文件。從會議紀要到學習筆記，從研究報告到待辦清單，Notebook 讓知識積累更系統、更持久。

Notebook 是話題級別的文件儲存空間。當對話中產生了值得保留的內容，助理可以將其儲存到 Notebook 中，形成結構化的文件庫。這些文件與當前話題關聯，方便你在後續對話中查閱和引用。

## Notebook 能做什麼

### 儲存筆記和備忘

助理可以幫你快速記錄想法、待辦事項、靈感片段。你只需說 "幫我記一下"，內容就會儲存到 Notebook 中。

### 整理研究資料

當你讓助理搜尋訊息或分析資料時，可以將有價值的結果儲存下來。下次繼續研究時，這些資料隨時可用。

### 生成報告和文章

助理可以幫你撰寫結構化的報告、分析文件、長篇文章，並直接儲存到 Notebook。你能隨時查看、編輯、補充內容。

### 管理文件版本

你可以讓助理更新已有文件，追加新內容或修改現有內容。文件在 Notebook 中持續演進，保持最新狀態。

### 啟用 Notebook 插件

Notebook 是搭載插件，需要為助理啟用後才能使用文件管理功能。

### 在助理檔案中啟用

- 進入助理檔案頁面，點擊「+ 整合技能」，勾選「Notebook」即可開啟。

### 在會話中啟用

- 進入會話頁面，點擊對話框下方技能圖示，勾選「Notebook」即可。

### 使用 Notebook

你可以讓助理讀取文件內容：

- "看一下之前儲存的筆記"
- "那份報告寫了什麼" 刪除文件當文件不再需要時，可以給助理發送指令刪除或展開 Notebook 面板手動刪除。查看和管理文件所有儲存的文件都會顯示在話題右側 Notebook 面板中。右上角點擊文稿圖示即可呼出面板。你可以：
- 瀏覽文件列表，查看標題和摘要
- 點擊文件查看完整內容
- 直接在面板中編輯文件
- 點擊「在文稿中編輯」，將會話內文稿同步到「文稿」板塊
