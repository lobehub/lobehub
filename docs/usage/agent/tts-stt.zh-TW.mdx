# 文字語音轉換使用指南

LobeHub 支援文字語音轉換功能，允許使用者通過語音輸入內容，以及將 AI 輸出的內容通過語音播報。

## 文字轉語音（TTS）

在對話視窗中選中任意內容，選擇`文字轉語音`，AI 將通過 TTS 模型對文字內容進行語音播報。

<Image alt={'TTS'} src={'/blog/assets907ea775d228958baca38e2dbb65939a.webp'} />

## 語音轉文字（STT）

在輸入視窗中選擇語音輸入功能，LobeHub 將您的語音轉換為文字並輸入到文字框中，完成輸入後可以直接發送給 AI。

<Image alt={'STT'} src={'/blog/assets34424062ad6ab98df7f56c9e61341be5.webp'} />

## 文字語音轉換設定

你可以在設定中為文字語音轉換功能指定您希望使用的模型。

<Image alt={'TTS 設定'} src={'/blog/assets89168f61edcb2ee92d2ad7064da218b2.webp'} />

- 開啟`設定`面板
- 找到`文字轉語音`設定
- 選擇您所需的語音服務和 AI 模型
