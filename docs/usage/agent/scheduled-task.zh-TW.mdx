# 定時任務

定時任務是定期在雲端執行的任務。

簡單來說，你可以讓 Agent 定期根據你的 Prompt 去執行任務，例如定期檢查社交媒體內容併發送通知。

## 建立任務

在 Agent 會話頁面左側面板找到定時任務，點擊 `新增定時任務` 開始建立任務。

在建立頁面，你可以填寫任務名稱，設定任務頻率和具體的執行時間，設定任務最多執行的次數，設定任務內容。

![建立任務](https://file.rene.wang/clipboard-1770261091677-74b74e4d6bf23.png)

在 Task Content 區域，你可以輸入提供給 Agent 的 Prompt 或指令。例如需要完成的任務內容、是否調用插件等。每一次定時觸發，都會完整執行這裡定義的內容。建立完成後，你可以隨時修改定時任務的設定。

## 暫停任務

如果暫時不需要某個定時任務，可以關閉啟用狀態。關閉啟用狀態後，任務不再自動執行，該任務的執行計劃、Prompt 設定都會保留。恢復啟用狀態後該任務會繼續執行。

![暫停任務](https://file.rene.wang/clipboard-1770266335710-1fec523143aab.png)

## 刪除任務

如果不再需要某個定時任務，可以將其刪除。刪除任務後，該任務的執行計劃、Prompt 設定都會一併移除，系統將不再觸發任何後續執行。

## 使用場景

定時任務適用於所有具備固定節奏、需要持續跟進或定期交付結果的工作場景。以下是一些常見且高頻的使用方式。

### 定期檢查社交媒體內容併發送通知

你可以設定定時任務，週期性檢查指定平臺或關鍵詞相關的社交媒體內容。任務會自動抓取最新動態，篩選符合條件的資訊，並在檢測到重要更新時生成摘要或觸發通知。這一場景適合用於品牌輿情監測、競品動態跟蹤、創作者內容更新提醒等。你只需查看結果，無需反覆手動搜尋。

### 週期性生成總結與報告

對於需要定期覆盤的工作，例如資料分析、項目進展跟蹤或內容表現評估，可以通過定時任務自動完成彙總和分析。任務會在指定時間收集相關資訊，輸出結構化結論，幫助你持續掌握趨勢變化，而不必每次從零整理。

### 定時提醒通知

你可以提前設定需要提醒的事項，例如需要處理的工作、重要節點、週期性檢查任務等，讓 LobeHub 自動生成提醒資訊並通過郵件等方式提醒，無需你手動觸發。這一方式適合用於個人待辦提醒、重要事項通知、週期性任務提示等場景，幫助你在正確的時間收到明確的行動提示，把需要記住的事情交給系統處理。
