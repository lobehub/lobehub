# GTD 工具

GTD Tools 是 LobeHub 搭載的插件，將經典的 GTD（Getting Things Done）時間管理方法論深度整合到你的對話體驗中。開啟該插件後，你的助理將化身為專業的任務管理專家，幫助你將大腦從瑣碎的雜事中解放出來，專注於當下的創作與思考。通過 GTD Tools，你可以直接在會話中以自然語言管理日程。無論是突如其來的靈感、待辦的家務，還是嚴肅的工作計劃，助理都能為你精準記錄並追蹤進度。

## 啟用 GTD Tools

GTD Tools 是 LobeHub 的搭載插件，需要為助理啟用後才能使用。

### 在助理檔案中啟用

進入助理檔案頁面，點擊「+ 整合插件」，勾選「GTD Tools」插件即可開啟。

### 在會話中啟用

進入會話頁面，點擊對話框下方插件圖示，勾選「GTD Tools」插件即可。

### 建立任務

你可以在會話中直接發送你的計劃，助理會自動識別並確認記錄。

### 消除任務

你可以在會話中通過對話指令讓助理自動更新。
