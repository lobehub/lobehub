# Topics

In LobeHub, conversations with an Agent are organized into Topics. Search and organize your history, explore a new direction without losing the original discussion, or export and share a conversation for others to read.

## Topic Panel

The sidebar list is built for quick switching. To see every topic of an Agent at a glance, filter by criteria, or tidy up in bulk, click **Topics** in the left navigation of the Agent's conversation page to open the topic panel.

The panel itself is for browsing, filtering, and bulk actions. Per-topic actions such as rename, export, and delete are in each topic's action menu in the sidebar list (described below).

### Browse and Filter

- **Status tabs** — **All / Active / Running / Archived** at the top show a count for each group. Click a tab to switch.
- **Filters** — Click **Add filter** to add a filter, for example **Time** to show topics from a given period.
- **Search** — Use the search box in the top-right to search the current Agent's topics.
- **View** — Switch between **Card** and **List** views. The card view shows the title, a preview of the first message, message count, last update, and status. The list view shows the title, project, status, source, and update time.
- **Sort** — Use **Sort** to order topics by update time, creation time, or title.
- **Grouping** — Group topics by time period or by project.

### Bulk Actions

Check the box in the top-right corner of one or more cards to select them. A bulk action bar appears at the bottom showing **N selected** and these actions:

- **Favorite** — Favorite the selected topics.
- **Archive** — Archive them without deleting conversation content.
- **Move to Agent** — Choose a target Agent and move the selected topics there together.
- **Delete** — Delete the selected topics. This requires confirmation and cannot be undone.
- **×** — Clear the selection and leave bulk mode.

Click any topic in the panel to open its conversation and continue.

## Topic List Menu

In the sidebar topic list, click the **···** button next to a topic (or right-click the topic) to open its action menu.

| Action | What it does |
| --- | --- |
| **Archive** | Set aside a topic you no longer need in your active list |
| **Favorite / Unfavorite** | Mark frequently used topics for quick access |
| **Smart Rename / Rename** | Generate a title from the conversation or enter one yourself |
| **Check Message Chain** | Diagnose hidden messages and disconnected branches, and repair recoverable issues |
| **Open in New Tab** | Open the topic in another desktop app tab |
| **Open on Right** | View the topic in the right-side panel for reference |
| **Open in a new window** | Open the topic in a separate desktop app window |
| **Copy Topic ID** | Copy the topic identifier for locating a record or troubleshooting |
| **Copy Link** | Copy the topic's in-app link without changing access permissions |
| **Duplicate** | Create a new copy while keeping the original topic |
| **Forward to another agent** | Send the conversation content to other Agents for further work in new topics |
| **Move to another agent** | Move the original topic under a different Agent |
| **Export** | Open image, text, PDF, and JSON export options |
| **Delete** | Permanently delete the topic after confirmation |

Available actions depend on the topic's state, your client, and your permissions. **Open in New Tab** and **Open in a new window** are desktop app actions. Actions that require creating or editing content may be unavailable if you lack those permissions.

## Search and Organize Topics

Open search in the topic list and enter a keyword to find a previous conversation.

![Search Topics in Conversation](/blog/assets3cdf933016e6f53bca12b8cedb17061f.webp)

Use the list's organization and filter controls to choose a grouping mode:

- **By status** — Group topics by states such as running, waiting for input, failed, and archived.
- **By time** — Group topics into periods such as today, yesterday, this week, and this month.
- **By project** — Group topics by their project or directory, with a separate group for those without one.
- **Flat** — Show topics in one list without grouping.

You can also sort by creation or update time and use **Show Archived** to control whether archived topics appear.

### Archive

Choose **Archive** for a topic you want to keep but no longer need to see regularly. Archiving does not delete the conversation.

### Favorite and Unfavorite

Choose **Favorite** to mark an important or frequently used topic for quick access in the favorites area. Choose **Unfavorite** to remove the mark without deleting the topic.

![Favorite Topics](/blog/assets04d6fae3d9aa3c33697028f1cc9f4706.webp)

### Rename

- **Rename** — Enter a descriptive title and save it.
- **Smart Rename** — Generate a title from the conversation. You can still edit it manually afterward.

For example, a title such as “Client A · Partnership proposal” is easier to recognize than a generic conversation title.

## Check the Message Chain

Use **Check Message Chain** if messages are missing from view, appear out of order, or seem disconnected from an earlier part of the conversation.

1. Open the topic menu and select **Check Message Chain**.
2. Review the results for hidden messages or disconnected branches.
3. If a **Repair** button is available, use it to repair recoverable message connections, then return to the topic to review the result.

This checks how messages are connected and displayed, not whether an answer is factually correct. It cannot recover message text that was never successfully saved. If the check fails, you can retry it.

## Open a Topic Elsewhere

- **Open in New Tab** — Add a tab in the desktop app to switch between topics.
- **Open on Right** — Open the topic in the right-side panel while keeping your current content available for comparison.
- **Open in a new window** — Use a separate desktop window for multi-window or multi-monitor work. If the main window indicates that the topic is open elsewhere, continue the conversation in that separate window.

These actions change where you view a topic; they do not create a duplicate.

## Copy the Topic ID or Link

- **Copy Topic ID** — Copy the topic's unique identifier to locate it precisely or include it in a support request.
- **Copy Link** — Copy the in-app address for returning to the original conversation or saving a bookmark.

**Copying a link does not publish the conversation.** It does not change access permissions or grant access to someone who could not already open the topic. To let others read a shared, read-only version, use [Shareable Links](#shareable-links) below.

## Duplicate, Forward, or Move

### Duplicate a Topic

Choose **Duplicate** to create a new topic copy. Continue the discussion in the copy while keeping the original topic.

This is useful for exploring alternative approaches from the same starting point—for example, keeping an original architecture discussion while testing a different design in the copy. **Duplicate** creates a topic; it does not copy conversation text to the clipboard. Use export options to copy text.

### Forward to Another Agent

Choose **Forward to another agent** to have another Agent continue work from this conversation:

1. Search for and select one or more target Agents.
2. Optionally add instructions, such as “Turn this discussion into action items.”
3. Confirm the forward.

The conversation content is assembled into a new message and sent to a new topic for each selected Agent, triggering further processing. The original topic stays with its original Agent. Forwarding is neither a complete topic clone nor a public share. Consider the target Agents' models, tools, and associated usage costs.

### Move to Another Agent

To change where the topic belongs, choose **Move to another agent**, select the target Agent, and confirm.

The original topic leaves the current Agent's list and appears under the target Agent. Use the completion prompt to go there. Moving does not leave a second copy behind; duplicate or forward the topic if you need to keep it in both places.

## Export and Share

Choose **Export** from the topic menu to open the export window. You can also use **Share** in the top-right corner of the conversation. If a link-sharing panel opens first, select **Export** there.

| Format | Best for |
| --- | --- |
| **Screenshot** | Showing a conversation in messaging apps or on social media |
| **Text** | Editing, quoting, extracting content, and taking notes |
| **PDF** | Reports, study notes, and readable archives |
| **JSON** | Structured message data, analysis, and integrations |

Review the preview before exporting, including any system prompts, user messages, tool calls, and sensitive content. A conversation export is not a complete account backup or a package of every attachment and Agent setting.

### Screenshot Sharing

Export the conversation as an image with the following options:

- **Width mode** — Wide for desktop reading, narrow for mobile reading.
- **Agent profile** — Optionally include role-setting content such as the system prompt.
- **Footer** — Choose whether to include the information at the bottom.
- **Image format** — JPG, PNG, SVG, or WEBP.

Copy the image to the clipboard or download it to your device.

<Image alt={'Screenshot Sharing'} src={'/blog/assets196d679bc7071abbf71f2a8566f05aa3.webp'} />

### Text Sharing

Export text for copying, editing, or using as Markdown notes. Choose whether to include:

- **Agent profile** — Role-setting content such as the system prompt.
- **Message roles** — Labels identifying who sent each message.
- **User messages** — Keep or exclude the messages sent by the user, not just the user's name.
- **Tool messages** — Related tool messages and call details.

Copy the result to the clipboard or download a text file.

![Text Export Options](/blog/assetsa8e173bec038d1d21d413f6fa0ace342.webp)

### PDF Sharing

Export a PDF for reading, reporting, or archiving. As with text export, you can choose whether to include the Agent profile, message roles, user messages, and tool messages.

Choose the content to include and select **Generate PDF**. Once it is ready, review the preview and select **Download PDF**. Regenerate the PDF after changing export options.

<Image alt={'PDF Sharing'} src={'/blog/assets7dccdd4df55aede71001da649639437f.webp'} />

### JSON Sharing

JSON export offers two modes:

- **Default** — LobeHub's structured topic and message data, including message identifiers, timestamps, roles, and related metadata.
- **OpenAI Compatible** — A simplified message format for further processing. Check the destination API's field requirements before integrating it.

Choose whether to include the system prompt from the Agent profile. JSON can include tool calls and tool messages, so inspect its contents before sharing. Copy the JSON to the clipboard or download it as a file.

## Shareable Links

If link sharing is available for your account and permitted for the Agent, open **Share** in the top-right corner of the conversation to set its visibility:

- **Private** — Only you can access this share link.
- **Anyone with the link** — Anyone who obtains the link can read the shared conversation. It is not an invitation restricted to named recipients.

### Publish or Revoke a Public Link

1. Open the **Share** panel.
2. Set visibility to **Anyone with the link**.
3. Review the privacy notice and check the entire conversation for credentials, keys, tool-call details, images, uploaded files, and other content that should not be public. Then confirm sharing.
4. Use **Copy Link** to get the share address and send it to others.
5. To stop public access, change visibility back to **Private**. This does not recall screenshots, text, or files that others have already saved.

If publishing is unavailable, check the permission message in the interface. Being able to export content does not necessarily mean you can publish a public link.

The shared page is for read-only access to the conversation; visitors cannot directly run your Agent's tools. Any links to explore or try an Agent are separate from continuing your original topic. To publish an Agent, see [Become a Creator](/docs/usage/community/become-a-creator).

## Delete a Topic

Choose **Delete** from the topic menu, review the prompt, and confirm. **Deletion is permanent and cannot be undone.** Export any content you still need first. Use archive instead if you only want to tidy the list.

If the confirmation includes **Also delete images and files uploaded in this topic**, check its selection before proceeding and decide whether those resources should also be removed.

### Check Documents and Browser State Before Deleting

[Agent Documents](/docs/usage/agent/agent-documents) manage documents created by an Agent. Documents can have Agent-level scope or be associated with the current topic. Check their scope and save a copy of content you still need before deleting the topic.

With the [built-in browser](/docs/usage/agent/built-in-browser), you can interact with web pages alongside a conversation. Closing or deleting a topic does not mean you have signed out of a website. Sign out on the website when necessary.
