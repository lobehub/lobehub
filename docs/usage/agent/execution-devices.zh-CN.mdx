# 执行设备

执行设备决定设备工具和编程助理实际在哪里完成工作。它与你发送消息时使用的界面是两件事。

你可以在支持相关功能的网页、桌面或手机界面中发送任务。可用工具与运行方式取决于所选设备和集成。

## 选择执行位置

| 选项 | 工作在哪里运行 | 需要检查什么 |
| --- | --- | --- |
| 本机 | 通过桌面应用连接的电脑 | 设备状态、项目路径、CLI 安装与权限 |
| 云沙箱 | 服务端的沙箱环境 | 可用工具、项目文件、运行时和导出支持 |
| 远程设备 | 另一台已连接的电脑 | 该电脑的连接状态、项目路径、CLI 安装与权限 |

可选方式取决于助理和工具。请在所选设备或云端环境中分别准备项目文件，并完成 CLI 登录。

浏览器配对是另一种连接方式，可将浏览器标签页接入为设备，无需安装桌面应用。可用工具与桌面设备有所不同。

## 选择设备与项目

1. 打开聊天输入框中的**执行设备**选择器。
2. 选择存有项目或支持所需任务的设备。
3. 如需检查设备，打开**管理**。
4. 检查设备名称、平台、访问范围与连接状态。
5. 在发出第一条项目任务前，将工作目录设为该设备上的项目路径。

设备详情面板会列出最近使用的目录。本机路径不一定存在于远程设备或云沙箱中。

工作目录告诉助理要处理哪个项目，但不会限制它的访问范围。文件访问还取决于工具、操作批准与操作系统权限。

连接设备与连接外部助理是两步操作：连接设备后，任务可以在该设备上运行；**创建助理 → 连接外部助理**扫描该设备并接入助理。完整流程见[连接外部助理](/zh/docs/usage/agent/connect-external-agents)。该向导使用本机桌面环境或已连接电脑，不会自动创建云沙箱。

## 连接设备

### 桌面端

桌面应用会自动注册你的电脑。开始工作前，在设备选择器中检查该设备。处理编程任务时，还需检查 CLI 安装与登录状态。

### 远程电脑

在实际执行任务的电脑上运行 `lh connect`，按已安装 CLI 显示的说明完成连接。

连接完成后，在设备选择器中选中该电脑。发送任务前，检查其状态和项目目录。

### 通过浏览器

连接浏览器标签页的步骤：

1. 打开**设备**页面。
2. 选择**通过浏览器**。
3. 生成配对码。
4. 按界面提示完成配对码交换。
5. 检查当前浏览器标签页是否已显示为设备。

这种配对方式不需要桌面应用。配对本身不会授予原生 Shell 执行权限或不受限制的文件访问权。

使用期间请保持标签页打开。发生中断后，先检查设备和任务状态，再继续发送任务。

## 连接故障与设备变更

- **设备不可用**：检查连接状态，以及提供连接的桌面应用、CLI 连接或浏览器标签页。
- **找不到项目**：检查所选设备上的路径，不要只检查显示聊天界面的电脑。
- **CLI 不可用**：检查执行设备上的 CLI 安装、进程可用的 `PATH` 和登录状态。
- **任务中断**：重试前检查任务状态、命令输出和文件改动，不要假定操作已回滚或已自动完成。
- **更换设备或目录**：重新检查项目和 CLI。编程助理的原会话不会随聊天记录自动迁移。

可通过**管理**查看已注册设备及可用的连接操作。切换设备前，请检查原设备上是否还有未完成的任务。

## 工具权限与项目发现

LobeHub 工具权限决定连接器直接运行、先询问，还是关闭。接入的编程助理还有自己的 CLI 权限，两层权限相互独立。

服务端运行的助理可在绑定目录中发现 `.agents/skills`、`.claude/skills`、`AGENTS.md` 和 `CLAUDE.md`。两个目录存放项目技能，两个 Markdown 文件存放项目说明。
