# 内置浏览器

内置浏览器让助理在侧边栏打开并操作网页。你可以观察操作过程，也可以手动接手。

## 区分三种功能

| 功能 | 用途 |
| --- | --- |
| 联网搜索 | 查找网络信息并读取检索到的网页 |
| 内置浏览器 | 打开网页并操作其中的控件 |
| 浏览器配对 | 将当前浏览器标签页连接为执行设备 |

浏览器配对本身不会启用内置浏览器。配对步骤见[执行设备](/zh/docs/usage/agent/execution-devices)。

## 助理能做什么

内置浏览器工具可用时，助理可以：

- 打开网址并读取页面内容
- 点击链接和按钮
- 填写文本字段和表单
- 截取页面截图
- 保持页面可见，供你手动接手。

例如，可以让助理读取产品页面、比较可见信息，或先填写表单供你审核。提交后，请检查网站是否显示成功确认。

## 开始浏览器任务

1. 确认当前助理与环境可使用内置浏览器工具。
2. 检查该工具的 LobeHub 权限。
3. 给助理一个网址和明确的任务。
4. 在侧边栏观察页面。
5. 遇到需要你输入的步骤时，手动接手。
6. 检查最终页面，再确认任务完成。

示例：「打开这个页面，读取套餐说明并总结。不要提交表单或购买。」

对于表单，请说明只允许填写，还是也允许提交。购买、发布、删除等会产生实际影响的操作，应先由你审核。

## 登录与手动接手

如果网站要求登录，请接手并自行输入凭据，不要把密码或验证码发到聊天里。

开始下一项任务前，请检查可见页面和当前账号。需要退出时，请使用网站的退出登录功能，而不是只切换或关闭话题。

## 可用范围与限制

可用性取决于当前助理和执行环境。开始前，可以检查内置浏览器工具是否可用。部分网站需要你手动登录或完成验证。
