# 语音输入

语音输入可以让你直接说出问题或想法，并以语音消息的形式发送给助手，无需打字。

目前，录音完成后会直接发送语音消息，**暂不支持将录音转换为消息框中可编辑的文字**。

## 发送语音消息

语音输入入口位于**助手页面消息框的右下角、发送键旁边**，图标为圆形声波图标。

1. 打开助手页面，在消息框右下角找到**语音输入**图标。
2. 点击图标；首次使用时，如果浏览器或系统请求麦克风权限，请允许访问。
3. 对着麦克风说出你想发送的内容，完成后按界面提示结束录音。
4. 录音完成后，内容会以**语音消息**发送。

如果需要在发送前反复修改内容，请改用文字输入。

## 录音建议

- 尽量在安静的环境中录音，减少背景噪音。
- 保持麦克风位置适当，以正常语速清晰地说话。
- 开始录音前先整理好要说的内容，避免遗漏重要信息。

## 无法使用麦克风时

如果点击语音输入后无法录音，请检查浏览器的网站权限和系统的麦克风隐私设置，确认当前浏览器或应用已获准使用麦克风。同时检查麦克风是否已连接、是否静音，以及是否选择了正确的输入设备。

## 隐私提醒

录音完成后会直接发送，请在开始前留意周围环境，避免录入密码、不宜分享的敏感信息或旁人的谈话。
