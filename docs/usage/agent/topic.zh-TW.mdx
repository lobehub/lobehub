# 話題

在 LobeHub 中，每次與助手的對話會形成一個話題。你可以搜尋、重命名、收藏、刪除話題，方便管理和查找歷史對話。

## 搜尋話題

在會話頁面，你可以搜尋與助手聊過的話題。進入會話，點擊話題列表的「更多」，通過搜尋話題快速找到需要的歷史對話。

![clipboard-1769000274218-d02c4c8024709.png](/blog/assets3cdf933016e6f53bca12b8cedb17061f.webp)

## 重命名話題

你可以為話題設定更有意義的名稱，方便識別。

- 手動重命名：找到要重命名的話題後點擊「重命名」，輸入新的話題名稱並即可儲存。
- 智慧重命名：找到要重命名的話題後點擊「智慧重命名」，系統會根據對話內容自動生成合適的名稱。

## 建立話題副本

你可以建立某個話題的副本，保留原對話的同時建立新的分支。找到要複製的話題後點擊「建立副本」，系統會建立一個完全相同的話題副本。適合在原對話基礎上嘗試不同的討論方向。

## 收藏話題

對於重要或常用的話題，可以點擊收藏按鈕進行收藏。找到要收藏的話題後點擊收藏按鈕，話題會被標記為收藏。收藏的話題會顯示在話題列表的「收藏」列表裡，方便快速存取。\[Image]

![clipboard-1769000328858-48f0503640245.png](/blog/assets04d6fae3d9aa3c33697028f1cc9f4706.webp)

## 刪除話題

不需要的話題可以刪除。找到要刪除的話題後點擊「刪除」，確認刪除後話題將被移除。話題列表話題列表按時間組織，方便查找不同時期的對話。收藏列表：顯示所有收藏的話題。時間列表：其他話題預設根據建立時間自動分組，展開對應時間的列表，可以查看該時間段的所有話題。如果不想使用時間分組，可以選擇「不分組」。

## 話題列表

話題列表按時間組織，方便查找不同時期的對話。

- 收藏列表：顯示所有收藏的話題。
- 時間列表：其他話題預設根據建立時間自動分組，展開對應時間的列表，可以查看該時間段的所有話題。

如果不想使用時間分組，可以選擇「不分組」。
