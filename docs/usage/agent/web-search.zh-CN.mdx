# 网络搜索

通过网络搜索，助理可以查询当前新闻、价格、文档，以及训练数据之外的信息。执行搜索后，助理会在回答中引用使用的来源。

## 网络搜索能做什么

开启网络搜索后，助理可以：

- 访问实时信息 —— 当前新闻、价格和时事
- 对照最新来源核实信息
- 引用参考的网页来源
- 同时从多个来源研究某个主题
- 回答训练数据之外的近期事件问题

## 工作原理

当你提出需要实时信息的问题时：

1. 助理将你的问题转化为搜索词
2. 在互联网上执行搜索
3. 检索并分析相关来源
4. 将查到的信息整理为回答
5. 在回答中附上来源引用

开启 Web Search 后，助理可以按问题需要搜索；你也可以明确提出搜索请求。搜索执行仍需相应服务可用且权限许可。

## 搜索依据显示

使用网络搜索时，AI 回复上方会出现一个可折叠的**搜索依据**卡片，显示：

- **来源数量** — 参考了多少个网页来源
- **网站图标预览** — 来源网站的图标
- **可展开的搜索词** — AI 实际使用的搜索词（点击展开查看）
- **引用来源** — 来源标题、域名和可点击的 URL

展开依据卡片，可以查看信息的确切来源，并自行评估来源的可信度。

## 启用网络搜索

在助理聊天输入框下方开启 Web Search，无需进入助理设置，也无需安装技能包。

1. 点击助理聊天输入框下方的 **+**。
2. 开启 **Web Search**。
3. 在搜索选项中选择 **Smart Search** 或 **Provider Search**。
4. 输入问题。需要最新信息时，说明搜索范围与时间。

### 两种搜索模式

| 模式                  | 说明                                |
| ------------------- | --------------------------------- |
| **Smart Search**    | LobeHub 优化的搜索服务，用于改善检索结果。         |
| **Provider Search** | 服务商侧的搜索模式。界面提示开启后可能出现非预期行为，不推荐使用。 |

**Off** 是关闭状态，不是第三种搜索模式。选择 **Off** 即可关闭 Web Search。

如果没有执行搜索，请检查 Web Search 是否开启、搜索工具权限和搜索服务配置。

### 网络搜索、浏览器与站内搜索

| 功能               | 用途                          | 范围与限制                           |
| ---------------- | --------------------------- | ------------------------------- |
| **网络搜索**         | 通过搜索服务查找互联网信息，并读取可访问的网页作为依据 | 不等于操作已登录的浏览器                    |
| **浏览器工具**        | 打开网页、点击、填写表单，或与动态页面交互       | 需要相应浏览器工具、执行环境和权限，这些工具和权限需要单独配置 |
| **LobeHub 站内搜索** | 查找助理、话题、页面等 LobeHub 内部内容    | 搜索范围是有权限访问的站内内容，不是互联网           |

查找文件或知识库资料时，请使用相应的搜索工具，并检查访问权限。技能可以指导研究步骤，搜索工具仍需单独启用。

<Callout type={'info'}>
  内置网络搜索在客户端无需安装市场插件或 MCP。**自托管部署**仍需配置服务端搜索提供商（默认 SearXNG，
  依赖 `SEARXNG_URL` / `SEARCH_PROVIDERS`）—— 见
  [在线搜索](/zh/docs/self-hosting/advanced/online-search)。LobeHub Cloud 托管环境已预置好。
</Callout>

### 可选：基于 MCP 的搜索工具

如果你希望使用特定的搜索后端（如 Brave Search、Google Search、DuckDuckGo、AnySearch 等），或希望自行配置搜索服务，也可以在**设置 → 连接器**中额外连接搜索类 MCP 服务器。这是可选项，独立于内置网络搜索；它仍需服务授权、助理启用和工具策略许可。参阅 [MCP 市场](/zh/docs/usage/community/mcp-market)。

AnySearch 的远程 MCP 地址是 `https://api.anysearch.com/mcp`，可匿名使用，并提供垂直领域搜索、领域发现、并行批量搜索和网页内容提取。如果配置 AnySearch API Key，请将 Bearer Token 保存在连接器认证设置中。

## 使用网络搜索

### 自动搜索

开启 Web Search 后，最新信息类问题可以触发联网搜索；并非每条消息都会执行搜索：

```
"比特币现在的价格是多少？"
"最近一届世界杯的冠军是谁？"
"AI 领域最新进展是什么？"
```

### 明确搜索请求

你也可以主动要求网络搜索：

```
"搜索 iPhone 15 的最新评测"
"查一下气候变化的最新研究"
"查找加州当前的房贷利率"
```

### 追问深挖

每次搜索都建立在对话上下文之上。你可以继续追问，逐步缩小范围：

```
"2024 年最流行的编程语言有哪些？"
→ "搜索 Python 开发者的就业市场趋势"
→ "查找欧洲高级 Python 工程师的薪资数据"
```

## 使用场景

**研究与资讯** — 获取新闻、市场、金融和学术领域的最新信息。「\[主题] 最新进展」「\[话题] 近期论文」「X 的当前股价」。

**技术信息** — 访问最新文档、API 变更、包发布和 Bug 修复讨论。对于迭代快速的框架尤其有用，因为训练数据可能已经过时。「React 19 有什么新特性？」「查找 \[具体错误] 的解决方案」。

**产品研究** — 比较当前价格、查找最新评测、发现替代方案。「比较最新 MacBook 型号」「200 美元以内降噪耳机评测」。

**出行规划** — 获取旅游、活动和本地推荐的实时数据。「现在奥斯汀最好的餐厅」「巴黎当前的博物馆展览」「2025 年科技大会」。

## 理解引用来源

网络搜索回复可附带引用信息，建议查看：

- **来源标题** — 页面或文章名称
- **域名** — 托管信息的网站
- **URL** — 点击访问原始来源
- **相关摘要** — 所用内容的预览

**核实重要信息**：点击来源链接，查看原文。对时效性强的内容，可以检查发布日期，并判断来源是新闻媒体、官方文档、学术论文，还是博客和论坛帖子。对于关键事实，可以比较多个来源；如果只有一个来源提到某项结论，值得进一步核实。

## 获得更好搜索结果的技巧

**具体表述** —「2024 年 11 月有哪些最新 LLM 发布？」比「告诉我关于 AI 的事」更能明确搜索范围。

**加入时间上下文** — 添加「最近」「最新」「当前」或具体日期，以获取及时的结果。

**要求比较** — 「比较 X 和 Y」或「Z 的优缺点是什么」 往往能触发有价值的多源搜索。

**查看引用来源** — 可以展开搜索依据卡片，查看参考了哪些来源并判断其质量。

**追问深挖** — 继续追问，从整体概况逐步深入到具体细节。

## 隐私提示

<Callout type={'warning'}>
  网络搜索可能会被你配置的搜索提供商记录日志。请避免搜索敏感信息或涉及个人隐私的内容。
</Callout>

搜索词会发送给你配置的搜索提供商。当你点击引用来源时，目标网站也可能追踪你的访问。具体隐私处理方式请参阅所选搜索提供商的隐私政策。

## 功能限制

- **付费墙内容** — 无法访问订阅制内容（如部分学术期刊、付费新闻网站）
- **极近期事件** — 非常新的信息（数小时内）可能尚未被索引
- **地区限制内容** — 部分来源可能受地区访问限制
- **响应延迟增加** — 网络搜索会为响应增加几秒钟的延迟
- **创意与个人任务** — 纯创意写作或个人建议类问题不适合网络搜索 —— 它适用于有事实依据的问题
- **Token 用量** — 搜索结果会占用额外的上下文 Token
- **频率限制** — 部分搜索服务商有用量限制
- **逐秒变化的数据** — 不适合实时股票行情等每秒变化的数据
- **未索引的内容** — 无法访问搜索引擎尚未索引的内容

<Callout type={'info'}>
  客户端启用内置网络搜索时无需安装技能包或 MCP。自托管服务端仍需配置搜索提供商（见
  [在线搜索](/zh/docs/self-hosting/advanced/online-search)）。可选 MCP 搜索后端可能需要自行申请
  API Key 或订阅。
</Callout>
