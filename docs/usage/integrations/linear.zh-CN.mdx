# Linear 集成

**Linear 集成把一个 Linear 工作区连接到 LobeHub。** 你通过 Linear OAuth 授权一次，连接就会保存在你的账号或工作区下。

LobeHub 只申请 **只读** 权限。这个连接用来识别你的 Linear 工作区和授权的用户，并在你导入时读取 Issue，不能创建或修改 Issue。

> \[!NOTE]
>
> 集成目前是 Alpha 功能。先在 **设置 → 实验室 → 集成** 中开启，设置里才会出现 **集成**。
>
> 想让 Agent 在会话中查找和更新 Linear issue，请使用 Linear 连接器，见 [连接器](/docs/usage/agent/connectors)。

## 连接 Linear

1. 打开 **设置 → 集成 → Linear**。
2. 点击 **连接工作区**，Linear 会打开授权页面。
3. 选择要连接的 Linear 工作区，然后批准授权。
4. Linear 会带你回到 LobeHub，页面提示 **已连接 Linear：\<工作区>**。

连接后的工作区会出现在 **连接** 中，显示是谁、在什么时候连接的。要前往该工作区，在右侧菜单中选择 **在 Linear 中打开**。

在 LobeHub 工作区中，连接属于该工作区。只有具备编辑权限的工作区成员才能连接或断开 Linear。

## 将 Issue 导入为任务

把 Linear 的 Issue 导入为某个 LobeHub 项目的任务，在这里继续处理。同步是 **单向** 的：LobeHub 只读取 Linear，不会修改、关闭或删除任何 Issue。

同步在项目中进行，所以要先按上文连接 Linear 工作区；同一账号或工作区下的所有项目都可以使用这个连接。

1. 打开项目，进入 **设置 → 高级设置**，在 **从 Linear 同步** 中点击 **导入 Issue**。项目 **任务** 页顶部的 Linear 图标也会打开同一个弹窗。连接了多个 Linear 工作区时，先选择其中一个。
2. **选择范围**：选择 **Linear 团队**，也可以再选择其中一个 **Linear 项目**；状态默认只勾选未关闭的，不包含已完成和已取消的。点击 **下一步**。
3. **选择 Issue**：列表显示符合范围的 Issue，已同步的会标出对应的任务编号。然后任选其一：
   - 勾选需要的 Issue，点击 **导入 N 个 Issue**；
   - 点击 **保存为规则并全部同步**，导入所有符合条件的 Issue，并把范围保存为同步规则。
4. **同步**：同步在后台进行，弹窗会显示进度和结果（新建、更新、关闭、跳过的数量及原因）。可以点击 **后台继续** 关闭弹窗，同步结束时会收到提示，结果也会记在 **高级设置** 的 **同步记录** 中。

每个 Issue 对应一个任务：Issue 标题成为任务名称，描述成为任务指令（附原 Issue 链接），优先级保持不变。子 Issue 和父 Issue 在同一项目中时，子任务会挂在父任务下。评论、附件、负责人和标签不会导入。

### 再次同步

项目保存的规则列在它的 **设置 → 高级设置** 页的 **同步规则** 中，点击 **立即同步** 即可在后台再次运行，进度和结果显示在 **同步记录** 中。再次导入已关联的 Issue 效果相同。同步时：

- 更新该 Issue 已对应的任务，不会重复创建；导入列表会在这类 Issue 旁显示绿色对勾和任务编号。同一账号或工作区中一个 Issue 只对应一个任务，已同步到其他项目的 Issue 仍保留在原项目；
- 保留你的修改：在 LobeHub 中改过名称、指令或优先级的任务，不再被覆盖；
- Issue 在 Linear 中完成或取消后，对应任务也会关闭；正在运行的任务不会被打断；
- 不会重新打开或删除任务；已移入回收站的任务会被跳过。

一次同步最多新建 100 个任务。还有待导入的 Issue 时，结果中会提示，再次同步即可继续。

删除规则只会删除保存的筛选条件，已创建的任务会保留。删除项目时，它的规则也会一起删除。

## 断开 Linear

1. 在 **连接** 中打开工作区右侧的菜单，选择 **断开连接**。
2. 确认后，LobeHub 会请求 Linear 撤销访问令牌，并把该工作区从 **连接** 中移除。

撤销是尽力而为的：如果 Linear 暂时无法访问，工作区仍会被移除，但令牌可能仍然有效。要确保访问已终止，请同时在 Linear 设置的已授权应用中撤销 LobeHub。

## 常见问题

| 提示                                | 处理方式                         |
| --------------------------------- | ---------------------------- |
| **已在 Linear 上取消授权。**              | 再次点击 **连接工作区** 并批准授权。        |
| **连接请求已过期**                       | 从 **连接工作区** 重新开始，每次请求只能使用一次。 |
| **Linear 已授权，但 LobeHub 未能保存此次连接** | 再次点击 **连接工作区**。              |
| **只有工作区成员可以在此连接 Linear。**         | 请工作区所有者或管理员给你成员角色，或在个人账号下连接。 |
| **当前部署未配置 Linear 应用**             | 见 [自托管部署](#自托管部署)。           |
| **Linear 连接已失效**                  | 点击 **连接工作区**，重新授权同一工作区后再试。   |

## 自托管部署

自托管部署需要配置 Redis（`REDIS_URL`）来保存短期的连接请求，没有 Redis 时 **连接工作区** 会失败。此外还需要创建自己的 Linear OAuth 应用：

1. 在 Linear 中进入 **Settings → API → OAuth applications**，创建一个应用。
2. 把回调地址设为 `<APP_URL>/api/webhooks/linear/oauth/callback`，`<APP_URL>` 是你的 LobeHub 地址，必须与 `APP_URL` 完全一致。
3. 在服务端设置 `LINEAR_CLIENT_ID` 和 `LINEAR_CLIENT_SECRET` 为该应用的 Client ID 和 Secret，然后重启 LobeHub。
