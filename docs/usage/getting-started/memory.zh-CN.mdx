# 记忆

启用记忆后，助理可以保存与你相关的背景和偏好，并在后续对话中按需使用，减少重复说明。

记忆会整理你的身份、工作背景、偏好和习惯。你可以随时查看和修改这些内容。

## 记忆可以怎样帮助你

未启用记忆时，你可能需要：

- 你不断重复上下文
- 助理在不同会话间忘记你的偏好
- 再次说明希望采用的格式或语气

启用后，助理可以结合已保存的内容调整回答。你也可以定期回看并修正记忆。

## 记忆如何保存和使用

记忆会按以下流程工作：

1. **对话分析** — 在你与助理交互时，记忆助理识别有价值的洞见：明确的偏好、隐含的规律、项目背景以及沟通风格。
2. **保存记忆** — 相关信息会整理为偏好、事实或背景等条目。
3. **回看和修改** — 你可以搜索、编辑或删除已保存的条目。新旧信息冲突时，可以直接修改对应记忆。
4. **用于后续对话** — 当记忆与当前问题相关时，助理可以参考它来回答。

### 回看与管理

自动提取会保存对话中有用的背景信息。你可以在记忆面板中回看和编辑已保存的条目、删除不想保留的内容，也可以手动添加记忆。

## 记忆类型

**个人偏好** — 你的工作和沟通习惯：回复长度、技术深度、语气、格式偏好以及工作时间。

**个人背景** — 你的身份和当前状态：职位、所在组织、团队、进行中的项目以及关键干系人。

**技能与知识** — 你已掌握的内容和正在学习的领域。有助于助理根据你的水平调整解释方式。

**规律与习惯** — 反复出现的行为和工作流程：每周例会、常见请求、决策标准以及典型项目流程。

**历史背景** — 过去的项目和决策：经验教训、以往选择的理由以及关键合作者信息。

## 理解助理记忆

助理记忆是 LobeHub 的内置插件。它自动从你与助理的对话中识别并提取关键信息，形成结构化的记忆库。助理会在后续对话中按需参考这些记忆。记忆保存的是背景和偏好摘要，不是逐字聊天记录。

![助理记忆界面](/blog/assets6ebefe8183f31de4de5bac1a921fb153.webp)

## 启用记忆

记忆是内置插件，需要为每个助理单独启用。你可以从助理档案页面启用，也可以在对话中直接开启。

### 从助理档案启用

进入助理档案页面，点击 **+ 添加插件**，勾选**记忆**插件即可启用。

![从助理档案添加记忆插件](/blog/assets27b2bf8596f8e65d545322c66a0d81a2.webp)

### 在对话中启用

打开一个对话，点击输入框下方的插件图标，勾选**记忆**插件即可激活。

![在对话中启用记忆插件](/blog/assets07820089deb72e5636024ae7e3d1855f.webp)

## 管理记忆

### 查看记忆

点击左侧边栏底部的**记忆**图标，打开记忆管理面板。该面板展示从对话中提取的所有记忆，按类型分类。每条记忆包含：

- **标题** — 对记忆核心内容的简洁概括，例如 「不喜欢咖啡」
- **偏好权重** — 表示该记忆的重要程度。权重越高，助理在对话中越会优先考虑它
- **创建时间** — 该记忆从哪次对话中提取
- **记忆指令** — 从对话中得出的行为规则，例如：「除非用户主动要求，否则避免推荐咖啡；建议无咖啡因替代选项」
- **助理可能的行动** — 助理如何应用该记忆，例如：「根据场景提供茶、热巧克力、果汁或无咖啡因选项」
- **标签** — 便于分类和搜索

![记忆管理面板](/blog/assetseb9b70814679291052dfa4618a44a856.webp)

### 搜索记忆

记忆条目较多时，使用搜索功能快速定位。你也可以随时打开命令菜单搜索记忆。

### 编辑记忆

修改从对话中生成的记忆指令，使其更准确地反映你的实际需求和偏好。

![编辑记忆](/blog/assetsd6eba2b1881977c9533ba86c1cd3dfce.webp)

### 删除记忆

选中要删除的记忆，点击删除按钮即可。

![删除记忆](/blog/assetse14ddb728d66905c164664b8b5e044d3.webp)

## 记忆助理

**记忆助理**是专门管理个人记忆的内置助理：

- **记忆提取** — 分析对话，识别值得记忆的有价值洞见
- **记忆整理** — 对记忆进行分类和结构化，便于检索
- **记忆维护** — 识别过时或冲突的记忆，并提议更新
- **记忆应用** — 判断何时将相关记忆注入助理上下文

你可以直接与记忆助理对话，请求添加、更新或查阅记忆。提出修改请求后，请到记忆面板核对是否已保存：

- 「记住我更喜欢上午开会，而不是下午。」
- 「你记住了我当前项目的哪些内容？」
- 「更新我的职位：我现在是产品副总裁，不再是高级产品经理了。」
- 「你记住了我在沟通风格方面的哪些偏好？」

## 高效使用记忆

### 快速入门

首次使用 LobeHub 时，主动帮助助理了解你：

- 分享你的职位、团队和当前优先事项
- 明确表达偏好（「我更喜欢用项目符号而非段落」）
- 手动添加重要事实，并核对已保存的条目是否准确

### 在后续对话中使用记忆

建立初始背景后，你可以照常与助理对话。相关记忆可以帮助助理：

**没有记忆时：**

- 助理询问：「你想要什么格式？」 / 「干系人有哪些？」 / 「应该包含哪些章节？」

**有了记忆后：**

- 使用你偏好的模版
- 加入你经常需要的章节（如用户研究）
- 在相关任务中参考已保存的干系人信息

### 持续完善记忆

你可以随时更新记忆：

- 当助理理解有误时，纠正它：「其实，我更喜欢 X 而不是 Y。」 随后到记忆面板核对，必要时直接编辑条目。
- 当情况发生变化时，告知助理：「我现在除了 Web 端，还接管了移动端团队。」
- 每月检查一次记忆面板 —— 删除过时条目，添加新信息。

## 隐私与控制

通过记忆面板回看、编辑、删除或清空已保存的条目。避免将密码、财务细节或其他敏感信息存入记忆。

需要移除已保存的信息时，可以在记忆面板中删除。清理个人信息时，还可以同时检查对话历史。

有关存储、访问权限、共享及模型训练的政策，请查阅所用服务的隐私条款，或咨询部署管理员。

## 最佳实践

- **从关键背景开始** — 首次使用时与记忆助理对话：「让我介绍一下我自己和我的工作方式。」 涵盖职位、当前优先事项、沟通偏好和常见工作流程。
- **明确表达偏好** — 「我的 PRD 总是包含竞品分析章节」比「加上竞品分析」更容易作为长期偏好保存。
- **立即纠正错误** — 当助理记错时，说：「不对，我更喜欢 X 而不是 Y。」 随后核对已保存的条目，若仍不准确，请直接编辑。
- **每月回顾记忆** — 删除过时背景，更新已变更的偏好，添加新的重要信息。
- **不要存储敏感数据** — 避免存储密码、财务信息或高度私密的个人内容。记忆适合用于工作偏好、职业背景和一般规律。
