# Lobe AI

Lobe AI is LobeHub's built-in assistant. It's available the moment you open LobeHub — no configuration needed. Use it for everyday tasks, quick questions, or deep research sessions.

## What You Can Do

- **Code** — Review snippets, generate boilerplate, debug errors, explain unfamiliar code
- **Research** — Search the web, summarize articles, compare options, cite sources
- **Write** — Draft emails, polish documents, brainstorm ideas, generate outlines
- **Analyze** — Process data, build reports, visualize results, interpret findings
- **Create** — Generate images, produce audio, render artifacts directly in the conversation

## Built-in Skills

Lobe AI supports the same Skills as any custom Agent. Enable them in the conversation to extend what it can do:

| Skill                                      | What it does                                      |
| ------------------------------------------ | ------------------------------------------------- |
| [Web Search](/docs/usage/agent/web-search) | Search the internet in real time                  |
| [Artifacts](/docs/usage/agent/artifacts)   | Render code, charts, and rich content inline      |
| [Notebook](/docs/usage/agent/notebook)     | Save and organize notes from the conversation     |
| [GTD](/docs/usage/agent/gtd)               | Manage tasks using the Getting Things Done method |
| [Sandbox](/docs/usage/agent/sandbox)       | Run and test code in an isolated environment      |

## When to Use a Custom Agent Instead

Lobe AI is a great starting point, but a [custom Agent](/docs/usage/getting-started/agent) is worth setting up when you need:

- A persistent system prompt (specific role, tone, or domain expertise)
- A dedicated knowledge base or long-term memory
- A fixed set of Skills always enabled
- A shareable, reusable assistant for your team
