# Lobe AI

Lobe AI is LobeHub's built-in Agent. Open LobeHub and start a conversation without entering API keys or configuring an Agent. You can ask a question, get help with an error, or draft a presentation outline.

## What You Can Do

**Code**

Share the relevant code and error message. Lobe AI can explain the problem and walk you through a fix.

**Research**

Ask Lobe AI to compare three cloud providers for a migration. It can search the web, compare pricing and limits, explain trade-offs, and cite sources for you to check.

**Write**

Describe the goal and audience for an email, blog post, or cover letter. Lobe AI can draft it and help you revise the wording.

**Analyze**

Lobe AI can analyze spreadsheet data, identify patterns, and show visualizations as Artifacts in the conversation. You can export the result or take a screenshot.

**Create**

You can ask Lobe AI to generate images, audio, and visual Artifacts, such as a landing-page image, a documentation diagram, or a demo audio clip.

## Tools, Skills, and Connectors

You can add tools and skills to Lobe AI in the same way as custom Agents. Use [Connectors](/docs/usage/agent/connectors) to add tools and skills, check authorization, and choose Pinned, Auto, or Disabled. Web search and execution environments also have their own controls.

| Capability | Purpose |
| --- | --- |
| [Connectors](/docs/usage/agent/connectors) | Explore LobeHub built-in capabilities, community skills, MCP integrations, and services |
| [Task Tools](/docs/usage/agent/connectors#task-tools) | Manage tasks, dependencies, and execution configuration through chat |
| [Documents](/docs/usage/agent/connectors#documents) | Create and maintain agent documents |
| [Artifacts](/docs/usage/agent/connectors#artifacts) | Create previewable pages, SVG graphics, and interactive components |
| [Image Generation](/docs/usage/agent/connectors#image-generation) | Use available image-generation models |
| [Web Search](/docs/usage/agent/web-search) | Retrieve information from the web |
| [Sandbox](/docs/usage/agent/sandbox) | Run code in an available isolated environment |

## When to Create a Custom Agent

If you often reuse the same coding style, brand guidelines, or Skills, a custom Agent can keep those settings ready for future work.

When you [create a custom Agent](/docs/usage/getting-started/agent), you can save its system prompt, knowledge base, preferred Skills, and Memory for use across conversations.

|                    | Lobe AI               | Custom Agent                              |
| ------------------ | --------------------- | ----------------------------------------- |
| **Setup**          | None, ready instantly | You define the profile                    |
| **System prompt**  | General-purpose       | Tailored to a role, tone, or domain       |
| **Knowledge base** | Shared                | Dedicated per Agent                       |
| **Memory**         | Shared                | Per-Agent, persistent                     |
| **Skills**         | Toggle on demand      | Pre-configured, always on                 |
| **Sharing**        | —                     | Publishable to the Community |
