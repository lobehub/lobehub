# 獲取 LobeHub

## 在瀏覽器中使用 LobeHub

你可以存取 [app.lobehub.com](https://app.lobehub.com) 在瀏覽器中使用 LobeHub。

## 安裝 macOS App

前往[下載頁](https://lobehub.com/download)即可下載 macOS App。

目前不支援在 App Store 下載。

## 安裝 Windows App

前往[下載頁](https://lobehub.com/download)即可下載 Windows App。

目前不支援在 Windows Store 下載。

## 安裝 Android App

前往[Google Play](https://play.google.com/store/apps/details?id=com.lobehub.app)即可下載 Android App。

或者，前往[下載頁](https://lobehub.com/download)下載 APK 檔案，然後手動安裝。

## 安裝 iOS App

前往[App Store](https://apps.apple.com/app/id6471212236)即可下載 iOS App。
