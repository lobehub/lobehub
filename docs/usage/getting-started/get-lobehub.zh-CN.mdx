# 获取 LobeHub

LobeHub 随你所在 —— 浏览器、桌面或手机均可使用。同一账号登录，助理、文稿和记忆在所有设备间同步。

## 在浏览器中使用

无需安装。在任意现代浏览器中打开 [app.lobehub.com](https://app.lobehub.com)，即可开始使用。数据同步至云端，可随时切换设备。

**适合：** 快速访问、安装前试用，或在共享 / 受限电脑上使用。

## 桌面端应用

### macOS

前往[下载页](https://lobehub.com/download)下载原生应用。目前不支持在 Mac App Store 下载。

**优势：** 离线访问工作空间、系统级集成、独立窗口专注工作。

### Windows

前往[下载页](https://lobehub.com/download)下载。目前不支持在 Microsoft Store 下载。

**优势：** 与 macOS 相同 —— 原生体验，支持离线使用。

## 移动端应用

### iOS

前往 [App Store](https://apps.apple.com/app/id6471212236) 下载。使用 LobeHub 账号登录，即可在手机上访问助理和对话。

**适合：** 语音对话、快速查看、外出时回顾输出内容。

### Android

前往 [Google Play](https://play.google.com/store/apps/details?id=com.lobehub.app) 下载，或从[下载页](https://lobehub.com/download)获取 APK 手动安装。

**适合：** 与 iOS 相同 —— 随时随地访问你的工作空间。
