# Lobe AI

Lobe AI 是 LobeHub 的内置助理。打开 LobeHub 即可开始对话，无需填写 API Key 或配置助理。你可以提出问题、请它帮忙分析错误，或起草演示大纲。

## 能做什么

**编程**

发来相关代码和错误信息，Lobe AI 可以解释问题，并引导你逐步修复。

**研究**

例如，可以请 Lobe AI 为迁移项目比较三家云服务商。它可以联网搜索、比较定价和限制、说明取舍，并附上来源供你核实。

**写作**

写邮件、博客文章或求职信时，说明目标和受众，Lobe AI 可以帮你起草并修改措辞。

**分析**

Lobe AI 可以分析表格数据、查找规律，并在对话中以 Artifact 展示图表。你可以导出结果或截图保存。

**创作**

你可以让 Lobe AI 生成图片、音频和可视化 Artifact，例如落地页主图、文档流程图或演示音频。

## 工具、技能与连接器

你可以像配置自定义助理一样，为 Lobe AI 添加工具与技能。在[连接器](/zh/docs/usage/agent/connectors)中添加所需工具与技能，检查授权并选择固定、自动或禁用。网页搜索和执行环境还有各自的设置入口。

| 工具或功能 | 用途 |
| --- | --- |
| [连接器](/zh/docs/usage/agent/connectors) | 了解 LobeHub 内置工具、社区 Skills、MCP 和第三方服务 |
| [任务工具](/zh/docs/usage/agent/connectors#task-tools) | 通过对话管理任务、依赖和执行配置 |
| [文档](/zh/docs/usage/agent/connectors#documents) | 创建和维护助理文档 |
| [Artifacts](/zh/docs/usage/agent/connectors#artifacts) | 创建可预览的网页、SVG 和交互组件 |
| [图片生成](/zh/docs/usage/agent/connectors#image-generation) | 调用可用的图片生成模型 |
| [网络搜索](/zh/docs/usage/agent/web-search) | 检索互联网信息 |
| [沙盒](/zh/docs/usage/agent/sandbox) | 在可用的隔离环境中运行代码 |

## 什么时候该创建自定义助理

如果经常使用相同的编码风格、品牌指南或技能，可以用自定义助理保存这些设置，方便后续使用。

[创建自定义助理](/zh/docs/usage/getting-started/agent)后，你可以保存它的系统提示词、知识库、常用技能和记忆，在不同对话中继续使用。

|           | Lobe AI   | 自定义助理          |
| --------- | --------- | -------------- |
| **配置**    | 无需配置，即刻可用 | 由你定义助理档案       |
| **系统提示词** | 通用        | 针对特定角色、语气或领域定制 |
| **知识库**   | 共享        | 每个助理独立配置       |
| **记忆**    | 共享        | 按助理独立，持久保存     |
| **技能**    | 按需开启      | 预配置，始终启用       |
| **分享**    | —         | 可发布到社区      |
