# Getting LobeHub

You can use LobeHub on the web, desktop, and mobile. Sign in with the same personal account to access your cloud content. Files stored only on a device do not sync automatically.

## Platform Overview

| Platform | Get it | Notes |
| --- | --- | --- |
| **Web** | [Open LobeHub](https://app.lobehub.com) | No desktop installation required |
| **macOS** | [Official downloads](https://lobehub.com/downloads) | Choose Apple Silicon or Intel for your device |
| **Windows** | [Official downloads](https://lobehub.com/downloads) | Check current installers and system requirements |
| **Linux** | [Official downloads](https://lobehub.com/downloads) | Check the current Linux package |
| **iOS** | [Official downloads](https://lobehub.com/downloads) | Use the store link on the official page |
| **Android** | [Official downloads](https://lobehub.com/downloads) | Use the download channels on the official page |

Use the official download page to find the packages and store links available for your platform and region.

## Web

Open [LobeHub](https://app.lobehub.com) in a modern browser. Sign in with your account. Web access suits quick visits, trials before installation, and devices where you cannot install desktop apps.

The web interface can also control connected execution devices. Opening a page does not grant access to local files or a terminal.

## Desktop

Download the **macOS, Windows, or Linux** app from the [official download page](https://lobehub.com/downloads). Desktop suits sustained work, multiple tabs, and tasks that need local tools.

### Side-by-Side Work and Multiple Tabs

- **Work panel beside chat**: Manage Agent Documents and work in progress next to the conversation. The panel can collapse to leave more chat space. See the [April 20, 2026 changelog](/changelog/2026-04-20-daily-brief).
- **Desktop tabs**: Pin tabs or find overflow tabs in a dropdown. Each tab retains its work state when you switch away and return. See the [August 3, 2026 changelog](/changelog/2026-08-03-home-dashboard).

### Device Tools and Local Work

Desktop supports automatic device registration and an execution-device selector in the chat input. See the [May 31, 2026 changelog](/changelog/2026-05-31-drag-and-drop-skills).

Desktop can also install and run MCP connectors on your computer or local network. See the [August 3, 2026 changelog](/changelog/2026-08-03-home-dashboard).

Tool calls still depend on connector permissions, device status, dependencies, and operating-system permissions.

<Callout type="info">
  **Desktop does not mean fully offline.** Cloud models, sync, and online tools still require a network connection.
  The chat interface alone does not determine the execution location. See [Execution Devices](/docs/usage/agent/execution-devices)
  and [Feature Status and Availability](/docs/usage/feature-status).
</Callout>

## Mobile

Open the [official download page](https://lobehub.com/downloads) for current iOS or Android download channels. Sign in with the same personal account.

Mobile suits conversations on the go, reviews of Task results, and available voice features. For desktop tools, use a connected execution device.
