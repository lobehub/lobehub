# 资源库

资源库集中保存对话中上传的文档、AI 生成的图片和创建的文稿。你可以按项目整理这些内容，并在对话中引用需要的资源。

## 上传文件与助理文档库

上传文件属于资源库。助理为自身工作创建的笔记属于[助理文档库](/zh/docs/usage/agent/agent-documents)，两者的列表与作用范围不同。找不到上传文件时，可以到资源库中搜索。

## 资源的来源

- **对话上传** — 在与助理对话时上传的文件会自动保存到资源库。例如你上传一份 PDF 让助理总结，这份文件会保留在资源库中，下次可以继续使用。
- **AI 生成** — 在图像板块生成的图片会自动保存到资源库。你可以随时查看、下载、在对话和文稿中使用这些图片。
- **主动上传** — 你可以在资源库直接上传文件或文件夹，主动构建知识库。支持文档、图片、视频、音频等多种格式。
- **文稿创建** — 在文稿板块创建的文稿也会出现在资源库中，与其他资源统一管理。
- **Notion 导入** — 你可以将 Notion 中的内容导入到 LobeHub 资源库，打通两个平台的知识管理。

**进入资源库** — 在 LobeHub 主界面左侧边栏点击**资源**图标。

## 创建资源库

资源库可以按主题、项目、类型等方式组织。创建不同的资源库，让资源管理更有条理。

在资源库页面左侧面板点击**新建资源库**，输入资源库名称，添加简介（可选），点击新建即可。

![创建资源库](/blog/assets62f82cba03d5dcad5465ec6c626aeb05.webp)

### 上传文件夹

选择上传文件夹，可以批量上传整个文件夹的文件。

### 连接 Notion

在 Notion 选择文档并导出，再在**连接 Notion**页面选择导入 Notion ZIP 即可。导入后，你可以在 LobeHub 中继续编辑这些文档。

![导入 Notion 内容](/blog/assets99a30932374a5f6193de7c842a34850f.webp)

## 使用语义搜索

语义搜索可以找到含义相关但措辞不同的内容。例如，搜索「如何登录」时，也可能找到包含「身份验证」或「登入」的段落。

## 管理资源库

**文件分块** — 对长文档进行分块后，助理可以在问答时定位相关段落。文件状态显示处理完成后，即可用于检索。

### 批量操作

勾选多个文件，展开右上角菜单可以进行批量操作：将多个文件批量移入资源库、批量分块和批量删除文件。

![批量操作](/blog/assets8b75f09941172c3a8620617cddfb7a4b.webp)

### 支持的文件格式与限制

**支持的格式：**

- 文档：PDF、Word（.docx）、PowerPoint（.pptx）、Excel（.xlsx）、Markdown、纯文本（.txt）
- 图片：JPEG、PNG、GIF、WebP、SVG
- 音频：MP3、WAV、M4A、FLAC
- 视频：MP4、MOV、WebM
- 其他：CSV、JSON、HTML

每个文件的大小限制通常为 50 MB。对于超大文档，建议上传前拆分为较小的文件，以获得更好的搜索效果。

### 搜索最佳实践

- **具体表述** — 可以搜索「国际订单的退款条款是什么？」而不只输入「退款」
- **使用具体名词** — 例如「退订政策是什么？」
- **加入上下文** — 例如「Python 解析 JSON 的函数」
- **迭代搜索** — 首次搜索未找到目标时，尝试用不同措辞重新检索

### 跨功能协作

- **对话 + 资源库** — 在对话中引用资源，让助理读取相关内容
- **文稿 + 资源库** — 编写文稿时使用资源库中的素材
- **图像 + 资源库** — 将生成的图片保存到资源库，统一管理所有视觉素材

## 使用场景

- **技术文档** — 上传 API 文档、指南或规范，用自然语言提问
- **企业知识库** — 集中管理入职材料、政策文档和内部 Wiki，借助助理快速检索
- **客户支持** — 上传常见问题和产品文档，支撑准确的客服回复
- **研究调研** — 汇集论文和文章，让助理跨资源综合发现规律
