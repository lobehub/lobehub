# 記憶

傳統的 AI 每次對話都像第一次見面，你需要反覆說明相同的資訊。Agent 記憶功能讓助手真正瞭解你，從對話中自動識別和記住關鍵資訊，讓每次交流都更高效、更個性化。

這不是簡單的對話歷史記錄，而是智慧的知識提取和組織。助手會識別你的身分資訊、工作情景、個人偏好、實踐經驗，並將它們結構化存儲。下次對話時，助手能主動調用這些記憶，提供更貼合你需求的回答，就像一個真正瞭解你的工作夥伴。

## 理解 Agent 記憶

Agent 記憶是 LobeHub 的搭載插件。它能從你與助手的對話中自動識別和提取關鍵資訊，形成結構化的記憶庫。這些記憶會在後續對話中被助手主動調用，讓交流更加個性化和高效。助理不會簡單記錄對話內容，而是理解並提取關鍵資訊，形成可執行的記憶指令。在後續對話中，助理會根據問題調用相關記憶，提供更個性化的回答，避免重複詢問已知資訊，基於你的偏好調整輸出。

## 啟用 Agent 記憶

記憶是 LobeHub 的搭載插件，需要為助理啟用後才能使用。你可以在「助手檔案」頁面新增插件處啟用記憶插件，也可以進入會話，在對話框勾選插件處啟用記憶插件。在助理檔案中啟用

進入助理檔案頁面，點擊「+ 整合插件」，勾選「記憶」插件即可開啟。

![clipboard-1768961895831-d380de3507b63.png](/blog/assets27b2bf8596f8e65d545322c66a0d81a2.webp)

### 在會話中啟用

進入會話頁面，點擊對話框下方插件圖示，勾選「記憶」插件即可。

![clipboard-1768961929559-f1d7d74c54ca1.png](/blog/assets07820089deb72e5636024ae7e3d1855f.webp)

## 管理記憶

### 查看記憶

在 LobeHub 首頁左側邊欄下方點擊「記憶」圖示，進入記憶管理面板。這裡展示了助手從對話中提取的所有記憶。記憶面板按類型組織，方便查看和管理。每條記憶包含以下資訊：

- 記憶標題標題簡潔概括了記憶的核心內容，如 "Dislikes coffee"。
- 偏好權重顯示該記憶的重要程度，權重越高，助理在對話中越會優先考慮這條記憶。
- 建立時間顯示記憶是何時從對話中提取的。
- 記憶指令助理基於對話內容形成的行為指令，這是助理在後續對話中實際遵循的規則。例如："Avoid recommending coffee or coffee-based drinks unless the user explicitly asks for them; suggest non-coffee alternatives instead."
- 助理可能採取的行動展示助理如何應用程式這條記憶，例如："Offer tea, hot chocolate, juice, smoothies, or decaf/non-coffee options depending on context.
- 標籤記憶相關的標籤，方便分類和搜尋。

![clipboard-1768962259734-dc28b56340cb1.png](/blog/assetseb9b70814679291052dfa4618a44a856.webp)

### 搜尋記憶

當記憶數量較多時，可以使用搜尋功能快速定位。你也可以隨時呼出命令選單來查找記憶。

### 編輯記憶

你可以調整助手基於對話形成的記憶指令，讓記憶更準確地反映你的真實需求。

![clipboard-1768962379267-f580e519a03f2.png](/blog/assetsd6eba2b1881977c9533ba86c1cd3dfce.webp)

### 刪除記憶

選中想刪除的記憶，點擊刪除即可。
