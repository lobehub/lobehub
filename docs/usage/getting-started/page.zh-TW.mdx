# 文稿

LobeHub 提供專業的文稿編輯空間，讓你能專注於長文字創作。無論是技術文件、學習筆記、項目方案，還是博客文章，文稿功能都能滿足你的需求。支援 Markdown 格式，提供即時預覽，自動儲存每次編輯。

你可以隨時呼出 AI 助手參與編寫。助手不只是提供建議，還能直接在文稿中編輯內容 —— 潤色文字、補充段落、優化結構、新增示例。

## 理解文稿功能

文稿是 LobeHub 的搭載寫作空間，專為長文字創作和編輯設計。與對話功能不同，文稿提供了：

- 持久的創作空間：文稿獨立存在，你可以隨時回到文稿繼續編輯，內容永久儲存。
- 結構化的內容組織：支援完整的 Markdown 語法，讓你能用標題、列表、程式碼塊、引用等元素組織內容，呈現專業的文件效果。
- 靈活的檔案管理：建立、導入、重命名、複製 —— 完整的檔案管理功能，讓你高效組織所有文稿。

### 建立和導入文稿

## 新建文稿

在 LobeHub 主界面進入「文稿」，點擊「新建文稿」，或在主界面新建圖示的下拉選單處選擇「建立文稿」快速建立。建立完成後，即可開始編寫。文稿會自動儲存，你可以隨時關閉，下次繼續編輯。

### 導入 Markdown 檔案

如果你已經有現成的 Markdown 文件，可以直接導入。在文稿板塊點擊「上傳 Markdown 檔案」，選擇並上傳，檔案內容會自動載入到新文稿中，你可以立即開始編輯。

### 編輯文稿

文稿使用 Markdown 格式編輯。Markdown 是一種輕量級標記語言，用簡單的符號表示格式，讓你專注於內容。在文稿標題上方，可以為文稿新增 icon。icon 會顯示在文稿標題前。

### 命令面板

在編輯時按下 / 鍵，會呼出命令面板。這是一個快捷工具，讓你能快速插入各種格式元素。

![插入命令](/blog/assets7caf7e0d83b8a4f3d177283bb0bc55d1.webp)

### 與 Lobe AI 合作編輯

在編輯文稿時，點擊編輯器右側的 AI 助手圖示按鈕，助手面板會從右側滑出。面板與文稿並排顯示，你可以一邊編輯文稿，一邊與助手對話。

呼出助手面板後，預設使用「文稿助理」。這是專門為文稿編寫優化的助手，如果需要特定領域的專業幫助，可以在助手面板左上方切換到自己建立的助手。

助手可以直接在文稿中編輯內容。

### 管理文稿

在文稿列表，可以重命名文稿、建立副本、複製全文、刪除文稿。
