# Agent

在 LobeHub，你可以自由建立和定製 AI 助理 —— 翻譯助理記得你的術語偏好，編程助理熟悉你的程式碼風格，寫作助理瞭解你的表達習慣。通過設定提示詞、選擇模型、新增插件和關聯資源庫，你能打造真正符合需求的專屬助理。

本篇指南將詳細介紹如何建立和設定你的 AI 助理。

## 新建 AI 助理

新建助理有三種方式：使用 Agent Builder 智慧建立、從零開始打造專屬助理，或從社群快速新增。無論哪種方式，都能讓助理精準匹配你的工作需求。

### 使用 Agent builder 智慧建立

Agent Builder 是 LobeHub 的搭載助理，可以幫助你完成 AI 助理的建立。只需與 Agent Builder 對話，描述你的需求，它就能理解並自動生成完整的助理設定 —— 包括角色設定、系統提示詞、插件設定。

- 在首頁左側邊欄找到建立助理按鍵，或選擇對話框下方 「建立 Agent」 開始建立。
- 在助理檔案頁面右側，你可以和 Agent builder 對話，描述需求，完成智慧建立。
- 完成智慧建立後，你也可以手動進行調整。

![clipboard-1768963219814-ba3d14d1facf3.png](/blog/assets2964497066067ca0588a7767eb4c1709.webp)

### 建立自訂助理

自訂助理能最大程度地貼合你的習慣。你可以自行定製助理的頭像、名稱、提示詞，設定想使用的 AI 模型、插件，從而打造個人專屬 AI 助理。在助理檔案頁面手動完成定製即可。

### 從社群新增

如果想快速獲取設定完整的助理，可以選擇從社群直接新增 AI 助理。社群有大量種類豐富的優質助理 —— 設計專家、程式碼助理、文案策劃師、學術導師…… 新增即用。

- 首頁左側邊欄找到 「社群」→「助理」，或直接下滑主界面，找到「社群助理」。
- 選擇想新增的助理，點擊進入詳情界面瞭解具體資訊，點擊 「新增助理並會話」 即可完成新增。

![clipboard-1768963283361-5b62ccd3a1862.png](/blog/assetsbcd98b0913d2dfc30d5a2b5523115d33.webp)

### 設定 AI 助理

助理建立完成後，你可以通過新增插件和連結外部工作流來增強它的能力。插件讓助理獲得各種擴充功能功能，連結外部工作流讓助理能直接讀取或操作你的更多常用工具。強化 AI 助理能夠極大程度優化你的工作流程。

### 編輯助理資訊

你可以隨時編輯助理的任何資訊，讓它持續跟隨你的腳步。選擇助理進入會話，選擇左側邊欄「助理檔案」即可編輯。

### 新增插件和連結工具

為助理新增插件，連結其他工具，能夠讓你們的配合更加高效。

選擇助理進入會話，選擇左側邊欄「助理檔案」→「+ 整合插件」。

![clipboard-1769050642741-4b72fd17934cf.png](/blog/assetsdc6362a2c6db476fc1b7b9d6bf443af2.webp)

### 關聯資源庫

在會話中為助理關聯資源庫後，助手能基於你的資源庫提供更精準、更個性化的回答。

進入會話頁面，找到相應按鍵即可選擇資源庫進行關聯。

![clipboard-1769050621749-3709f9939d7d4.png](/blog/assetsc89931ace11a936d87d0b87a6bca1069.webp)

## 管理 Agent

助手和群聊數量過多時，分組是最直觀的管理方式，能夠讓助手列表更加簡潔清晰，切換助手更加輕鬆。

### 建立分組

在 LobeHub 首頁助手列表選單選擇「新增新分組」以建立新的分組。

![clipboard-1768908420554-e3b90ce1a2e5.png](/blog/assets98cddf4b80b8bac0c250a5236062d198.webp)

### 移入分組

選擇已有助手和群聊選單，點擊「移動到分組」進行移入。也可以直接在分組內建立助手和群聊。\[Image]

### 管理分組

存在多個分組時，在助手列表或分組選單選擇「分組管理」，可以便捷修改分組顯示順序、分組命名。\[Image]

### 置頂常用助手

你可以把頻繁使用的助手置頂在列表最上方，以節省查找和滾動的時間。選中助手，在選單中選擇「置頂」即可。置頂的助手會固定在列表頂部，方便快速存取。\[Image]

## 建立副本

你可以複製一個助手，建立副本。選中助手，在選單中選擇「建立副本」，系統會建立一個完全相同的助手副本。適合在原助手基礎上建立不同設定的變體。

## 刪除助手

不需要的助手可以刪除。選中助手，在選單中選擇「刪除」，確認刪除後助手將被移除。
