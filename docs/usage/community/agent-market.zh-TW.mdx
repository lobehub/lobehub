# 助手市場

LobeHub 的助理市場匯聚了來自全球創作者的優質 AI 助理。無論你需要編程助理、寫作顧問、語言教師，還是專業領域的諮詢專家，都能在這裡找到合適的助理。這些助理由社群成員精心打造，經過實際使用驗證，能直接投入工作和學習場景。

助理市場不只是獲取資源的地方，更是一個開放的創作平臺。你可以發佈自己定製的助理，與全球使用者分享你的創意和專業知識。

## 瀏覽助理市場

點擊左側邊欄的「社群」→「助理」，進入助理市場首頁。

![Agent 市場](/blog/assetsbcd98b0913d2dfc30d5a2b5523115d33.webp)

助理市場按類別組織，方便你快速找到所需的助理類型。

## 安裝和使用助理

查看和安裝助理

點擊任意助理卡片，進入詳情頁面。這裡展示了助理的概覽、設定、能力和版本歷史等資訊。確認助理符合你的需求時，可以在此頁面「新增助理並會話」。

![安裝和使用助理](/blog/assets60bf3667e56862024d047444d9b4c2fb.webp)

### 使用助理

選擇「新增助理並會話」後，你可以立即開始與助理對話，測試助理的功能和效果。根據需要調整助理的系統提示詞、模型選擇、插件設定等。你也可以基於市場助理建立副本，在保留原有能力的基礎上進行個性化修改。
