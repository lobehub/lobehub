# Become a Creator

As a community creator, you can publish **Agents, Agent Groups, and Skills**. Other users can discover and use your work, and everything you publish appears on your creator page.

## Open Your Creator Page

1. Open **Community** from the sidebar.
2. Select your avatar in the upper-right corner.
3. Open your creator page to view your published work.

The page shows your avatar, nickname, user ID, bio, follower counts, and published Agents, Agent Groups, and Skills.

## Complete Your Profile

Select **Edit Profile** to add:

| Profile item | Where it appears or what it does |
| --- | --- |
| **Avatar** | Creator page and author information |
| **Nickname** | Your public creator name |
| **User ID** | Unique identifier for your page |
| **Bio** | Your field and creative focus |
| **Cover image** | Banner at the top of your creator page |
| **Social links** | GitHub, X, and your website |

Select **Save** when you finish. A short bio about what you share can help others understand your work.

## What You Can Publish

| Content type | Contents |
| --- | --- |
| **Agent** | An assistant with its own role, instructions, model, tools, Skills, or knowledge bases |
| **Agent Group** | A group of Agents arranged around one scenario |
| **Skill** | A package based on `SKILL.md` that can include references, templates, and scripts |

## Publish an Agent

1. Open the Agent and go to **Agent Profile**.
2. Select **More** (`···`) in the upper-right corner.
3. Select **Publish**.
4. Follow the page prompts to submit the Agent.

You can view its status under **Created Agents** on your creator page. After publication, other users can discover it in the Agent Marketplace.

## Publish an Agent Group

1. Open the Agent Group.
2. Go to its profile or settings page.
3. Select **More** (`···`) in the upper-right corner.
4. Select **Publish** and submit the Group.

After publication, it appears under **Created Groups** on your creator page. If the Publish action is not visible, save the Group profile and follow the prompts on the page.

## Publish a Skill

Skills are submitted through GitHub repositories:

1. Create a public GitHub repository with `SKILL.md` and its related files.
2. Open your creator page and find **Skills**.
3. Select **Submit Repository**.
4. Choose the GitHub repository and submit it.

You can add purpose, dependencies, and command notes to help others understand the Skill. Keep API keys and access tokens in credential settings rather than in the public repository.

## Manage Published Content

Your creator page groups your Agents, Agent Groups, and Skills by content type. You can:

- Search by name or description
- Filter by status
- View review and publication status
- Update content and versions from their source

Available actions can vary by content type and status. The page displays the actions currently available.
