# Skills 市场

Skills 市场汇集了社区发布的技能包。Skill 可以告诉 Agent 怎样完成一项任务，例如制作演示文稿、审查代码、开展研究或处理文档。

每个 Skill 以 `SKILL.md` 为入口，也可以包含参考资料、模板、脚本和其他文件。

## 进入 Skills 市场

在 LobeHub 左侧边栏打开**社区**，然后点击 **Skills**。你也可以访问 [lobehub.com/skills](https://lobehub.com/skills) 浏览公开市场。

市场有以下浏览方式：

- **搜索**：按 Skill 名称、简介或关键词查找
- **分类**：按编程、Web 开发、研究、生产力、文档、媒体生成和安全等领域浏览
- **排序**：按下载量、发布时间、更新时间、名称或 GitHub Stars 排列
- **技能卡片**：查看名称、作者、简介、分类、更新时间、下载量、评分和评价数

市场中的数量和排序会持续更新，以页面显示为准。

## 查看 Skill 详情

点击技能卡片即可打开详情页。页首会显示 Skill 图标、名称、作者、分类、更新时间、安装按钮和社区使用数据。

详情页包含四个标签：

| 标签 | 内容 |
| --- | --- |
| **概览** | Skill 简介、`SKILL.md`、特性、更新内容和相关技能 |
| **安装** | 安装提示词、CLI 命令、目录位置、下载入口和文件列表 |
| **评价** | 平均评分、评分分布和社区评价 |
| **信息** | 发布者、分类、版本、更新时间、许可证、安装量和源码链接 |

各个 Skill 展示的信息可能有所不同。

## 阅读 SKILL.md

`SKILL.md` 会介绍 Skill 的使用方法，内容可能包括：

- 适用场景
- 任务步骤
- 输入和输出
- 示例与参考资料
- 脚本、命令和运行条件
- 与工具或 MCP Server 配合使用的方法

你可以在安装前展开 `SKILL.md`，快速了解这个 Skill 是否适合当前任务。

## 在 LobeHub 中安装

1. 在**社区 → Skills**中打开目标 Skill。
2. 点击右上角的**安装**。
3. 安装成功后，按钮会变为**已安装**。

点击**已安装**旁的菜单可以卸载 Skill，操作前会出现确认提示。

如果安装按钮不可用，可以查看当前账号或工作区是否允许安装社区内容。

## 让 Agent 安装 Skill

在**安装 → 我是 Agent**中，页面会生成一段安装提示词。Agent 会根据提示：

1. 打开该 Skill 的市场安装说明。
2. 安装 Skill。
3. 读取安装目录中的 `SKILL.md`。
4. 按照其中的步骤完成任务。

点击**在 LobeAI 上使用**，可以把安装提示词直接发送给 LobeAI。

## 安装到外部 Agent

在**安装 → 我是人类**中，可以选择：

- Claude Code
- Codex
- Cursor
- VS Code
- Cline

页面会生成相应的安装命令，例如：

```bash
npx -y @lobehub/market-cli skills install <identifier> --agent codex
```

页面还会显示安装目录和**下载技能**入口。安装完成后，可以重新启动外部 Agent 或新建会话，让它加载新 Skill。

## 查看技能包文件

**安装**标签下方会列出技能包中的文件及大小，包括 `SKILL.md`、脚本、模板和参考资料。

如果 Skill 包含其他文件，你可以打开它们，进一步了解用途和运行条件。

## 查看评价和源码

在**评价**中，你可以查看：

- 平均评分和评分数量
- 1–5 星评分分布
- 其他用户留下的评价

在**信息**中，你可以查看发布者、版本、更新时间、许可证、安装量和源码链接。GitHub 来源会显示**在 GitHub 查看**入口。

## Skill、连接器与 MCP

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| **Skill** | 告诉 Agent 怎样完成任务 | 写作规范、审查清单、报告模板 |
| **连接器** | 连接内置能力或外部服务 | GitHub、图片生成、数据库 MCP |
| **工具** | 执行具体操作 | 读取 Issue、查询数据、发送消息 |

Skill 可以告诉 Agent 如何使用工具。外部服务的连接、账号授权和工具权限在[连接器](/zh/docs/usage/agent/connectors)中设置。

## 发布 Skill

如果你想分享自己的 Skill，可以准备一个公开的 GitHub 仓库，在其中放入 `SKILL.md` 和相关文件。你还可以补充用途、输入输出、依赖和命令说明，方便其他用户了解和使用。

发布步骤见[成为创作者](/zh/docs/usage/community/become-a-creator)。

## 使用小贴士

- 安装前可以浏览 `SKILL.md` 和技能包文件
- 包含脚本时，可以先了解命令和运行条件
- API Key 和令牌可以保存在凭证设置中
- 只在一个项目中使用时，可以选择项目级安装
- 初次使用时，可以先用测试数据体验运行效果

## 故障排查

**安装后没有显示 Skill**

- 查看安装是否已经完成
- 查看目标平台和安装目录是否正确
- 对外部 Agent，重新启动客户端或新建会话

**Skill 已加载，但任务没有完成**

- 查看 `SKILL.md` 中的运行条件和依赖
- 查看所需连接器和账号授权是否已经配置
- 查看当前执行设备是否能访问所需文件、命令和网络服务
