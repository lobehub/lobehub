## How the Marketplaces Differ

| Marketplace | Main content | What it helps you do |
| --- | --- | --- |
| **Agent Marketplace** | Agents published by community creators | Quickly find an Agent for a specific scenario |
| **MCP Marketplace** | MCP servers that connect external services | Let Agents use databases, development tools, and business apps |
| **Skills Marketplace** | Skill packages built from `SKILL.md` and related files | Add working methods for writing, research, coding, design, and more |

If you want to share your own work, see [Become a Creator](/docs/usage/community/become-a-creator).
