# 提交你的 Agent

如果你建立了優質的 Agent，可以提交到市場與全球使用者分享。

如果你是首次提交 Agent，需要先[建立社群個人檔案](/docs/usage/community/become-a-creator)，以便在社群上提交和管理上架資訊。

當你已成為創作者，選擇需要發佈的 Agent 進入「Agent 檔案」，點擊「分享助理到社群」即可。

![分享成功](/blog/assetsa88afc117d283790187c366f29d03284.webp)

通過審核後，你的 Agent 會出現在市場中，供全球使用者使用。LobeHub 歡迎所有使用者加入這個不斷成長的生態系統，共同參與到助理的迭代與優化中來。共同創造出更多有趣、實用且具有創新性的助理，進一步豐富助理的多樣性和實用性。
