# 自訂插件

## 安裝自訂插件

如果你希望安裝一個不在 LobeHub 插件商店中的插件，例如自己開發的 LobeHub，你可以點擊「自訂插件」進行安裝：

<Video src="/blog/assets28616219/034a328c-8465-4499-8f93-fdcdb03343cd.mp4" />

此外，LobeHub 的插件機制相容了 ChatGPT 的插件，因此你可以一鍵安裝相應的 ChatGPT 插件。

如果你希望嘗試自行安裝自訂插件，你可以使用以下連結來嘗試：

- `自訂 Lobe 插件` Mock Credit Card：[https://lobe-plugin-mock-credit-card.vercel.app/manifest.json](https://lobe-plugin-mock-credit-card.vercel.app/manifest.json)
- `ChatGPT 插件` Access Links：[https://www.accesslinks.ai/.well-known/ai-plugin.json](https://www.accesslinks.ai/.well-known/ai-plugin.json)

## 開發自訂插件

如果你希望自行開發一個 LobeHub 的插件，歡迎查閱 [插件開發指南](/zh/docs/usage/plugins/development) 以擴充功能你的 AI 智慧助手的可能性邊界！
