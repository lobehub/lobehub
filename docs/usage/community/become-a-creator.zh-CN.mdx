# 成为创作者

成为社区创作者后，你可以发布 **Agent、Agent Group 和 Skill**。其他用户可以在市场中发现和使用你的作品，你发布的内容也会集中显示在创作者主页。

## 打开创作者主页

1. 打开左侧边栏，进入**社区**。
2. 点击社区页面右上角的个人头像。
3. 进入创作者主页，查看自己发布的内容。

主页会显示头像、昵称、用户 ID、个人简介、关注与粉丝数量，以及你发布的 Agent、Agent Group 和 Skill。

## 完善个人资料

点击**编辑个人资料**，即可设置：

| 资料 | 显示位置或用途 |
| --- | --- |
| **头像** | 创作者主页和作品作者信息 |
| **昵称** | 对外显示的创作者名称 |
| **用户 ID** | 个人主页的唯一标识 |
| **个人简介** | 介绍你的领域和创作方向 |
| **背景图** | 创作者主页顶部的横幅 |
| **社交链接** | GitHub、X 和个人网站 |

填写完成后点击**保存**。你可以在简介中简单介绍自己经常分享的内容，方便其他用户了解你的创作方向。

## 可以发布什么

| 内容类型 | 内容 |
| --- | --- |
| **Agent** | 配置了角色、指令、模型、工具、技能或知识库的助理 |
| **Agent Group** | 围绕同一场景组合的一组 Agent |
| **Skill** | 以 `SKILL.md` 为入口，可以包含参考资料、模板和脚本的技能包 |

## 发布 Agent

1. 打开要发布的 Agent，进入**助理档案**。
2. 点击右上角的**更多**按钮（`···`）。
3. 选择**发布**。
4. 按页面提示提交资料。

提交后，你可以在创作者主页的**创作的助理**中查看状态。发布完成后，其他用户就能在助理市场中发现它。

## 发布 Agent Group

1. 打开要发布的 Agent Group。
2. 进入群组资料或配置页面。
3. 点击右上角的**更多**按钮（`···`）。
4. 选择**发布**并提交。

发布完成后，Agent Group 会显示在创作者主页的**创作的群组**中。如果没有看到发布入口，可以先保存群组资料，再根据页面提示继续。

## 发布 Skill

Skill 通过 GitHub 仓库提交：

1. 准备一个公开的 GitHub 仓库，在其中放入 `SKILL.md` 和相关文件。
2. 打开创作者主页，找到**技能**区域。
3. 点击**提交仓库**。
4. 选择 GitHub 仓库并提交。

你还可以在仓库中补充 Skill 的用途、依赖和命令说明，方便其他用户了解和使用。API Key 和访问令牌可以保存在凭证设置中，不写入公开仓库。

## 管理已发布内容

创作者主页按类型显示你创作的 Agent、Agent Group 和 Skill。你可以：

- 按名称或描述搜索
- 按状态筛选
- 查看审核和发布状态
- 从作品来源更新内容和版本

不同内容和状态下的可用操作可能有所不同，页面会显示当前可以使用的操作。
