## 三类市场有什么不同

| 市场 | 主要内容 | 适合用来做什么 |
| --- | --- | --- |
| **助理市场** | 社区创作者发布的助理 | 快速找到适合某个场景的助理 |
| **MCP 市场** | 连接外部服务的 MCP Server | 让助理使用数据库、开发工具和业务应用 |
| **Skills 市场** | `SKILL.md` 和相关文件组成的技能包 | 为助理添加写作、研究、编程和设计等工作方法 |

如果你也想分享自己的内容，可以前往[成为创作者](/zh/docs/usage/community/become-a-creator)查看发布方式。
