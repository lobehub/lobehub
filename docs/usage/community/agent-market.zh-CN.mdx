# 助理市场

助理市场汇集了社区创作者发布的助理。你可以搜索不同用途的助理，查看详情，并基于喜欢的助理创建自己的版本。

## 进入助理市场

在 LobeHub 左侧边栏打开**社区**，然后点击**助理**。

市场有以下浏览方式：

- **搜索**：按名称、简介或关键词查找助理
- **分类**：浏览不同场景下的助理
- **助理卡片**：查看创作者、简介、分类和更新时间

## 查看助理详情

点击助理卡片即可进入详情页。

| 标签 | 内容 |
| --- | --- |
| **概览** | 助理用途、演示内容和相关助理 |
| **助理简介** | 角色、语言、使用方式等详细介绍 |
| **助理能力** | 助理附带的技能和资源库 |
| **版本历史** | 已发布版本、最新版本和发布日期 |
| **相似助理** | 与当前助理相关的其他社区助理 |

各个助理展示的信息可能有所不同。

## 派生并开始聊天

找到合适的助理后，点击**派生并聊天**。LobeHub 会创建一个属于你的版本，并打开新会话。

派生后，你可以继续调整：

- 系统提示词和助理资料
- 默认模型
- 技能、工具和资源库
- 开场白和其他会话设置

这些修改会保存在你的版本中，不会影响市场中的原助理。

## 查看版本和使用情况

在详情页中，你还可以查看：

- 已发布版本及其发布日期
- 助理附带的技能和资源库
- 使用量和派生数量

这些信息可以帮助你了解助理的配置和社区使用情况。

## 发布自己的助理

如果你也想分享助理，可以先完善助理资料，然后从助理档案页提交。发布步骤见[成为创作者](/zh/docs/usage/community/become-a-creator)。
