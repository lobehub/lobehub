# Agent Marketplace

The Agent Marketplace brings together Agents published by community creators. You can search for Agents by purpose, view their details, and create your own version of one you like.

## Open the Agent Marketplace

Open **Community** from the LobeHub sidebar, then select **Agents**.

The marketplace includes:

- **Search** by name, description, or keyword
- **Categories** for different scenarios
- **Agent cards** with creator, description, category, and update time

## View Agent Details

Select an Agent card to open its detail page.

| Tab | Contents |
| --- | --- |
| **Overview** | Purpose, demos, and related Agents |
| **Agent Profile** | Role, language, usage notes, and other details |
| **Capabilities** | Skills and knowledge bases included with the Agent |
| **Version History** | Published versions, the latest version, and release dates |
| **Similar Agents** | Other community Agents related to the current one |

The information shown can vary by Agent.

## Derive an Agent and Start Chatting

When you find an Agent you like, select **Fork & Chat**. LobeHub creates a version for you and opens a new conversation.

You can then customize:

- System instructions and Agent profile
- Default model
- Skills, tools, and knowledge bases
- Welcome message and other conversation settings

Your changes stay in your version and do not affect the original Agent in the marketplace.

## View Versions and Usage

The detail page also shows:

- Published versions and release dates
- Included Skills and knowledge bases
- Usage and fork counts

These details help you understand the Agent setup and how the community uses it.

## Publish Your Own Agent

If you want to share an Agent, complete its profile and submit it from the Agent Profile page. See [Become a Creator](/docs/usage/community/become-a-creator) for the publishing steps.
