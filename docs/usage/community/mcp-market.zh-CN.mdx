# MCP 市场

MCP（Model Context Protocol）可以让助理连接数据库、API、文件系统、开发工具和业务应用。MCP 市场汇集了社区发布的 MCP Server，你可以从市场中查找并安装需要的服务。

## MCP 和 Skill 有什么不同

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| **MCP Server** | 连接外部工具和数据 | 数据库、GitHub、浏览器和业务应用 |
| **Skill** | 告诉助理怎样完成任务 | 写作规范、审查清单和工作流程 |

MCP 连接和授权在**设置 → 连接器**中管理。Skill 的浏览和安装见[Skills 市场](/zh/docs/usage/community/skills-market)。

## 进入 MCP 市场

在 LobeHub 左侧边栏打开**社区**，然后点击 **MCP**。

市场有以下浏览方式：

- **搜索**：按名称、简介或关键词查找 MCP
- **分类**：按开发、效率、信息检索、媒体、商业服务等场景浏览
- **排序**：按推荐、安装量或更新时间等方式排列
- **市场卡片**：查看名称、作者、简介、等级、安装量和 GitHub Stars

市场中的数量和排序会持续更新，以页面显示为准。

## 查看 MCP 卡片

市场卡片可能显示：

| 信息 | 含义 |
| --- | --- |
| **名称、作者和简介** | MCP Server 的基本用途 |
| **等级** | 根据验证、安装方式、功能和仓库信息生成的综合等级 |
| **推荐、官方认证或已验证** | MCP 在市场中的状态标记 |
| **Tools、Prompts 和 Resources** | MCP Server 包含的工具、提示词和资源数量 |
| **本地、云端或混合服务** | MCP Server 的运行方式 |
| **安装量和 GitHub Stars** | 市场安装情况和源码仓库关注度 |

不同 MCP 展示的信息可能有所不同。

## 查看 MCP 详情

点击卡片即可进入详情页。你可以查看：

- **概览**：用途摘要、README、标签和相关 MCP
- **安装方式**：连接方式、系统依赖、命令、参数和环境变量
- **技能功能**：Tools、Prompts 和 Resources
- **评分**：综合等级和评分明细
- **版本历史**：版本号、发布日期和最新版本
- **源码信息**：官网、许可证和 GitHub 仓库

## 从市场安装 MCP

1. 在**社区 → MCP**中打开目标 MCP。
2. 你可以先浏览简介、安装方式和功能列表。
3. 点击**安装 MCP Server**。
4. 根据页面提示填写连接地址、API Key 或环境变量。
5. 完成安装后，在助理设置中启用该连接器。

如果服务需要账号授权，页面会引导你登录。需要运行本地命令的 STDIO MCP 可在桌面端使用；HTTP MCP 可以连接远程服务，也可以在桌面端连接本机或局域网服务。

## 手动添加 MCP

如果目标 MCP 不在市场中，可以前往**设置 → 连接器**手动添加。

### HTTP Server

填写 MCP Server 的 URL，并根据服务要求添加认证信息或请求头。桌面端也可以连接本机或局域网地址，例如：

```text
http://127.0.0.1:3000/mcp
```

### STDIO Server

填写启动命令、参数和环境变量。STDIO Server 会作为本地进程运行，目前可在桌面端使用。

你也可以导入 `mcpServers` JSON：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/workspace"],
      "type": "stdio"
    }
  }
}
```

## 在助理中使用 MCP

安装完成后，可以为需要使用它的助理开启连接：

1. 打开**助理设置**。
2. 进入**连接器**。
3. 选择 MCP Server。
4. 设置各个工具的权限并保存。

工具权限有三种：

| 权限 | 运行方式 |
| --- | --- |
| **Allow** | 工具可以直接运行 |
| **Ask** | 每次运行前询问你 |
| **Deny** | 工具不会运行 |

完成连接后，助理会在合适的任务中调用 MCP 工具。你可以在对话中的工具调用记录里查看运行过程和结果。

## 使用小贴士

- 第一次使用 MCP 时，可以先从只读权限开始
- API Key 和令牌可以保存在连接器的认证设置中
- 本地或局域网地址可以在桌面端连接
- 如果 MCP 包含启动命令，可以先查看命令和所需依赖
- 新连接可以先使用测试数据体验运行效果

## 故障排查

**安装后没有显示 MCP**

- 查看安装是否已经完成
- 对于 STDIO Server，查看启动命令是否可用
- 查看服务器日志中的启动信息
- 重新打开 LobeHub

**工具没有出现在对话中**

- 在**设置 → 连接器**中查看连接状态
- 查看当前助理是否已经启用该连接器
- 查看工具权限是否为 **Allow** 或 **Ask**

**连接或认证失败**

- 查看 API Key 或令牌是否仍然有效
- 查看认证方式是否与服务要求一致
- 对于 HTTP Server，查看当前设备是否能访问连接地址
- 在服务器日志中查看认证和网络信息
