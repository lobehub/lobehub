# 欢迎来到 LobeHub

**为工作与生活打造的终极空间。** 发现、构建，并与随你成长的助理队友协作。

![LobeHub](https://hub-apac-1.lobeobjects.space/landing/images/home/overview-light.webp)

你大概经历过这样的场景：让一个 AI 起草报告，把结果粘贴到另一个 AI 里润色语气，再复制到第三个工具里排版。

它们彼此不知道对方做了什么，也不记得你上周做了什么。每次对话都从零开始，每段上下文都在流失，而串联这一切的人，是你自己。

LobeHub 为受够了这个循环的人而生。在这里，你的助理共享上下文、记住你的偏好、以团队形式协作，并随时间持续进化。你可以少花时间重复自己，多花时间做真正重要的事。

## 创建：一句话就够了

你不需要配置模型、编写系统提示词或对接 API。

只需描述你的需求。「一个匹配我品牌调性的写作助手」，或者「一个熟悉我们技术栈的代码审查员」。LobeHub 会自动匹配合适的模型、技能和上下文，组装成一个可运行的助理。

从最简单的开始。当助理需要领域知识时，加入知识库。当它需要实时信息时，开启联网搜索。当它需要执行操作时，接入 MCP 工具。你的助理随你的工作一起成长。

不确定从哪开始？逛逛[社区](/zh/docs/usage/community/agent-market)，数千个现成的助理正等着你。找到一个接近需求的，安装它，然后按自己的方式改造。

## 协作：你的助理以团队形式工作

想象一下，你同时给一位研究分析师、一位文案和一位事实核查员布置同一个项目。只不过它们都是助理，共享同一个上下文，并行工作，不需要你来管理交接。

这就是[群组](/zh/docs/usage/agent/agent-team)的工作方式。多个专业助理协同完成一个任务，讨论方案、迭代输出、共同打磨结果。你定义目标，它们协调执行。

除了群组，LobeHub 还将助理融入你的日常工作流。

**[文稿](/zh/docs/usage/agent/pages)**

深夜赶一份方案？叫上多个助理做共同编辑，它们共享同一个上下文。一个起草，一个点评，一个核查数据。最终交付的是一份成型的文档，而不是一堆聊天记录。

**定时任务**

需要每周一早上收到竞品分析报告？设置一次就好。你的助理自动汇总、总结、交付，即使你还在睡觉。

**空间**

你的团队和你的助理共享同一个空间。所有人看到相同的项目、相同的上下文、相同的进度。

## 演进：它们记得，它们学习，它们适应

大多数 AI 工具的记忆像金鱼一样短暂。你解释了你的编码风格、你偏好的语气、公司的命名规范，下次对话，全忘了。你又得从头来过。

LobeHub 的助理不会忘记。它们构建对你工作方式的结构化理解：你的偏好、你的习惯、你的领域知识。这些[记忆](/zh/docs/usage/getting-started/memory)贯穿每一次对话。你们合作得越多，你需要解释的就越少。

而且不同于黑盒系统，这些记忆完全属于你。结构化、可编辑、完全透明。你能看到助理记住了什么，修改不对的，删除过时的。助理的推理过程通过思维链逐步展开，你始终清楚它 *为什么* 做出某个决定，而不仅仅是 *做了什么*。

## 为每个任务选择最合适的模型

不是所有问题都需要最强的模型。

一段快速翻译？轻量模型几毫秒搞定，成本微乎其微。一份需要深度推理的法律分析？交给推理能力最强的模型。

LobeHub 接入了 **70+ 模型**，包括 GPT-4o、Claude、Gemini、DeepSeek、Llama、Qwen 等，来自十几家服务商。你可以在对话中随时切换模型，也可以让助理自动为每个回合选择最优模型。如果你的数据需要留在本地，还可以接入本地模型。

每个助理都可以设置独立的默认模型。你的代码审查员用一个模型，文案用另一个，全自动运行，无需每次手动选择。

## 10,000+ 技能：把助理连接到你的工具链

一个只能聊天的助理只发挥了一半的能力。

通过[技能](/zh/docs/usage/agent/skills)，你的助理可以读取 GitHub Issue、查询数据库、发送 Slack 消息、生成 PDF 或预订会议，全部在同一个对话中完成。

LobeHub 支持[模型上下文协议（MCP）](/zh/docs/usage/community/mcp-market)，这是一个开放标准，将助理连接到一个持续增长的 **10,000+ 工具**生态。从市场一键安装技能，或者自己构建并分享给社区。

几个实际场景：

- *「总结排名前 5 的 GitHub Issue，然后把摘要发到 Slack」* → 你的助理读取 Issue、撰写摘要、发送消息。
- *「拉取本周的销售数据，做一张图表」* → 你的助理查询数据库、处理数字、渲染可视化 Artifact。
- *「找下个月去东京的机票，800 美元以内」* → 你的助理搜索、比较、呈现带预订链接的选项。

## 资源库：给你的助理真正的知识

通用的 AI 回答能应付通用的问题。但当你需要一个了解 *你的* 代码库、*你的* 产品文档、*你的* 公司制度的助理时，[资源库](/zh/docs/usage/agent/resources)就派上用场了。

上传文档、图片、表格、音频或视频。你的助理在对话中引用这些资料，让回答基于你的真实数据，而不仅仅是训练集里的知识。为每个助理建立独立的知识库，或者在空间中共享资源。

想象一个读过你整个帮助中心的客服助理。一个熟悉你所有合同模板的法务助手。一个看过你写的每一份 PRD 的产品经理。这就是资源库在做的事。

## 语音：解放双手

有时候你需要助理，但双手正忙着。通勤、做饭、巡查仓库。LobeHub 支持文字转语音和语音转文字，让你无需打一个字就能完成完整对话。

走回办公室的路上口述一份会议纪要。开车时让助理把一篇长分析念给你听。或者单纯地把想法说出来，让助理捕捉结构。

## 在对话中直接创作视觉内容

需要一张博客文章的封面图？一张架构文档的流程图？一个用来推销创意的快速原型？

直接问你的助理。它使用 DALL-E 3、fal.ai 等模型生成图片，并以 Artifact 的形式直接渲染在聊天里。不需要切换到另一个设计工具，不需要导出、下载、再上传。图片就在那里，在上下文中，紧挨着产生它的对话。

## 社区：共享的智慧

LobeHub 的理念以人为本。[社区](/zh/docs/usage/community/agent-market)是数千名创作者发布助理、技能和工作流的地方，所有人都可以发现、安装和二次创作。

看到一个满足你 80% 需求的助理？安装它，调整提示词，换个模型，加上你自己的知识库，它就变成了你的。或者从零构建一个，分享回社区。最好的想法在开放中加速复合增长。

## 让它适应你

LobeHub 适应你的工作方式，而不是反过来。

**[外观](/zh/docs/usage/user-interface/appearance)**

浅色、深色、自定义强调色和布局密度。让你的工作空间有家的感觉。

**[快捷键](/zh/docs/usage/user-interface/shortcuts)**

效率型用户可以不碰鼠标就完成导航、切换对话和触发操作。

**[命令菜单](/zh/docs/usage/user-interface/command-menu)**

按一个键就能搜索一切：助理、对话、设置、操作，全部在一个入口。

## 随处可用

LobeHub 可在[浏览器](https://app.lobehub.com)、[macOS 和 Windows](/zh/docs/usage/getting-started/get-lobehub)，以及 [iOS 和 Android](/zh/docs/usage/getting-started/get-lobehub) 上使用。一个账号，你的助理、文稿和记忆在所有设备间同步。

在笔记本上开始一个研究任务，午休时用手机继续对话，回到办公桌后在台式机上接着来。不会丢失任何东西。
