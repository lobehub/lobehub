# 在微信使用 LobeHub

微信 Messenger 让你通过自己的微信账号，私聊 LobeHub Agent。扫码完成关联并选择当前 Agent 后，即可在微信的 LobeHub 会话中直接收发消息。

> \[!NOTE]
>
> 本页介绍 **Messenger**：将你的微信账号关联到 LobeHub 托管的服务，并可随时切换当前 Agent。如果你需要把一个微信连接固定绑定到某个 Agent，请参阅[通过渠道将 LobeHub 连接到微信](/zh/docs/usage/channels/wechat)。

## 前置条件

- 一个开通 **Pro** 方案的 LobeHub 账号
- 手机端微信账号

## 第 1 步：打开「设置 → Messenger → 微信」

在 LobeHub 中打开 **设置 → Messenger**，然后点击 **微信** 卡片。

{/* TODO: 截图 —— 设置 → Messenger 入口页，显示微信卡片与 Pro 标识 */}

## 第 2 步：使用微信扫码

使用手机微信扫描微信详情页显示的二维码，并在微信中确认连接。如果二维码过期，点击 **重新扫码** 生成新的二维码。

{/* TODO: 截图 —— 微信详情页，显示二维码与「重新扫码」按钮 */}

## 第 3 步：选择工作区与当前 Agent

连接成功后，页面会将你的微信账号显示为已连接用户。你可以选择：

- **工作区** —— 选择要使用个人工作区还是团队工作区中的 Agent。
- **当前激活 Agent** —— 选择接收下一条消息的 Agent。

修改会对你发送的下一条消息立即生效。

{/* TODO: 截图 —— 已连接的微信用户行，显示工作区和当前激活 Agent 选择器 */}

## 第 4 步：在微信中开始对话

打开微信中的 LobeHub 会话并发送消息。消息会被路由到当前 Agent，Agent 的回复会返回同一个私聊会话。

## 切换 Agent 与工作区

你可以通过两种方式修改当前消息路由：

- **在微信中** —— 发送 `/agents` 查看 Agent 列表并切换当前 Agent；发送 `/switch` 在个人工作区与团队工作区之间切换。
- **在 LobeHub 中** —— 打开 **设置 → Messenger → 微信**，使用工作区和当前 Agent 选择器。

## 指令

在微信的 LobeHub 私聊中发送以下指令：

| 指令          | 作用                                            |
| ----------- | --------------------------------------------- |
| `/agents`   | 列出你的 Agent，并切换当前激活 Agent                    |
| `/switch`   | 在个人工作区与团队工作区之间切换                             |
| `/new`      | 开启新对话                                         |
| `/mode`     | 查看或切换 Agent / Chat 模式                         |
| `/stop`     | 停止当前执行                                        |
| `/feedback <内容>` | 向 LobeHub 团队发送反馈，不会触发 AI 回复             |
| `/help`     | 查看全部可用指令                                      |

## 主动消息推送

受微信平台限制，机器人只能在**发送窗口**开启期间主动向你推送消息。先在微信中给 LobeHub 会话发送任意消息，即可打开该窗口。

你每次回复后，主动推送额度会重置为 **24 小时内 10 条**。如果发送窗口已关闭，请先从微信再次发送一条消息，再回到 LobeHub 尝试推送。

## 断开连接

在 **设置 → Messenger → 微信** 中，点击已连接用户行上的 **断开**。断开后，微信账号与 LobeHub 的关联会被解除，消息也不再路由。

需要恢复时，返回同一页面并重新扫码即可。

## 故障排查

- **二维码已过期** —— 点击 **重新扫码**，再使用微信扫描新二维码。
- **扫码后页面未显示「已连接」** —— 确认已在微信中完成连接确认，然后刷新 LobeHub 页面；仍未成功时，生成新二维码后重试。
- **回复来自错误的 Agent** —— 检查当前激活 Agent 选择器，或在微信中发送 `/agents` 后重新选择。
- **显示了错误工作区的 Agent** —— 修改工作区选择器，或在微信中发送 `/switch`。
- **LobeHub 无法主动推送消息** —— 微信发送窗口已关闭或额度已用完。请先在微信中给 LobeHub 会话发送一条消息，重新打开窗口。
- **连接一段时间后失效** —— 断开连接并扫描新的二维码重新关联。
