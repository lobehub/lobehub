# 将 LobeHub 连接到微信

<Callout type={'info'}>
  此功能目前正在开发中，可能尚未完全稳定。您可以通过在 **设置** → **高级设置** → **开发者模式**
  中启用 **开发者模式** 来使用此功能。
</Callout>

通过将微信渠道连接到您的 LobeHub 代理，用户可以通过微信私聊和群聊与 AI 助手互动。

## 前置条件

- 一个拥有有效订阅的 LobeHub 账户
- 一个已在 iLink Bot 平台注册的微信账户

## 第一步：在 iLink Bot 平台注册

<Steps>
  ### 打开 iLink Bot 平台

  访问 [iLink Bot 平台](https://ilinkai.weixin.qq.com)，使用您的微信账号登录。

  ### 创建机器人

  按照平台说明创建一个新的机器人应用。填写机器人名称和描述。

  ### 获取 App Token

  机器人创建完成后，导航到机器人的设置页面，获取您的 **App Token**。此令牌用于验证 API 请求。

  > **重要提示：** 请妥善保管您的 App Token，切勿公开分享。
</Steps>

## 第二步：在 LobeHub 中配置微信

<Steps>
  ### 打开渠道设置

  在 LobeHub 中，导航到您的代理设置，然后选择 **渠道** 标签页。从平台列表中点击 **微信**。

  ### 输入凭证

  填写以下字段：

  - **App Token** — 从 iLink Bot 平台获取的令牌

  ### 保存配置

  点击 **保存配置**。您的凭证将被加密并安全存储。

  LobeHub 将使用长轮询方式连接 iLink Bot API，并自动开始接收消息。
</Steps>

## 第三步：测试连接

在 LobeHub 的渠道设置中点击 **测试连接** 以验证集成。然后打开微信，找到您的机器人并发送消息。机器人应通过您的 LobeHub 代理进行响应。

## 将机器人添加到群聊

要在微信群聊中使用机器人：

1. 将机器人添加到微信群聊中
2. @提及机器人或在群中发送消息以触发响应
3. 机器人将在群聊中回复

## 配置参考

| 字段            | 是否必需 | 描述                       |
| ------------- | ---- | ------------------------ |
| **App Token** | 是    | 从 iLink Bot 平台获取的机器人认证令牌 |

### 高级设置

| 设置         | 默认值     | 描述                      |
| ---------- | ------- | ----------------------- |
| **字符限制**   | 2048    | 每条消息的最大字符数（范围：100–2048） |
| **消息合并窗口** | 2000 毫秒 | 等待更多消息再回复的时间            |
| **显示使用统计** | 关闭      | 在回复中显示 Token 用量 / 成本统计  |

## 工作原理

与基于 Webhook 的平台（Telegram、Slack）不同，微信使用 iLink Bot API 的 **长轮询** 机制：

1. LobeHub 持续轮询 iLink API 获取新消息（35 秒间隔）
2. 当消息到达时，通过 LobeHub 代理进行处理
3. 代理的响应通过 iLink API 发送回微信

此轮询由后台定时任务管理，连接会自动维护。

## 功能限制

- **不支持消息编辑** — 微信不支持编辑已发送的消息。更新的回复将作为新消息发送。
- **不支持表情回应** — 微信 iLink Bot API 不支持表情回应功能。
- **不支持输入状态提示** — 微信不提供机器人输入状态指示器功能。
- **仅支持文本** — 目前仅支持文本消息。图片和文件附件暂不可用。
- **消息长度限制** — 超过 2048 个字符的消息将被自动截断。
- **会话过期** — 机器人会话可能会过期，需要重新认证。LobeHub 会在此情况发生时通知您。

## 故障排除

- **机器人未响应：** 验证 App Token 是否正确且未过期。尝试在 LobeHub 渠道设置中重新输入令牌。
- **会话过期错误：** iLink Bot 会话已过期。请更新 App Token 重新认证。
- **测试连接失败：** 仔细检查 LobeHub 渠道设置中的 App Token。确保您的机器人在 iLink 平台上处于活跃状态。
- **响应延迟：** 长轮询在两次轮询之间有最多 35 秒的自然延迟。这是预期行为。
