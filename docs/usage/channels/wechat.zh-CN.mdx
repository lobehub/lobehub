# 将 LobeHub 连接到微信

通过将微信渠道连接到您的 LobeHub 代理，用户可以通过微信私聊与 AI 助手互动。此页面介绍按助理配置的渠道连接，不是 Messenger 官方机器人的账号关联。

## 前置条件

- 个人付费 Plan
- 一个微信账户

### 付费访问要求

[2026-07-08 公告](/zh/changelog/2026-07-08-wechat-chat-adjustment)预计从美国东部时间 2026-07-10 12:00 PM（北京时间 2026-07-11 00:00）调整微信访问：新建或重新连接需要个人付费 Plan，预告期结束后继续使用已有连接也需要付费 Plan。调整仅针对微信消息通道，不影响 LobeHub 对话、模型使用或其他基础功能。

## 第一步：打开渠道设置

在 LobeHub 中，导航到您的代理设置，然后选择 **渠道** 标签页。从平台列表中点击 **微信**。

## 第二步：扫码连接

<Steps>
  ### 点击 "扫码连接"

  在微信渠道页面中，点击 **扫码连接** 按钮。将弹出一个显示二维码的对话框。

  ### 使用微信扫码

  打开手机微信，点击右上角的 **+** 按钮，选择 **扫一扫**，扫描 LobeHub 中显示的二维码。

  ### 确认登录

  扫码后，微信中会出现确认提示。点击 **确认** 授权连接。

  ![](/blog/assets8a08815733e06500b6552019d6dfbe7b.webp)

  ### 连接完成

  确认后，LobeHub 将自动保存凭证并连接机器人。您应该会在渠道设置中看到成功消息。
</Steps>

## 第三步：测试机器人

打开微信，找到您的机器人联系人，发送一条消息。机器人应通过您的 LobeHub 代理进行响应。

## 群聊支持边界

本指南仅说明微信私聊接入。仓库原文对群聊的说明存在冲突，2026-07-08 公告只说明付费访问调整，并未确认群聊能力。因此，此处不提供拉群或群内 `@` 触发步骤，也不将群聊列为已确认支持的功能。

如需群聊，请先核实当前微信连接的实际支持范围，或选择[渠道概览](/zh/docs/usage/channels/overview)中已明确支持群聊的平台。

## 高级设置

| 设置         | 默认值     | 描述                                                                                      |
| ---------- | ------- | --------------------------------------------------------------------------------------- |
| **字符限制**   | 2000    | 每条消息的最大字符数（范围：100–2048）                                                                 |
| **并发模式** | `burst` | 将短时间内到达的图片和文字合并为同一轮消息；也可以选择 `debounce` |
| **消息合并窗口** | 5000 毫秒 | 在 `burst` 或 `debounce` 模式下等待同一轮后续消息的时间 |
| **显示使用统计** | 关闭      | 在回复中显示 Token 用量 / 成本统计                                                                  |

## 工作原理

与基于 Webhook 的平台（Telegram、Slack）不同，微信使用 iLink Bot API 的 **长轮询** 机制：

1. 当您扫描二维码时，LobeHub 从微信 iLink API 获取 bot token
2. LobeHub 通过 iLink API 持续等待新消息；单次长轮询的等待窗口通常约为 35 秒，结束后会立即开始下一次轮询
3. 当消息到达时，通过 LobeHub 代理进行处理
4. 代理的响应通过 iLink API 发送回微信

轮询连接由后台消息网关维护，并会自动续接。

## 功能限制

- **不支持消息编辑** — 微信不支持编辑已发送的消息。更新的回复将作为新消息发送。
- **不支持表情回应** — 微信 iLink Bot API 不支持表情回应功能。
- **消息长度限制** — 超过字符限制的消息将被自动拆分为多条消息发送。
- **会话过期** — 机器人会话可能会过期，需要重新扫码认证。

## 故障排除

- **二维码已过期：** 在弹窗中点击 **刷新二维码** 生成新的二维码。
- **机器人未响应：** 会话可能已过期。前往微信渠道设置，重新扫码连接。
- **响应延迟：** 35 秒是单次长轮询的等待窗口，并不表示每条消息都会等待 35 秒。如果持续延迟，请检查连接状态并重新扫码。
- **一段时间后连接断开：** 微信会话会定期过期。再次点击 "扫码连接" 重新认证。
