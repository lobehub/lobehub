# Connect LobeHub to DingTalk

By connecting a DingTalk channel to your LobeHub agent, users can chat with the assistant in DingTalk private messages and in group chats when they explicitly `@` the bot.

## Prerequisites

- A LobeHub instance with access to the **Channels** feature
- A DingTalk enterprise account with permission to create an internal app

## Step 1: Prepare the DingTalk App

<Steps>
  ### Open the DingTalk Developer Console

  Visit the DingTalk Open Platform and open your enterprise internal app.

  ### Enable Bot / Event Callback Capability

  Make sure the app can receive chat messages and configure event callbacks.

  ### Copy the Required Credentials

  Prepare these values from the DingTalk app settings:

  - **AppKey** — use this as `Application ID` in LobeHub
  - **AppSecret** — use this as `App Secret`
  - **Verification Token** — use this as `Verification Token`
  - **AES Key** — use this as `AES Key`
</Steps>

## Step 2: Configure DingTalk in LobeHub

<Steps>
  ### Open Channel Settings

  In LobeHub, open the target agent and go to **Channels** → **DingTalk**.

  ### Fill in the Credentials

  Enter the DingTalk values you prepared in Step 1.

  ### Choose the Reply Mode

  - **Markdown** — sends replies using DingTalk's markdown template
  - **Text** — sends plain-text replies

  ### Save and Copy the Webhook URL

  Click **Save Configuration**. After saving, LobeHub shows the webhook URL for this channel. Copy it for the DingTalk console.
</Steps>

## Step 3: Configure the Callback in DingTalk

<Steps>
  ### Paste the Webhook URL

  Go back to the DingTalk developer console and open the callback / event subscription settings for the app.

  Paste the webhook URL copied from LobeHub into the callback URL field.

  ### Use the Same Verification Token and AES Key

  Make sure the **Verification Token** and **AES Key** in DingTalk exactly match the values saved in LobeHub.

  ### Save the Callback Configuration

  DingTalk will verify the endpoint during setup. Once verification succeeds, the bot can start receiving messages.
</Steps>

## Behavior and Limitations

- **Private chats** trigger the bot automatically
- **Group chats** trigger the bot only when the bot is mentioned
- **Shared group thread** — each DingTalk group maps to one shared conversation thread in LobeHub
- **Inbound support** — text messages only in the current MVP
- **Outbound support** — text and markdown replies are supported
- **No edit / reaction / typing support** — DingTalk webhook mode does not currently support these bot features in LobeHub

## Configuration Reference

| Field                    | Required | Description                                            |
| ------------------------ | -------- | ------------------------------------------------------ |
| **Application ID**       | Yes      | DingTalk `AppKey`                                      |
| **App Secret**           | Yes      | DingTalk `AppSecret`                                   |
| **Verification Token**   | Yes      | Verifies incoming DingTalk callback requests           |
| **AES Key**              | Yes      | Decrypts DingTalk encrypted callback payloads          |
| **Reply Mode**           | No       | Choose between `Markdown` and `Text`                   |
| **Webhook URL**          | —        | Auto-generated by LobeHub after saving the channel     |

## Troubleshooting

- **Test Connection failed** — recheck the AppKey and AppSecret in LobeHub
- **Callback verification failed** — ensure the webhook URL, Verification Token, and AES Key match exactly on both sides
- **The bot does not reply in groups** — DingTalk group messages require an explicit `@` mention in this MVP
- **Markdown formatting looks odd** — switch the channel to **Text** reply mode for a plainer fallback
