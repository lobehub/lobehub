# 将 LobeHub 连接到企业微信

把企业微信智能机器人接入 LobeHub 代理后，同事可以在企业微信单聊里直接和 AI 助手对话，也可以在企业内部群里 @ 机器人提问。

LobeHub 使用企业微信智能机器人的 **API 模式 + 长连接**：由 LobeHub 主动连接企业微信，**不需要公网 IP、回调地址或备案域名**。

> **当前可用范围：** 企业微信机器人的回复必须走它自己的那条长连接，所以只能在由 LobeHub 服务进程自己维持渠道连接的部署中使用（例如自部署的 LobeHub）。使用外部消息网关托管渠道连接的部署暂时不会显示企业微信。

## 前置条件

- 一个企业微信企业，以及可以进入管理后台的管理员账号
- 未认证的企业最多 100 人使用企业微信；未认证企业能否创建智能机器人，官方文档没有说明

## 第一步：创建智能机器人

<Steps>
  ### 打开管理后台

  访问 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame) 并登录。

  ### 创建 API 模式的机器人

  进入 **智能专区 → 智能机器人**，点击 **创建**，选择 **API 模式**，并使用 **长连接** 接收消息。

  ### 复制 BotID 和 Secret

  在机器人的 API 配置中复制 **BotID** 和长连接 **Secret**。

  > **重要提示：** 同一个机器人同一时间只能有一条长连接。在其他地方（另一套部署、本地开发环境、其他工具）接入同一个机器人，会让 LobeHub 这边的连接断开。
</Steps>

## 第二步：在 LobeHub 中配置

<Steps>
  ### 打开渠道设置

  在 LobeHub 中进入代理设置，选择 **渠道** 标签页，从平台列表中点击 **WeCom**。

  ### 填写凭证

  - **BotID** — 第一步复制的 BotID
  - **Secret** — 第一步复制的长连接 Secret

  ### 保存并连接

  点击 **保存配置**。LobeHub 会用 BotID 和 Secret 建立长连接，状态变为已连接后即可使用。
</Steps>

## 第三步：测试

- **单聊：** 在企业微信里找到机器人，发一条消息。机器人会先显示正在回复的气泡，回复完成后填入内容。
- **群聊：** 把机器人加入企业内部群，在消息里 @ 它。外部群和互联群不支持机器人。

## 接入策略

和其他渠道一样，**私信策略**、**群组策略**、**允许的用户 ID** 控制机器人接收哪些消息，详见 [渠道概览](/docs/usage/channels/overview#direct-message-policy)。用户 ID 和群 ID 使用企业微信消息里的 `userid` 和 `chatid`。机器人创建者不是超级管理员时，`userid` 是加密后的 open_userid。

## 配置参考

| 字段                  | 是否必需 | 描述                   |
| ------------------- | ---- | -------------------- |
| **BotID**           | 是    | 智能机器人（API 模式）的 BotID |
| **Secret**          | 是    | 机器人的长连接 Secret       |
| **字符限制**            | 否    | 单条回复的最大字数，默认且最大 6000 |
| **私信策略** / **群组策略** | 否    | 控制谁可以私信、机器人在哪些群响应    |

## 功能限制

- **群聊只收文字** — 群里 @ 机器人时，企业微信只推送文本、图文混排和引用消息。
- **没有话题 / 线程** — 每个群是一个会话。
- **不支持编辑、撤回、表情回应** — 机器人发出的消息不能修改。
- **回复暂不带附件** — 当前版本只回复文字。
- **回复窗口** — 收到消息 24 小时内可以回复；单条流式回复需要在 10 分钟内完成，超过后结果会作为一条新消息推送。

## 故障排除

- **状态显示失败，提示被另一个连接接管：** 同一个 BotID 在别处建立了长连接。停掉另一处的接入后，在 LobeHub 中重新保存或重连。
- **保存时提示凭证无效：** 检查 BotID 和 Secret 是否来自同一个机器人，以及机器人是否为 API 模式。
