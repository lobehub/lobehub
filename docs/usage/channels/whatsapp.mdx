# Connect LobeHub to WhatsApp

> **Current status: Coming Soon.** The WhatsApp channel is not yet available for configuration, so you cannot connect it to LobeHub at this time.

The planned WhatsApp channel will let users interact with LobeHub agents in a familiar mobile chat environment. It is intended for teams that support customers, follow up on conversations, or provide services directly through messaging.

## What You Can Do Now

- Check the WhatsApp launch status on the agent **Channels** page.
- Use one of the channels that is currently available; see the [Channels Overview](/docs/usage/channels/overview) for the complete list.
- Return to this page after the WhatsApp channel launches for the supported setup procedure.

## Configuration Is Not Available Yet

Before launch, you cannot:

- Connect a WhatsApp or WhatsApp Business account
- Enter access tokens, phone numbers, or webhook settings
- Test inbound or outbound messages
- Configure DM, group, or allowed-user policies

Do not infer the required WhatsApp fields from another platform's setup. Account requirements, connection method, supported message types, and access policies will be documented here when the channel becomes available.

## Frequently Asked Questions

### Why does the Channels page show “Coming Soon”?

This is the current product status. It does not indicate an account-permission or configuration error. The WhatsApp channel has not launched yet.

### Can I use the WhatsApp connector instead?

The WhatsApp service connector available as an agent tool is separate from the **message channel** described here. A connector lets an agent perform authorized messaging actions. A channel binds a conversation entry point to an agent. They have separate availability and authorization flows and do not replace each other.

### When will it launch?

The current documentation does not provide a verified release date, so this page does not make a timing commitment. The full setup steps will be added here when the status changes.
