## Report an Issue

Found a bug or have a feature request? Open an issue on GitHub — we track everything there and respond as we can.

- [**GitHub Issues**](https://github.com/lobehub/lobe-chat/issues/new/choose) — Bug reports, feature requests, and discussions

Before submitting, check existing issues to see if someone has already reported it. Include steps to reproduce for bugs, and describe your use case for feature requests.

## Community Support

Ask questions, share tips, and help others in the LobeHub community:

- [**Discord**](https://discord.com/invite/AYFPHvv2jT) — Real-time chat, announcements, and support
- [**Reddit**](https://www.reddit.com/r/LobeHub/) — Discussions and community updates

Community members and the team often respond within hours. Search existing threads first — your question may already have an answer.

## Contact Us

For partnerships, enterprise inquiries, or topics that don't fit elsewhere:

- **Email** — [hi@lobehub.com](mailto:hi@lobehub.com)
- **X (Twitter)** — [@lobehub](https://x.com/lobehub)

We read every message but can't always reply quickly. For technical support, GitHub Issues or Discord usually get faster responses.
