## 反馈问题

发现 Bug 或有功能建议？在 GitHub 提交 Issue，我们会在此跟进并尽可能回复。

- [**GitHub Issues**](https://github.com/lobehub/lobe-chat/issues/new/choose) — Bug 反馈、功能建议与讨论

提交前建议先搜索已有 Issue，看是否已有人反馈。Bug 请附上复现步骤，功能建议请说明使用场景。

## 社区支持

在 LobeHub 社区提问、分享技巧、帮助他人：

- [**Discord**](https://discord.com/invite/AYFPHvv2jT) — 实时交流、公告与支持
- [**Reddit**](https://www.reddit.com/r/LobeHub/) — 讨论与社区动态

社区成员和团队通常会在数小时内回复。建议先搜索已有讨论 —— 你的问题可能已有答案。

## 联系我们

合作、企业咨询或其他不适合上述渠道的事项：

- **邮箱** — [hi@lobehub.com](mailto:hi@lobehub.com)
- **X (Twitter)** — [@lobehub](https://x.com/lobehub)

我们会阅读每封邮件，但无法保证及时回复。技术类问题通过 GitHub Issues 或 Discord 通常能更快得到响应。
