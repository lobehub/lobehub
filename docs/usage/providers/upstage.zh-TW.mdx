# 在 LobeHub 中使用 Upstage

<Image cover src={'/blog/assets710bf5a4704e520976b19dd2466fa56a.webp'} />

[Upstage](https://www.upstage.ai/) 是一個提供 AI 模型和服務的平臺，專注於自然語言處理和機器學習應用程式。它允許開發者通過 API 接入其強大的 AI 功能，支援多種任務，如文字生成、對話系統等。

本文將指導你如何在 LobeHub 中使用 Upstage。

<Steps>
  ### 步驟一：獲得 Upstage 的 API Key

  - 註冊並登入 [Upstage 控制檯](https://console.upstage.ai/home)
  - 進入 `API Keys` 頁面
  - 建立一個新的 API 密鑰
  - 複製並儲存生成的 API 密鑰

  <Image alt={'儲存 API 密鑰'} inStep src={'/blog/assets74fbd94a0dc865d2178954662dc964ae.webp'} />

  ### 步驟二：在 LobeHub 中設定 Upstage

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `Upstage` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets9f6d4113be26efbcab41d83ed39dcb14.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Upstage 的模型即可開始對話

  <Image alt={'選擇 Upstage 模型並開始對話'} inStep src={'/blog/assets6ef9f3f3627633bb5282fe9df1d31a4a.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Upstage 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Upstage 提供的模型進行對話了。
