# 在 LobeHub 中使用 NagaAI

[NagaAI](https://naga.ac) 是一个 API 网关，通过一个兼容 OpenAI 的端点提供多家厂商的模型，模型 ID 形如 `vendor/model`。它是独立的网关，不是模型厂商的官方 API。

<Steps>
  ### 步骤一：创建 API 密钥

  - 登录 [naga.ac](https://naga.ac)
  - 打开 [API Keys](https://naga.ac/dashboard/api-keys)，点击 **Create API key**

  ### 步骤二：在 LobeHub 中配置 NagaAI

  - 打开 **应用设置 → AI 服务商**，找到 `NagaAI`
  - 填入 API 密钥，并打开服务商开关
  - 点击 **检查** 验证连接
  - 点击 **获取模型列表** 加载当前模型，然后启用需要的模型

  <Callout type={'warning'}>
    NagaAI 按 token 计费，当前价格见 [NagaAI 模型页面](https://naga.ac/models)。
  </Callout>
</Steps>

## API 模式

对话与结构化输出发送到 Responses API（`https://api.naga.ac/v1/responses`）。模型列表来自 `https://api.naga.ac/v1/models`，仅列出支持 Responses API 的模型。
