# 在 LobeHub 中使用 Perplexity AI

<Image alt={'在 LobeHub 中使用 Perplexity AI'} cover src={'/blog/assets17870709/0c2c399f-2ed3-44b5-97c8-53e007e8c095.webp'} />

Perplexity AI API 現在可供所有人使用，本文件將指導你如何在 LobeHub 中使用 [Perplexity AI](https://www.perplexity.ai/):

<Steps>
  ### 步驟一：獲取 Perplexity AI API 密鑰

  - 建立一個 [Perplexity AI](https://www.perplexity.ai/) 帳戶
  - 獲取您的 [API 密鑰](https://www.perplexity.ai/settings/api)

  <Image alt={'建立 API Key'} inStep src={'/blog/assets17870709/80e22593-dc0f-482c-99bf-69acdb62d952.webp'} />

  ### 步驟二：在 LobeHub 中設定 Perplexity AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`Perplexity AI`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets17870709/51f8f8f6-5d8a-4cf0-a2e5-d96c69fe05b8.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Perplexity AI 的模型即可開始對話

  <Image alt={'選擇 Perplexity AI 模型並開始對話'} inStep src={'/blog/assets17870709/e6a429cb-96e1-4e85-9aa3-1334ffcad8c0.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Perplexity AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Perplexity AI 提供的模型進行對話了。
