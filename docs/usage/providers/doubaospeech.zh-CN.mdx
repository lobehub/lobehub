# 在 LobeHub 中使用豆包语音

[豆包语音](https://www.volcengine.com/product/tts) 是字节跳动火山引擎的语音合成服务，Seed-TTS 2.0 模型使用官方音色合成自然的中英文语音。在 LobeHub 中，豆包语音（Doubao Speech）只提供语音合成（TTS），没有对话模型。

豆包语音与火山方舟（**火山引擎** 服务商，提供豆包对话、图像与视频模型）是两套独立的服务，控制台与凭证都不同。

<Steps>
  ### 步骤一：获取豆包语音凭证

  - 登录 [火山引擎语音控制台](https://console.volcengine.com/speech/new)，开通豆包语音合成模型 2.0；
  - 推荐：在新版控制台的 **API Key 管理** 中创建并复制 API Key；
  - 旧版控制台账号：改为复制应用的 **App ID** 与 **Access Token**。

  ### 步骤二：在 LobeHub 中配置豆包语音

  - 打开 **应用设置 → AI 服务商**，选择 **Doubao Speech**（可在服务商搜索框中输入 `Doubao` 快速定位）；
  - 将 API Key 粘贴到 **API Key**，或填写 **App ID（旧版控制台）** 与 **Access Token（旧版控制台）**。两者都填写时使用 API Key。修改会自动保存，凭证在存储前会使用 AES-GCM 加密；
  - 打开服务商名称右侧的开关；
  - 可选：如需经代理发送请求，可在 **API 代理地址** 中填写。留空则使用 `https://openspeech.bytedance.com`。

  ### 步骤三：选择模型

  **模型列表** 的 **TTS** 标签下列出了 **Doubao Speech 2.0**（`seed-tts-2.0`），默认启用。

  豆包语音没有对话模型，因此服务商页面不显示 **检查** 按钮。可按下文方式生成一段语音来验证凭证。

  <Callout type={'warning'}>
    豆包语音合成模型 2.0 按 3 元 / 万字符计费，汉字、字母、标点和空格都按 1 个字符计。大量生成音频前，请先查看 [火山引擎语音计费说明](https://www.volcengine.com/docs/6561/1359370)。
  </Callout>
</Steps>

## 生成语音

语音合成通过 LobeHub 的语音合成接口完成，LobeHub CLI（`lh`）与兼容 OpenAI 的 `POST /api/v1/audio/speech` 接口都使用该接口：

```bash
lh generate tts "你好，LobeHub" -m doubaospeech/seed-tts-2.0 -o hello.mp3
```

- **音色**：未指定时使用 Vivi 2.0（`zh_female_vv_uranus_bigtts`）。可用 `--voice <voice_type>` 指定其他官方 2.0 音色，例如 `zh_male_m191_uranus_bigtts`（云舟）、`en_male_tim_uranus_bigtts`（Tim），或你自己的复刻音色（`S_…`，会自动改用声音复刻资源 `seed-icl-2.0`，需要开通豆包声音复刻模型 2.0）。1.0 音色（`*_moon_bigtts`、`*_mars_bigtts`）不能用于 2.0 模型；
- **长度**：语音以单个响应返回，每次请求最多 4096 个字符，更长的文本请拆成多次请求；
- **格式**：`mp3`（默认）或 `opus`（固定 48 kHz）；
- **语速与音量**：`0.5` 至 `2`；
- **音调**：`-12` 至 `12` 个半音；
- **采样率**：8000、16000、22050、24000（默认）、32000、44100 或 48000 Hz。

## 常见问题

**“Doubao Speech API Key is incorrect or empty, please check your Doubao Speech API Key and try again.”**：没有找到凭证、App ID 与 Access Token 只填了一项，或凭证被火山引擎拒绝。请在 **应用设置 → AI 服务商 → Doubao Speech** 中填写有效的 API Key（或 App ID + Access Token），或请管理员在服务端设置 `DOUBAOSPEECH_API_KEY`。

**“Enable the voice for this account…”**：账号未开通该音色。请在火山引擎语音控制台开通，或换用其他音色。

**“The voice does not belong to this model version…”**：在 2.0 模型上使用了 1.0 音色，或账号未开通豆包语音合成模型 2.0。

**限流或额度错误**：账号达到并发上限（默认 10 路），或余额、试用额度已用完。请在火山引擎控制台查看。

自托管部署请参阅 [模型服务商环境变量](/zh/docs/self-hosting/environment-variables/model-provider#doubao-speech) 中的 `DOUBAOSPEECH_API_KEY`。
