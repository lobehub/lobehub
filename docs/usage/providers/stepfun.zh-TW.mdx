# 在 LobeHub 中使用 Stepfun 階躍星辰

<Image alt={'在 LobeHub 中使用 Stepfun 階躍星辰'} cover src={'/blog/assets34400653/95717e2b-1a55-4fca-a96b-b1c186ed4563.webp'} />

[Stepfun 階躍星辰](https://www.stepfun.com/)是一家專注於通用人工智慧 (AGI) 研發的創業公司，目前已推出 Step-1 千億參數語言大模型、Step-1V 千億參數多模態大模型，以及 Step-2 萬億參數 MoE 語言大模型預覽版。

本文件將指導你如何在 LobeHub 中使用 Stepfun 階躍星辰:

<Steps>
  ### 步驟一：獲取 Stepfun 階躍星辰 API 密鑰

  - 存取並登入 [Stepfun Stepfun 階躍星辰開放平臺](https://platform.stepfun.com/)
  - 進入`接口密鑰`選單，系統已為你建立好 API 密鑰
  - 複製已建立的 API 密鑰

  <Image alt={'獲取 Stepfun 階躍星辰API密鑰'} inStep src={'/blog/assets34400653/33d8ce3b-0083-48aa-9a66-3825e726c4de.webp'} />

  ### 步驟二：在 LobeHub 中設定 Stepfun Stepfun 階躍星辰

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到` Stepfun 階躍星辰`的設定項

  <Image alt={'填寫 API 密鑰'} inStep src={'/blog/assets34400653/470e5669-650b-46cf-8024-a1476c166059.webp'} />

  - 開啟 Stepfun 階躍星辰並填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Stepfun 階躍星辰的模型即可開始對話

  <Image alt={'選擇 Stepfun 階躍星辰模型並開始對話'} inStep src={'/blog/assets34400653/0275a552-f189-42b5-bf40-f9891c428b3d.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Stepfun 階躍星辰的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Stepfun 階躍星辰提供的模型進行對話了。
