# Using Minimax in LobeHub

<Image alt={'Using Minimax in LobeHub'} cover src={'/blog/assets34400653/703f170b-c03b-4c71-b57d-c2357596bdfb.webp'} />

[MiniMax](https://www.minimaxi.com/) is a general artificial intelligence company founded in 2021, dedicated to co-creating intelligence with users. MiniMax has independently developed multi-modal general-purpose large models, including trillion-parameter MoE text models, speech models, and image models. It has also launched applications such as Conch AI.

This guide will walk you through how to use MiniMax in LobeHub:

To configure this provider in LobeHub, open **App Settings → AI Providers**, select the provider, and turn on its switch.

<Steps>
  ### Step 1: Obtain a MiniMax API Key

  - Register and log in to the [MiniMax Developer Platform](https://www.minimaxi.com/platform)
  - Navigate to the `Account Management` section and find the `API Keys` menu to create a new key

  <Image alt={'Create a MiniMax API Key'} inStep src={'/blog/assets34400653/f6e46f1c-0ac9-42ae-8e83-ddb0cc6c5bf8.webp'} />

  - Enter a name for your API key and create it

  <Image alt={'Enter API Key Name'} inStep src={'/blog/assets34400653/cbc23ca9-1188-4b85-8ef0-e75ac7d74b92.webp'} />

  - Copy the API key from the pop-up dialog and store it securely

  <Image alt={'Save API Key'} inStep src={'/blog/assets34400653/fb0f7574-c2f5-40d6-8613-3749e85ce881.webp'} />

  <Callout type={'warning'}>
    Make sure to store your API key securely, as it will only be shown once. If you lose it, you’ll need to generate a new one.
  </Callout>

  ### Step 2: Configure MiniMax in LobeHub

  - Go to the `Settings` page in LobeHub
  - In the provider list, select the `MiniMax` configuration section

  <Image alt={'Enter API Key'} inStep src={'/blog/assets34400653/b839e04e-0cef-46a3-bb84-0484a3f51c69.webp'} />

  - Enable MiniMax and paste in your API key
  - Choose a MiniMax model for your AI assistant to start chatting

  <Image alt={'Select MiniMax Model and Start Chatting'} inStep src={'/blog/assets34400653/f7d59c7a-abd0-4ebd-8c72-ca10c47a0f1a.webp'} />

  <Callout type={'warning'}>
    Please note that usage may incur charges from the API provider. Refer to MiniMax’s pricing policy for more details.
  </Callout>
</Steps>

You're all set! You can now start chatting with models powered by MiniMax in LobeHub.

## Generate music

MiniMax Music writes songs with vocals from lyrics and a style prompt, or covers a reference track. It uses the same MiniMax key and API host as chat; there is nothing extra to configure.

<Callout type={'warning'}>
  MiniMax stopped offering the music API to new accounts. Only accounts that already have paid music API access can generate music. Other keys pass the provider **Check** (it uses a chat model), but every music song fails with `MiniMax music API error (410): This Music API is no longer available to new users…` (the raw API returns status code `2153`).
</Callout>

The **Model List** shows the music models under the **Music** tab. They are off by default; turn on the ones your account can use:

| Model         | Use                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------ |
| `music-3.0`   | A song with vocals from lyrics and a style prompt, or an instrumental track.               |
| `music-2.6`   | The previous generation of `music-3.0`.                                                    |
| `music-cover` | Covers a reference track (6 seconds to 6 minutes, up to 50 MB) in the style of the prompt. |

### On the Music page

1. Open the **Music** page. It is next to **Image** and **Video** in the creation mode switch, or go to `/music` directly.
2. Choose a MiniMax model under **Model**.
3. For `music-3.0` or `music-2.6`: describe the style in the prompt box and enter **Lyrics** (up to 3,500 characters, with tags such as `[Verse]` and `[Chorus]`). Without lyrics, turn on **Write lyrics for me** or **Instrumental**.
4. For `music-cover`: under **Reference Audio**, click **Upload Audio** or paste an audio URL and press Enter. Then describe the target style in the prompt box (10–300 characters). **Lyrics** are optional (10–1,000 characters) and replace the original words.
5. Optional: adjust **Audio Format**, **Sample Rate**, and **Bitrate** under **Audio Settings**.
6. Click **Generate**. The song card shows **Generating…**, then the player when the song is ready. Press play to listen, or download the file.

### Through the API

Use the same `lambda` tRPC calls as Suno (see [Generate music through the API](/docs/usage/providers/suno#generate-music-through-the-api)), with `provider` set to `minimax`. MiniMax returns one song per request. A cover with lyrics and a reference track:

```bash
curl -s -X POST "$LOBEHUB_URL/trpc/lambda/music.createMusic" \
  -H "X-API-Key: $LOBEHUB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"json":{
    "generationTopicId":"<generationTopicId>",
    "provider":"minimax",
    "model":"music-cover",
    "params":{
      "prompt":"Slow jazz ballad with soft piano and brushed drums",
      "lyrics":"[Verse]\nRain on the window, coffee gone cold\n[Chorus]\nStay a little longer",
      "referenceAudioUrl":"https://example.com/reference.mp3",
      "format":"mp3",
      "sampleRate":44100,
      "bitrate":256000
    }}}'
```

For `music-3.0` or `music-2.6`, drop `referenceAudioUrl` and send `prompt` with `lyrics`, or `instrumental: true`, or `autoLyrics: true`. Poll `generation.getGenerationStatus` with each returned `asyncTaskId` and `generation.id` until `status` is `success`; the audio is at `generation.asset.url`.

LobeHub sends this to MiniMax as a single synchronous request; the music API itself has no task to poll:

```bash
curl -s -X POST https://api.minimaxi.com/v1/music_generation \
  -H "Authorization: Bearer $MINIMAX_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "music-cover",
    "prompt": "Slow jazz ballad with soft piano and brushed drums",
    "lyrics": "[Verse]\nRain on the window, coffee gone cold\n[Chorus]\nStay a little longer",
    "audio_url": "https://example.com/reference.mp3",
    "output_format": "url",
    "audio_setting": { "format": "mp3", "sample_rate": 44100, "bitrate": 256000 }
  }'
# → {"data":{"audio":"<temporary audio URL>","status":2},"base_resp":{"status_code":0,"status_msg":"success"}}
```

`instrumental` is sent as `is_instrumental` and `autoLyrics` as `lyrics_optimizer`. Global accounts use `https://api.minimax.io/v1`; see `MINIMAX_PROXY_URL` in the [model provider environment variables](/docs/self-hosting/environment-variables/model-provider#minimax-ai).
