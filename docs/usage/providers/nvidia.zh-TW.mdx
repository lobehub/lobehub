# 在 LobeHub 中使用 Nvidia NIM

<Image alt={'在 LobeHub 中使用 Nvidia NIM'} cover src={'/blog/assetsd8927338578c426b833e5cb57e0b57ec.webp'} />

[NVIDIA NIM](https://developer.nvidia.com/nim) 是 NVIDIA AI Enterprise 的一部分，旨在通過微服務加速生成式 AI 應用程式的部署。它提供了一組易於使用的推理微服務，可以在任何雲、資料中心或工作站上執行，支援 NVIDIA GPU 加速。

本文件將指導你如何在 LobeHub 中接入並使用 Nvidia NIM 提供的 AI 模型:

<Steps>
  ### 步驟一：獲取 Nvidia NIM  API 密鑰

  - 首先，存取[Nvidia NIM 控制檯](https://build.nvidia.com/explore/discover)並完成註冊登入
  - 在 `Models` 頁面選擇你需要的模型，例如 Deepseek-R1

  <Image alt={'選擇模型'} inStep src={'/blog/assets74000cc1bc59ee4a15e8f0304afbf866.webp'} />

  - 在模型詳情頁點擊`使用此NIM構建`
  - 在彈出的對話框中點擊`生成 API Key` 按鈕

  <Image alt={'獲取 API Key'} inStep src={'/blog/assetsaf57d31364a41634b10c243ed9b1f8f8.webp'} />

  - 複製並儲存建立好的 API Key

  <Callout type={'warning'}>
    請安全地儲存密鑰，因為它只會出現一次。如果你意外丟失它，您將需要建立一個新密鑰。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 Nvidia NIM

  - 存取 LobeHub 的 `應用程式設定` 的 `AI 服務供應商` 界面
  - 在供應商列表中找到 ` Nvidia NIM` 的設定項

  <Image alt={'填寫 Nvidia NIM API 密鑰'} inStep src={'/blog/assetscad58c557fda04b9379000cbbaa4c493.webp'} />

  - 開啟 Nvidia NIM 服務商並填入獲取的 API 密鑰
  - 為你的助手選擇一個 Nvidia NIM 模型即可開始對話

  <Image alt={'選擇 Nvidia NIM 模型'} inStep src={'/blog/assets45d90e73abffd7ae7d85808f81827bb9.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Nvidia NIM 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Nvidia NIM 提供的模型進行對話了。
