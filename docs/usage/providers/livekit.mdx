# Use LiveKit Inference in LobeHub

[LiveKit Inference](https://docs.livekit.io/agents/models/inference/) provides model inference through a LiveKit Cloud project. This integration supports its language-model gateway. Usage is billed through LiveKit Cloud; review the [current pricing](https://livekit.com/pricing) and your project's model availability.

1. Sign in to [LiveKit Cloud](https://cloud.livekit.io) and obtain your project's API key and matching API secret.
2. Open **App Settings → AI Providers → LiveKit**. Enter both **API Key** and **API Secret**, then enable the provider. Credentials are saved automatically.
3. Enable the desired models in the built-in model list. Use **Check** to verify a language-model request.
4. Select a LiveKit language model in the model selector. Adding the provider preserves your existing model selections.

The catalog is bundled with LobeHub and does not fetch model definitions from LiveKit. It includes selected Gemma and OpenAI language models. Model IDs retain their gateway prefix, such as `google/gemma-4-31b-it`.

## Troubleshooting

Self-hosted deployments can provide shared defaults with `LIVEKIT_INFERENCE_API_KEY` and `LIVEKIT_INFERENCE_API_SECRET`. Set both values from one project. A user's configured credential pair takes priority. The built-in catalog is used in either case. See the [provider environment reference](/docs/self-hosting/environment-variables/model-provider#livekit-inference).

If authentication fails, verify that both credentials belong to the same LiveKit Cloud project and that the project has access to Inference. An OpenAI API key does not authenticate LiveKit Inference.
