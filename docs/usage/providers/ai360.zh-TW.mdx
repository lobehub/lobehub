# 在 LobeHub 中使用 360 智腦

<Image cover src={'/blog/assets3386e7adc46d19be5cc6dae46533d9bd.webp'} />

[360 智腦](https://ai.360.com/)是 360 公司自主研發的認知型通用大模型，旨在為企業和開發者提供強大的自然語言處理能力。該模型已升級至 4.0 版本，能夠支援多種應用場景，包括對話服務、圖片生成、向量資料庫服務等。

本文將指導你如何在 LobeHub 中使用 360 智腦。

<Steps>
  ### 步驟一：獲得 360 智腦的 API Key

  - 註冊並登入 [360 智腦 API 開放平臺](https://ai.360.com/platform/keys)
  - 點擊左側 `API Keys` 選單
  - 建立一個 API 密鑰並複製

  <Image alt={'建立API密鑰'} inStep src={'/blog/assets688e6e10904ad46cf7f44bba6359f90c.webp'} />

  ### 步驟二：在 LobeHub 中設定 360 智腦

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `360` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets65c86d6e63ddd5dd9896a6a67c054c0d.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 360 智腦的模型即可開始對話

  <Image alt={'選擇360模型並開始對話'} inStep src={'/blog/assets78232916d13ddc942ab3d0b62b639509.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 360 智腦的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 360 智腦提供的模型進行對話了。
