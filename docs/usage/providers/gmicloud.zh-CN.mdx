# 在 LobeHub 中使用 GMI Cloud

[GMI Cloud](https://www.gmicloud.ai) 是一家 GPU 云服务商，提供兼容 OpenAI 的 Serverless 推理 API，支持 DeepSeek、Qwen、GLM、Kimi、MiniMax 等开源模型。

本文档将指导你如何在 LobeHub 中使用 GMI Cloud:

<Steps>
  ### 步骤一：获取 GMI Cloud API 密钥

  - 首先，你需要注册并登录 [GMI Cloud 控制台](https://console.gmicloud.ai)
  - 在 API Keys 页面中创建一个 API 密钥
  - 复制得到的 API 密钥并妥善保存

  <Callout type={'warning'}>
    请妥善保存生成的 API Key，它只会出现一次，如果不小心丢失了，你需要重新创建一个 API key
  </Callout>

  ### 步骤二：在 LobeHub 中配置 GMI Cloud

  - 打开 **应用设置 → AI 服务商**
  - 在服务商列表中选择 `GMI Cloud`
  - 打开 GMI Cloud 并填入获取的 API 密钥
  - 点击 `获取模型列表` 加载 GMI Cloud 的全部模型，然后为你的助手选择模型

  <Callout type={'warning'}>
    在使用过程中你可能需要向 API 服务提供商付费，请参考 GMI Cloud 的[价格说明](https://www.gmicloud.ai/pricing)。
  </Callout>
</Steps>

至此你已经可以在 LobeHub 中使用 GMI Cloud 提供的模型进行对话了。
