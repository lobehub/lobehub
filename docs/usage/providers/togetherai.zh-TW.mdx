# 在 LobeHub 中使用 Together AI

<Image alt={'在 LobeHub 中使用 Together AI'} cover src={'/blog/assets34400653/28e025dd-367b-4add-85b6-499f4aacda61.webp'} />

[together.ai](https://www.together.ai/) 是一家專注於生成式人工智慧 (AIGC) 領域的平臺，成立於 2022 年 6 月。 它致力於構建用於執行、訓練和微調開源模型的雲平臺，以低於主流供應商的價格提供可擴充功能的計算能力。

本文件將指導你如何在 LobeHub 中使用 Together AI:

<Steps>
  ### 步驟一：獲取 Together AI 的 API 密鑰

  - 存取並登入 [Together AI API](https://api.together.ai/)
  - 初次登入時系統會自動為你建立好 API 密鑰並贈送 $5.0 的額度

  <Image alt={'獲得 together.ai API 密鑰'} inStep src={'/blog/assets34400653/fcdcda9b-8668-4eac-b5cb-04803a888e92.webp'} />

  - 如果你沒有儲存，也可以在後續任意時間，通過 `設定` 中的 `API 密鑰` 界面查看

  <Image alt={'查看 together.ai API 密鑰'} inStep src={'/blog/assets34400653/663335d0-fb37-4882-9c7f-ebbd53275644.webp'} />

  ### 步驟二：在 LobeHub 中設定 Together AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`together.ai`的設定項

  <Image alt={'LobeHub 中填寫 Together AI API 密鑰'} inStep src={'/blog/assets34400653/0cc6c9b8-4688-472b-a80f-f84c5ebbc719.webp'} />

  - 開啟 together.ai 並填入獲得的 API 密鑰
  - 為你的助手選擇一個 Together AI 的模型即可開始對話

  <Image alt={' 選擇並使用 Together AI 模型 '} inStep src={'/blog/assets34400653/34d92da4-783f-4f16-8c4a-9d8e9a03c8da.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Together AI 的費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Together AI 提供的模型進行對話了。
