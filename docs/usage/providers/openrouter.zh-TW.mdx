# 在 LobeHub 中使用 OpenRouter

<Image alt={'在 LobeHub 中使用 OpenRouter'} cover src={'/blog/assets34400653/40520a43-ac03-4954-8a4d-282fbb946066.webp'} />

[OpenRouter](https://openrouter.ai/) 是一個提供多種優秀大語言模型 API 的服務，它支援 OpenAI (包括 GPT-3.5/4)、Anthropic (Claude2、Instant)、LLaMA 2 和 PaLM Bison 等眾多模型。

本文件將指導你如何在 LobeHub 中使用 OpenRouter:

<Steps>
  ### 步驟一：註冊 OpenRouter 帳號並登入

  - 存取 [OpenRouter.ai](https://openrouter.ai/) 並建立一個帳號
  - 你可以用 Google 帳號或 MetaMask 錢包登入

  <Image alt={'註冊 OpenRouter'} height={457} inStep src={'/blog/assets34400653/a024af40-e1d9-4df0-b998-0e6e87cebe5b.webp'} />

  ### 步驟二：建立 API 密鑰

  - 進入 `Keys` 選單或直接存取 [OpenRouter Keys](https://openrouter.ai/keys)
  - 點擊 `Create Key` 開始建立
  - 在彈出對話框中為 API 密鑰取一個名字，例如 "LobeHub Key"
  - 留空 `Credit limit` 表示不設定金額限制

  <Image alt={'建立 OpenRouter Key'} height={460} inStep src={'/blog/assets34400653/094d701f-ce80-464a-bbbc-0a5ecc8d08e3.webp'} />

  - 在彈出的對話框中複製 API 密鑰，並妥善儲存

  <Image alt={'獲取 OpenRouter Key'} height={519} inStep src={'/blog/assets34400653/7a012a11-87bd-4366-a567-0ebf6d12ae10.webp'} />

  <Callout type={'warning'}>
    請安全地儲存密鑰，因為它只會出現一次。如果您意外丟失它，您將需要建立一個新密鑰。
  </Callout>

  ### 步驟三：儲值信用額度

  - 進入 `Credit` 選單，或直接存取 [OpenRouter Credit](https://openrouter.ai/credits)
  - 點擊 `Manage Credits` 儲值信用額度，在 [https://openrouter.ai/models](https://openrouter.ai/models) 中可以查看模型價格
  - OpenRouter 提供了一些免費模型，未儲值的情況下可以使用

  <Image alt={'儲值 OpenRouter 信用額度'} height={385} inStep src={'/blog/assets34400653/50b73232-01fc-4ef0-939a-3e06354d1b5a.webp'} />

  ### 步驟四：在 LobeHub 中設定 OpenRouter

  - 存取 LobeHub 的 `設定` 界面
  - 在 `AI 服務商` 下找到 `OpenRouter` 的設定項
  - 開啟 OpenRouter 並填入獲得的 API 密鑰

  <Image alt={'在 LobeHub 中設定 OpenRouter'} height={518} inStep src={'/blog/assets34400653/5c3898ab-23d7-44c2-bbd9-b255e25e400c.webp'} />

  - 為你的助手選擇一個 OpenRouter 模型即可開始對話

  <Image alt={'使用 OpenRouter 模型'} height={518} inStep src={'/blog/assets34400653/77b5feee-3f46-486d-9a36-31ff60efa5e9.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 OpenRouter 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 OpenRouter 提供的模型進行對話了。
