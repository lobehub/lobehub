# 在 LobeHub 中使用訊飛星火

<Image cover src={'/blog/assetsa343af49a2d7da73a3fa51f2086afdd4.webp'} />

[訊飛星火](https://xinghuo.xfyun.cn/)是科大訊飛推出的一款強大的 AI 大模型，具備跨領域的知識和語言理解能力，能夠執行問答、對話和文學創作等多種任務。

本文將指導你如何在 LobeHub 中使用訊飛星火。

<Steps>
  ### 步驟一：獲得訊飛星火的 API Key

  - 註冊並登入 [訊飛開放平臺](https://console.xfyun.cn/)
  - 建立一個應用程式

  <Image alt={'建立應用程式'} inStep src={'/blog/assets4d0d191b487c114abf084eb7f2dc381c.webp'} />

  - 選擇一個大模型查看詳情
  - 複製右上角 http 服務接口認證資訊中的 `API Password`

  <Image alt={'複製 API 密鑰'} inStep src={'/blog/assets8669131e67e5276fe0744754ba4b1645.webp'} />

  ### 步驟二：在 LobeHub 中設定訊飛星火

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `訊飛星火` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets4169b5d9f7534f9f89c8426445e9a080.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個訊飛星火的模型即可開始對話

  <Image alt={'選擇訊飛星火模型並開始對話'} inStep src={'/blog/assets4175fc55c2093d635f15a3287e89e977.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考訊飛星火的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用訊飛星火提供的模型進行對話了。
