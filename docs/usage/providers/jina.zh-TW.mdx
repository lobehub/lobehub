# 在 LobeHub 中使用 Jina AI

<Image alt={'在 LobeHub 中使用 Jina AI'} cover src={'/blog/assetsc6ff27b7134f280727e1fd7ff83ed2fa.webp'} />

[Jina AI](https://jina.ai/) 是一家成立於 2020 年的開源神經搜尋公司，專注於利用深度學習技術處理多模態資料，提供高效的資訊檢索解決方案，支援文字、圖像、影片等多種資料類型的搜尋。

本文件將指導你如何在 LobeHub 中使用 Jina AI:

<Steps>
  ### 步驟一：獲取 Jina AI API 密鑰

  - 存取 [Jina AI 官方網站](https://jina.ai/)，點擊首頁的 `API` 按鈕

  <Image alt={'獲取 Jina AI API 密鑰'} inStep src={'/blog/assets273112caa08528852992b81dd8f3b75d.webp'} />

  - 在下方的 `API Key` 選單中找到系統為你生成的 API Key
  - 複製並儲存生成的 API Key

  <Callout type={'info'}>
    * Jina AI 會為每個使用者提供 1M 免費的 API Token，無需註冊即可使用 API \* 如果需要管理 API Key，或為
      API 儲值，你需要註冊並登入 [Jina AI 控制檯](https://jina.ai/api-dashboard/)
  </Callout>

  ### 步驟二：在 LobeHub 中設定 Jina AI

  - 存取 LobeHub 的 `應用程式設定`界面
  - 在 `AI 服務商` 下找到 `Jina AI` 的設定項

  <Image alt={'填寫 Jina AI API 密鑰'} inStep src={'/blog/assetsa74aedc4fbbfb2caf6b51f286922b576.webp'} />

  - 開啟 Jina AI 並填入獲取的 API 密鑰
  - 為你的助手選擇一個 Jina AI 模型即可開始對話

  <Image alt={'選擇 Jina AI 模型'} inStep src={'/blog/assetsd9f99f2adff9051313ca44205b022d8c.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Jina AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Jina AI 提供的模型進行對話了。
