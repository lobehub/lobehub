# 在 LobeHub 中使用 Minimax

<Image alt={'在 LobeHub 中使用 Minimax'} cover src={'/blog/assets34400653/703f170b-c03b-4c71-b57d-c2357596bdfb.webp'} />

[MiniMax](https://www.minimaxi.com/) 是 2021 年成立的通用人工智慧科技公司，致力於與使用者共創智慧。MiniMax 自主研發了不同模態的通用大模型，其中包括萬億參數的 MoE 文字大模型、語音大模型以及圖像大模型。並推出了海螺 AI 等應用程式。

本文件將指導你如何在 LobeHub 中使用 Minimax:

<Steps>
  ### 步驟一：獲取 MiniMax API 密鑰

  - 註冊並登入 [MiniMax 開放平臺](https://www.minimaxi.com/platform)
  - 在 `帳號管理` 中找到 `接口密鑰` 選單，並建立新的密鑰

  <Image alt={'建立 MiniMax API 密鑰'} inStep src={'/blog/assets34400653/f6e46f1c-0ac9-42ae-8e83-ddb0cc6c5bf8.webp'} />

  - 填寫一個 API 密鑰的名稱並建立

  <Image alt={'填寫 API 密鑰名稱'} inStep src={'/blog/assets34400653/cbc23ca9-1188-4b85-8ef0-e75ac7d74b92.webp'} />

  - 在彈出的對話框中複製 API 密鑰，並妥善儲存

  <Image alt={'儲存 API 密鑰'} inStep src={'/blog/assets34400653/fb0f7574-c2f5-40d6-8613-3749e85ce881.webp'} />

  <Callout type={'warning'}>
    請安全地存儲密鑰，因為它只會出現一次。如果您意外丟失它，您將需要建立一個新密鑰。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 MiniMax

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`MiniMax`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets34400653/b839e04e-0cef-46a3-bb84-0484a3f51c69.webp'} />

  - 開啟 Minimax 並填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 MiniMax 的模型即可開始對話

  <Image alt={'選擇 MiniMax 模型並開始對話'} inStep src={'/blog/assets34400653/f7d59c7a-abd0-4ebd-8c72-ca10c47a0f1a.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 MiniMax 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 MiniMax 提供的模型進行對話了。
