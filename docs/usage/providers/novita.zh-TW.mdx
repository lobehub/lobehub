# 在 LobeHub 中使用 Novita AI

<Image alt={'在 LobeHub 中使用 Novita AI'} cover src={'/blog/assets85af5a2a51b851fe125055d374cc8263.webp'} />

[Novita AI](https://novita.ai/) 是一個 AI API 平臺，它提供多種大語言模型與 AI 圖像生成的 API 服務。支援 Llama3 (8B, 70B)，Mistral 和其他最新的模型。

本文件將指導你如何在 LobeHub 中使用 Novita AI:

<Steps>
  ### 步驟一：註冊 Novita AI 帳號並登入

  - 存取 [Novita.ai](https://novita.ai/) 並建立帳號
  - 你可以使用 Google 或者 Github 帳號登入
  - 註冊後，Novita AI 會贈送 0.5 美元的使用額度

  <Image alt={'註冊 Novita AI'} height={457} inStep src={'/blog/assets86924c724c66931cf61417dbdcc04ee8.webp'} />

  ### 步驟二：建立 API 密鑰

  - 存取 Novita AI 的 [密鑰管理頁面](https://novita.ai/dashboard/key) ，建立並且複製一個 API 密鑰.

  <Image alt={'建立 Novita AI API 密鑰'} inStep src={'/blog/assets6f2a84bee4245ca507e98e96247d5c5e.webp'} />

  ### 步驟三：在 LobeHub 中設定 Novita AI

  - 存取 LobeHub 的 `設定` 界面
  - 在 `AI 服務商` 下找到 `novita.ai` 的設定項
  - 開啟 novita.ai 並填入獲得的 API 密鑰

  <Image alt={'在 LobeHub 中輸入 Novita AI API 密鑰'} inStep src={'/blog/assets05d786345e99f92d11baae5667a04a62.webp'} />

  - 為你的助手選擇一個 Novita AI 模型即可開始對話

  <Image alt={'Select and use Novita AI model'} inStep src={'/blog/assets9db16311eb6772ea74eb63dd2d397bc0.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Novita AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Novita AI 提供的模型進行對話了。
