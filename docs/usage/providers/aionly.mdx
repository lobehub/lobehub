# AiOnly Provider Configuration

AiOnly is an OpenAI-compatible model aggregation platform. This guide shows how to connect it in LobeHub.

## Prerequisites

Before using AiOnly, you need to:

1. Create an AiOnly account
2. Get an API key from the AiOnly MAAS dashboard
3. Use the OpenAI-compatible base URL: `https://api.aionly.com/v1`

You can also review the vendor guide here:

- [AiOnly documentation](https://maas.aionly.com/document?from=https%3A%2F%2Faionly.com)

## Configuration

1. Open LobeHub settings
2. Go to the provider section
3. Select AiOnly
4. Paste your API key
5. Keep the base URL set to `https://api.aionly.com/v1`

## Available Models

Currently, most of the mainstream models provided by AiOnly, such as:

- Claude Opus 4.8
- Claude Sonnet 5
- GPT-5.5
- GPT-5.4
- Gemini 3.1 Pro Preview
- Gemini 2.5 Pro
- DeepSeek V4 Pro
- GLM-5.2
- Qwen3.7 Plus

## Notes

- AiOnly uses an OpenAI-compatible API shape
- Model availability may change in the upstream gateway
