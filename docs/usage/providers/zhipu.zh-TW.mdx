# 在 LobeHub 中使用智譜 ChatGLM

<Image alt={'在 LobeHub 中使用 Together AI'} cover src={'/blog/assets34400653/497e3b20-57ca-4963-b6f4-897c9710c16e.webp'} />

[智譜 AI](https://www.zhipuai.cn/) 是一家源自清華大學計算機系技術成果的高科技公司，成立於 2019 年，專注於自然語言處理、機器學習和大資料分析，致力於在認知智慧領域拓展人工智慧技術的邊界。

本文件將指導你如何在 LobeHub 中使用智譜 AI:

<Steps>
  ### 步驟一：獲取智譜 AI 的 API 密鑰

  - 存取並登入 [智譜 AI 開放平臺](https://open.bigmodel.cn/)
  - 初次登入時系統會自動為你建立好 API 密鑰並贈送 25M Tokens 的資源包
  - 進入頂部的 `API密鑰` 可以查看你的 API

  <Image alt={'獲得智譜AI API 密鑰'} inStep src={'/blog/assets34400653/6d6f2bc5-1407-471d-95a8-fb03193edbdb.webp'} />

  ### 步驟二：在 LobeHub 中設定智譜 AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`智譜AI`的設定項

  <Image alt={'LobeHub 中填寫智譜AI API 密鑰'} inStep src={'/blog/assets34400653/2afffe79-1d37-423c-9363-f09605d5e640.webp'} />

  - 開啟智譜 AI 並填入獲得的 API 密鑰
  - 為你的助手選擇一個智譜 AI 的模型即可開始對話

  <Image alt={' 選擇並使用智譜AI模型 '} inStep src={'/blog/assets34400653/b83da559-73d1-4734-87d5-5e22955a9da2.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考智譜 AI 的費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用智譜 AI 提供的模型進行對話了。
