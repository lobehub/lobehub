# AiOnly 提供商配置

AiOnly 是一个兼容 OpenAI 的模型聚合平台。本指南说明如何在 LobeHub 中接入它。

## 前置条件

使用 AiOnly 之前，你需要：

1. 注册 AiOnly 账号
2. 从 AiOnly MAAS 控制台获取 API Key
3. 使用兼容 OpenAI 的 Base URL：`https://api.aionly.com/v1`

你也可以查看官方文档：

- [AiOnly 文档](https://maas.aionly.com/document?from=https%3A%2F%2Faionly.com)

## 配置步骤

1. 打开 LobeHub 设置
2. 进入模型提供商配置
3. 选择 AiOnly
4. 填入你的 API Key
5. 保持 Base URL 为 `https://api.aionly.com/v1`

## 可用模型

当前 AiOnly 提供的大部分主流模型，例如：

- Claude Opus 4.8
- Claude Sonnet 5
- GPT-5.5
- GPT-5.4
- Gemini 3.1 Pro Preview
- Gemini 2.5 Pro
- DeepSeek V4 Pro
- GLM-5.2
- Qwen3.7 Plus

## 说明

- AiOnly 使用兼容 OpenAI 的接口格式
- 上游网关中的模型可用性可能会变化
