# 在 LobeHub 中使用 Vertex AI

<Image alt={'在 LobeHub 中使用 Vertex AI '} cover src={'/blog/assets95e6fe7c19ebfb9ead1c5a267aaf2a4e.webp'} />

[Vertex AI](https://cloud.google.com/vertex-ai) 是 Google Cloud 的一款全面託管、整合式 AI 開發平臺，旨在構建與應用程式生成式 AI。你可輕鬆存取 Vertex AI Studio、Agent Builder 以及超過 160 種基礎模型，進行 AI 開發。

本文件將指導你如何在 LobeHub 中接入 Vertex AI 的模型:

<Steps>
  ### 步驟一：準備 Vertex AI 項目

  - 首先，存取[Google Cloud](https://console.cloud.google.com/)並完成註冊登入
  - 建立一個新的 Google Cloud 項目，或選擇一個已存在的項目
  - 進入 [Vertex AI 控制檯](https://console.cloud.google.com/vertex-ai)
  - 確認該項目已開通 Vertex AI API 服務

  <Image alt={'進入 Vertex AI'} inStep src={'/blog/assets87010372bdf39890a7478a7a8cd4a9f0.webp'} />

  ### 步驟二：設定 API 存取權限

  - 進入 Google Cloud [IAM 管理頁面](https://console.cloud.google.com/iam-admin/serviceaccounts)，並導航至`服務帳號`
  - 建立一個新的服務帳號，併為其分配一個角色權限，例如 `Vertex AI User`

  <Image alt={'建立服務帳號'} inStep src={'/blog/assets6b01801b405c366fa4ebe683a77f289d.webp'} />

  - 在服務帳號管理頁面找到剛剛建立的服務帳號，點擊`密鑰`並建立一個新的 JSON 格式密鑰
  - 建立成功後，密鑰檔案將會以 JSON 檔案的格式自動儲存到你的電腦上，請妥善儲存

  <Image alt={'建立密鑰'} inStep src={'/blog/assets69146738e31a47ac6425070208ebd906.webp'} />

  ### 步驟三：在 LobeHub 中設定 Vertex AI

  - 存取 LobeHub 的 `應用程式設定` 的 `AI 服務供應商` 界面
  - 在供應商列表中找到 `Vertex AI` 的設定項

  <Image alt={'填寫 Vertex AI API 密鑰'} inStep src={'/blog/assetsd89998edb6b2dc8311d8d86664d5cd4d.webp'} />

  - 開啟 Vertex AI 服務供應商
  - 將剛剛獲取的 JSON 格式的全部內容填入 API Key 字段中
  - 為你的助手選擇一個 Vertex AI 模型即可開始對話

  <Image alt={'選擇 Vertex AI 模型'} inStep src={'/blog/assets5997a6461e20103f5bc9d6b78b872833.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Google Cloud 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Vertex AI 提供的模型進行對話了。
