# 在 LobeHub 中使用 AI21 Labs

<Image cover src={'/blog/assetsa25c48c9faa225bf6f72658e5bd58d64.webp'} />

[AI21 Labs](https://www.ai21.com/) 是一家專注於人工智慧的公司，提供先進的語言模型和 API 服務，旨在幫助開發者和企業利用自然語言處理技術。其旗艦產品 "Jamba" 系列模型能夠進行復雜的語言理解和生成任務，廣泛應用程式於內容創作、對話系統等領域。

本文將指導你如何在 LobeHub 中使用 AI21 Labs。

<Steps>
  ### 步驟一：獲得 AI21 Labs 的 API Key

  - 註冊並登入 [AI21 Studio](https://studio.ai21.com)
  - 點擊 `使用者頭像` 選單，點擊 `API Key`
  - 複製並儲存生成的 API 密鑰

  <Image alt={'複製 API 密鑰'} inStep src={'/blog/assets0f847842a5dedf7bef1f534278aec584.webp'} />

  ### 步驟二：在 LobeHub 中設定 AI21 Labs

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `AI21labs` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assetsc16177645281b332883403e7f193f6e3.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 AI21 Labs 的模型即可開始對話

  <Image alt={'選擇 AI21 Labs 模型並開始對話'} inStep src={'/blog/assets5f1a6cb003752055b9ed131c1715154c.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 AI21 Labs 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 AI21 Labs 提供的模型進行對話了。
