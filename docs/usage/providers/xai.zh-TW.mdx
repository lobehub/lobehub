# 在 LobeHub 中使用 xAI

<Image cover src={'/blog/assetsc557d9ee77afeb958d198abf5ca79761.webp'} />

[xAI](https://x.ai/) 是由埃隆・馬斯克於 2023 年成立的一家人工智慧公司，旨在探索和理解宇宙的真實本質。該公司的目標是通過人工智慧技術解決複雜的科學和數學問題，並推動人工智慧的發展。

本文將指導你如何在 LobeHub 中使用 xAI。

<Steps>
  ### 步驟一：獲取 xAI 的 API 密鑰

  - 註冊並登入 [xAI 控制檯](https://console.x.ai/)
  - 建立一個 API Token
  - 複製並儲存 API Token

  <Image alt={'xAI API'} inStep src={'/blog/assets6b6c251a2d4a77784c08fb07fc51abf9.webp'} />

  <Callout type={'warning'}>
    妥善儲存彈窗中的 API 令牌，它只會出現一次，如果不小心丟失了，你需要重新建立一個 API 令牌。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 xAI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `xAI` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets513c9045fef49b4d46549f485e69f505.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 xAI 的模型即可開始對話

  <Image alt={'選擇 xAI 模型並開始對話'} inStep src={'/blog/assets88248c034ef28ca9b909219d2e7ef32a.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 xAI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 xAI 提供的模型進行對話了。
