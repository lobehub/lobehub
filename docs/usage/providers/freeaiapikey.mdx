# FreeAIapikey

[FreeAIapikey](https://freeaiapikey.com) is an OpenAI-compatible API gateway offering one-key access to frontier models — GPT-5.5, GPT-5.6 Sol, GPT-6 Sol, GPT-6 Astra, Claude Opus 4.7/4.8/5/5.5 and Claude Sonnet 5 — at a fraction of official pricing. The live model catalog is available at `GET https://api.freeaiapikey.com/v1/models`.

## Configure in LobeHub

1. Open **Settings → Language Model**.
2. Find **FreeAIapikey** in the provider list and enable it.
3. Fill in the API key from your [FreeAIapikey dashboard](https://freeaiapikey.com/dashboard).
4. Pick a model, e.g. `openai/gpt-6-sol`, or use **Fetch Model List** to pull the live catalog.
