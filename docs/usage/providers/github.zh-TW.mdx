# 在 LobeHub 中使用 GitHub Models

<Image cover src={'/blog/assetsf117203c39294f45930785d85773c83e.webp'} />

[GitHub Models](https://github.com/marketplace/models) 是 GitHub 最近推出的一項新功能，旨在為開發者提供一個免費的平臺來存取和實驗多種 AI 模型。GitHub Models 提供了一個互動沙盒環境，使用者可以在此測試不同的模型參數和提示語，觀察模型的回應。該平臺支援多種先進的語言模型，包括 OpenAI 的 GPT-4o、Meta 的 Llama 3.1 和 Mistral 的 Large 2 等，覆蓋了從大規模語言模型到特定任務模型的廣泛應用程式。

本文將指導你如何在 LobeHub 中使用 GitHub Models。

## GitHub Models 速率限制

當前 Playground 和免費 API 的使用受到每分鐘請求數、每日請求數、每個請求的令牌數以及併發請求數的限制。若達到速率限制，則需等待限制重置後方可繼續發出請求。不同模型（低、高及嵌入模型）的速率限制有所不同。 模型類型資訊請參閱 GitHub Marketplace。

<Image alt={'GitHub Models 速率限制'} inStep src={'/blog/assets50607dece1bbffe80fdcbe76324ff9b6.webp'} />

<Callout type="note">
  這些限制可能隨時更改，具體資訊請參考 [GitHub
  官方文件](https://docs.github.com/en/github-models/prototyping-with-ai-models#rate-limits)。
</Callout>

## GitHub Models 設定指南

<Steps>
  ### 步驟一：獲得 GitHub 的存取令牌

  - 登入 GitHub 並開啟 [存取令牌](https://github.com/settings/tokens) 頁面
  - 建立並設定一個新的存取令牌

  <Image alt={'建立存取令牌'} inStep src={'/blog/assetsc376d2e9e97f9ea9d788589f0a9e23d6.webp'} />

  - 在返回的結果中複製並儲存生成的令牌

  <Image alt={'儲存存取令牌'} inStep src={'/blog/assets9880145be3e52b8f9dcd8343cd34a6ca.webp'} />

  <Callout type={"warning"}>
    - GitHub Models 測試期間，要使用 GitHub Models，使用者需要申請加入[等待名單（waitlist）](https://github.com/marketplace/models/waitlist/join) 通過後才能獲得存取權限。

    - 請安全地存儲存取令牌，因為它只會出現一次。如果您意外丟失它，您將需要建立一個新令牌。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 GitHub Models

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `GitHub` 的設定項

  <Image alt={'填入存取令牌'} inStep src={'/blog/assetse0d53ba2bfb6ba5bf33f2b8a547f4e41.webp'} />

  - 填入獲得的存取令牌
  - 為你的 AI 助手選擇一個 GitHub 的模型即可開始對話

    <Image alt={'選擇 GitHub 模型並開始對話'} inStep src={'/blog/assetsb6959f725c38f86053e4b07c9188d825.webp'} />
</Steps>

至此你已經可以在 LobeHub 中使用 GitHub 提供的模型進行對話了。
