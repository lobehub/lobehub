# 在 LobeHub 中使用紫東太初

<Image alt={'在 LobeHub 中使用太初'} cover src={'/blog/assetsd3fefc9a525701b9d0f25116cea2ff00.webp'} />

本文將指導你如何在 LobeHub 中使用紫東太初：

<Steps>
  ### 步驟一：獲取紫東太初 API 密鑰

  - 建立一個[紫東太初](https://ai-maas.wair.ac.cn/)帳號
  - 建立並獲取 [API 密鑰](https://ai-maas.wair.ac.cn/#/settlement/api/key)

  <Image alt={'建立 API Key'} inStep src={'/blog/assets04ab03ac7920031925f7ee27846b3f7d.webp'} />

  ### 步驟二：在 LobeHub 中設定紫東太初

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`紫東太初`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets8f3458d794828c38220e88b66e994e2a.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個紫東太初的模型即可開始對話

  <Image alt={'選擇太初模型並開始對話'} inStep src={'/blog/assets94499977be2f01c795b9876e4fe60709.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考紫東太初的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用紫東太初提供的模型進行對話了。
