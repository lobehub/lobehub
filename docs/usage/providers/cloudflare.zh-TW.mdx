# 在 LobeHub 中使用 Cloudflare Workers AI

<Image cover src={'/blog/assets1837dd567f75fcc083553a1078c0f088.webp'} />

[Cloudflare Workers AI](https://www.cloudflare.com/developer-platform/products/workers-ai/) 是一種將人工智慧能力整合到 Cloudflare Workers 無伺服器計算平臺的服務。其核心功能在於通過 Cloudflare 的全球網路提供快速、可擴充功能的計算能力，降低維運開銷。

本文件將指導你如何在 LobeHub 中使用 Cloudflare Workers AI:

<Steps>
  ### 步驟一：獲取 Cloudflare Workers AI 的 API Key

  - 存取 [Cloudflare 官網](https://www.cloudflare.com/) 並註冊一個帳號。
  - 登入 [Cloudflare 控制檯](https://dash.cloudflare.com/).
  - 在左側的選單中找到 `AI` > `Workers AI` 選項。

  <Image alt={'Cloudflare Workers AI'} inStep src={'/blog/assetsadbc0db573a0f581b22c30ecf243f721.webp'} />

  - 在 `使用 REST API` 中點擊 `建立 Workers AI API 令牌` 按鈕
  - 在彈出的側邊欄中複製並儲存你的 `API 令牌`
  - 同時也複製並儲存你的 `帳號ID`

  <Image alt={'Cloudflare Workers AI API Token'} inStep src={'/blog/assets620c308554394e72034d27ea743f8bff.webp'} />

  <Callout type={'warning'}>
    - 請安全地存儲 API 令牌，因為它只會出現一次。如果您意外丟失它，您將需要建立一個新令牌。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 Cloudflare Workers AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `Cloudflare` 的設定項

  <Image alt={'填入存取令牌'} inStep src={'/blog/assets5374759bfe39ca7fc864e72ddfce98d0.webp'} />

  - 填入獲得的 `API 令牌`
  - 填入你的`帳號ID`
  - 為你的 AI 助手選擇一個 Cloudflare Workers AI 的模型即可開始對話

  <Image alt={'選擇 Cloudflare Workers AI 模型並開始對話'} inStep src={'/blog/assets65003d69fa745e7cac376a79ea4bb742.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Cloudflare 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Cloudflare Workers AI 提供的模型進行對話了。
