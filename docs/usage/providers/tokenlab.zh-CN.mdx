# 在 LobeHub 中使用 TokenLab

[TokenLab](https://tokenlab.sh/?utm_source=lobehub) 是 OpenAI 兼容的 API 网关，一个密钥即可调用 OpenAI、Anthropic、Google、DeepSeek、Moonshot 等厂商的模型，按 token 计费。

<Steps>
  ### 步骤一：创建 API 密钥

  - 在 [TokenLab](https://tokenlab.sh/?utm_source=lobehub) 注册。
  - 打开控制台，创建一个 API 密钥。

  ### 步骤二：配置 LobeHub

  - 打开 **应用设置 → AI 服务商**，选择 **TokenLab**。
  - 填入 API 密钥并打开开关。
  - 点击 **获取模型列表**。LobeHub 读取 TokenLab 的 `GET /v1/models`，只保留对话模型，每个模型使用自己的上下文窗口和输出上限。

  ### 步骤三：开始对话

  - 在模型选择器中选一个 TokenLab 模型，发送消息。
</Steps>

自托管部署也可以设置 `TOKENLAB_API_KEY`，见 [模型服务商环境变量](/zh/docs/self-hosting/environment-variables/model-provider#tokenlab)。

价格见 [TokenLab 价格页](https://tokenlab.sh/en/pricing?utm_source=lobehub)。
