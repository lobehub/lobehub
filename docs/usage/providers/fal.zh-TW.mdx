# 在 LobeHub 中使用 Fal

<Image alt={'在 LobeHub 中使用 Fal'} cover src={'https://hub-apac-1.lobeobjects.space/docs/f253e749baaa2ccac498014178f93091.png'} />

[Fal.ai](https://fal.ai/) 是一個專門從事 AI 媒體生成的快速推理平臺，提供包括 FLUX、Kling、HiDream 等在內的最先進圖像和影片生成模型。本文將指導你如何在 LobeHub 中使用 Fal：

<Steps>
  ### 步驟一：獲取 Fal API Key

  - 註冊 [Fal.ai](https://fal.ai/) 帳號；
  - 前往 [API Keys 控制檯](https://fal.ai/dashboard/keys)，點擊 **Add key** 建立新的 API 密鑰；
  - 複製生成的 API Key 並妥善儲存，它只會顯示一次。

  <Image
    alt={'開啟建立視窗'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/3f3676e7f9c04a55603bc1174b636b45.png'
}
  />

  <Image
    alt={'建立 API Key'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/214cc5019d9c0810951b33215349136e.png'
}
  />

  <Image
    alt={'獲取 API Key'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/499a447e98dcc79407d56495d0305e2a.png'
}
  />

  ### 步驟二：在 LobeHub 中設定 Fal

  - 存取 LobeHub 的 `設定` 頁面；
  - 在 `AI服務商` 下找到 `Fal` 的設定項；

  <Image alt={'填入 API 密鑰'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/fa056feecba0133c76abe1ad12706c05.png'} />

  - 貼上獲取到的 API Key；
  - 選擇一個 Fal 模型（如 `Flux.1 Schnell`、`Flux.1 Kontext Dev`）用於圖像或影片生成。

  <Image alt={'選擇 Fal 模型進行媒體生成'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/7560502f31b8500032922103fc22e69b.png'} />

  <Callout type={'warning'}>
    在使用過程中，你可能需要向 Fal 支付相應費用，請在大量調用前查閱 Fal 的官方計費政策。
  </Callout>
</Steps>

至此，你已經可以在 LobeHub 中使用 Fal 提供的先進圖像和影片生成模型來創作精美的視覺內容了。
