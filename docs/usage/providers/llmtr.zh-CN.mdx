# 在 LobeHub 中使用 LLMTR

[LLMTR](https://llmtr.com) 是一个 OpenAI 兼容网关。你只需提供 LLMTR API 密钥并选择模型，LobeHub 就会把对话请求发到 `https://llmtr.com/v1`。

按以下步骤在 LobeHub 中配置 LLMTR：

<Steps>
  ### 第一步：创建 LLMTR API 密钥

  - 打开 [llmtr.com](https://llmtr.com)，如尚无账号请先注册。
  - 创建一个 API 密钥。LLMTR 的密钥以 `llmtr-` 开头。
  - 请妥善保存密钥。LLMTR 使用预付费余额，平台抽成在充值时收取。账户与计费细节见 [LLMTR 文档](https://llmtr.com/docs)。

  ### 第二步：在 LobeHub 中配置 LLMTR

  - 打开 **应用设置 → AI 服务商**。
  - 在服务商列表中选择 **LLMTR**。
  - 启用该服务商并填入 API 密钥。默认接口地址为 `https://llmtr.com/v1`。仅在你使用文档中说明的自定义地址时才需要改写。

  ### 第三步：选择模型

  - LLMTR 的模型 ID 通常是 `provider/model` 形式（例如 `qwen/qwen-flash`）。
  - 在有效密钥下，LobeHub 可以通过 `GET https://llmtr.com/v1/models` 刷新模型列表。
  - 为助手选择一个模型后即可开始对话。

  <Callout type={'warning'}>
    调用会产生 LLMTR 账户费用，费率取决于所选模型。发送请求前请查看服务商的计价说明。
  </Callout>
</Steps>

现在可以在 LobeHub 中使用 LLMTR 的模型了。
