# 在 LobeHub 中使用騰訊雲

<Image alt={'在 LobeHub 中使用騰訊雲'} cover src={'/blog/assetsf625540e8340bafe69ccbb89ad75707a.webp'} />

[騰訊雲（Tencent Cloud）](https://cloud.tencent.com/)是騰訊公司旗下的雲端運算服務品牌，專門為企業和開發者提供雲端運算服務。騰訊雲提供了一系列 AI 大模型解決方案，通過這些工具可以穩定高效接入 AI 模型。

本文件將指導你如何在 LobeHub 中接入騰訊雲的 AI 模型:

<Steps>
  ### 步驟一：獲取騰訊雲 API 密鑰

  - 首先，存取[騰訊雲](https://cloud.tencent.com/)並完成註冊登入
  - 進入騰訊雲控制檯並導航至[知識引擎原子能力](https://console.cloud.tencent.com/lkeap)
  - 開通大模型知識引擎，開通過程需要實名認證

  <Image alt={'進入知識引擎原子能力頁面'} inStep src={'/blog/assets89b45345c84f8b7c3bf4d554169689ac.webp'} />

  - 在`使用OpenAI SDK方式接入`選項中，點擊 `建立 API Key` 按鈕，建立一個新的 API Key
  - 在 `API key 管理` 中可以查看和管理已建立的 API Key
  - 複製並儲存建立好的 API Key

  ### 步驟二：在 LobeHub 中設定騰訊雲

  - 存取 LobeHub 的 `應用程式設定` 的 `AI 服務供應商` 界面
  - 在供應商列表中找到 `騰訊雲` 的設定項

  <Image alt={'填寫騰訊雲 API 密鑰'} inStep src={'/blog/assets79e8fff075490d2a4535590a02333316.webp'} />

  - 開啟騰訊雲服務商並填入獲取的 API 密鑰
  - 為你的助手選擇一個騰訊雲模型即可開始對話

  <Image alt={'選擇騰訊雲模型'} inStep src={'/blog/assets308f9fd45d0e8a140c1c18e6c92a1a57.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考騰訊雲的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用騰訊雲提供的模型進行對話了。
