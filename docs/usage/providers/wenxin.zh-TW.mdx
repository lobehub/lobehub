# 在 LobeHub 中使用文心千帆

<Image cover src={'/blog/assets89b0698da3476c6df24ba1f0a07e438e.webp'} />

[文心千帆](https://qianfan.cloud.baidu.com/)是百度推出的一個人工智慧大語言模型平臺，支援多種應用場景，包括文學創作、商業文案生成、數理邏輯推算等。該平臺具備跨模態、跨語言的深度語義理解與生成能力，廣泛應用程式於搜尋問答、內容創作和智慧辦公等領域。

本文將指導你如何在 LobeHub 中使用文心千帆。

<Steps>
  ### 步驟一：獲得文心千帆的 API Key

  - 註冊並登入 [百度智慧雲控制檯](https://console.bce.baidu.com/)
  - 進入 `百度智慧雲千帆 ModelBuilder`
  - 在左側選單中選擇 `API Key`

  <Image alt={'API Key'} inStep src={'/blog/assets67a17a6c66592ad85dbcf190e73b182d.webp'} />

  - 點擊建立 API Key
  - 在 `服務` 中選擇 `千帆ModelBuilder`
  - 在 `資源` 中選擇 `所有資源`
  - 點擊 `確定` 按鈕
  - 複製 `API Key` 並妥善儲存

  <Image alt={'建立密鑰'} inStep src={'/blog/assets87c281587b15f05b6b4e1afcd5bb47e8.webp'} />

  <Image alt={'複製密鑰'} inStep src={'/blog/assets257e1a3a0d99ee043a4c6cb90e160a2b.webp'} />

  ### 步驟二：在 LobeHub 中設定文心千帆

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `文心千帆` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets8f95f09ce51ad5917107d84db1e980ab.webp'} />

  - 填入獲得的 `API Key`
  - 為你的 AI 助手選擇一個文心千帆的模型即可開始對話

  <Image alt={'選擇文心千帆模型並開始對話'} inStep src={'/blog/assets768ec6fd300785186b202437985857c4.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考文心千帆的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用文心千帆提供的模型進行對話了。
