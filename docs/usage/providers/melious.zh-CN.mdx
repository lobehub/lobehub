# 在 LobeHub 中使用 Melious

[Melious](https://melious.ai) 通过兼容 OpenAI 的 API，在欧洲基础设施（符合 GDPR/TTDSG）上提供开放权重模型，并为每次响应报告能耗与费用。

本文将指导你如何在 LobeHub 中快速接入 Melious 的 AI 能力。

<Callout type="info">
  LobeHub 通过 `https://api.melious.ai/v1` 上兼容 OpenAI 的接口与 Melious 通信。Melious 同时提供兼容 Anthropic 的 Messages 接口，但本服务商不使用该接口。
</Callout>

<Steps>
  ### 步骤一：获取 Melious API Key

  - 登录 [Melious 控制台](https://melious.ai/account/api/keys)
  - 进入「账户 → API keys」并创建密钥
  - 复制以 `sk-mel-` 开头的密钥。密钥仅显示一次，请在关闭弹窗前妥善保存

  ### 步骤二：配置 LobeHub 模型服务

  - 打开 **应用设置 → AI 服务商**
  - 在「AI 服务商」模块选择「Melious」
  - 粘贴已获取的 API 密钥
  - 点击「检查」验证连接是否正常

  ### 步骤三：选择模型

  - 点击「获取模型列表」，从 Melious 拉取实时目录
  - 选择一个模型并开始对话

  Melious 的同一个目录接口会同时返回对话、向量、图像、音频与安全护栏模型。LobeHub 会将列表过滤为对话模型，因此选择器中只会出现可用于对话的模型。
</Steps>

## 模型与计费

模型列表为实时获取，因此始终反映当前密钥可访问的范围。可在 [Melious 模型中心](https://melious.ai/hub/models)查看完整目录与各模型的最新价格；用量按 token 以欧元计费，并汇总在[用量面板](https://melious.ai/account/usage)中。

支持推理的模型接受 `low`、`medium`、`high` 三档推理强度，LobeHub 将其作为模型参数暴露。该参数没有关闭选项 —— 即使显式传入 “none” 仍会返回推理内容。

## 常见问题

- **连接检查失败。** 请确认密钥以 `sk-mel-` 开头，且 API 代理地址为 `https://api.melious.ai/v1`，结尾不要带斜杠。
- **模型列表为空。** 密钥缺少 `inference.models` 权限。请在控制台中补充该权限，或手动填写模型 ID。
- **模型返回 404。** 模型 ID 已过期，请重新获取模型列表以同步当前目录。
