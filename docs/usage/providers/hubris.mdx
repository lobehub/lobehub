# Hubris Provider Configuration

[Hubris](https://hubris.pw) is an OpenAI-compatible gateway that serves models from Anthropic, OpenAI, Google, DeepSeek, Moonshot, xAI, Z.ai, Qwen and others behind a single API key. It is aimed at users in Russia and bills in Russian roubles.

## Prerequisites

1. **Create a Hubris account**
   - Sign up at [hubris.pw](https://hubris.pw/sign-in).
   - The account balance is topped up in roubles; usage is charged per token as you go, with no subscription.

2. **Create an API key**
   - Open [hubris.pw/keys](https://hubris.pw/keys) and create a key.
   - The full key (`sk-gw-…`) is shown once, at creation time. Copy it then.

## Configuration

### In the LobeHub UI

1. Open **Settings → Language Model** and pick **Hubris**.
2. Paste your `sk-gw-…` key.
3. Press **Fetch models** to load the live catalogue, then **Check** to verify the connection. The check uses `google/gemini-3.7-flash`, one of the cheaper models.

### Environment variables (self-hosted)

```bash
# Hubris API key
HUBRIS_API_KEY=sk-gw-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Setting `HUBRIS_API_KEY` enables the provider on the server side. `HUBRIS_MODEL_LIST` and `HUBRIS_PROXY_URL` are optional; see [Model Provider environment variables](/docs/self-hosting/environment-variables/model-provider).

## Models

Model IDs use the `vendor/model` form, for example `anthropic/claude-sonnet-5`, `openai/gpt-6-astra`, `google/gemini-3.8-flash`, `deepseek/deepseek-v4-pro`. A dozen widely used models ship as built-in cards; the full catalogue (500+ entries) arrives through the model fetcher, which reads `GET https://api.hubris.pw/v1/models`.

That endpoint is public — you can browse the catalogue, its context windows and its supported parameters without a key.

### What is wired up

- **Chat completions**, streaming and non-streaming.
- **Function calling** and **structured output** on models whose catalogue entry lists `tools` and `structured_outputs`.
- **Vision** on models that accept image input.
- **Reasoning**: LobeHub's thinking controls are sent as `reasoning.effort`, `reasoning.max_tokens` or `reasoning.enabled: false`, the same shape OpenRouter uses.

### Pricing

Hubris publishes every price in Russian roubles, and LobeHub's model cards only carry USD and CNY. Rather than ship a converted number that would drift as the exchange rate moves, the built-in cards carry no price at all — the cost line stays empty for this provider. Current prices are on the [model catalogue](https://hubris.pw/models) and in the `pricing` block of `GET /v1/models`.

## Troubleshooting

- **401** — the key is wrong, or it was revoked. Create a new one at [hubris.pw/keys](https://hubris.pw/keys).
- **402** — the account balance is exhausted. Top it up at [hubris.pw/billing](https://hubris.pw/billing).
- **404 on a model ID** — Hubris resolves IDs exactly, with no aliasing. Copy the ID from `GET /v1/models` or from the catalogue page rather than guessing a short name.
