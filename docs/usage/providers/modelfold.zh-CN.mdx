# 在 LobeHub 中使用 ModelFold

1. 登录 [ModelFold](https://modelfold.ai)，打开「API Keys」并创建密钥。详见[身份验证指南](https://modelfold.ai/docs/guide/authentication)。
2. 在 LobeHub 的模型服务商设置中选择 **ModelFold**，填入密钥。保留默认地址 `https://modelfold.ai/v1`，不要追加 `/chat/completions`。
3. 获取模型列表，启用当前账号有权限使用的对话模型。连通性检查使用 `deepseek-v4-flash`；如果列表中没有它，可以选择列表中的其他模型发起对话。

对话使用你的 ModelFold 账号，使用及计费说明见 [ModelFold 文档](https://modelfold.ai/docs/)。若身份验证失败，请检查密钥是否有效。此集成使用 Chat Completions，不使用 Anthropic Messages 或 Responses API。
