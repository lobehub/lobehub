# 在 LobeHub 中使用 Google Gemini

<Image alt={'在 LobeHub 中使用 Google Gemini'} cover src={'/blog/assets34400653/9a8dc1d4-152b-415f-a7cd-8f0c8fbb9913.webp'} />

Gemini AI 是由 Google AI 建立的一組大型語言模型（LLM），以其在多模式理解和處理方面的尖端進步而聞名。它本質上是一個強大的人工智慧工具，可以處理涉及不同類型資料的各種任務，而不僅僅是文字。

本文件將指導你如何在 LobeHub 中使用 Google Gemini:

<Steps>
  ### 步驟一：獲取 Google 的 API 密鑰

  - 存取並登入 [Google AI Studio](https://aistudio.google.com/)
  - 在 `獲取 API 密鑰` 選單中 `建立 API 密鑰`

  <Image alt={'生成 Google Gemini 密鑰'} inStep src={'/blog/assets34400653/ba3595e3-d9cb-4d0d-b414-8306b16df186.webp'} />

  - 選擇一個項目並建立 API 密鑰，或者在新項目中建立 API 密鑰

  <Image alt={'輸入 API 密鑰名稱'} inStep src={'/blog/assets34400653/fa725e49-4c17-4055-82bc-98a31e73fa54.webp'} />

  - 在彈出的對話框中複製 API 密鑰

  <Image alt={'複製 API 密鑰'} inStep src={'/blog/assets34400653/28d89add-cb18-4b86-9807-f2a5ed65ceba.webp'} />

  ### 步驟二：在 LobeHub 中設定 OpenAI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`Google Gemini`的設定項

  <Image alt={'LobeHub 中填寫 Google Gemini API 密鑰'} inStep src={'/blog/assets34400653/11442ce4-a615-49c4-937a-ca2ae93dd27c.webp'} />

  - 開啟 Google Gemini 並填入獲得的 API 密鑰
  - 為你的助手選擇一個 Gemini 的模型即可開始對話

  <Image alt={' 選擇並使用 Gemini 模型 '} inStep src={'/blog/assets34400653/ef9ed1b8-6828-4dd6-b86b-bb0b4fa40619.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Google Gemini 的費用政策。
  </Callout>
</Steps>

至此，你已經可以在 LobeHub 中使用 Google Gemini 啦。
