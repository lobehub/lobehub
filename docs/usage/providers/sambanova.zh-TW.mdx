# 在 LobeHub 中使用 SambaNova

<Image alt={'在 LobeHub 中使用 SambaNova'} cover src={'/blog/assetsd9e6fe2197270f0f774accd6abcf4019.webp'} />

[SambaNova](https://sambanova.ai/) 是一家位於美國加利福尼亞州帕洛阿爾託的公司，專注於開發高性能 AI 硬體和軟體解決方案，提供快速的 AI 模型訓練、微調和推理能力，尤其適用於大規模生成式 AI 模型。

本文件將指導你如何在 LobeHub 中使用 SambaNova:

<Steps>
  ### 步驟一：獲取 SambaNova API 密鑰

  - 首先，你需要註冊並登入 [SambaNova Cloud](https://cloud.sambanova.ai/)
  - 在 `APIs` 頁面中建立一個 API 密鑰

  <Image alt={'獲取 SambaNova API 密鑰'} inStep src={'/blog/assets2f83a9f03f13e73b7393641078627cf1.webp'} />

  - 複製得到的 API 密鑰並妥善儲存

  <Callout type={'warning'}>
    請妥善儲存生成的 API Key，它只會出現一次，如果不小心丟失了，你需要重新建立一個 API key
  </Callout>

  ### 步驟二：在 LobeHub 中設定 SambaNova

  - 存取 LobeHub 的 `應用程式設定`界面
  - 在 `AI 服務商` 下找到 `SambaNova` 的設定項

  <Image alt={'填寫 SambaNova API 密鑰'} inStep src={'/blog/assetsf78c85b0a0183a3ae3f2e916d59c0a67.webp'} />

  - 開啟 SambaNova 並填入獲取的 API 密鑰
  - 為你的助手選擇一個 SambaNova 模型即可開始對話

  <Image alt={'選擇 SambaNova 模型'} inStep src={'/blog/assets03f3f52817a626339071e6329b445cb3.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 SambaNova 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 SambaNova 提供的模型進行對話了。
