# 在 LobeHub 中使用 GitHub Models

<Image cover src={'/blog/assetsf117203c39294f45930785d85773c83e.webp'} />

[GitHub Models](https://github.com/marketplace/models) 是 GitHub 最近推出的一项新功能，旨在为开发者提供一个免费的平台来访问和实验多种 AI 模型。GitHub Models 有互动式模型试用环境，可以测试不同的模型参数和提示词。可用模型会随 GitHub Models 目录更新，你可以在 LobeHub 的模型列表中查看当前选项。

本文将指导你如何在 LobeHub 中使用 GitHub Models。

## GitHub Models 速率限制

当前 Playground 和免费 API 的使用受到每分钟请求数、每日请求数、每个请求的令牌数以及并发请求数的限制。若达到速率限制，则需等待限制重置后方可继续发出请求。不同模型（低、高及嵌入模型）的速率限制有所不同。 模型类型信息请参阅 GitHub Marketplace。

<Image alt={'GitHub Models 速率限制'} inStep src={'/blog/assets50607dece1bbffe80fdcbe76324ff9b6.webp'} />

<Callout type="note">
  这些限制可能随时更改，具体信息请参考 [GitHub
  官方文档](https://docs.github.com/en/github-models/prototyping-with-ai-models#rate-limits)。
</Callout>

## GitHub Models 配置指南

<Steps>
  ### 步骤一：获得 GitHub 的访问令牌

  - 登录 GitHub 并打开 [访问令牌](https://github.com/settings/tokens) 页面
  - 创建并设置一个新的访问令牌

  <Image alt={'创建访问令牌'} inStep src={'/blog/assetsc376d2e9e97f9ea9d788589f0a9e23d6.webp'} />

  - 在返回的结果中复制并保存生成的令牌

  <Image alt={'保存访问令牌'} inStep src={'/blog/assets9880145be3e52b8f9dcd8343cd34a6ca.webp'} />

  <Callout type={"warning"}>
    请安全地存储访问令牌，因为它只会出现一次。如果您意外丢失它，您将需要创建一个新令牌。
  </Callout>

  ### 步骤二：在 LobeHub 中配置 GitHub Models

  - 打开 **应用设置 → AI 服务商**，选择 **GitHub Models**，然后打开服务商

  <Image alt={'填入访问令牌'} inStep src={'/blog/assetse0d53ba2bfb6ba5bf33f2b8a547f4e41.webp'} />

  - 填写获得的个人访问令牌，然后点击 **检查** 测试连接
  - 在模型列表中启用需要的 GitHub Models 模型，然后在助理设置中选择该模型

    <Image alt={'选择 GitHub 模型并开始对话'} inStep src={'/blog/assetsb6959f725c38f86053e4b07c9188d825.webp'} />
</Steps>

至此你已经可以在 LobeHub 中使用 GitHub 提供的模型进行对话了。
