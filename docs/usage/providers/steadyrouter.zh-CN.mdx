# 在 LobeHub 中使用 SteadyRouter

[SteadyRouter](https://www.steadyrouter.com) 是 AI 模型 API 网关：一个 Key 用几百个型号，一个来源失败自动换下一个。智能路由开着时（新 Key 默认开），一个来源失败会在同一次调用里换下一个来源重试，504 / 524 超时除外。

<Steps>
  ### 步骤一：获取 API Key

  在 [SteadyRouter](https://www.steadyrouter.com/sign-up?aff=Dn19) 注册账号，到控制台的 **API Keys** 创建一个 Key。

  ### 步骤二：在 LobeHub 中配置

  打开 **设置** → **AI 服务商**，找到 **SteadyRouter**，填入 Key 并打开开关。

  ### 步骤三：选择型号

  点击 **获取模型列表**，加载这个 Key 能用的型号，然后在对话的型号选择器里选一个。
</Steps>

型号和当前价格见[模型广场](https://www.steadyrouter.com/pricing)，详细用法见 [API 文档](https://www.steadyrouter.com/site/docs.html)。
