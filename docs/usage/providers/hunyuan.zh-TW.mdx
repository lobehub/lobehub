# 在 LobeHub 中使用騰訊混元

<Image cover src={'/blog/assetsff480f9009cf873852a43c252ac36828.webp'} />

[騰訊混元](https://hunyuan.tencent.com/)是由騰訊推出的一款大模型，旨在為使用者提供智慧助手服務。它能夠通過自然語言處理技術，幫助使用者解決問題、提供建議以及進行內容生成等任務。使用者可以通過與模型的對話，快速獲取所需資訊，從而提高工作效率。

本文將指導你如何在 LobeHub 中使用騰訊混元。

<Steps>
  ### 步驟一：獲得騰訊混元的 API Key

  - 註冊並登入 [騰訊雲控制檯](https://console.cloud.tencent.com/hunyuan/api-key)
  - 進入 `混元大模型` 並點擊 `API KEY 管理`
  - 建立一個 API 密鑰

  <Image alt={'建立 API 密鑰'} inStep src={'/blog/assets01dbe69cc092163f7ac782afb7d314c5.webp'} />

  - 點擊`查看`，在彈出面板中複製 API 密鑰，並妥善儲存

  <Image alt={'儲存密鑰'} inStep src={'/blog/assets856bd407c8a1510f616a4bdb1e02a883.webp'} />

  ### 步驟二：在 LobeHub 中設定騰訊混元

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `騰訊混元` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assetsbd8c97ef67055e3ff93c56e46c33fa8d.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個騰訊混元的模型即可開始對話

  <Image alt={'選擇騰訊混元模型並開始對話'} inStep src={'/blog/assets3c54d6f2d55fae843fbbfdc0bd7ffec7.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考騰訊混元的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用騰訊混元提供的模型進行對話了。
