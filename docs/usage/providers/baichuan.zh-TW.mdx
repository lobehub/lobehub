# 在 LobeHub 中使用百川

<Image alt={'在 LobeHub 中使用百川'} cover src={'/blog/assets9c1839eb146b89e9e2d262ca95d24323.webp'} />

本文將指導你如何在 LobeHub 中使用百川：

<Steps>
  ### 步驟一：獲取百川智慧 API 密鑰

  - 建立一個[百川智慧](https://platform.baichuan-ai.com/homePage)帳號
  - 建立並獲取 [API 密鑰](https://platform.baichuan-ai.com/console/apikey)

  <Image alt={'建立 API Key'} inStep src={'/blog/assets217222e643d99ab3ba01fe92906f3314.webp'} />

  ### 步驟二：在 LobeHub 中設定百川

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`百川`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets8d4fbb776e2209a1ec58c6b3516351a1.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個百川的模型即可開始對話

  <Image alt={'選擇百川模型並開始對話'} inStep src={'/blog/assets2cfe64ead120815f7ba7100bc3dcfd48.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考百川的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用百川提供的模型進行對話了。
