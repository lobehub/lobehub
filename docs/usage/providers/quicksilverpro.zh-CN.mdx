# 在 LobeHub 中使用 QuickSilver Pro

[QuickSilver Pro](https://quicksilverpro.io) 是一个由 MachineFi Inc.（美国）运营的 OpenAI 兼容 AI 网关。它通过统一 API（`https://api.quicksilverpro.io/v1`）提供来自多家上游供应商的模型，包括 Claude、GPT、Gemini、Grok、DeepSeek、GLM、MiMo 与 Qwen 等。

本文将介绍如何在 LobeHub 中使用 QuickSilver Pro。

要在 LobeHub 中配置该供应商，请打开 **应用设置 → AI 供应商**，选择该供应商并打开开关。

<Steps>
  ### 第一步：获取 QuickSilver Pro API Key

  - 按照 [QuickSilver Pro 文档](https://quicksilverpro.io/docs) 注册账号并获取 API Key（格式形如 `sk-...`）
  - 复制并保存生成的 API Key

  ### 第二步：在 LobeHub 中配置 QuickSilver Pro

  - 进入 LobeHub 的 `设置` 页面
  - 在 `语言模型` 板块下找到 `QuickSilver Pro` 的配置
  - 粘贴你先前获取的 API Key
  - 选择一个 QuickSilver Pro 模型，即可开始对话

    <Callout type={'warning'}>
      使用 API 可能产生费用。各模型的最新价格（美元 / 百万 tokens）请查看机器可读的 [QuickSilver Pro 定价目录](https://quicksilverpro.io/pricing.json)。
    </Callout>
</Steps>

就是这样！现在你可以在 LobeHub 中使用 QuickSilver Pro 的模型进行对话了。
