# 在 LobeHub 中使用無問芯穹

[無問芯穹](https://cloud.infini-ai.com/)是基於多元晶片優化的大模型服務平臺，提供高效統一的 AGI 基礎設施解決方案。

本文將指導你如何在 LobeHub 中快速接入無問芯穹的 AI 能力。

<Callout type="info">
  無問芯穹的圖片連結輸入有白名單機制，目前已知支援阿里雲 OSS / AWS S3
  等服務的圖片連結。如果您在使用圖片對話時遇到 400 報錯，請嘗試[使用 base64
  編碼上傳圖片](/docs/self-hosting/environment-variables/s3#llm-vision-image-use-base-64)。
</Callout>

<Steps>
  ### 步驟一：獲取無問芯穹 API Key

  - 登入[大模型服務平臺](https://cloud.infini-ai.com/genstudio/model)
  - 在左側導航欄選擇「API KEY 管理」
  - 在新開啟的頁面中，點擊「建立 API KEY」按鈕，填入名稱，點擊「建立」

  ### 步驟二：設定 LobeHub 模型服務

  - 開啟 LobeHub 進入「設定」界面
  - 在「語言模型」模組選擇「Infini-AI」
  - 貼上已獲取的 API 密鑰
</Steps>
