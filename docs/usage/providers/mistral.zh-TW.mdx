# 在 LobeHub 中使用 Mistral AI

<Image alt={'在 LobeHub 中使用 Mistral AI'} cover src={'/blog/assets17870709/a3f9f63a-48f8-4567-b960-7f3636c0d4ed.webp'} />

Mistral AI API 現在可供所有人使用，本文件將指導你如何在 LobeHub 中使用 [Mistral AI](https://mistral.ai/):

<Steps>
  ### 步驟一：獲取 Mistral AI API 密鑰

  - 建立一個 [Mistral AI](https://mistral.ai/) 帳戶
  - 獲取您的 [API 密鑰](https://console.mistral.ai/user/api-keys/)

  <Image alt={'建立 API Key'} inStep src={'/blog/assets17870709/79faa59a-dfc0-4365-a679-5fc12c12bc70.webp'} />

  ### 步驟二：在 LobeHub 中設定 Mistral AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`Mistral AI`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets17870709/ba8e688a-e0c1-4567-9013-94205f83fc60.webp'} />

  <Callout type={'warning'}>
    如果您使用的是 mistral.ai，則您的帳戶必須具有有效的訂閱才能使 API 密鑰正常工作。新建立的 API
    密鑰需要 2-3 分鐘才能開始工作。如果單擊 「測試」 按鈕但失敗，請在 2-3 分鐘後重試。
  </Callout>

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Mistral AI 的模型即可開始對話

  <Image alt={'選擇 Mistral AI 模型並開始對話'} inStep src={'/blog/assets17870709/82cf4f5c-be5c-4126-a475-3a03468a9c39.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Mistral AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Mistral AI 提供的模型進行對話了。
