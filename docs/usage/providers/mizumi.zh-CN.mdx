# 在 LobeHub 中使用 Mizumi

[Mizumi](https://mizumi.co/) 是兼容 OpenAI 的 API 网关，通过官方 API 渠道提供 OpenAI 与 Gemini 模型，只需一个端点（`https://api.mizumi.co/v1`）和一个 API 密钥。

本文档将指导你如何在 LobeHub 中使用 Mizumi：

<Steps>
  ### 步骤一：注册并登录 Mizumi

  - 访问 [mizumi.co](https://mizumi.co/) 并创建账号
  - 新账号可获得免费试用额度，无需绑定银行卡

  ### 步骤二：创建 API 密钥

  - 打开 Mizumi 控制台，创建 `sk-mizumi-...` 格式的 API 密钥并复制

  ### 步骤三：在 LobeHub 中配置 Mizumi

  - 打开 **应用设置 → AI 服务商**

  - 在服务商列表中选择 `Mizumi`

  - 启用 Mizumi 并粘贴你的 API 密钥

  - 模型列表会从网关实时拉取；也可以点击 **检查** 按钮，使用默认检查模型 `gpt-4.1-mini` 验证连通性

  - 为你的助手选择一个 Mizumi 模型（例如 `gpt-6.1-sol` 或 `gpt-6-luna`）即可开始对话

  <Callout type={'warning'}>
    使用 API 可能产生费用，详情请参考 [Mizumi 定价](https://mizumi.co/docs/models)。
  </Callout>
</Steps>

完成！现在你可以在 LobeHub 中直接使用 Mizumi 提供的模型进行对话了。
