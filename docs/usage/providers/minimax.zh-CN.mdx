# 在 LobeHub 中使用 Minimax

<Image alt={'在 LobeHub 中使用 Minimax'} cover src={'/blog/assets34400653/703f170b-c03b-4c71-b57d-c2357596bdfb.webp'} />

[MiniMax](https://www.minimaxi.com/) 是 2021 年成立的通用人工智能科技公司，致力于与用户共创智能。MiniMax 自主研发了不同模态的通用大模型，其中包括万亿参数的 MoE 文本大模型、语音大模型以及图像大模型。并推出了海螺 AI 等应用。

本文档将指导你如何在 LobeHub 中使用 Minimax:

<Steps>
  ### 步骤一：获取 MiniMax API 密钥

  - 注册并登录 [MiniMax 开放平台](https://www.minimaxi.com/platform)
  - 在 `账户管理` 中找到 `接口密钥` 菜单，并创建新的密钥

  <Image alt={'创建 MiniMax API 密钥'} inStep src={'/blog/assets34400653/f6e46f1c-0ac9-42ae-8e83-ddb0cc6c5bf8.webp'} />

  - 填写一个 API 密钥的名称并创建

  <Image alt={'填写 API 密钥名称'} inStep src={'/blog/assets34400653/cbc23ca9-1188-4b85-8ef0-e75ac7d74b92.webp'} />

  - 在弹出的对话框中复制 API 密钥，并妥善保存

  <Image alt={'保存 API 密钥'} inStep src={'/blog/assets34400653/fb0f7574-c2f5-40d6-8613-3749e85ce881.webp'} />

  <Callout type={'warning'}>
    请安全地存储密钥，因为它只会出现一次。如果您意外丢失它，您将需要创建一个新密钥。
  </Callout>

  ### 步骤二：在 LobeHub 中配置 MiniMax

  - 打开 **应用设置 → AI 服务商**
  - 在服务商列表中选择`MiniMax`的设置项

  <Image alt={'填入 API 密钥'} inStep src={'/blog/assets34400653/b839e04e-0cef-46a3-bb84-0484a3f51c69.webp'} />

  - 打开 Minimax 并填入获得的 API 密钥
  - 为你的 AI 助手选择一个 MiniMax 的模型即可开始对话

  <Image alt={'选择 MiniMax 模型并开始对话'} inStep src={'/blog/assets34400653/f7d59c7a-abd0-4ebd-8c72-ca10c47a0f1a.webp'} />

  <Callout type={'warning'}>
    在使用过程中你可能需要向 API 服务提供商付费，请参考 MiniMax 的相关费用政策。
  </Callout>
</Steps>

至此你已经可以在 LobeHub 中使用 MiniMax 提供的模型进行对话了。

## 生成音乐

MiniMax Music 可以根据歌词和风格提示词生成带人声的歌曲，也可以翻唱参考音频。它与对话使用同一个 MiniMax 密钥和 API 主机，无需额外配置。

<Callout type={'warning'}>
  MiniMax 已不再向新账号开放音乐 API，只有已开通付费音乐 API 的账号才能生成音乐。其他密钥可以通过服务商 **检查**（检查使用对话模型），但每首歌都会失败，并显示 `MiniMax music API error (410): This Music API is no longer available to new users…`（直接调用 API 时状态码为 `2153`）。
</Callout>

**模型列表** 的 **音乐** 标签页列出音乐模型。它们默认关闭，请开启账号可用的模型：

| 模型            | 用途                                    |
| ------------- | ------------------------------------- |
| `music-3.0`   | 根据歌词和风格提示词生成带人声的歌曲，或生成纯音乐。            |
| `music-2.6`   | `music-3.0` 的上一代模型。                   |
| `music-cover` | 按提示词描述的风格翻唱参考音频（6 秒到 6 分钟，不超过 50 MB）。 |

### 在音乐页面生成

1. 打开 **音乐** 页面：在创作模式切换中与 **图片**、**视频** 并列，也可以直接访问 `/music`。
2. 在 **模型** 中选择一个 MiniMax 模型。
3. 使用 `music-3.0` 或 `music-2.6` 时：在提示词输入框描述风格，并填写 **歌词**（最多 3,500 字符，可用 `[Verse]`、`[Chorus]` 等标签）。不填歌词时，打开 **帮我写歌词** 或 **纯音乐**。
4. 使用 `music-cover` 时：在 **参考音频** 中点击 **上传音频**，或粘贴音频 URL 后按回车。然后在提示词输入框描述目标风格（10–300 字符）。**歌词** 可选（10–1,000 字符），用于替换原曲歌词。
5. 可选：在 **音频设置** 中调整 **音频格式**、**采样率** 与 **码率**。
6. 点击 **生成**。歌曲卡片显示 **生成中…**，完成后出现播放器。点击播放即可试听，也可以下载文件。

### 通过 API 生成

调用方式与 Suno 相同（见 [通过 API 生成](/zh/docs/usage/providers/suno)），把 `provider` 设为 `minimax`。MiniMax 每次请求返回一首歌。下面是带歌词和参考音频的翻唱请求：

```bash
curl -s -X POST "$LOBEHUB_URL/trpc/lambda/music.createMusic" \
  -H "X-API-Key: $LOBEHUB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"json":{
    "generationTopicId":"<generationTopicId>",
    "provider":"minimax",
    "model":"music-cover",
    "params":{
      "prompt":"Slow jazz ballad with soft piano and brushed drums",
      "lyrics":"[Verse]\nRain on the window, coffee gone cold\n[Chorus]\nStay a little longer",
      "referenceAudioUrl":"https://example.com/reference.mp3",
      "format":"mp3",
      "sampleRate":44100,
      "bitrate":256000
    }}}'
```

使用 `music-3.0` 或 `music-2.6` 时，去掉 `referenceAudioUrl`，并发送 `prompt` 加 `lyrics`，或 `instrumental: true`，或 `autoLyrics: true`。用返回的 `asyncTaskId` 和 `generation.id` 轮询 `generation.getGenerationStatus`，直到 `status` 为 `success`；音频地址在 `generation.asset.url`。

LobeHub 向 MiniMax 发送的是一次同步请求，音乐 API 本身没有需要轮询的任务：

```bash
curl -s -X POST https://api.minimaxi.com/v1/music_generation \
  -H "Authorization: Bearer $MINIMAX_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "music-cover",
    "prompt": "Slow jazz ballad with soft piano and brushed drums",
    "lyrics": "[Verse]\nRain on the window, coffee gone cold\n[Chorus]\nStay a little longer",
    "audio_url": "https://example.com/reference.mp3",
    "output_format": "url",
    "audio_setting": { "format": "mp3", "sample_rate": 44100, "bitrate": 256000 }
  }'
# → {"data":{"audio":"<临时音频 URL>","status":2},"base_resp":{"status_code":0,"status_msg":"success"}}
```

`instrumental` 以 `is_instrumental` 发送，`autoLyrics` 以 `lyrics_optimizer` 发送。海外账号使用 `https://api.minimax.io/v1`，见 [模型服务商环境变量](/zh/docs/self-hosting/environment-variables/model-provider) 中的 `MINIMAX_PROXY_URL`。
