# Using Cheaper Inference in LobeHub

[Cheaper Inference](https://cheaperinference.com) is an OpenAI-compatible gateway that gives access to models from many labs with one API key. Each model costs 15–60% less than the list price of its lab. See the [model list](https://cheaperinference.com/#models) for current models and prices.

<Steps>
  ### Step 1: Create an API key

  - [Sign up](https://cheaperinference.com/signup) for a Cheaper Inference account.
  - Create an API key in your account. Keys start with `ci_live_`.
  - Copy the key and store it securely. See the [documentation](https://cheaperinference.com/docs) for details.

  ### Step 2: Configure Cheaper Inference in LobeHub

  - Open **App Settings → AI Providers**, find **Cheaper Inference**, and enable it.
  - Enter your API key. If your self-hosted administrator has already configured a server key, you can use that configuration without entering a personal key.
  - Keep the default API base URL, `https://api.cheaperinference.com/v1`, unless you use a compatible proxy.
  - Run the connection check, then select a model for your assistant and send a short message.
</Steps>

## API compatibility

LobeHub sends requests to the OpenAI-compatible API at the base URL. GPT-5.x models use the Responses API (`/responses`). Other models use the Chat Completions API (`/chat/completions`). A custom proxy must support both paths. Click **Fetch models** to load the chat models available to your key. Cheaper Inference provides chat models only; it has no embeddings or audio endpoints.

## Self-hosting

Administrators can set `CHEAPERINFERENCE_API_KEY` on the server to enable Cheaper Inference with a shared key. `CHEAPERINFERENCE_PROXY_URL` overrides the base URL, and `CHEAPERINFERENCE_MODEL_LIST` customizes the model list. See the [Cheaper Inference environment variables](/docs/self-hosting/environment-variables/model-provider#cheaper-inference).
