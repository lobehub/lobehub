# 在 LobeHub 中使用 WaveSpeed AI

[WaveSpeed AI](https://wavespeed.ai) 是面向图像、视频与音频生成的推理平台，通过统一的低延迟 API 提供 Seedream、Nano Banana、GPT Image、Seedance、WAN 等业界领先的开源与闭源模型。本文将介绍如何在 LobeHub 中使用 WaveSpeed AI：

<Steps>
  ### 步骤一：获取 WaveSpeed AI API Key

  - 注册 [WaveSpeed AI](https://wavespeed.ai) 账号；
  - 进入控制台的 [API Keys](https://wavespeed.ai/dashboard/api-keys) 页面，创建一个新的 API Key；
  - 复制并妥善保存生成的 API Key。

  ### 步骤二：在 LobeHub 中配置 WaveSpeed AI

  - 打开 LobeHub 的`设置`页面；
  - 在 `AI 服务商`中找到 `WaveSpeed AI` 的配置项；
  - 粘贴获取的 API Key；
  - 选择一个 WaveSpeed AI 模型进行图像或视频生成。

  <Callout type={'warning'}>
    请注意，使用过程中可能会产生 WaveSpeed AI 的费用，在大量调用 API 前请先查阅其官方[价格说明](https://wavespeed.ai/pricing)。
  </Callout>
</Steps>

至此，你已经可以在 LobeHub 中使用 WaveSpeed AI 提供的模型生成图像与视频了。
