# 在 LobeHub 中使用 Black Forest Labs

<Image alt={'在 LobeHub 中使用 Black Forest Labs'} cover src={'https://hub-apac-1.lobeobjects.space/docs/c7274a5b037227f042ad7558f535b5ea.png'} />

[Black Forest Labs](https://bfl.ai/) 是當前世界最頂級的 AI 圖像生成實驗室團隊，研發了 FLUX 系列高品質圖像生成模型，FLUX Kontext 系列圖像編輯模型。本文將指導你如何在 LobeHub 中使用 Black Forest Labs：

<Steps>
  ### 步驟一：獲取 Black Forest Labs API Key

  - 註冊 [Black Forest Labs](https://auth.bfl.ai/) 帳號；
  - 前往 [API Keys 控制檯](https://dashboard.bfl.ai/api/keys)，點擊 **Add Key** 建立新的 API 密鑰；
  - 複製生成的 API Key 並妥善儲存，它只會顯示一次。

  <Image
    alt={'開啟 API 控制檯'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/36331f581e36a72ba91fb6c1dacbedd4.png'
}
  />

  <Image
    alt={'建立 API Key'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/3049ad79746bf913d1b2736cfe1d38fa.png'
}
  />

  <Image
    alt={'獲取 API Key'}
    inStep
    src={
'https://hub-apac-1.lobeobjects.space/docs/33143deb04f2a0cdb2fd543ff8161633.png'
}
  />

  ### 步驟二：在 LobeHub 中設定 Black Forest Labs

  - 存取 LobeHub 的 `設定` 頁面；
  - 在 `AI服務商` 下找到 `Black Forest Labs` 的設定項；

  <Image alt={'填入 API 密鑰'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/4fe1993d94fad72829612d22527a2ecd.png'} />

  - 貼上獲取到的 API Key；
  - 選擇一個 Black Forest Labs 模型用於圖像生成。

  <Image alt={'選擇 Black Forest Labs 模型進行圖像生成'} inStep src={'https://hub-apac-1.lobeobjects.space/docs/7a6dfdb1a1bdd5443104a6d2cb3a8bf4.png'} />

  <Callout type={'warning'}>
    在使用過程中，你可能需要向 Black Forest Labs 支付相應費用，請在大量調用前查閱 Black Forest Labs 的官方計費政策。
  </Callout>
</Steps>

至此，你已經可以在 LobeHub 中使用 Black Forest Labs 提供的先進圖像生成模型來創作精美的視覺內容了。
