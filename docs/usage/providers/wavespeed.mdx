# Using WaveSpeed AI in LobeHub

[WaveSpeed AI](https://wavespeed.ai) is an inference platform for image, video and audio generation. It serves flagship open and closed models — including Seedream, Nano Banana, GPT Image, Seedance and WAN — through a single fast, low-latency API. This guide walks you through using WaveSpeed AI in LobeHub:

<Steps>
  ### Step 1: Get Your WaveSpeed AI API Key

  - Sign up for a [WaveSpeed AI](https://wavespeed.ai) account;
  - Go to the [API Keys](https://wavespeed.ai/dashboard/api-keys) page in your dashboard and create a new API key;
  - Copy and securely save the generated API key.

  ### Step 2: Configure WaveSpeed AI in LobeHub

  - Open the `Settings` page in LobeHub;
  - Under `AI Providers`, locate the configuration section for `WaveSpeed AI`;
  - Paste the API key you obtained;
  - Select a WaveSpeed AI model for image or video generation.

  <Callout type={'warning'}>
    Please note that usage may incur charges from WaveSpeed AI. Be sure to review their official [pricing](https://wavespeed.ai/pricing) before making extensive API calls.
  </Callout>
</Steps>

And that’s it! You’re now ready to generate images and videos in LobeHub using the models provided by WaveSpeed AI.
