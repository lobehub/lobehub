# 在 LobeHub 中使用零一萬物

<Image alt={'在 LobeHub 中使用零一萬物'} cover src={'/blog/assets34400653/4485fbc3-c309-4c4e-83ee-cb82392307a1.webp'} />

[零一萬物](https://www.01.ai/)是一家致力於 AI 2.0 大模型技術和應用程式的全球公司，其發佈的千億參數的 Yi-Large 閉源模型，在斯坦福大學的英語排行 AlpacaEval 2.0 上，與 GPT-4 互有第一。

本文件將指導你如何在 LobeHub 中使用零一萬物:

<Steps>
  ### 步驟一：獲取零一萬物 API 密鑰

  - 註冊並登入 [零一萬物大模型開放平臺](https://platform.lingyiwanwu.com/)
  - 進入`工作臺`並存取`API Key管理`選單
  - 系統已為你自動建立了一個 API 密鑰，你也可以在此界面建立新的 API 密鑰

  <Image alt={'建立零一萬物 API 密鑰'} inStep src={'/blog/assets34400653/72f165f4-d529-4f01-a3ac-163c66e5ea73.webp'} />

  - 初次使用時需要完成帳號認證

  <Image alt={'完成帳號認證'} inStep src={'/blog/assets34400653/e6058456-8f9d-40c1-9ae5-1e9d5eeb9476.webp'} />

  - 點擊建立好的 API 密鑰
  - 在彈出的對話框中複製並儲存 API 密鑰

  <Image alt={'儲存 API 密鑰'} inStep src={'/blog/assets34400653/f892fe64-c734-4944-91ff-9916a41bd1c9.webp'} />

  ### 步驟二：在 LobeHub 中設定零一萬物

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`零一萬物`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets34400653/f539d104-6d64-4cc7-8781-3b36b00d32d0.webp'} />

  - 開啟零一萬物並填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 01.AI 的模型即可開始對話

  <Image alt={'選擇01.AI模型並開始對話'} inStep src={'/blog/assets34400653/8bf73498-4649-4c4d-a95b-b68447599781.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考零一萬物的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用零一萬物提供的模型進行對話了。
