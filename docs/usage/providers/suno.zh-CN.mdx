# 在 LobeHub 中使用 Suno

[Suno](https://suno.com) 可以生成带人声、歌词和伴奏的完整歌曲。Suno 官方 API 仅限受邀合作伙伴，因此 LobeHub 会用你的网关密钥请求第三方 Suno API 网关：默认是 [sunoapi.org](https://sunoapi.org)，也可以使用兼容其接口的服务。在 LobeHub 中，Suno 只提供音乐生成，没有对话模型。

<Steps>
  ### 步骤一：获取网关 API 密钥

  - 注册 [sunoapi.org](https://sunoapi.org)，打开 [API Key](https://sunoapi.org/api-key) 页面，创建并复制密钥。
  - 暂不支持 kie.ai 的密钥：kie.ai 的 Suno API 使用另一套协议（`/api/v1/jobs/createTask`）。
  - 在网关充值。每次请求由网关计费，而不是 Suno。

  <Callout type={'warning'}>
    启用前请确认网关条款与 Suno 服务条款。
  </Callout>

  ### 步骤二：在 LobeHub 中配置 Suno

  - 打开 **设置 → AI 服务商**，选择 **Suno**。
  - 将密钥粘贴到 **API Key**。
  - 使用 sunoapi.org 时 **API 代理地址** 留空（默认 `https://api.sunoapi.org`）；使用兼容网关时填写其 Base URL。
  - 点击 **检查**，密钥有效时显示 **检查通过**。LobeHub 会读取网关的余额，不会生成音乐，也不产生费用。密钥错误时显示 `Suno API密钥不正确或为空…`；展开下方的错误详情可查看网关返回的原始错误，例如 `Unauthorized – Authentication failed`。
  - 打开服务商名称旁的开关。

  ### 步骤三：选择模型

  **模型列表** 的 **音乐** 标签页列出 Suno 模型。**Suno V6** 和 **Suno V6 Wild** 默认启用，**Suno V6 Mini** 可在同一列表中开启。每次请求返回两首歌。
</Steps>

## 在音乐页面生成

1. 打开 **音乐** 页面：在创作模式切换中与 **图片**、**视频** 并列，也可以直接访问 `/music`。
2. 在 **模型** 中选择 **Suno V6**。
3. 在提示词输入框描述歌曲，例如 `一首关于深夜列车的温暖原声流行歌`。
4. 按需填写：
   - **风格**：曲风、情绪、人声、速度，例如 `acoustic pop, female vocals, 90 BPM`。
   - **歌词**：每行一句，用 `[Verse]`、`[Chorus]` 等标签标记段落。留空则由 Suno 自动作词。
   - **标题**、**排除风格**、**时长**：设置任一项会切换到 Suno 自定义模式，此时必须同时填写 **风格** 或 **歌词**。
   - **纯音乐**：不含人声，歌词不会被使用。
   - **时长**：10–360 秒，或 **自动**（由 Suno 决定）。
5. 点击 **生成**。提示词需搭配 **风格** 或 **歌词**，按钮才会可用，因为 Suno 不接受只有提示词的请求。页面出现两张歌曲卡片，状态依次为 **排队中…**、**生成中…**（通常 1–3 分钟）。
6. 完成后，卡片显示封面、标题、时长、标签和播放器。点击播放即可试听，也可以下载文件。

生成失败的歌曲会显示失败原因，并提供 **重试** 与 **复制错误信息**。

## 通过 API 生成

音乐页面调用的是 LobeHub 的 `lambda` tRPC API。你可以用 **设置 → API Key 管理** 中创建的 LobeHub API 密钥直接调用。先设置变量：

```bash
export LOBEHUB_URL=https://your-lobehub.example.com   # 或 http://localhost:3010
export LOBEHUB_API_KEY=sk-lh-xxxxxxxxxxxxxxxx
```

**1. 创建音乐话题。** 歌曲属于类型为 `music` 的话题。

```bash
curl -s -X POST "$LOBEHUB_URL/trpc/lambda/generationTopic.createTopic" \
  -H "X-API-Key: $LOBEHUB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"json":{"type":"music","title":"Suno test"}}'
# → {"result":{"data":{"json":"<generationTopicId>"}}}
```

**2. 提交生成。** `provider` 为 `suno`；`model` 可选 `suno-v6`、`suno-v6-wild`、`suno-v6-mini`。

```bash
curl -s -X POST "$LOBEHUB_URL/trpc/lambda/music.createMusic" \
  -H "X-API-Key: $LOBEHUB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"json":{
    "generationTopicId":"<generationTopicId>",
    "provider":"suno",
    "model":"suno-v6",
    "params":{
      "prompt":"A warm acoustic pop song about a late-night train ride",
      "style":"acoustic pop, female vocals, 90 BPM",
      "title":"Night Train",
      "lyrics":"[Verse]\nCity lights are fading slow\n[Chorus]\nRide the night train home",
      "instrumental":false
    }}}'
```

`params` 支持 `prompt`、`style`、`lyrics`、`title`、`negativeStyle`、`instrumental` 和 `duration`，未知字段会被拒绝；内置 Suno 模型不支持 `referenceAudioUrl`。响应包含批次信息，`data.generations` 中每首歌一条记录，每条记录带有 `id`（生成 ID）和 `asyncTaskId`：

```json
{ "result": { "data": { "json": {
  "success": true,
  "data": {
    "batch": { "id": "<batchId>", "model": "suno-v6", "provider": "suno" },
    "generations": [
      { "id": "<generationId-1>", "asyncTaskId": "<asyncTaskId-1>" },
      { "id": "<generationId-2>", "asyncTaskId": "<asyncTaskId-2>" }
    ]
  }
} } } }
```

**3. 轮询直到每首歌完成。** 服务端已经每 5 秒轮询一次网关，你只需要读取任务状态。对 `data.generations` 中的每条记录调用以下接口，直到 `status` 为 `success` 或 `error`：

```bash
curl -s -G "$LOBEHUB_URL/trpc/lambda/generation.getGenerationStatus" \
  -H "X-API-Key: $LOBEHUB_API_KEY" \
  --data-urlencode 'input={"json":{"asyncTaskId":"<asyncTaskId-1>","generationId":"<generationId-1>"}}'
```

`status` 依次为 `pending` → `processing` → `success`；被服务商拒绝的请求会从 `pending` 直接变为 `error`。成功时 `generation.asset.url` 是已存储的音频文件，`generation.asset` 还包含时长、标题、封面和标签。失败时 `error.body.detail` 是服务商返回的信息，例如 `Failed to submit music task: …`。

### LobeHub 发给网关的请求

LobeHub 会把上面的参数映射为网关的生成接口。直接发给 sunoapi.org 的等价请求如下：

```bash
curl -s -X POST https://api.sunoapi.org/api/v1/generate \
  -H "Authorization: Bearer $SUNO_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "V6",
    "customMode": true,
    "instrumental": false,
    "prompt": "A warm acoustic pop song about a late-night train ride",
    "style": "acoustic pop, female vocals, 90 BPM",
    "title": "Night Train",
    "lyrics": "[Verse]\nCity lights are fading slow\n[Chorus]\nRide the night train home",
    "duration": 180,
    "callBackUrl": "https://your-lobehub.example.com/api/webhooks/music/suno"
  }'
# → {"code":200,"msg":"success","data":{"taskId":"<taskId>"}}

curl -s "https://api.sunoapi.org/api/v1/generate/record-info?taskId=<taskId>" \
  -H "Authorization: Bearer $SUNO_API_KEY"
# → data.status：PENDING → TEXT_SUCCESS → FIRST_SUCCESS → SUCCESS
#   data.response.sunoData[].audioUrl：生成完成的歌曲
```

- `model` 是网关版本：`suno-v6` → `V6`，`suno-v6-wild` → `V6_WILD`，`suno-v6-mini` → `V6_MINI`。
- 设置了 `title`、`negativeStyle` 或 `duration` 时 `customMode` 为 `true`；`negativeStyle` 以 `negativeTags` 发送，`duration`（秒）只在自定义模式下发送。

## 常见问题

**「Suno needs a style, lyrics, or reference audio; a prompt alone is not accepted」**：补充 **风格** 或 **歌词**。

**「Suno custom mode … needs lyrics, a style, or a negative style」**：你设置了 **标题**、**排除风格** 或 **时长**，还需要填写 **风格** 或 **歌词**。

**「kie.ai's Suno API (/api/v1/jobs/createTask) is not supported yet」**：**API 代理地址** 指向了 kie.ai。请改用 sunoapi.org 的密钥，并将代理地址留空。

**检查失败并提示 `Unauthorized`**：密钥错误，或属于其他网关。确认 **API 代理地址** 与签发密钥的网关一致。

**余额不足**：在网关充值。

自托管部署请参考 [模型服务商环境变量](/zh/docs/self-hosting/environment-variables/model-provider#suno) 中的 `SUNO_API_KEY` 与 `SUNO_PROXY_URL`。
