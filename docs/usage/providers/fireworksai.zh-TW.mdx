# 在 LobeHub 中使用 Fireworks AI

<Image cover src={'/blog/assets05b20e40c03ced0ec8707fed2e8e0f25.webp'} />

[Fireworks.ai](https://fireworks.ai/) 是一個高性能的生成式 AI 模型推理平臺，允許使用者通過其 API 存取和使用各種模型。該平臺支援多種模態，包括文字和視覺語言模型，並提供函數調用和 JSON 模式等功能，以增強應用程式開發的靈活性。

本文將指導你如何在 LobeHub 中使用 Fireworks AI。

<Steps>
  ### 步驟一：獲得 Fireworks AI 的 API Key

  - 登入 [Fireworks.ai 控制檯](https://fireworks.ai/account/api-keys)
  - 進入 `User` 頁面，點擊 `API Keys`
  - 建立一個新的 API 密鑰

  <Image alt={'建立 API 密鑰'} inStep src={'/blog/assetsd0c4369f894abb5ad6e514059b8f378e.webp'} />

  - 複製並儲存生成的 API 密鑰

  <Image alt={'儲存 API 密鑰'} inStep src={'/blog/assets89a8dadc85902334ce8d2d5b78abf709.webp'} />

  <Callout type={'warning'}>
    請安全地儲存密鑰，因為它只會出現一次。如果您意外丟失它，您將需要建立一個新密鑰。
  </Callout>

  ### 步驟二：在 LobeHub 中設定 Fireworks AI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `Fireworks AI` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets74f5de8ee68e57b472d1fc56a2df40d5.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Fireworks AI 的模型即可開始對話

  <Image alt={'選擇 Fireworks AI 模型並開始對話'} inStep src={'/blog/assetsba0243e75b0421b6dd7dadad02e4b0d6.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Fireworks AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Fireworks AI 提供的模型進行對話了。
