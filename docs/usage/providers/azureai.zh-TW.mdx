# 在 LobeHub 中使用 Azure AI

<Image alt={'在 LobeHub 中使用 Azure AI '} cover src={'/blog/assets29de82efbe7657a8b9ba7daf0904585d.webp'} />

[Azure AI](https://azure.microsoft.com) 是一個基於 Microsoft Azure 雲平臺的開放式人工智慧技術平臺，提供包括自然語言處理、機器學習、計算機視覺等多種 AI 功能，幫助企業輕鬆開發和部署 AI 應用程式。

本文件將指導你如何在 LobeHub 中接入 Azure AI 的模型:

<Steps>
  ### 步驟一：部署 Azure AI 項目以及模型

  - 首先，存取[Azure AI Foundry](https://ai.azure.com/)並完成註冊登入
  - 登入後在首頁選擇`瀏覽模型`

  <Image alt={'進入 Azure AI Foundry'} inStep src={'/blog/assets8096422e62e10dcd58efe75c616f9e88.webp'} />

  - 在模型廣場中選擇你想要模型
  - 進入模型詳情，點擊`部署`按鈕

  <Image alt={'瀏覽模型'} inStep src={'/blog/assets7dbd100dac8e2614ef6b297885b3c9e2.webp'} />

  - 在彈出的對話框中建立一個新的項目

  <Image alt={'建立新項目'} inStep src={'/blog/assetsb9d1f02ab6c26f8a2c7873a949b4dd3c.webp'} />

  <Callout type={'note'}>
    Azure AI Foundry
    的詳細設定請參考[官方文件](https://learn.microsoft.com/azure/ai-foundry/model-inference/)
  </Callout>

  ### 步驟二：獲取模型的 API Key 及 Endpoint

  - 在已部署的模型詳情裡，可以查詢到 Endpoint 以及 API Key 資訊
  - 複製並儲存好獲取的資訊

  <Image alt={'獲取 API Key'} inStep src={'/blog/assets66829206b15b6c36fa3344835659c041.webp'} />

  ### 步驟三：在 LobeHub 中設定 Azure AI

  - 存取 LobeHub 的 `應用程式設定` 的 `AI 服務供應商` 界面
  - 在供應商列表中找到 `Azure AI` 的設定項

  <Image alt={'填寫 Azure AI  API 密鑰'} inStep src={'/blog/assets0a81d34f707bd87cee3852f26a3d14f0.webp'} />

  - 開啟 Azure AI 服務商並填入獲取的 Endpoint 以及 API 密鑰

  <Callout type={'warning'}>
    Endpoint 只需要填入前面部分 `https://xxxxxx.services.ai.azure.com/models` 即可
  </Callout>

  - 為你的助手選擇一個 Azure AI 模型即可開始對話

  <Image alt={'選擇 Azure AI 模型'} inStep src={'/blog/assetsbd69842ebb37848ecd50c242aad835b0.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Azure AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Azure AI 提供的模型進行對話了。
