# 在 LobeHub 中使用 Azure OpenAI

<Image alt={'在 LobeHub 中使用 Azure OpenAI'} cover src={'/blog/assets17870709/5efa34c2-6523-43e6-9ade-70ab5d802e13.webp'} />

本文件將指導你如何在 LobeHub 中使用 [Azure OpenAI](https://oai.azure.com/):

<Steps>
  ### 步驟一：獲取 Azure OpenAI API 密鑰

  - 如果尚未註冊，則必須註冊 [Azure OpenAI 帳戶](https://oai.azure.com/)。

  <Image alt={'註冊 Azure OpenAI 帳戶'} inStep src={'/blog/assets17870709/a77b0fb2-87d7-4527-a804-2f7ad3634aa5.webp'} />

  - 註冊完畢後，轉到 `Deployments` 頁面，然後使用您選擇的模型建立新部署。

  <Image alt={'選擇的模型建立新部署'} inStep src={'/blog/assets17870709/4fae3e6f-e680-4471-93c4-987c19d7170a.webp'} />

  - 轉到 `Chat` 頁面，然後單擊 `View Code` 以獲取您的終結點和密鑰。

  <Image alt={'轉到 Chat 頁面'} inStep src={'/blog/assets17870709/ac10d9dd-a977-43fb-8397-b2bbdee6a1a1.webp'} />

  <Image alt={'獲取終結點和密鑰'} inStep src={'/blog/assets17870709/ab94a7b5-6bc4-41e0-97bc-724ee8e315db.webp'} />

  ### 步驟二：在 LobeHub 中設定 Azure OpenAI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`Azure OpenAI`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets17870709/63d9f6d4-5b78-4c65-8cd1-ff8b7f143406.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Azure OpenAI 的模型即可開始對話

  <Image alt={'選擇 Azure OpenAI 模型並開始對話'} inStep src={'/blog/assets17870709/ddb44517-8696-4492-acd9-25b590f6069c.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Azure OpenAI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Azure OpenAI 提供的模型進行對話了。
