# 在 LobeHub 中使用 OpenAI

<Image alt={'在 LobeHub 中使用 OpenAI'} cover src={'/blog/assets17870709/c9e5eafc-ca22-496b-a88d-cc0ae53bf720.webp'} />

本文件將指導你如何在 LobeHub 中使用 [OpenAI](https://openai.com/):

<Steps>
  ### 步驟一：獲取 OpenAI API 密鑰

  - 註冊一個 [OpenAI 帳號](https://platform.openai.com/signup)，你需要使用國際手機號、非大陸信箱進行註冊；

  - 註冊完畢後，前往 [API Keys](https://platform.openai.com/api-keys) 頁面，點擊 `Create new secret key` 建立新的 API Key:

  - 開啟建立視窗

  <Image
    alt={'開啟建立視窗'}
    inStep
    src={
'https://github-production-user-asset-6210df.s3.amazonaws.com/28616219/296253192-ff2193dd-f125-4e58-82e8-91bc376c0d68.png'
}
  />

  - 建立 API Key

  <Image
    alt={'建立 API Key'}
    inStep
    src={
'https://github-production-user-asset-6210df.s3.amazonaws.com/28616219/296254170-803bacf0-4471-4171-ae79-0eab08d621d1.png'
}
  />

  - 獲取 API Key

  <Image
    alt={'獲取 API Key'}
    inStep
    src={
'https://github-production-user-asset-6210df.s3.amazonaws.com/28616219/296255167-f2745f2b-f083-4ba8-bc78-9b558e0002de.png'
}
  />

  <Callout type={'warning'}>帳號註冊後，一般有 5 美元的免費額度，但有效期只有三個月。</Callout>

  ### 步驟二：在 LobeHub 中設定 OpenAI

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`OpenAI`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets17870709/3f31bc33-509f-4ad2-ba81-280c2a6ec5fa.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 OpenAI 的模型即可開始對話

  <Image alt={'選擇 OpenAI 模型並開始對話'} inStep src={'/blog/assets17870709/ff7ebacf-27f0-42d7-810b-00314499a084.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 OpenAI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 OpenAI 提供的模型進行對話了。
