# 使用 Google Gemma 模型

<Image alt={'在 LobeHub 中使用 Gemma'} cover rounded src={'/blog/assets17870709/65d2dd2a-fdcf-4f3f-a6af-4ed5164a510d.webp'} />

[Gemma](https://blog.google/technology/developers/gemma-open-models/) 是 Google 開源的一款大語言模型（LLM），旨在提供一個更加通用、靈活的模型用於各種自然語言處理任務。現在，通過 LobeHub 與 [Ollama](https://ollama.com/) 的整合，你可以輕鬆地在 LobeHub 中使用 Google Gemma。

本文件將指導你如何在 LobeHub 中使用 Google Gemma：

<Steps>
  ### 本地安裝 Ollama

  首先，你需要安裝 Ollama，安裝過程請查閱 [Ollama 使用檔案](/zh/docs/usage/providers/ollama)。

  ### 用 Ollama 拉取 Google Gemma 模型到本地

  在安裝完成 Ollama 後，你可以通過以下命令安裝 Google Gemma 模型，以 7b 模型為例：

  ```bash
  ollama pull gemma
  ```

  <Image alt={'使用 Ollama 拉取 Gemma 模型'} height={473} inStep src={'/blog/assets28616219/7049a811-a08b-45d3-8491-970f579c2ebd.webp'} width={791} />

  ### 選擇 Gemma 模型

  在會話頁面中，選擇模型面板開啟，然後選擇 Gemma 模型。

  <Image alt={'模型選擇面板中選擇 Gemma 模型'} height={629} inStep src={'/blog/assets28616219/69414c79-642e-4323-9641-bfa43a74fcc8.webp'} width={791} />

  <Callout type={'info'}>
    如果你沒有在模型選擇面板中看到 Ollama 服務商，請查閱 [與 Ollama
    整合](/zh/docs/self-hosting/examples/ollama) 瞭解如何在 LobeHub 中開啟 Ollama 服務商。
  </Callout>
</Steps>

接下來，你就可以使用 LobeHub 與本地 Gemma 模型對話了。
