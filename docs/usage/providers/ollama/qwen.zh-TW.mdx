# 使用本地通義千問 Qwen 模型

<Image alt={'在 LobeHub 中使用 Qwen'} cover src={'/blog/assets17870709/b4a01219-e7b1-48a0-888c-f0271b18e3a6.webp'} />

[通義千問](https://github.com/QwenLM/Qwen1.5) 是阿里雲開源的一款大語言模型（LLM），官方定義是一個不斷進化的 AI 大模型，並通過更多的訓練集內容達到更精準的中文識別能力。

<Video src="/blog/assets28616219/31e5f625-8dc4-4a5f-a5fd-d28d0457782d.mp4" />

現在，通過 LobeHub 與 [Ollama](https://ollama.com/) 的整合，你可以輕鬆地在 LobeHub 中使用 通義千問。

本文件將指導你如何在 LobeHub 中使用通義千問本地部署版：

<Steps>
  ### 本地安裝 Ollama

  首先，你需要安裝 Ollama，安裝過程請查閱 [Ollama 使用檔案](/zh/docs/usage/providers/ollama)。

  ### 用 Ollama 拉取 Qwen 模型到本地

  在安裝完成 Ollama 後，你可以通過以下命令安裝 Qwen 模型，以 14b 模型為例：

  ```bash
  ollama pull qwen:14b
  ```

  <Image alt={'使用 Ollama 拉取 Qwen 模型'} height={473} inStep src={'/blog/assets1845053/fe34fdfe-c2e4-4d6a-84d7-4ebc61b2516a.webp'} />

  ### 選擇 Qwen 模型

  在會話頁面中，選擇模型面板開啟，然後選擇 Qwen 模型。

  <Image alt={'模型選擇面板中選擇 Qwen 模型'} height={430} inStep src={'/blog/assets28616219/e0608cca-f62f-414a-bc55-28a61ba21f14.webp'} />

  <Callout type={'info'}>
    如果你沒有在模型選擇面板中看到 Ollama 服務商，請查閱 [與 Ollama
    整合](/zh/docs/self-hosting/examples/ollama) 瞭解如何在 LobeHub 中開啟 Ollama 服務商。
  </Callout>
</Steps>

接下來，你就可以使用 LobeHub 與本地 Qwen 模型對話了。
