# 在 LobeHub 中使用 API Store

[API Store](https://apistore.cloud) 通过统一的 OpenAI 兼容 Chat Completions API 提供 Claude、GPT、Gemini 和 DeepSeek 对话模型。一个 API Key 即可调用所有模型，用量按 Token 从预付余额中扣费。

本文将指导你如何在 LobeHub 中使用 API Store。

<Steps>
  ### 步骤一：获取 API Store 的 API Key

  - 在 [API Store](https://apistore.cloud) 注册或登录。
  - 打开 API Keys 页面，创建一个新的 Key。
  - 复制该 Key（以 `sk-` 开头）并妥善保存。

  <Callout type={'info'}>
    你可以在 API Keys 页面把 Key 限定为只允许自己的 IP 地址使用。如果设置了该限制，请把 LobeHub
    服务端发出请求的地址也加入其中，否则请求会被拒绝并返回 `403 ip_not_allowed`。
  </Callout>

  ### 步骤二：在 LobeHub 中配置 API Store

  - 打开 LobeHub 的 **应用设置 → AI 服务商**。
  - 在服务商列表中找到 **API Store** 并打开开关。
  - 在 API Key 输入框中粘贴你的 Key。API 代理地址留空即使用默认地址 `https://api.apistore.cloud/v1`。
  - 点击 **检查** 验证连接。

  ### 步骤三：选择模型并开始对话

  - LobeHub 已内置 API Store 当前的对话模型。点击 **获取模型列表** 可从 API Store 刷新列表；图像和视频模型不会出现在列表中，因为 LobeHub 只通过 API Store 使用对话模型。
  - 在对话的模型选择器中选择模型，即可开始对话。

  <Callout type={'warning'}>
    API 用量由 API Store 收费。当前各模型的每 Token 价格请参阅 [API Store 价格页面](https://apistore.cloud/pricing)。
  </Callout>
</Steps>

## 能力

- 所有模型都支持工具（函数）调用和流式输出。
- Claude、GPT 和 Gemini 模型支持图片输入。
- 所有模型都可以设置推理强度。Claude 模型会返回推理文本，LobeHub 会将其显示为回复中的思考内容。

## 私有化部署

在私有化部署中，你可以在服务端提供 Key，而无需在界面中填写。请参阅 [模型服务商环境变量](/zh/docs/self-hosting/environment-variables/model-provider#api-store) 中的 `APISTORE_API_KEY`、`APISTORE_PROXY_URL` 和 `APISTORE_MODEL_LIST`。
