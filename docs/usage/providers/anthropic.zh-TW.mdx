# 在 LobeHub 中使用 Anthropic Claude

<Image alt={'在 LobeHub 中使用 Anthropic Claude'} cover src={'/blog/assets17870709/620b956b-dcb2-442a-8bb1-9aa22681dfa4.webp'} />

Anthropic Claude API 現在可供所有人使用，本文件將指導你如何在 LobeHub 中使用 [Anthropic Claude](https://www.anthropic.com/api):

<Steps>
  ### 步驟一：獲取 Anthropic Claude API 密鑰

  - 建立一個 [Anthropic Claude API](https://www.anthropic.com/api) 帳戶
  - 獲取您的 [API 密鑰](https://console.anthropic.com/settings/keys)

  <Image alt={'建立 API Key'} inStep src={'/blog/assets17870709/15e09e71-5899-4805-9c5e-1f7c57be04ae.webp'} />

  <Callout type={'warning'}>
    Claude API 現在提供 5 美元的免費積分，但是，它僅適用於某些特定國家 / 地區，您可以轉到 Dashboard >
    Claim 查看它是否適用於您所在的國家 / 地區。
  </Callout>

  - 設定您的帳單，讓 API 密鑰在 [https://console.anthropic.com/settings/plans](https://console.anthropic.com/settings/plans) 上工作（選擇 「生成」 計劃，以便您可以新增積分並僅為使用量付費）

  <Image alt={'設定您的帳單'} inStep src={'/blog/assets17870709/385f663f-cae2-4383-9bb0-52c45e5d7d7a.webp'} />

  ### 步驟二：在 LobeHub 中設定 Anthropic Claude

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到`Anthropic Claude`的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets17870709/ff9c3eb8-412b-4275-80be-177ae7b7acbc.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 Anthropic Claude 的模型即可開始對話

  <Image alt={'選擇 Anthropic Claude 模型並開始對話'} inStep src={'/blog/assets17870709/6cdc5c0e-0508-44ed-a283-03f6b538ed8a.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 Anthropic Claude 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 Anthropic Claude 提供的模型進行對話了。
