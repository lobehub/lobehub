# 在 LobeHub 中使用火山引擎

<Image alt={'在 LobeHub 中使用火山引擎'} cover src={'/blog/assets80a8b9627374fc345f4bf8e3adf11074.webp'} />

[火山引擎](https://www.volcengine.com/)是字節跳動旗下的雲服務平臺，通過 "火山方舟" 提供大型語言模型 (LLM) 服務，支援多個主流模型如百川智慧、Mobvoi 等。

本文件將指導你如何在 LobeHub 中使用火山引擎:

<Steps>
  ### 步驟一：獲取火山引擎 API 密鑰

  - 首先，存取[火山引擎官網](https://www.volcengine.com/)並完成註冊登入
  - 進入火山引擎控制檯並導航至[火山方舟](https://console.volcengine.com/ark/)

  <Image alt={'進入火山方舟API管理頁面'} inStep src={'/blog/assetsf7007eebef93bc1d8a29aaf9080ab404.webp'} />

  - 進入 `API key 管理` 選單，並點擊 `建立 API Key`
  - 複製並儲存建立好的 API Key

  ### 步驟二：在 LobeHub 中設定火山引擎

  - 存取 LobeHub 的 `應用程式設定` 的 `AI 服務供應商` 界面
  - 在供應商列表中找到 `火山引擎` 的設定項

  <Image alt={'填寫火山引擎 API 密鑰'} inStep src={'/blog/assetsf3e7c2e961d1d2886fe231a4ac59e2f1.webp'} />

  - 開啟火山引擎服務商並填入獲取的 API 密鑰
  - 為你的助手選擇一個火山引擎模型即可開始對話

  <Image alt={'選擇火山引擎模型'} inStep src={'/blog/assetsd56d1af67bb2be60b0c580be0a6c7110.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考火山引擎的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用火山引擎提供的模型進行對話了。
