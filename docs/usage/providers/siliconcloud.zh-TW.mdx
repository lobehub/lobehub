# 在 LobeHub 中使用 SiliconCloud

<Image cover src={'/blog/assets0e9c7125960a2d00b8c3c3d15d88f0a7.webp'} />

[SiliconCloud](https://siliconflow.cn/) 是一個基於開源基礎模型的人工智慧服務平臺，提供多種生成式 AI（GenAI）服務。

本文將指導你如何在 LobeHub 中使用 SiliconCloud。

<Steps>
  ### 步驟一：獲得 SiliconCloud 的 API Key

  - 註冊並登入 [SiliconCloud](https://cloud.siliconflow.cn/account/ak)
  - 點擊左側 `API 密鑰` 選單
  - 建立一個 API 密鑰並複製

  <Image alt={'建立API密鑰'} inStep src={'/blog/assets56e5331e7fae3754820790c824cdc480.webp'} />

  ### 步驟二：在 LobeHub 中設定 SiliconCloud

  - 存取 LobeHub 的`設定`界面
  - 在`AI 服務商`下找到 `SiliconFlow` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'/blog/assets94f55c97a24a08c7a5923c23ee2d7eef.webp'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 SiliconCloud 的模型即可開始對話

  <Image alt={'選擇 SiliconCloud 模型並開始對話'} inStep src={'/blog/assets94397c91265c37b9f313dc439b90125f.webp'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 SiliconCloud 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 SiliconCloud 提供的模型進行對話了。
