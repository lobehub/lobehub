# 在 LobeHub 中使用 GMI Cloud Speech

[GMI Cloud](https://www.gmicloud.ai) 在一个多模态请求队列 API 后面提供多个语音模型系列，包括 Inworld 实时 TTS 和 MiniMax 语音合成。在 LobeHub 中，GMI Cloud Speech 仅作为文本转语音提供商：不提供聊天模型。

<Steps>
  ### 第一步：获取 GMI Cloud API Key

  - 在 [GMI Cloud](https://console.gmicloud.ai) 注册或登录。
  - 在组织设置中创建 API Key。
  - 复制并妥善保管 Key。

  ### 第二步：在 LobeHub 中配置 GMI Cloud Speech

  - 打开 **App 设置 → AI 服务商**，选择 **GMI Cloud Speech**（在搜索框输入 `GMI` 可快速找到）。
  - 将 Key 粘贴到 **API Key**。更改会自动保存，Key 会以 AES-GCM 加密存储。
  - 打开服务商名称旁边的开关。
  - 可选：在 **API Proxy URL** 中填写代理地址。留空则使用 `https://console.gmicloud.ai`。

  ### 第三步：选择模型

  **模型列表** 的 **TTS** 标签下会显示 GMI Cloud 的语音模型。Inworld TTS 2 和 MiniMax Speech 2.8 Turbo 默认启用。

  GMI Cloud Speech 没有聊天模型，因此服务商页面不显示 **检查** 按钮。请通过下述语音生成验证 Key。

  <Callout type={'info'}>
    生成任务经由 GMI Cloud 的请求队列处理。Inworld TTS 2 是低延迟选项；MiniMax 生成通常较快，但偶尔会有请求耗时较长。
  </Callout>
</Steps>

## 生成语音

语音合成通过 LobeHub 的文本转语音 API 运行，LobeHub CLI（`lh`）和 OpenAI 兼容的 `POST /api/v1/audio/speech` 端点都使用它：

```bash
lh generate tts "Hello from LobeHub" -m gmicloudspeech/inworld-tts-2 -o hello.mp3
```

- **音色** — 未指定音色时使用系列默认音色（Inworld 为 `Dennis`，MiniMax 为 `English_expressive_narrator`）。用 `--voice <voice id>` 可指定模型系列支持的其他音色。
- **格式** — LobeHub TTS API 为该服务商输出 MP3（内联响应格式为 `mp3`、`opus` 和 `aac`；GMI Cloud 生成 MP3 或 WAV）。

<Callout type={'warning'}>
  LobeHub TTS API 为该服务商输出 MP3。GMI Cloud 上的 Chatterbox 模型需要 Resemble 音色 UUID，未在 LobeHub 中列出。
</Callout>
