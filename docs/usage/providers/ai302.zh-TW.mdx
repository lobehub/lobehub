# 在 LobeHub 中使用 302.AI

<Image cover src={'https://file.302.ai/gpt/imgs/20250722/d346c796faa4443eb0bd4218f84205f6.jpg'} />

[302.AI](https://www.302.ai/) 是一個按需付費的 AI 應用程式平臺，提供市面上最全的 AI API 和 AI 線上應用程式。

本文將指導你如何在 LobeHub 中使用 302.AI。

<Steps>
  ### 步驟一：獲得 [302.AI](https://www.302.ai/) 的 API Key

  - 點擊 `開始使用`，註冊並登入 [302.AI](https://www.302.ai/)
  - 點擊左側的 `API Keys`
  - 點擊 `新增API KEY`，複製並儲存生成的 API 密鑰

  <Image alt={'獲取 API 密鑰'} inStep src={'https://file.302.ai/gpt/imgs/20250722/01abd69fd61540489781fd963e504a04.jpg'} />

  ### 步驟二：在 LobeHub 中設定 302.AI

  - 存取 LobeHub 的`設定`界面
  - 在`語言模型`下找到 `302.AI` 的設定項

  <Image alt={'填入 API 密鑰'} inStep src={'https://file.302.ai/gpt/imgs/20250722/5247463e74c742f79bef416bbb0722bf.jpg'} />

  - 填入獲得的 API 密鑰
  - 為你的 AI 助手選擇一個 302.AI 的模型即可開始對話

  <Image alt={'選擇 302.AI 模型並開始對話'} inStep src={'https://file.302.ai/gpt/imgs/20250722/d346c796faa4443eb0bd4218f84205f6.jpg'} />

  <Callout type={'warning'}>
    在使用過程中你可能需要向 API 服務提供商付費，請參考 302.AI 的相關費用政策。
  </Callout>
</Steps>

至此你已經可以在 LobeHub 中使用 302.AI 提供的模型進行對話了。
