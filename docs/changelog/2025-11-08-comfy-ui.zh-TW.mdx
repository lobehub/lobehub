# ComfyUI 整合與知識庫優化 ⭐

LobeHub 在十月至十一月整合 ComfyUI 工作流，新增多個 AI 服務商與模型支援，並持續優化知識庫與使用者體驗。

## 🌟 重要更新

- 🎨 ComfyUI 整合：支援 ComfyUI 工作流整合
- 🤖 新增服務商：Cerebras、CometAPI 等服務商支援
- 📄 PDF 導出：支援將對話導出為 PDF 格式
- 🗂️ 知識庫優化：新增瀑布流佈局、支援上傳時自動解壓縮檔案
- 🖼️ 圖像生成擴充功能：支援矽基流動、混元 Text-to-Image 3 等圖像生成衣務

## 📊 模型庫更新

新增 Claude Haiku 4.5、GPT-5 Pro、MiniMax-M2、Imagen 4 for Vertex AI 等模型

## 💫 體驗優化

優化富文字連結顯示、改進搜尋體驗、支援禁用富文字編輯、新增刪除與重新生成快捷鍵、改進更新通知
