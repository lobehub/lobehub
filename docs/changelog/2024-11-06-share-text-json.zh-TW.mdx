# 對話內容分享升級：支援文字格式導出

我們在最新版本 v1.28.0 中推出了對話內容的文字格式導出功能，現在支援將對話內容導出為 Markdown 和 OpenAI 格式的 JSON 兩種格式。

Markdown 格式導出功能滿足了使用者將對話內容直接用於筆記和文件撰寫的需求。您可以輕鬆地將有價值的對話內容儲存下來，並在各類筆記軟體中進行管理和複用。

![將對話導出為 Markdown 格式文字](/blog/assets/29b13dc042e3b839ad8865354afe2fac.webp)

同時，我們還支援將對話導出為符合 OpenAI messages 規範的 JSON 格式。這種格式不僅可以直接用於 API 除錯，還能作為高品質的模型訓練語料。

![將對話導出為 OpenAI 接口規範的 JSON](/blog/assets/5bbb4b421d6df63780b3c7a05f5a102d.webp)

特別值得一提的是，我們會完整保留對話中的 Tools Calling 原始資料，這對提升模型的工具調用能力具有重要價值。

這次更新讓對話內容的分享和應用場景得到了極大擴充功能，期待這些新功能能夠提升您的使用體驗。
