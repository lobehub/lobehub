# MCP 市場與搜尋服務商擴充功能 🔍

LobeHub 在六月至七月推出 MCP 插件市場，新增多個搜尋服務商支援，並整合 Amazon Cognito 與 Google SSO 認證，持續優化使用者體驗與開發者生態。

## 🌟 重大更新

- 🛒 MCP 市場上線：桌面端支援 MCP 插件一鍵安裝，提供豐富的插件生態與便捷的安裝體驗
- 🔍 搜尋服務商擴充功能：新增 Brave、Google PSE、Kagi 等搭載搜尋服務商，支援 Vertex AI Google Search Grounding
- 🔐 認證系統增強：整合 Amazon Cognito 與 Google SSO 作為認證提供商，支援頁面存取保護
- 🤖 v0 (Vercel) 支援：新增 Vercel v0 服務商支援
- 📊 資料分析框架：實現資料分析事件追蹤框架，優化使用者行為分析

## 💫 體驗優化

- 界面改進：優化行動端模型選擇佈局、改進文字溢出處理、修復載入動畫切換問題
- 推理設定：優化 Gemini thinkingBudget 設定、正確處理 reasoning\_effort 參數
- 搜尋優化：支援 Browserless blockAds 與 stealth 參數、修復 Firefox Mermaid 顯示錯誤
- 桌面端增強：改進多顯示器視窗開啟體驗、修復主題問題、優化分塊載入
- 回應動畫：改進回應動畫合併邏輯、支援過渡動畫開關
