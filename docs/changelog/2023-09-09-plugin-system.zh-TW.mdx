# 支援插件系統

LobeHub 的插件生態系統是其核心功能的重要擴充功能，它極大地增強了 LobeHub 助手的實用性和靈活性。

<Video src="/blog/assets/28616219/f29475a3-f346-4196-a435-41a6373ab9e2.mp4" />

通過利用插件，LobeHub 的助手們能夠實現即時資訊的獲取和處理，例如搜尋網路資訊，為使用者提供即時且相關的資訊。

此外，這些插件不僅侷限於新聞聚合，還可以擴充功能到其他實用的功能，如快速檢索文件、生成圖片、獲取 Bilibili 、Steam 等各種平臺資料，以及與其他各式各樣的第三方服務交互。
