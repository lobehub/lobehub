# ElevenLabs Text-to-Speech

ElevenLabs is now available under **App Settings → AI Providers**. Add your ElevenLabs API key there, or set `ELEVENLABS_API_KEY` on a self-hosted server, and generate speech with ElevenLabs models through the LobeHub CLI (`lh generate tts`) or the OpenAI-compatible `/api/v1/audio/speech` endpoint.

## Features

- **Generate speech with ElevenLabs models.** Eleven v4, Eleven Multilingual v2, and Eleven Flash v2.5 are enabled by default; Eleven v3, Eleven Flash v2, and Eleven Turbo v2.5 can be turned on in the model list. Usage is billed per character and recorded like other speech providers.
- **Pick a voice, format, and speed.** A built-in list of long-lived ElevenLabs voices is included, any voice id from your own library also works, and audio comes back as MP3 or Opus. Multilingual v2 and the Flash and Turbo models accept a speed from 0.7 to 1.2.
- **Use a regional endpoint.** The API proxy URL accepts an ElevenLabs data-residency endpoint.

## Improvements

- **Know when a speech key is missing.** When no API key is configured, or the provider rejects it, speech requests now return the same "API Key is incorrect or empty" message used across LobeHub, with the provider's own reason attached, instead of a generic failure.

See [Using ElevenLabs in LobeHub](/docs/usage/providers/elevenlabs) for setup steps.
