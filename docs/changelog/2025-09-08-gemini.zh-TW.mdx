# Gemini 圖像生成與非流式模式支援 🎨

LobeHub 在八月至九月新增 Gemini 2.5 Flash Image 圖像生成能力，支援非流式回應模式，並擴充功能多個 AI 服務商與模型支援。

## 🌟 重大更新

- 🎨 Gemini 圖像生成：支援 Gemini 2.5 Flash Image（Nano Banana）、Imagen 4 GA 等圖像生成模型
- 🔄 非流式模式：新增非流式回應模式支援，相容更多使用場景
- 🌐 服務商擴充功能：新增 Nebius、AkashChat、BFL 等圖像生成衣務商支援
- 🖼️ Azure OpenAI 圖像生成：支援通過 Azure OpenAI 生成圖像
- 🔧 HTML 預覽：支援 HTML 內容預覽功能 📊 模型庫更新新增 GPT-5 系列、Claude Opus 4.1、Grok Code Fast 1、DeepSeek V3.1、Gemini URL Context Tool 支援

## 💫 體驗優化

優化思維滾動遮罩效果、支援會話切換快捷鍵、改進行動端控件表單顯示、優化 Gemini 錯誤提示
