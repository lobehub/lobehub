# Chief Agent Operator —— 会自审、能自跑的长周期 Agent

## Chief Agent Operator (v2.2.0)

Chief Agent Operator 把一次性对话升级为长周期的「操盘手」。Agent 现在可以对自己产出的结果做自审，并自动执行通过审核的后续动作 —— 以前你需要主动说一句「好，继续下一步」的流程，现在它会自己往前推进。当遇到真正需要决策的节点时，Agent 会切换到 `waitingForHuman` 状态，通过 `AskUserQuestion` 带上自由文本备注向你提问，而不是凭猜测继续。

操盘手也能临时组队。新的异构 AssistantGroup 允许一个 Agent 即时组建一支子 Agent 团队，子线程通过 Monitor 风格的 Signal 回调流式回报。你可以进入任何一个分支查看队友的工作，但分支线程保持只读，主导权依然在主 Agent 手里。

## 新功能

- 自审动作：Agent Signal 自动执行通过审核的后续动作，不再每步都暂停等待确认
- Agent 团队编排：异构 AssistantGroup 配 Monitor 风格的 Signal 回调，并支持只读地查看子 Agent 线程
- 操盘手状态新增 `waitingForHuman`，结合 `AskUserQuestion` 的自由文本备注
- 调度器加固：`maxExecutions` 上限、屏蔽小于 10 分钟的心跳，并修复 SchedulerForm 的竞态问题
- Agent 文档索引：以更整洁的表格形式呈现，并隐藏网页抓取记录
- 工作侧栏新增项目技能（Project Skills），并支持内联 Markdown 预览
- 按场景配置后续动作模型：不同的后续提取上下文可指定不同模型
- 新模型：百度文心一言 5.1；DeepSeek 价格恢复官方定价，Anthropic 兼容端点的 base URL 归一化

## 体验优化与修复

- 桌面端不再因为 token 刷新重试导致频繁退出登录；应用更新重启后会恢复你之前所在的路由。
- 聊天输入框的动作 Chip 调整为「图标 + 彩色标签」样式；仅最后一段 Markdown 内容进行流式动画。
- Tab 栏在未激活标签之间使用 Chrome 风格分割线；任务看板的计划时间标签不再换行。
- 本地文件 Shell 对以 `.` 开头的模式自动启用隐藏文件匹配；`grepContent` 参数完整透传。
- 文档处理在遇到不支持的解析器时会主动拒绝；工具异常会回退到 `stderr`，并带 `UNKNOWN_EXEC_ERROR` 前缀。
- 修复 Gemini 工具调用的 `thoughtSignature` 处理，以及 enum /required 的类型清洗；每工具超时配置端到端生效。
- 任务路由保留 Agent 上下文；Agent Signal 将记忆 Agent 的消息与主线程隔离。
