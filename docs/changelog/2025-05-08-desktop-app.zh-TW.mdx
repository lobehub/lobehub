# 全新設計風格與桌面端發佈 ✨

LobeHub 在四月完成重大視覺升級，推出全新 Lobe UI v2 設計系統，並正式發佈桌面端應用程式，帶來更現代、更流暢的使用體驗。

## 🌟 重大更新

- 🎨 全新設計系統：升級至 Lobe UI v2，帶來更現代化的界面設計與交互體驗
- 💻 桌面端正式發佈：支援 Windows、macOS 系統托盤、視窗控制等原生功能，提供更便捷的桌面使用體驗
- 🔌 MCP 協議增強：支援 Streamable HTTP MCP 伺服器，優化 stdio MCP 伺服器安裝體驗，新增環境變數參數支援
- 🔍 搜尋功能擴充功能：新增 Search1API 搜尋服務商支援，優化 SearXNG 分類與時間範圍選擇
- 🔑 SSO 認證擴充功能：新增 Keycloak 單點登入支援，改進 OIDC OAuth 工作流

## 📊 模型庫更新

- OpenAI: GPT-4.1 系列、o3/o4-mini
- Google: Gemini 2.5 Pro Experimental、推理 Token 統計支援
- xAI: Grok 3 系列模型
- Anthropic、Mistral、Qwen、Ollama 等平臺最新模型

## 💫 體驗優化

- 界面改進：支援系統角色摺疊、優化行動端樣式、整齊排列模型標籤、錯誤時允許複製 / 編輯
- 性能統計：顯示 Token 生成性能、阿里雲百鍊 Token 使用追蹤、Google Gemini 推理 Token 統計
- 快捷鍵增強：新增清除聊天訊息、刪除訊息等快捷鍵，支援自訂快捷鍵設定
- 工具調用優化：支援更新工具調用參數並重新觸發、本地檔案插件新增寫入檔案功能
- 網頁爬取：新增小紅書爬蟲規則支援
