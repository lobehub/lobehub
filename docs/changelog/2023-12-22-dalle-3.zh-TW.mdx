# 支援 Text to Image 文生圖

現已支援最新的文字到圖片生成技術，LobeHub 現在能夠讓使用者在與助手對話中直接調用文成圖工具進行創作。通過利用 [`DALL-E 3`](https://openai.com/dall-e-3)、[`MidJourney`](https://www.midjourney.com/) 和 [`Pollinations`](https://pollinations.ai/) 等 AI 工具的能力， 助手們現在可以將你的想法轉化為圖像。同時可以更私密和沉浸式的完成你的創造過程。
