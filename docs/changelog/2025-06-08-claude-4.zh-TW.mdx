# 提示詞變數與 Claude 4 推理模型支援 🚀

LobeHub 在五月至六月持續優化核心功能，新增提示詞變數系統、支援 Claude 4 推理模型，並擴充功能多個 AI 服務商的搜尋與推理能力。

## 🌟 主要更新

- 💬 提示詞變數系統：支援在提示詞和輸入框中使用佔位符變數，實現動態內容替換
- 🧠 Claude 4 系列支援：完整接入 Anthropic Claude 4 推理模型，支援 Web Search 工具與 Beta Header
- 🔍 搜尋能力擴充功能：新增 ModelScope 服務商，支援更多平臺的搜尋與爬蟲功能
- 📄 檔案上傳優化：支援直接將檔案上傳至聊天上下文，改進 PDF、XLSX 檔案內容解析
- 🔐 頁面保護功能：支援頁面存取保護，優化 Clerk 中間件路由保護
