# 随时掌握助理进展的新首页

## 新功能

- **一眼看到助理在你离开时做了什么。** 首页现在是一块仪表盘：一侧是问候语和输入框，另一侧是卡片栏，展示需要你处理的事项、正在运行的任务、每日简报和推荐。输入框可以在对话、任务、笔记之间切换，同一个输入框既能开启话题，也能创建任务或新建页面。
- **开始使用时获得起步任务。** 新手引导会根据你描述的工作内容推荐具体的起步任务，不再把你留在空白页面上。
- **在桌面端同时打开更多标签页。** 标签页会自动收窄以适应宽度，不再横向滚动出可视区域；当前标签始终保留可读的标题，放不下的标签会收进下拉菜单，你还可以把标签固定到最前或用中键关闭。
- **通过一个向导接入本地助理。** 在自己的电脑上配置助理现在走统一的引导流程，不再每种连接器一套步骤。
- **在桌面端安装本地工具。** 桌面端现在可以安装并运行位于本机或局域网内的 MCP 连接器。
- **用 Markdown 编写助理简介。** 助理简介新增源码模式，可以直接编辑原始 Markdown。
- **按固定档位缩放桌面端界面。** 缩放改用与浏览器一致的预设档位，字号变化更可预期。
- **调整 Kimi K3 的思考强度。** Kimi K3 提供思考强度控制，模型列表中也补充了 Kimi K3 Fast 的说明。

## 体验优化

- **应用启动更快。** 桌面端和网页端的打开速度都有提升，加载画面改为展示真实的应用框架而非居中的标识，首屏不再跳变。
- **切换标签页不会丢失进度。** 桌面端每个标签页都会保留自己的视图，切走再切回来不会中断进行中的工作。
- **搜索助理时更容易找到目标。** 助理搜索先筛选再排序，恢复了正确的排序结果和真实的相关度分数。
- **用键盘回应助理的提问。** 当助理请你做选择时，回车确认，Esc 关闭。
- **更轻松地查看交付检查。** 验收清单的分组更合理，可以整页滚动，验证详情的排版也更清晰。
- **看清话题卡在哪个模型上。** 模型选择器会直接显示已不可用的模型名称，而不是原始的供应商与模型标识。
- **回到任务列表时不再闪一下加载态。** 侧边栏的任务列表会在多次访问之间缓存，骨架屏不会重复出现。
- **从标签标题判断当前位置。** 助理子页面的浏览器标签标题现在会带上所在板块和助理名称。
- **清理存储空间时有明确指引。** 存储提示会引导你去删除文件，而不只是告知容量上限。
- **子助理的工具权限更可控。** 子助理只能使用被授予的工具，无法调用上级助理的全部工具。
- **设置页面的结构更统一。** 设置页共用同一套页头样式，关于页面也重新做了整理。

## 问题修复

- **Windows 上的命令执行更稳定。** 修复了多个高频反馈的命令执行问题，文件搜索也会基于你的工作目录解析路径。
- **桌面端不再因图片结果崩溃。** 上传工具返回的图片不会再导致应用退出，冷启动也不会多开一个标签页。
- **桌面端跟随系统语言。** 界面语言改为读取操作系统设置，而不是裁剪后的应用语言。
- **子助理会沿用你指定的模型。** 显式设置的模型会保留到子助理话题中，分组后的子助理回答也不会丢失。
- **重试不再产生重复消息。** 重试某一步会复用已有消息，重复的续写会被忽略，失败的占位消息也会被过滤。
- **取消一个线程不会影响其他线程。** 停止某个线程中的对话不再连带取消其他正在进行的工作。
- **步骤数与实际调用一致。** 助理消息上显示的步骤数现在与实际发生的模型调用次数相符。
- **定时任务会按时启动。** 设置了周期的任务默认按 cron 计划开始运行。
- **已处理的简报不会再出现。** 处理过的简报在页面跳转后不会重新回到列表。
- **推理模型的行为更正确。** Moonshot 支持在思考的同时输出结构化内容，OpenAI Responses 的推理内容会完整保存，Cerebras 与 Groq 也可以接收进阶推理参数。
- **空回复和纯图片回复能被正确识别。** 没有文字内容的回复（包括只有图片的回复）会被识别并提示，而不是静默失败。
- **切换账号会清除上一个会话。** 残留的登录状态不会再带入新账号。
- **通知的关闭按钮不会被遮挡。** 较长的通知文案不会再盖住关闭控件。
- **提示词编辑器不再自动跳到底部。** 切换查看模式时，页面会停留在原处。
