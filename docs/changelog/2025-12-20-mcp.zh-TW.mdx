# MCP 雲端點與模型庫擴充功能 🔌

LobeHub 在十一月持續優化模型支援與使用者體驗，新增多個 AI 服務商，並改進知識庫功能。

## 🌟 重要更新

- 🔌 MCP 雲端點：支援市場雲端點 MCP 整合，擴充功能工具生態
- 🤖 新增服務商：支援 ZenMux、Nano Banana Pro、七牛雲等多個 AI 服務商
- 📚 知識庫增強：支援建立頁面、優化檔案管理，改進 RAG 搜尋體驗
- 🎨 圖像生成：新增多個圖像模型支援，優化圖像生成設定
- 🔐 認證優化：改進 OIDC 認證流程，優化桌面端登入體驗
- 💬 對話優化：支援話題超連結、改進訊息編輯與刪除功能

## 💫 體驗優化

優化話題列表交互、改進工具調用顯示、完善富文字編輯、優化 Token 使用統計動畫、改進模型選擇器排序
