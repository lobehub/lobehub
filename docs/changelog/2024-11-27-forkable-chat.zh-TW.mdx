# 重磅推出分支對話功能 🎉

我們很高興地宣佈，LobeHub 推出了全新的分支對話功能，讓您的對話體驗更加流暢自然：

## 核心特性

- **訊息分支**: 支援在任意訊息處建立新的對話分支
- **雙模式切換**:
  - 延續模式 (Continuation): 保持原有上下文繼續探討
  - 獨立模式 (Standalone): 基於選定訊息開啟全新話題

## 使用方式

1. 在任意訊息右側點擊「建立分支」按鈕
2. 開始新的對話分支
