# Heterogeneous Agent — Claude Code & Codex on Desktop

This release graduates Heterogeneous Agent out of the lab and brings sharper desktop ergonomics around it.

Claude Code and Codex now run as first-class desktop runtimes, with native terminal output, tool inspectors, and the same task surface as the LobeHub-native runtime. A new Agent Signal runtime backs context and memory in long sessions, and self-iteration lets agents revise their plan after observing tool output.

Desktop reach also gets tighter. A screen-capture overlay (with macOS permission gating), Quick Chat tray, and floating chat panel let you summon the agent without leaving the current app, and the workspace branch chip supports one-click git pull and push.

Conversations and tasks pick up several quality-of-life wins: each topic remembers its own scroll position, the user message stays pinned to the viewport top with long messages folded, the last user message can be edited and resent inline, and follow-up sends queue cleanly during a concurrent turn. Tasks gain subtask avatars, a redesigned brief actions row, and a topic-completion filter on the list view.

On models, this release adds GPT-5.5, DeepSeek V4 Flash and Pro with a reasoning-effort slider, LobeHub-hosted gpt-image-2, Kimi K2.6, MiMo-V2.5 and Pro, plus two new providers — OpenCode Zen and OpenCode Go.

## Improvements and fixes

- Disabled markdown streaming on the first assistant block to avoid mid-stream layout shifts.
- Conversation no longer repins to the bottom after a manual scroll.
- Tool inspectors render correctly for Codex and heterogeneous-agent follow-ups.
- FileEditor migrated from antd Modal to base-ui Modal for consistent focus and keyboard behavior.
- QStash heartbeat self-reschedules to keep long-running tasks alive.
