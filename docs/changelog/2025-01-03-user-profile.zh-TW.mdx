# 使用者資料統計與活躍度分享 💯

想要了解自己在 LobeHub 上的活躍度表現嗎？

現在，您可以通過資料統計功能，全方位瞭解自己的 AI 資料，還可以生成個人活躍度分享圖片，與好友分享您在 LobeHub 上的活躍度。

## 📊 資料統計

- **資料統計**: 助手數 / 話題數 / 訊息數 / 累計字數
- **排行版**:
  - 模型使用率 `Top 10`
  - 助手使用率 `Top 10`
  - 話題內容量 `Top 10`
- **熱力圖**: 過去一年內的活躍度分佈
- **使用者活躍度分享**: 生成個人活躍度分享圖片

## 👉 使用方式

1. 需要使用 `PgLite` 或 `資料庫` 模式
2. 點擊個人頭像進入「帳號管理」-「資料統計」頁面
