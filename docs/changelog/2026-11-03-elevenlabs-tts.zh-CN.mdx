# 支持 ElevenLabs 语音合成

现在可以在 **应用设置 → AI 服务商** 中找到 ElevenLabs。在这里填写 ElevenLabs API Key，或在自托管服务端设置 `ELEVENLABS_API_KEY`，即可通过 LobeHub CLI（`lh generate tts`）或兼容 OpenAI 的 `/api/v1/audio/speech` 接口，用 ElevenLabs 模型生成语音。

## 新功能

- **使用 ElevenLabs 模型生成语音。** 默认启用 Eleven v4、Eleven Multilingual v2 和 Eleven Flash v2.5；Eleven v3、Eleven Flash v2 和 Eleven Turbo v2.5 可在模型列表中手动开启。按字符计费，用量与其他语音服务商一样被记录。
- **选择音色、格式与语速。** 内置一组长期可用的 ElevenLabs 音色，也可以使用你自己音色库中的任意音色 ID；音频以 MP3 或 Opus 返回。Multilingual v2 以及 Flash、Turbo 系列支持 0.7 至 1.2 的语速。
- **使用区域端点。** API 代理地址可填写 ElevenLabs 的数据驻留地址。

## 体验优化

- **缺少语音密钥时提示更明确。** 未配置 API Key 或密钥被服务商拒绝时，语音请求会返回 LobeHub 通用的 “API Key 不正确或为空” 提示，并附上服务商给出的原因，而不再是笼统的失败信息。

设置步骤见 [在 LobeHub 中使用 ElevenLabs](/zh/docs/usage/providers/elevenlabs)。
