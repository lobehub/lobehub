# 异构 Agent —— Claude Code 与 Codex 进入桌面端

这次更新让异构 Agent 正式毕业出 Lab，并围绕桌面端做了一轮体感优化。

Claude Code 与 Codex 现在是桌面端的一等运行时，原生终端输出、工具检查器、任务视图与 LobeHub 原生运行时一致。底层新增的 Agent Signal 运行时统一处理长会话中的上下文与记忆，自迭代能力让 Agent 能在观察工具结果后修订自己的计划。

桌面触达也更紧凑。新增的屏幕截图覆盖层（带 macOS 权限引导）、快捷聊天托盘和悬浮聊天面板，让你无需离开当前应用就能呼出 Agent；工作区中的分支芯片也支持一键拉取或推送。

对话与任务带来一组体感明显的优化：话题级别记忆滚动位置；用户消息固定在视口顶部、过长内容自动折叠；最后一条用户消息可直接编辑并重发；并发对话期间的后续发送会顺序排队。任务侧新增子任务头像、改版的简报操作行，以及任务列表的完成态筛选。

模型方面，本次新增 GPT-5.5、DeepSeek V4 Flash / Pro（带思考强度滑块）、LobeHub 托管的 gpt-image-2、Kimi K2.6、MiMo-V2.5 与 Pro，以及两个新接入的提供商：OpenCode Zen 与 OpenCode Go。

## 体验优化与修复

- 第一条助手消息不再启用 Markdown 流式渲染，避免渲染过程中的布局抖动。
- 手动滚动后不再重新自动钉住对话底部。
- 修复了 Codex 与异构 Agent 后续轮次中工具检查器渲染异常的问题。
- FileEditor 从 antd Modal 迁移到 base-ui Modal，焦点与键盘行为更一致。
- QStash 心跳支持自我重调度，长任务运行更稳定。
