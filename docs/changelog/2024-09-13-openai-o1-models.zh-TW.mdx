# OpenAI O1 系列模型現已登陸 LobeHub

我們很高興地宣佈，LobeHub v1.17.0 已完整支援 OpenAI 最新推出的 O1 系列模型。無論是社群版還是 [Cloud 版本](https://LobeHub.com)使用者，都可以體驗到這一重大更新。

## 新增模型支援

- ✨ OpenAI o1-preview
- ✨ OpenAI o1-mini

## 增強的能力

O1 系列模型在以下方面表現出色：

- 💻 程式碼編寫與理解
- 🔢 數學問題處理
- 🎯 更精準的任務執行
- ⚡️ 優化的性能表現

## 立即體驗

- 🌐 [Cloud 版本](https://LobeHub.com) 訂閱使用者現已可以直接使用
- 🔧 自部署使用者可通過更新至 v1.17.0 開始體驗

這次更新讓 LobeHub 在支援最新 AI 模型方面又邁出了重要一步。我們期待 O1 系列模型能夠幫助使用者實現更多可能！
