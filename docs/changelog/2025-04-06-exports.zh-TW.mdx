# 完美整合 DeepSeek R1 ，開啟思維鏈新體驗

LobeHub 在三月持續優化使用者體驗，新增快捷鍵自訂、資料導出等實用功能，並擴充功能 AI 服務商生態。

## 🌟 重要更新

- ⚡ 快捷鍵自訂：支援自訂鍵盤快捷鍵，打造個性化操作體驗
- 💾 資料導出功能：支援 PGlite 和 PostgreSQL 資料導出，資料安全更有保障
- 🔮 AI 服務商擴充功能：新增 Xinference、Cohere、Search1API、Infini-AI、PPIO 等服務商
- 🧠 推理模型優化：支援推理內容選擇器，優化 Claude 3.7、DeepSeek R1 等模型的思維鏈展示
- 🌐 網頁爬取增強：特別支援 YouTube、Reddit、微信公眾號連結，優化短內容爬取，新增 Search1API 爬蟲實現

## 📊 模型庫更新

新增了多個主流 AI 模型，包括 Google 的 Gemini 2.5 Pro Experimental 和 Gemini 2.0 Flash 系列變體，Anthropic 支援上下文快取功能，OpenAI 的 gpt-4o-mini-tts 語音模型， DeepSeek-V3-0324 和 Hunyuan-T1-Latest，以及 QwQ、QVQ-Max、文心 ernie-x1-32k-preview 等模型。

## 💫 體驗優化

- 界面改進：重構 Drawer 樣式，優化編輯滾動體驗，支援截圖分享到剪貼簿
- 搜尋增強：支援非函數調用模型（如 DeepSeek R1）使用線上搜尋，Wenxin、Hunyuan 支援搭載網路搜尋
- 檔案處理：新增 EPUB 檔案分塊支援，優化 PDF 處理
- 性能提升：重構 Agent Runtime 實現，優化資料庫核心程式碼，修復 LiteLLM 流式使用統計
- 穩定性修復：解決主題閃爍、知識庫、微信登入等多個問題
