# 浏览器配对与实时运行状态

配对设备不再需要桌面端——现在用一次配对码交换，就能把浏览器标签页注册成一台设备，把任意会话指向它，并在聊天里直接浏览它上面的文件与 Git。运行进行时，聊天输入框上方会出现一个状态栏，实时显示耗时、Token 与花费。同时还有一批新模型上线，领衔的是 Claude Fable 5。

## 在浏览器里配对设备

连接设备不再依赖桌面端。设备页面新增了 **通过浏览器** 的方式：生成配对码、完成交换，当前浏览器标签页就成了一台助理可以运行的设备。空状态与设备列表也一并做了梳理。

设备连上后，你无需离开聊天就能查看它上面的内容。经批准的本地文件会以只读预览标签打开——其中 HTML 现在可以内嵌渲染——即便文件在当前空间范围之外也行。助理可以列出设备上的 Git worktree，分支切换器新增了重命名与删除操作，设备上的项目技能也会直接显示在侧边栏里。

## 实时看到每一次运行

助理工作时，聊天输入框正上方会出现一个状态栏：逐秒跳动的耗时，加上本次操作开始以来累计的 Token 数与花费——再长、再多步的运行也不再是黑盒。Token 用量现在还会显示提示词缓存命中率，更容易看出缓存何时帮你省了钱。

## 新模型与更清晰的模型选择

Claude **Fable 5** 加入 Anthropic 系列；同时新增 **蚂蚁百灵（AntGroup）**、**商汤 SenseNova**（6.7 Flash Lite 与 U1 Fast），以及更新后、可在线拉取模型列表的 **Longcat** 模型。模型卡片现在会标注各模型的**知识截止时间**，模型标签栏也常驻显示，切换少点一下。

## 体验优化与修复

- 可一次性把多个会话转移到另一个助理，话题侧边栏新增状态标识，话题选择器也能直达更多操作。
- 全新的话题分享体验，带来新的分享页与一键分享的快捷气泡。
- 可在接入流程中添加自定义的 OAuth MCP 连接器，也能在连接器详情里编辑或卸载。
- Markdown 里的 GitHub、Linear 与外部链接现在会以链接卡片的形式呈现。
- 文稿编辑器把自动保存历史按 10 分钟合并为一个版本；文稿、助理、群组与任务在他人编辑时会自动加锁。
- 可直接在工作侧边栏里管理技能——查看、重命名与删除。
- 桌面端：可从标签栏「+」打开新的首页标签、拖拽重排标签、双击托盘图标打开主窗口；云端桌面版构建也恢复了。
- 新注册用户现在会直接进入引导流程。
- Codex 等外部 CLI 助理的运行更稳定，DeepSeek 结构化输出更好，模型列表加载失败时的报错也更清晰。
