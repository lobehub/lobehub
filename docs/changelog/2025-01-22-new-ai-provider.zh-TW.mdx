# 全新 AI Provider 管理系統 🎉

我們很高興地宣佈，LobeHub 推出了全新的 AI Provider 管理系統，已經在開源版與 Cloud 版（[LobeHub.com](https://LobeHub.com)）中可用：

## 🚀 主要更新

- 🔮 **自訂 AI 服務商**: 現在，您可以根據需要新增、刪除或編輯 AI 服務商。
- ⚡️ **自訂模型與能力設定**: 輕鬆新增您自己的模型，滿足個性化需求。
- 🌈 **多模態支援**: 新的 AI Provider 管理系統全面支援多種模態，包括語言、圖像、語音等，影片和音樂生成功能，敬請期待！
