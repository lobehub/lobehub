# 重磅更新：LobeHub 迎來 Artifacts 時代

我們很高興地宣佈 LobeHub v1.19 版本正式發佈！這次更新帶來了多項重要功能，讓 AI 助手的交互體驗更上一層樓。

## 🎨 Artifacts 支援：解鎖全新創作維度

在這個版本中，我們幾乎完整還原了 Claude Artifacts 的核心特性。現在，您可以在 LobeHub 中體驗到：

- SVG 圖形生成與展示
- HTML 頁面生成與即時渲染
- 更多格式的文件生成

值得一提的是，Python 程式碼執行功能也已完成開發，將在後續版本中與大家見面。屆時，使用者將能夠同時運用 Claude Artifacts 和 OpenAI Code Interpreter 這兩大強大工具，極大提升 AI 助手的實用性。

![Artifacts 功能展示](/blog/assets/8d6c17a6ea5e784edf4449fb18ca3f76.webp)

## 🔍 全新發現頁面：探索更多可能

發現頁面迎來了重大升級，現在包含更豐富的內容類別：

- AI 助手市場
- 插件展示
- 模型列表
- 服務商介紹

這次改版不僅提升了頁面的資訊密度，更為使用者開啟了探索 AI 能力的新視窗。未來，我們計劃進一步擴充功能發現頁面的功能，可能會加入：

- 知識庫分享
- Artifacts 展示
- 精選對話分享

## 🚀 GitHub Models 支援：更多模型選擇

感謝社群成員 [@CloudPassenger](https://github.com/CloudPassenger) 的貢獻，現在 LobeHub 已經支援 GitHub Models 服務商。使用者只需：

1. 準備 GitHub Personal Access Token (PAT)
2. 在設定中設定服務商資訊
3. 即可開始使用 GitHub Models 上的免費模型

這一功能的加入大大擴充功能了使用者可選用的模型範圍，為不同場景下的 AI 對話提供了更多選擇。

## 🔜 未來展望

我們將持續致力於提升 LobeHub 的功能和使用者體驗。接下來的版本中，我們計劃：

- 完善 Python 程式碼執行功能
- 增加更多 Artifacts 類型支援
- 擴充功能發現頁面的內容維度

感謝每一位使用者的支援與回饋，讓我們一起期待 LobeHub 帶來更多驚喜！
