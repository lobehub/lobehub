# 助手常駐側邊欄：打造更便捷的對話體驗

我們在 v1.26.0 版本中推出了一項期待已久的新功能 —— 助手常駐側邊欄。這項功能旨在提升使用者對高頻助手的存取體驗，讓您的得力助手觸手可及。

## 功能亮點

- **快捷切換**：支援通過快捷鍵快速切換不同助手，讓工作流更加流暢
- **空間優化**：啟動側邊欄時會自動隱藏會話列表，為您騰出更大的對話空間
- **智慧顯示**：將置頂助手自動同步到側邊欄，讓重要助手始終在視線範圍內

## 如何使用

目前這項功能處於實驗階段，預設未開啟。如需體驗，您可以通過新增環境變數 `FEATURE_FLAGS=+pin_list` 來啟用。

我們已在 Cloud 版本中同步開啟此功能，歡迎所有使用者體驗並提供回饋。您可以在 [GitHub Discussions](https://github.com/lobehub/lobe-chat/discussions/4515) 中分享使用感受，幫助我們將這個功能打磨得更加完善。

## 設計理念

這次更新的核心目標是優化工作效率。通過合理利用側邊欄空間，我們讓高頻使用的助手觸手可及，同時通過隱藏會話列表來擴大對話區域，為使用者帶來更專注的對話體驗。

我們期待這項新功能能夠顯著提升您的使用體驗。歡迎升級到 v1.26.0 版本開始體驗！
