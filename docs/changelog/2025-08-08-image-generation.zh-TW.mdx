# AI 圖像生成與桌面端增強 🎨

LobeHub 在七月至八月推出 AI 圖像生成功能，新增多個服務商支援，並持續優化桌面端體驗與認證系統。

## 🌟 重大更新

- 🎨 AI 圖像生成：支援通過 Google Imagen、Qwen、Zhipu CogView4、MiniMax 等服務商生成圖像
- 🔐 認證系統擴充功能：新增 Amazon Cognito、Google SSO、Okta 認證支援
- 🖥️ 桌面端優化：支援網路代理設定、自訂快捷鍵、OAuth 重構與遠端聊天支援
- 🔌 MCP 認證增強：支援 Streamable HTTP MCP Server 認證
- 🔑 API Key 管理：實現完整的 API Key 管理功能

## 📊 模型庫更新

新增 Claude Opus 4.1、Grok-4、Kimi K2、Ollama gpt-oss 支援，更新 Gemini 2.5 Flash-Lite GA、Hunyuan A13B thinking、Doubao 思維模型等

## 💫 體驗優化

桌面端新增通知功能、優化設定視窗布局、改進多顯示器體驗；優化 MCP 插件調用與顯示、修復 Gemini Artifacts 換行問題
