# 知識庫功能重磅發佈：智慧檔案管理與對話的革新

我們很高興地宣佈，備受期待的 LobeHub 知識庫功能現已正式發佈！🎉 該功能已同步在開源版和 Cloud 版（LobeHub.com）中上線。

## 全新的檔案管理體驗

- 📁 **專屬檔案入口**：在左側邊欄新增「檔案」一級選單，提供便捷的檔案存取與管理
- 📄 **全類型檔案支援**：支援文件、圖片、音訊、影片等各類檔案的上傳和儲存
- 👀 **強大的預覽功能**：搭載支援 PDF、Excel、Word、PPT 和 TXT 等多種格式的線上預覽
- 🔄 **可擴充功能的預覽架構**：基於開源方案打造的預覽組件，支援未來擴充功能更多檔案類型

## 智慧知識庫管理

- 📚 **無限知識庫**：支援建立無限數量的知識庫，滿足不同場景需求
- 🔍 **智慧向量化**：自動進行檔案分塊和向量化處理，支援片段預覽功能
- 💡 **交互創新**：整合 Portal 交互範式，實現檔案內容的快速預覽和檢索
- 🔮 **未來可期**：架構預留擴充功能空間，計劃支援音訊、圖片、影片等多媒體檔案的智慧處理

## 便捷的使用體驗

- 💪 **開箱即用**：支援在對話框直接上傳檔案，操作簡單直觀
- 🎯 **即時回饋**：優化的上傳體驗，提供清晰的進度回饋
- ☁️ **雙版本可選**：提供開源自部署版本和官方 Cloud 版本，滿足不同使用者需求

所有功能均已在 [GitHub 來源](https://github.com/lobehub/lobe-chat) 開源，歡迎存取 [LobeHub Cloud](http://LobeHub.com) 體驗完整功能。
