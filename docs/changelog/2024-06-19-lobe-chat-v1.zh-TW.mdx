# LobeHub 1.0：新的架構與新的可能

自從 3 月份宣佈邁向 1.0 ，我們就開始著手全方面的升級。經過 2 個月的密集研發，我們很高興地宣佈 LobeHub 1.0 正式發佈了！一起來看看我們的全新樣貌吧～

## 伺服端資料庫支援

在 LobeHub 1.0 中，最大的特性是支援了伺服端資料庫。在 0.x 時代，由於缺乏伺服端持久化儲存，許多使用者迫切需要的功能實現困難，或完全無法實現，例如知識庫、跨端同步、私有助手市場等等。

## 使用者認證管理

在 0.x 時代，和伺服端資料庫搭配的呼聲最高的特性就是使用者認證管理。在此之前，我們已經接入了 next-auth 和 clerk 作為認證解決方案。並針對多使用者管理的訴求，將設定界面重構為了使用者面板，在新的使用者面板中整合了相關的使用者資訊。

## LobeHub Cloud 開啟 Beta 測試

LobeHub Cloud 是我們基於 LobeHub 開源版的商業化版本，上述 1.0 的功能在 LobeHub Cloud 中均已上線，目前已開啟 Beta 測試。如果你感興趣，可以在這裡加入我們的 waitlist ， Beta 測試期間每天都會發放體驗名額。
