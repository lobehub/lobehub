# LobeHub Database Docker 鏡像：雲端部署的最後一塊拼圖

我們很高興地宣佈，LobeHub v1.8.0 正式發佈了期待已久的資料庫 Docker 鏡像！這是我們在伺服端資料庫領域的重要里程碑，為使用者提供了完整的雲端部署解決方案。

## 🚀 核心特性

- **輕量級部署**：Docker 鏡像僅 90MB，卻提供完整的資料庫功能
- **優化性能**：預置 Server Postgres 與 NextAuth 認證體系，確保最佳連通性能
- **雲端同步**：部署後即可享受流暢的雲端資料同步體驗
- **靈活認證**：支援與 Auth0 等第三方 SSO 服務提供商整合

## 📘 部署文件全新升級

為確保使用者能夠順利完成部署，我們優化了部署文件的結構：

- 清晰的框架思路介紹
- 詳細的部署案例指引
- 完整的自部署操作指南

現在，您可以通過存取 [官方文件](https://lobehub.com/zh/docs/self-hosting/server-database) 開始部署您自己的 LobeHub 服務。

## 🔮 未來展望

我們的知識庫功能也正在開發中，敬請期待更多激動人心的更新！

這次更新標誌著 LobeHub 在雲端部署方案上的重要突破，讓私有部署變得前所未有的簡單。感謝社群的耐心等待，我們將繼續努力為使用者帶來更好的體驗。
