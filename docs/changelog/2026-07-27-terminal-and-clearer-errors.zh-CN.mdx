# 更顺手的终端与更清晰的错误反馈

## 新功能

- **使用 Gemini 3.6 Flash。** Gemini 3.6 Flash 现已在 LobeHub 中提供四档思考强度，并支持多模态输入、网页搜索与工具调用。
- **更轻松地管理多个终端会话。** 桌面终端现在提供更清晰的标签页，可以通过右键菜单关闭当前会话或其他会话；面板开合更流畅，当前终端的渲染也更快。

## 体验优化

- **快速看懂远程设备状态。** 设备工具卡片现在会展示易读的名称、平台、访问范围和连接状态，并提供更明确的空状态、成功提示与错误提示。
- **更清爽地审查交付检查。** 验收列表和证据卡片简化了筛选项与标签，并使用更紧凑的 Markdown 预览。
- **已有订阅时获得明确指引。** 如果系统因已有订阅而将你跳转回应用，账单页面现在会说明原因，不再停留在没有解释的页面。

## 问题修复

- **iPhone 上的对话输入框不再意外放大。** 聚焦输入框时，移动端布局会保持稳定，同时保留正常的双指缩放能力。
- **供应商设置不再混入上一个供应商的内容。** 切换供应商时，表单会先重置，再载入所选供应商的配置。
- **MiniMax 可以正常接收使用自动清晰度的图片。** 发送前会移除其不支持的图片清晰度信息，避免不必要的请求失败。
- **搜索失败不再被误认为没有结果。** 网页搜索与社区助理搜索会在可能时切换到其他供应商，并在所有供应商都失败时显示明确错误。
- **Grok 的提示词缓存更稳定。** 登录后的请求会在 xAI 与 SuperGrok 中使用一致的缓存标识。
