# Claude Sonnet 4.5 與搭載 Python 插件 🐍

LobeHub 在九月至十月新增 Claude Sonnet 4.5 模型支援，推出搭載 Python 插件，並優化聊天列表導航與富文字編輯體驗。

## 🌟 主要更新

- 🐍 搭載 Python 插件：支援直接在聊天中執行 Python 程式碼
- 🤖 Claude Sonnet 4.5：接入 Anthropic 最新推理模型
- 🗺️ 聊天列表小地圖：新增快速導航功能，提升長對話瀏覽效率
- 📝 富文字編輯器：支援數學公式、任務列表、並行發送等功能
- 🎨 Qwen 圖像編輯：支援通過 Qwen 模型進行圖像編輯
- 🌐 Vercel AI Gateway：新增 Vercel AI Gateway 服務商支援

## 📊 模型庫更新

新增 Seedream 4.0、CometAPI、NewAPI 等服務商，更新 Gemini 2.5 影片理解能力

## 💫 體驗優化

優化聊天輸入框支援調整大小、改進行動端標題顯示、支援 Base64 圖像語法、優化 .doc 檔案解析
