# Smoother Terminal, Clearer Errors

## New Features

- **Manage multiple terminal sessions more easily.** The desktop terminal now has clearer tabs, right-click actions to close one or all other sessions, smoother open and close transitions, and faster rendering for active terminals.

## Improvements

- **Understand remote devices at a glance.** Device tool cards now show friendly names, platform, access scope, and connection status, with clearer empty, success, and error states.
- **Review delivery checks with less clutter.** Acceptance lists and evidence cards use simpler filters, cleaner labels, and more compact markdown previews.
- **Get a clear next step for an existing subscription.** If billing redirects you because a subscription already exists, the Billing page now explains what happened instead of leaving you at an unexplained screen.

## Bug Fixes

- **Chat input no longer zooms unexpectedly on iPhone.** Focusing the composer keeps the mobile layout stable while preserving normal pinch-to-zoom.
- **Provider settings no longer carry values between providers.** Switching providers resets the form before loading the selected provider's configuration.
- **MiniMax can receive images that use automatic detail.** Unsupported image-detail metadata is removed before sending, preventing avoidable request failures.
- **Search failures are no longer mistaken for empty results.** Web and Community Agent searches can recover through another provider when possible and show a clear error when every provider fails.
- **Grok prompt caching is more consistent.** Signed-in requests now use stable cache keys across xAI and SuperGrok.
