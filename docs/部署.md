# 部署指南

## 步骤一：本地重新打包代码

在本地终端执行：

```bash
cd /Users/l/Documents/lobehub

# 打包成 tar（排除 node_modules 和 .git）
tar --exclude='./node_modules' \
  --exclude='./.git' \
  --exclude='./apps/desktop/node_modules' \
  --exclude='./.next' \
  -czf ~/lobehub-src.tar.gz .

# 可选：生成校验值
sha256sum ~/lobehub-src.tar.gz
```

## 步骤二：传到服务器

```bash
scp ~/lobehub-src.tar.gz root@192.168.1.162:/home/loctek/ai-os2/
```

## 步骤三：服务器上操作

SSH 进服务器后执行：

```bash
cd /home/loctek/ai-os2

# 删除旧的压缩包（可选）
rm -f lobehub-src.tar.gz

# 查看上传包
ls -lah lobehub-src.tar.gz

# 可选：先备份旧源码
[ -d src ] && mv src "src.bak.$(date +%Y%m%d-%H%M%S)"
mkdir -p src

# 解压最新上传包到 src
tar -xzf lobehub-src.tar.gz -C ./src

# 进入源码目录
cd src

# 强制重建镜像（避免缓存导致旧代码）
docker build --no-cache -t my-lobehub:latest .

# 重启服务
cd /home/loctek/ai-os2
docker compose up -d --force-recreate lobe

# 查看日志确认启动成功
docker compose logs --tail=200 lobe
```

## 确保已更新到最新（强烈建议）

在服务器执行以下校验，确认运行中的容器就是最新镜像：

```bash
cd /home/loctek/ai-os2/src

# 校验关键修复点是否已进源码（按需替换关键字）
grep -n "if (!data) return;" src/store/agent/slices/agent/action.ts
grep -n "agentId || params.aid || activeAgentId || ''" src/hooks/useInitAgentConfig.ts

# 查看镜像 ID
docker image inspect my-lobehub:latest --format 'image_id={{.Id}} created={{.Created}}'

# 查看运行中容器镜像 ID
cd /home/loctek/ai-os2
cid=$(docker compose ps -q lobe)
docker inspect "$cid" --format 'container_image_id={{.Image}} started={{.State.StartedAt}}'
```

`image_id` 与 `container_image_id` 一致，表示容器已使用最新构建镜像。

## 仅更新模型 ENV（无需重新打包）

适用于只调整模型配置（API Key、模型列表、代理地址），不涉及代码变更的场景。\
在服务器上执行：

```bash
# 1) 进入部署目录
cd /home/loctek/ai-os2

# 2) 首次部署才需要
[ -f .env ] || cp .env.example .env

# 3) 先备份当前 .env（用于回滚）
cp .env ".env.bak.$(date +%Y%m%d-%H%M%S)"

# 4) 写入/更新模型相关环境变量
cat > /tmp/lobehub-env-update.sh << 'SH'
set -e
ENV_FILE=".env"

upsert_env () {
  key="$1"
  value="$2"
  if grep -q "^${key}=" "$ENV_FILE"; then
    sed -i.bak "s#^${key}=.*#${key}=${value}#g" "$ENV_FILE"
  else
    printf "\n%s=%s\n" "$key" "$value" >> "$ENV_FILE"
  fi
}

# OpenAI
upsert_env OPENAI_PROXY_URL https://api.tu-zi.com
upsert_env OPENAI_API_KEY <YOUR_OPENAI_API_KEY>
upsert_env OPENAI_MODEL_LIST -all,+gpt-5.4,+gpt-5.4-mini
upsert_env ENABLED_OPENAI 1

# Gemini
upsert_env GOOGLE_PROXY_URL https://api.tu-zi.com
upsert_env GOOGLE_API_KEY <YOUR_GOOGLE_API_KEY>
upsert_env ENABLED_GOOGLE 1

# Kimi / Moonshot
upsert_env MOONSHOT_PROXY_URL https://api.moonshot.cn/v1
upsert_env MOONSHOT_API_KEY <YOUR_MOONSHOT_API_KEY>
upsert_env MOONSHOT_MODEL_LIST -all,+kimi-k2.5,+kimi-k2-thinking,+kimi-k2-thinking-turbo
SH

bash /tmp/lobehub-env-update.sh
docker compose --env-file .env up -d
docker compose --env-file .env logs --tail=120 lobe
```

## 回滚 .env（可选）

如果本次 ENV 修改后异常，可回滚到最近一次备份：

```bash
cd /home/loctek/ai-os2
latest_backup="$(ls -t .env.bak.* | head -n 1)"
cp "$latest_backup" .env
docker compose --env-file .env up -d
docker compose --env-file .env logs --tail=120 lobe
```

## 后续迭代

每次本地改完代码，重复步骤一到三即可。构建时间约 5-10 分钟。

## 设置管理员账号

```bash
# 将 hexu@loctek.com 设为 admin
docker exec -it lobe-postgres psql -U postgres -d lobechat -c \
  "UPDATE users SET role = 'admin' WHERE email = 'hexu@loctek.com';"

# 确认结果
docker exec -it lobe-postgres psql -U postgres -d lobechat -c \
  "SELECT email, role FROM users WHERE email = 'hexu@loctek.com';"
```

设置后重新登录，进入 `/settings/shared-agents` 管理共享助手。

## 从 hexu 账号复制助手到共享助手

```bash
# 第一步：确认数据（先看看有哪些助手）
docker exec -it lobe-postgres psql -U postgres -d lobechat -c \
  "SELECT title, model, provider FROM agents WHERE user_id = (SELECT id FROM users WHERE email = 'hexu@loctek.com');"

# 第二步：复制到 shared_agents（确认第一步数据正确后执行）
docker exec -it lobe-postgres psql -U postgres -d lobechat -c \
  "INSERT INTO shared_agents (title, description, avatar, system_role, model, provider, enabled, sort) \
   SELECT title, description, avatar, system_role, model, provider, true, 0 \
   FROM agents WHERE user_id = (SELECT id FROM users WHERE email = 'hexu@loctek.com');"

# 第三步：确认插入成功
docker exec -it lobe-postgres psql -U postgres -d lobechat -c \
  "SELECT title, model, enabled FROM shared_agents;"
```
