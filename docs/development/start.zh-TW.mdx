# 技術開發上手指南

歡迎來到 LobeHub 技術開發上手指南。LobeHub 是一款基於 Next.js 框架構建的 AI 會話應用程式，它彙集了一系列的技術棧，以實現多樣化的功能和特性。本指南將詳細介紹 LobeHub 的主要技術組成，以及如何在你的開發環境中設定和使用這些技術。

## 基礎技術棧

LobeHub 的核心技術棧如下：

- **框架**：[Next.js](https://nextjs.org/) 16 + [React](https://react.dev/) 19，為項目提供伺服端渲染、Router Handler 等關鍵功能。
- **組件庫**：[Ant Design (antd)](https://ant.design/) 作為基礎組件庫，[@lobehub/ui](https://github.com/lobehub/lobe-ui) 作為業務組件庫。
- **狀態管理**：[zustand](https://github.com/pmndrs/zustand)，一款輕量級且易於使用的狀態管理庫。
- **資料獲取**：[SWR](https://swr.vercel.app/) 用於客戶端資料獲取。
- **路由**：採用混合路由架構 —— [Next.js App Router](https://nextjs.org/) 處理靜態頁面（如認證頁），[React Router DOM](https://reactrouter.com/) 承載主應用程式 SPA。
- **API**：[tRPC](https://trpc.io/) 實現端到端類型安全的 API 通訊。
- **資料庫**：[Drizzle ORM](https://orm.drizzle.team/) + PostgreSQL。
- **國際化**：[react-i18next](https://react.i18next.com/) 實現多語言支援。
- **樣式**：[antd-style](https://github.com/ant-design/antd-style)，與 Ant Design 配套的 CSS-in-JS 庫。
- **單元測試**：[Vitest](https://github.com/vitest-dev/vitest) 進行單元測試。

## 資料夾目錄架構

LobeHub 採用 Monorepo 架構（`@lobechat/` 命名空間），頂層目錄結構如下：

```bash
lobe-chat/
├── apps/desktop/          # Electron 桌面應用程式
├── packages/              # 共享包（@lobechat/*）
│   ├── database/          # 資料庫 schemas、models、repositories
│   ├── agent-runtime/     # Agent 執行時
│   ├── model-runtime/     # 模型執行時
│   └── ...                # 更多共享包
├── src/                   # 主應用程式源碼
│   ├── app/               # Next.js App Router，包含路由組和 API 路由
│   ├── components/        # 可複用的 UI 組件
│   ├── config/            # 應用程式組態檔，包含客戶端與伺服端環境變數
│   ├── const/             # 應用程式常數和枚舉
│   ├── envs/              # 環境變數定義和校驗（分析、認證、LLM 等）
│   ├── features/          # 業務功能模組，如 Agent 設定、插件開發彈窗等
│   ├── helpers/           # 工具輔助函數
│   ├── hooks/             # 全應用程式複用的自訂 Hooks
│   ├── layout/            # 佈局組件（AuthProvider、GlobalProvider 等）
│   ├── libs/              # 第三方整合（better-auth、OIDC、tRPC 等）
│   ├── locales/           # 國際化的語言檔案
│   ├── server/            # 伺服端模組、路由和服務
│   ├── services/          # 客戶端服務接口
│   ├── store/             # zustand 狀態管理
│   ├── styles/            # 全域樣式和 CSS-in-JS 設定
│   ├── tools/             # 搭載工具（artifacts、inspectors、interventions 等）
│   ├── types/             # TypeScript 類型定義
│   └── utils/             # 通用工具函數
├── locales/               # 國際化翻譯檔案（zh-TW、en-US 等）
└── e2e/                   # E2E 測試（Cucumber + Playwright）
```

有關目錄架構的詳細介紹，詳見： [資料夾目錄架構](/zh/docs/development/basic/folder-structure)

## 程式碼風格與貢獻指南

在 LobeHub 項目中，我們十分重視程式碼的品質和一致性。為此，我們制定了一系列的程式碼風格規範和貢獻流程，以確保每位開發者都能順利地參與到項目中。以下是你作為開發者需要遵守的程式碼風格和貢獻準則。

- **程式碼風格**：我們使用 `@lobehub/lint` 統一程式碼風格，包括 ESLint、Prettier、remarklint 和 stylelint 設定。請遵守我們的程式碼規範，以保持程式碼的一致性和可讀性。
- **貢獻流程**：我們採用 gitmoji 和 semantic release 作為程式碼提交和發佈流程。請使用 gitmoji 標註您的提交資訊，並確保遵循 semantic release 的規範，以便我們的自動化系統能夠正確處理版本控制和發佈。

所有的貢獻都將經過程式碼審查。維護者可能會提出修改建議或要求。請積極回應審查意見，並及時做出調整，我們期待你的參與和貢獻。

詳細的程式碼風格和貢獻指南，請參考 [程式碼風格與貢獻指南](/zh/docs/development/basic/contributing-guidelines)。

## 國際化實現指南

LobeHub 採用 `react-i18next` 實現多語言支援，確保使用者全球化體驗。

預設語言檔案位於 `src/locales/default/`（英文），
翻譯檔案位於 `locales/` 目錄。
開發時只需編輯 `src/locales/default/` 中的 key，
CI 會自動生成其他語言的翻譯檔案。

如果要新增新語種，需遵循特定步驟，詳見 [新語種新增指南](/zh/docs/development/internationalization/add-new-locale)。 我們鼓勵你參與我們的國際化努力，共同為全球使用者提供更好的服務。

詳細的國際化實現指南，請參考 [國際化實現指南](/zh/docs/development/internationalization/internationalization-implementation)。
