# Office document acceptance fixture specification

This specification defines deterministic, redistributable fixtures for T-324. The files should contain only synthetic data and locally generated assets. Builders must be checked into the eventual implementation test package so every fixture can be regenerated byte-for-byte where the format permits, or semantically equivalently where producer metadata varies.

## Shared conventions

- Base name: `office-roundtrip-v1`.
- Canonical files: `office-roundtrip-v1.pptx`, `office-roundtrip-v1.xlsx`, `office-roundtrip-v1.docx`.
- Stress files: `office-stress-v1.pptx`, `office-stress-v1.xlsx`, `office-stress-v1.docx`.
- Sentinel prefix: `LH-OFFICE-V1`. Every major structure contains a unique sentinel.
- Use only bundled/system-safe fonts: Arial, Times New Roman, and Courier New. Missing-font substitution is still recorded.
- The same 640×360 synthetic PNG is embedded in PPTX and DOCX. It contains the text `LH-OFFICE-V1-IMAGE`, a red square in the upper left, a blue circle in the lower right, and a 20 px transparent border. This makes crop, aspect ratio, alpha, and color loss visible.
- Every builder emits `fixture-manifest.json` with SHA-256, byte size, producer, timestamp, and semantic expectations. Binary hashes are informative; semantic assertions are authoritative after round trip.

## PPTX fixture

Document properties: 16:9 widescreen; theme colors navy `#17324D`, teal `#1C8C8C`, amber `#F2A93B`; 4 slides; title `LH-OFFICE-V1-PPTX`.

1. Slide 1 (`LH-OFFICE-V1-PPT-S1`): title and subtitle using theme fonts; one footer and slide number.
2. Slide 2 (`LH-OFFICE-V1-PPT-S2`): two text boxes, the synthetic PNG cropped to 16:9, one rounded rectangle, one line, and explicit z-order with the line behind the rectangle.
3. Slide 3 (`LH-OFFICE-V1-PPT-S3`): clustered column chart with categories `North`, `South`, `West` and values `12`, `19`, `15`; chart title `Quarterly units`; one data-label series.
4. Slide 4 (`LH-OFFICE-V1-PPT-S4`): title plus a 2×3 native table containing `Owner`, `Status`, `Due`, `Ari`, `Ready`, `2026-09-30`; intentionally uses a different layout from slide 2.

Required edit script:

- Change slide 1 subtitle to `Round-trip edited`.
- Replace `South` chart value `19` with `23`.
- Move the rounded rectangle +0.5 in on X and resize it +0.25 in wide.
- Replace the slide 2 image while preserving its frame and crop mode.
- Duplicate slide 2, move the copy after slide 4, then delete the original slide 2. Final order sentinels: S1, S3, S4, S2-COPY; final count: 4.
- Undo delete and redo delete once before save.

Assertions: all four final sentinels present exactly once; slide count/order exact; chart values `[12,23,15]`; theme colors unchanged; table cell values unchanged; image aspect ratio within 1%; no object outside slide bounds; no repair prompt on open.

Stress variant: 80 slides alternating image/text/chart layouts, 20 images reused by content but embedded independently, 20 charts, and 2,000 total text runs. It is for responsiveness and save cancellation, not pixel-perfect review of every slide.

## XLSX fixture

Workbook properties: title `LH-OFFICE-V1-XLSX`; sheets initially ordered `Inputs`, `Sales Data`, `Summary`.

`Inputs`:

- `A1:B5`: title plus typed assumptions. `B2=0.08` formatted `0.0%`; `B3=DATE(2026,9,1)` formatted `yyyy-mm-dd`; `B4=1250.5` formatted `"$"#,##0.00`; `B5="LH-OFFICE-V1-XLS-INPUT"`.

`Sales Data`:

- Headers in `A1:F1`: `Date`, `Region`, `Product`, `Units`, `Unit Price`, `Revenue`.
- Six rows, including a zero-unit row and a product ID with leading zero stored as text (`0017`):

| Row | Date       | Region | Product | Units | Unit Price | Revenue |
| --- | ---------- | ------ | ------- | ----: | ---------: | ------: |
| 2   | 2026-09-01 | North  | `0017`  |     5 |        100 |     500 |
| 3   | 2026-09-02 | South  | A02     |     4 |        125 |     500 |
| 4   | 2026-09-03 | West   | B03     |     3 |        150 |     450 |
| 5   | 2026-09-04 | North  | C04     |     2 |        200 |     400 |
| 6   | 2026-09-05 | South  | D05     |     0 |         90 |       0 |
| 7   | 2026-09-06 | West   | E06     |     1 |        100 |     100 |

- `F2:F7` formulas are `=Drow*Erow`; expected sum `F8=1950.00` with formula `=SUM(F2:F7)`.
- Autofilter on headers, frozen top row, alternating fill, currency format on E:F, date format on A, and one conditional-format rule highlighting revenue above 400.

`Summary`:

- `B2=SUM('Sales Data'!F2:F7)` expected `1950.00`.
- `B3=AVERAGE('Sales Data'!D2:D7)` expected `2.5`.
- `B4=IF(B2>1000,"On track","At risk")` expected `On track`.
- `B5=XLOOKUP("West",'Sales Data'!B2:B7,'Sales Data'!F2:F7,"Missing")` expected `450.00`.
- Column chart sourced from a small region summary table and titled `Revenue by region`.
- Sentinel `LH-OFFICE-V1-XLS-SUMMARY`.

Required edit script:

- Move the total row to row 10. Paste `2026-09-07/East/F07/2/75` and `2026-09-08/North/G08/1/50` into `Sales Data!A8:E9`, then fill formulas into `F8:F9`; expected new total is `2150.00`.
- Insert one column after `Product`, name it `Channel`, and fill `Online`/`Retail` values.
- Rename `Sales Data` to `Transactions`; verify formulas update references.
- Add sheet `Notes`, move it before `Summary`, then delete it; final order `Inputs`, `Transactions`, `Summary`.
- Change `Inputs!B2` from 8% to 10%; verify dependent status remains valid.
- Undo and redo the sheet rename once before save.

Assertions: typed dates/numbers remain typed; formulas and cached results both present; formulas contain correct quoted cross-sheet references; no formula-error tokens; exact sheet order; exact totals; formats/merges/freeze/filter/conditional formatting/chart survive; leading-zero ID remains text; no repair prompt.

CSV export assertion: exporting `Transactions` produces exactly one RFC 4180-compatible table with nine data rows and no formulas/styles; exporting the workbook to CSV without choosing a sheet must show a loss warning.

Stress variant: 5 sheets × 20,000 rows × 20 columns, 25% formula cells, frozen panes, filters, and 3 charts. The manifest supplies totals for three sampled columns and 30 sampled cell coordinates.

## DOCX fixture

Document properties: A4 portrait; 2.5 cm margins; title `LH-OFFICE-V1-DOCX`; footer contains `LH-OFFICE-V1-DOC-FOOTER` and page number.

Content in order:

1. Title style: `Office round-trip fixture`.
2. Heading 1: `LH-OFFICE-V1-DOC-H1`.
3. Two body paragraphs, one with bold/italic/underlined runs and one containing Chinese text `中文保真检查` and emoji `✅`.
4. Heading 2: `Checklist`; a three-item numbered list followed by a two-item bulleted list.
5. A 3×3 table with header `Item / Owner / Status` and rows `Draft / Ari / Ready`, `Export / Bo / Pending`.
6. The shared synthetic PNG at 12 cm wide with alt text `LH-OFFICE-V1-IMAGE-ALT` and caption `Figure 1 — Synthetic fidelity image`.
7. Hyperlink text `LobeHub source` targeting `https://github.com/lobehub/lobehub`.
8. A manual page break, Heading 1 `Appendix`, and sentinel `LH-OFFICE-V1-DOC-END`.

Required edit script:

- Replace `Pending` with `Ready` in the table.
- Paste a paragraph after the first body paragraph and apply Body Text style.
- Change `Checklist` from Heading 2 to Heading 1, then undo and redo.
- Add a fourth numbered item; verify numbering is `1,2,3,4`.
- Replace the image while retaining width, alt text, caption association, and aspect ratio.
- Change the hyperlink display text to `LobeHub repository` without changing its target.

Assertions: all sentinels exactly once; heading levels `[Title,H1,H1,H1]` after edit; body text and CJK/emoji intact; run emphasis intact; ordered/unordered list semantics intact; table dimensions and values exact; image relationship resolves and alt text remains; hyperlink relationship target exact; footer/page-number field remains; no repair prompt; render has no clipped text/table/image.

Stress variant: 120 pages, 12 heading sections, 20 tables that cross pages, 30 images, 2,000 list items, headers/footers, and mixed CJK/Latin content. It is used for input latency, scrolling, autosave, cancel, and recovery.

## Generation and validation contract

Each future builder must provide these commands (names may be adapted to the owning package):

```bash
bun run office:fixtures:build
bun run office:fixtures:inspect
bun run office:fixtures:render
bun run office:fixtures:compare --before fixtures/original --after artifacts/roundtrip
```

`build` creates the six files and manifest from source. `inspect` performs ZIP/package integrity and semantic assertions. `render` renders every PPTX slide and DOCX page plus all XLSX used ranges. `compare` emits JSON results and image diffs with tolerances. A check is failed, not skipped, when the relevant renderer is missing in CI; local developer runs may report `BLOCKED_ENVIRONMENT` with the missing executable named.

Fixture binaries are intentionally not committed by T-324: the available artifact runtime was not exposed in this execution context, and the presentation/spreadsheet authoring contracts prohibit substituting unrelated libraries. This task supplies complete deterministic recipes; the implementation node that introduces the editor/test package should materialize them with the approved artifact runtime and check in the builders plus generated fixtures.
