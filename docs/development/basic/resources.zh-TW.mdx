# 資源與參考

LobeHub 的設計和開發離不開社群和生態中的優秀項目。我們在設計和開發過程中使用或參考了一些優秀的資源和指南。以下是一些主要的參考資源，供開發者在開發和學習過程中參考：

1. **OpenAI API 指南**：我們使用 OpenAI 的 API 來獲取和處理 AI 的會話資料。你可以查看 [OpenAI API 指南](https://platform.openai.com/docs/api-reference/introduction) 瞭解更多詳情。
2. **OpenAI SDK**：我們使用 OpenAI 的 Node.js SDK 來與 OpenAI 的 API 交互。你可以在 [OpenAI SDK](https://github.com/openai/openai-node) 的 GitHub 來源中查看源碼和文件。
3. **AI SDK**：我們使用 Vercel 的 AI SDK 來獲取和處理 AI 的會話資料。你可以查看 [AI SDK](https://sdk.vercel.ai/docs) 的文件來了解更多詳情。
4. **LangChain**：我們早期的會話功能是基於 LangChain 實現的。你可以存取 [LangChain](https://langchain.com) 來了解更多關於它的資訊。
5. **Chat-Next-Web**：Chat Next Web 是一個優秀的項目，LobeHub 的部分功能、Workflow 等參考了它的實現。你可以在 [Chat-Next-Web](https://github.com/Yidadaa/ChatGPT-Next-Web) 的 GitHub 來源中查看源碼和文件。
6. **Next.js 文件**：我們的項目是基於 Next.js 構建的，你可以查看 [Next.js 文件](https://nextjs.org/docs) 來了解更多關於 Next.js 的資訊。
7. **FlowGPT**：FlowGPT 是目前全球最大的 Prompt 社群，LobeHub 中的一些 Agent 來自 FlowGPT 的活躍作者。你可以存取 [FlowGPT](https://flowgpt.com/) 來了解更多關於它的資訊。
