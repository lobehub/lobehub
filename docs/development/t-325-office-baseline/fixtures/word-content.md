# T-325 办公文档基线报告

本报告用于验证 Word 文档从创建到导出的完整闭环。修改后，本句必须包含标记 T-325-R1。

## 验证范围

覆盖文本编辑、层级样式、字体与对齐、列表、表格、图片、链接、保存、再次打开和导出。

### 编号步骤

1. 创建或导入文档。
2. 编辑内容与格式。
3. 保存、关闭并重新打开。
4. 导出并复核结果。

### 风险清单

- 内容丢失
- 格式漂移
- 图片或表格错位

## 数据表

| 项目 | 预期 | 标记     |
| ---- | ---- | -------- |
| 正文 | 完整 | BODY-OK  |
| 表格 | 3×3  | TABLE-OK |
