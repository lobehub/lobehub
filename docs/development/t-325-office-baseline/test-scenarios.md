# 可复现验收场景与判定记录

## 通用执行规则

每个场景在 LobeHub 和当次可访问的 ChatGPT/Codex 各执行一次。执行前记录产品版本、账号 / 套餐、浏览器或桌面端版本、操作系统、时区和测试文件 SHA-256。每个关键步骤截图；保存前、保存后、重开后、导出后各保留一份文件。不得把 “预览能打开” 记作 “可编辑”，不得把下载原文件记作 “导出编辑结果”。

记录状态只允许：`PASS`、`FAIL`、`BLOCKED`、`NV`。`PASS` 必须同时附：步骤截图 / 录屏索引、输出文件路径与 SHA-256、结构检查输出、视觉对比结果。任一核心步骤失败，整个场景 `FAIL`。

### 统一记录表

| 字段        | 内容                                            |
| ----------- | ----------------------------------------------- |
| 场景 ID     | 例如 PPT-01                                     |
| 产品 / 版本 | LobeHub commit 或 ChatGPT/Codex surface + build |
| 环境        | OS、浏览器 / 桌面端、账号能力                   |
| 输入文件    | 文件名 + SHA-256                                |
| 步骤结果    | 每步 PASS/FAIL + 时间戳                         |
| 保存状态    | dirty/saving/saved/error 是否可辨认             |
| 输出文件    | 文件名 + SHA-256 + 文件大小                     |
| 重开检查    | 内容、对象数、顺序、样式、公式结果              |
| 视觉检查    | 截图编号或 render diff                          |
| 恢复检查    | undo/redo、失败信息、恢复路径                   |
| 总判定      | PASS/FAIL/BLOCKED/NV + 一句话原因               |

硬断言：共 4 页，顺序为 `封面→方案→结论→数据`；标题含 `T-325-R1`；第 2 页 SVG 与矩形均存在且不重叠；图表值为 120/150/180；重开和导出后的页数、文本、对象、位置和样式一致；PPTX 可被 PowerPoint 或 LibreOffice 打开。

## Excel 场景

### XLSX-01 多表、公式、格式、重开、导出

素材：`fixtures/excel-seed.csv` 与 `fixtures/expected-results.json`。

1. 新建 workbook，将 CSV 导入 `明细`。
2. 新建 `汇总` 与 `参数`；将 `参数!B1` 设为税率 `13%`。
3. 在 `明细` 新增 `金额`、`含税金额` 两列，公式分别为 `数量*单价`、`金额*(1+'参数'!$B$1)`，向下填充。
4. 设置日期、整数、人民币和百分比格式；标题加粗、冻结首行。
5. 复制两行、删除其中一行；插入一列再撤销；验证数据没有错位。
6. 在 `汇总` 按地区汇总金额并建立柱状图。
7. 将 `参数` 重命名为 `参数表`，移动到第 1 个 sheet，并修复 / 确认跨表引用。
8. 保存，关闭重开，导出 / 下载 XLSX。

硬断言：3 个 sheet，顺序 `参数表→明细→汇总`；总未税金额 `3115.00`，总含税金额 `3519.95`；华东 `1765.00`、华南 `1350.00`；公式仍为公式而不是静态值；无 `#REF!/#DIV/0!/#VALUE!/#NAME?/#N/A`；格式与图表保留；导出文件可打开。

## 一致性与可恢复性场景

### COMMON-01 统一交互

对三类文件依次执行：打开→一次编辑→观察 dirty→保存→观察 saving/saved→撤销 / 重做→关闭重开→下载。记录入口、按钮位置、快捷键和提示语。

硬断言：相同概念使用相同文案和快捷键；关闭未保存文件会阻止或明确确认；成功与失败反馈可区分；用户能看出当前文件名和保存目标。

### COMMON-02 保存失败恢复

在保存前断网或令目标目录不可写，触发一次失败，然后恢复条件并重试。

硬断言：失败不能丢失编辑；必须显示可理解原因和重试 / 另存路径；恢复后可继续保存；重开文件包含失败前全部修改。

### COMMON-03 长内容与连续操作

分别使用 50 页 PPT、10,000 行 / 10 sheet XLSX、100 页 DOCX，连续执行 20 次编辑和 10 次 undo/redo。

硬断言：无崩溃 / 无响应超过 5 秒；最终状态与操作日志一致；保存重开后没有静默丢失。
