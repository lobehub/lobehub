# 設定 `OPENAI_PROXY_URL` 環境變數但返回值為空

### 問題描述

設定 `OPENAI_PROXY_URL` 環境變數後，可能會遇到 AI 的返回訊息為空的情況。這可能是由於 `OPENAI_PROXY_URL` 設定不正確導致。

### 解決方案

重新檢查並確認 `OPENAI_PROXY_URL` 是否設定正確，包括是否正確地新增了 `/v1` 後綴（如果需要）。
