# 與 Ollama 整合

Ollama 是一款強大的本地執行大型語言模型（LLM）的框架，支援多種語言模型，包括 Llama 2, Mistral 等。現在，LobeHub 已經支援與 Ollama 的整合，這意味著你可以在 LobeHub 中輕鬆使用 Ollama 提供的語言模型來增強你的應用程式。

本文件將指導你如何設定與部署 LobeHub 來使用 Ollama：

## 本地啟動 Ollama

首先，你需要安裝 Ollama，安裝與設定 Ollama 的詳細步驟可以參考 [Ollama 官方站點](https://ollama.com)。

## 本地執行 LobeHub

假設你已經在本地 `11434` 連接埠啟動了 Ollama 服務。執行以下 Docker 命令行，在本地啟動 LobeHub：

```bash
docker run -d -p 3210:3210 -e OLLAMA_PROXY_URL=http://host.docker.internal:11434 lobehub/lobe-chat
```

接下來，你就可以使用 LobeHub 與本地 LLM 對話了。

關於在 LobeHub 中使用 Ollama 的更多資訊，請查閱 [Ollama 使用](/zh/docs/usage/providers/ollama)。

## 非本地存取 Ollama

由於 Ollama 預設參數在啟動時設定了僅本地存取，所以跨域存取以及連接埠監聽需要進行額外的環境變數設定 `OLLAMA_ORIGINS` 和 `OLLAMA_HOST`。

### Ollama 環境變數

| 環境變數                | 描述               | 預設值                                                      | 附加說明                          |
| ------------------- | ---------------- | -------------------------------------------------------- | ----------------------------- |
| `OLLAMA_HOST`       | 綁定的主機和連接埠         | "127.0.0.1:11434"                                        | 設定 0.0.0.0: 連接埠號 可以指定所有人存取特定連接埠 |
| `OLLAMA_ORIGINS`    | 允許的跨域源列表，逗號分隔    | 僅本地存取                                                    | 設定 "\*" 可以避免 CORS 跨域錯誤，按需設定   |
| `OLLAMA_MODELS`     | 模型存放的路徑          | "\~/.ollama/models" 或 "/usr/share/ollama/.ollama/models" | 按需指定                          |
| `OLLAMA_KEEP_ALIVE` | 模型在顯存中保持載入的持續時間  | "5m"                                                     | 按需載入和釋放顯存可以有效降低顯卡壓力，但會增加硬碟讀寫  |
| `OLLAMA_DEBUG`      | 設定為 1 以啟用額外的除錯日誌 | 預設關閉                                                     |                               |

### 在 Windows 上設定環境變數

在 Windows 上，Ollama 繼承了您的使用者和系統環境變數。

1. 首先通過 Windows 任務欄點擊 Ollama 退出程式。
2. 從控制面板編輯系統環境變數。
3. 為您的使用者帳號編輯或新建 Ollama 的環境變數，比如`OLLAMA_HOST`、`OLLAMA_ORIGINS`等。
4. 點擊`OK/套用`儲存。
5. 重新執行`Ollama`。

### 在 Mac 上設定環境變數

如果 Ollama 作為 macOS 應用程式執行，你需要使用 `launchctl` 設定環境變數：

1. 對於每個環境變數，調用 `launchctl setenv`。

   ```bash
   launchctl setenv OLLAMA_HOST "0.0.0.0"
   launchctl setenv OLLAMA_ORIGINS "*"
   ```

2. 重啟 Ollama 應用程式。

### 在 Linux 上設定環境變數

如果 Ollama 作為 systemd 服務執行，應該使用`systemctl`設定環境變數：

1. 通過調用`sudo systemctl edit ollama.service`編輯 systemd 服務。

   ```bash
   sudo systemctl edit ollama.service
   ```

2. 對於每個環境變數，在`[Service]`部分下新增`Environment`：

   ```bash
   [Service]
   Environment="OLLAMA_HOST=0.0.0.0"
   Environment="OLLAMA_ORIGINS=*"
   ```

3. 儲存並退出。

4. 重載`systemd`並重啟 Ollama：

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart ollama
   ```

### 在 Docker 上設定環境變數

如果 Ollama 作為 Docker 容器執行，你可以將環境變數新增到 `docker run` 命令中。

詳細設定方法可以參考 [Ollama 官方文件](https://github.com/ollama/ollama/blob/main/docs/faq.md#how-do-i-configure-ollama-server)。
