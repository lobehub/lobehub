Upgrade your Neon PostgreSQL project to PostgreSQL 17 before deploying LobeHub v2. Neon supports the `pg_search` extension out of the box only on PostgreSQL 17.
<Callout type={'warning'}>
  **Before you begin**:
  - **Back up your database first.** In Neon, create a backup with [Fork Branch](https://neon.tech/docs/manage/branches#create-a-branch).
  - Proceed only if you accept the migration risk. LobeHub is not responsible for data loss or issues that occur during migration.
  - Use this guide only if you have database migration experience.
  - Ask for help in [Discord](https://discord.com/invite/AYFPHvv2jT) or open a [GitHub Issue](https://github.com/lobehub/lobe-chat/issues/11707).
 </Callout>

## Choose a migration path

| Method                                | Best for             |
| ------------------------------------- | -------------------- |
| [Simple migration](#simple-migration) | Database size under 10 GB |
| [Full migration](#full-migration)     | Large databases |

## Simple migration

Use this method if you meet all of the following conditions:

-- Use Neon as your database provider.
-- Run PostgreSQL earlier than 17.
-- Keep your database size under 10 GB.
-- Expect extra Neon charges if your database exceeds the free-tier quota.

In LobeHub v2, the `pg_search` extension is required for database migrations. Upgrade your database to PostgreSQL 17 first to avoid deployment failures.

### Follow these steps

1. Back up your database with [Fork Branch](https://neon.tech/docs/manage/branches#create-a-branch).

2. **Copy the connection string.**
Copy the unpooled connection string to improve the import success rate.
[connection-string](https://github.com/user-attachments/assets/9126999a-a6f2-4d4b-ae68-70631e1657cc)

3. **Use Neon's built-in Import Data feature.**
Open the Import Data entry in the Neon console:
[import-data](https://github.com/user-attachments/assets/3b48b842-afb1-4e7c-afdf-b1dc4e4c603e)

4. **Paste the connection string and follow the Neon instructions:**
 <Callout type={'warning'}>
  **Region requirement**:
  Select an AWS region that supports `pg_search`. See the [Neon pg_search documentation](https://neon.com/docs/extensions/pg_search).
 </Callout>
[import-instructions](https://github.com/user-attachments/assets/806c285b-ce8a-4a68-8405-553f7fae8499)

5. **Replace your original `DATABASE_URL`.**
Open the connection settings, select the `import` branch, copy its connection string, replace your original `DATABASE_URL` environment variable, and rebuild or restart LobeHub.

After the rebuild completes, confirm that the database migration finishes successfully.

## Full migration

Use this method if you meet all of the following conditions:

-- Use Neon and your database size exceeds 10 GB.
-- Have database management and migration experience.
-- Have already installed PostgreSQL tools.

<Callout type={'warning'}>
  Neon does not support `pg_dumpall`. Use `pg_dump` instead.
 </Callout>

If you want to use logical replication, follow [Neon's official PostgreSQL upgrade guide](https://neon.com/docs/postgresql/postgres-upgrade).

1. **Dump your LobeHub database.**
 ```bash
 pg_dump -Fc -v -d postgresql://[user]:[password]@[neon_hostname]/[dbname] -f <dump_file_name>
 ```

2. **Restore the dump to your PostgreSQL 17 database.**
 ```bash
 pg_restore -v -d <neon_database_connection_string> <dump_file_name>
 ```

3. **Replace your original `DATABASE_URL`.**
Replace the `DATABASE_URL` environment variable with the new connection string, then rebuild or restart LobeHub.

After the restart completes, confirm that LobeHub starts normally and that the database migration succeeds.
