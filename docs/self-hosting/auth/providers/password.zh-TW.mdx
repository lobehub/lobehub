# 設定信箱密碼登入

LobeHub 預設支援傳統的信箱密碼登入方式。本指南介紹可用的設定選項。

## 預設行為

預設情況下，信箱密碼登入已啟用。使用者可以使用信箱位址註冊並設定密碼。

## 設定選項

### 禁用信箱密碼登入（僅 SSO 模式）

如果你希望強制使用者只能通過 SSO 提供商登入，請設定以下環境變數：

| 環境變數                          | 類型 | 描述               |
| ----------------------------- | -- | ---------------- |
| `AUTH_DISABLE_EMAIL_PASSWORD` | 可選 | 設定為 `1` 禁用信箱密碼登入 |

啟用後：

- 登入頁面隱藏信箱輸入框
- 僅顯示 SSO 提供商登入按鈕
- 註冊頁面重新導向到登入頁面
- 使用者必須通過設定的 SSO 提供商進行身分驗證

<Callout type={'warning'}>
  啟用僅 SSO 模式前，請確保已通過 `AUTH_SSO_PROVIDERS` 設定了至少一個 SSO
  提供商。否則使用者將無法登入。
</Callout>

### 啟用信箱驗證

要求使用者在登入前驗證信箱位址：

| 環境變數                      | 類型 | 描述             |
| ------------------------- | -- | -------------- |
| `AUTH_EMAIL_VERIFICATION` | 可選 | 設定為 `1` 啟用信箱驗證 |

這需要設定郵件服務（SMTP）。詳情請參閱[郵件服務設定](/zh/docs/self-hosting/auth/email)。

### 啟用魔法連結登入

允許通過郵件魔法連結實現無密碼登入：

| 環境變數                     | 類型 | 描述               |
| ------------------------ | -- | ---------------- |
| `AUTH_ENABLE_MAGIC_LINK` | 可選 | 設定為 `1` 啟用魔法連結登入 |

這也需要設定郵件服務（SMTP）。

## 修改密碼

使用者可以通過以下兩種方式修改密碼：

1. **個人設定**：前往 設定 > 個人資料 修改密碼
2. **忘記密碼**：在登入頁面輸入信箱後，進入密碼輸入步驟，點擊密碼框下方的「忘記密碼」

<Callout type={'info'}>
  以上兩種方式都需要設定郵件服務（SMTP）以發送密碼重置郵件。
</Callout>

## 設定示例

### 僅 SSO（禁用信箱密碼）

```bash
AUTH_DISABLE_EMAIL_PASSWORD=1
AUTH_SSO_PROVIDERS=google,github
```

### 信箱密碼 + 信箱驗證

```bash
AUTH_EMAIL_VERIFICATION=1
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=noreply@example.com
SMTP_PASS=your-password
```

### 信箱密碼 + 魔法連結

```bash
AUTH_ENABLE_MAGIC_LINK=1
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=noreply@example.com
SMTP_PASS=your-password
```

<Callout type={'tip'}>
  前往[環境變數](/zh/docs/self-hosting/environment-variables/auth)查看所有身分驗證相關變數的詳細資訊。
</Callout>
