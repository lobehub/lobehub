# 設定 ZITADEL 身分驗證

[ZITADEL](https://zitadel.com/) 是一個開源的身分基礎設施，搭載多租戶支援。

<Steps>
  ### 在 ZITADEL 中建立應用程式

  1. 登入 ZITADEL 控制檯
  2. 前往你的項目（或建立新項目）
  3. 點擊 **New** 建立新應用程式
  4. 選擇 **Web** 作為應用程式類型
  5. 設定：
     - Name: `LobeHub`
     - Authentication Method: `CODE`（用於機密客戶端）
  6. 新增重新導向 URI：

  <Callout type={'info'}>
    **回調 URL 格式**: `https://your-domain.com/api/auth/callback/zitadel`
  </Callout>

  7. 建立後，記下 **Client ID** 並生成 **Client Secret**

  ### 獲取 Issuer URL

  Issuer URL 是 ZITADEL 實例 URL，通常為：

  - 雲版：`https://your-instance.zitadel.cloud`
  - 自託管：`https://your-zitadel-domain`

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                  | 類型 | 描述                                                           |
  | --------------------- | -- | ------------------------------------------------------------ |
  | `AUTH_SECRET`         | 必選 | 用於加密會話令牌的密鑰。使用以下命令生成：`openssl rand -base64 32`               |
  | `AUTH_SSO_PROVIDERS`  | 必選 | SSO 提供商。使用 ZITADEL 請填寫 `zitadel`                             |
  | `AUTH_ZITADEL_ID`     | 必選 | ZITADEL 應用程式的 Client ID                                        |
  | `AUTH_ZITADEL_SECRET` | 必選 | ZITADEL 應用程式的 Client Secret                                    |
  | `AUTH_ZITADEL_ISSUER` | 必選 | ZITADEL Issuer URL（例如 `https://your-instance.zitadel.cloud`） |

  <Callout type={'info'}>
    **相容的環境變數**：為了向後相容，以下別名也支援：

    - `ZITADEL_CLIENT_ID` / `ZITADEL_CLIENT_SECRET` / `ZITADEL_ISSUER`
  </Callout>

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variables/auth#zitadel) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>部署成功後，使用者將可以通過 ZITADEL 身分認證並使用 LobeHub。</Callout>
