# 設定 Authentik 身分驗證

[Authentik](https://goauthentik.io/) 是一個開源身分提供商，專注於靈活性和多功能性。

<Steps>
  ### 在 Authentik 中建立 OAuth2 提供商

  1. 在 Authentik 管理界面，前往 **Applications** > **Providers**
  2. 點擊 **Create**，選擇 **OAuth2/OpenID Provider**
  3. 設定提供商：
     - Name: `LobeHub`
     - Authorization flow: 選擇授權流程
     - Client type: `Confidential`
     - Redirect URIs: 新增回調 URL

  <Callout type={'info'}>
    **回調 URL 格式**: `https://your-domain.com/api/auth/callback/authentik`
  </Callout>

  ### 建立應用程式

  1. 前往 **Applications** > **Applications**
  2. 點擊 **Create**，關聯到剛建立的 OAuth2 提供商
  3. 記下 **Client ID** 和 **Client Secret**

  ### 獲取 Issuer URL

  Issuer URL 通常為：`https://your-authentik-domain/application/o/your-app-slug/`

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                    | 類型 | 描述                                             |
  | ----------------------- | -- | ---------------------------------------------- |
  | `AUTH_SECRET`           | 必選 | 用於加密會話令牌的密鑰。使用以下命令生成：`openssl rand -base64 32` |
  | `AUTH_SSO_PROVIDERS`    | 必選 | SSO 提供商。使用 Authentik 請填寫 `authentik`           |
  | `AUTH_AUTHENTIK_ID`     | 必選 | Authentik 提供商的 Client ID                       |
  | `AUTH_AUTHENTIK_SECRET` | 必選 | Authentik 提供商的 Client Secret                   |
  | `AUTH_AUTHENTIK_ISSUER` | 必選 | Authentik Issuer URL                           |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variables/auth#authentik) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>部署成功後，使用者將可以通過 Authentik 身分認證並使用 LobeHub。</Callout>
