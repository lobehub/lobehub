# 設定 GitHub 身分驗證

<Steps>
  ### 建立 GitHub App

  1. 前往 [GitHub 開發者設定](https://github.com/settings/apps/new)
  2. 填寫 **GitHub App name** 和 **Homepage URL**

  <Image alt="建立 GitHub App" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/2f919f99-2aaa-4fa7-9938-169d3ed09db7" />

  ### 設定回調 URL

  <Callout type={'info'}>
    回調 URL 格式：

    - 本地開發: `http://localhost:3210/api/auth/callback/github`
    - 生產環境: `https://your-domain.com/api/auth/callback/github`
  </Callout>

  按需設定 Webhook URL（不需要可禁用）。

  <Image alt="填寫其他字段" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/d7ef5ad1-b1a3-435e-b1bc-4436d2b6fecd" />

  ### 設定權限

  設定讀取使用者信箱位址的權限：

  <Image alt="設定所需權限" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/23131ca1-9e84-4a89-a840-ef79c4bc0251" />

  <Image alt="設定讀取郵件位址權限" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/358bca8d-3d82-4e76-9a5e-90d16a39efde" />

  設定公開存取還是僅自己存取。

  <Image alt="設定存取權限" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/995780cb-9096-4a36-ab17-d422703ab970" />

  點擊 **Create GitHub App**。

  ### 生成客戶端密鑰

  建立成功後，點擊 **Generate a new client secret**。

  <Image alt="建立客戶端密鑰" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/6d69bdca-7d18-4cbc-b3e0-220d8815cd29" />

  儲存 **Client ID** 和 **Client Secret**。

  <Image alt="儲存憑證" inStep src="https://github.com/lobehub/lobe-chat/assets/64475363/c6108133-a918-48b0-ab1a-e3fa607572a4" />

  ### 設定環境變數

  | 環境變數                 | 類型 | 描述                                     |
  | -------------------- | -- | -------------------------------------- |
  | `AUTH_SECRET`        | 必選 | 會話加密密鑰，使用 `openssl rand -base64 32` 生成 |
  | `AUTH_SSO_PROVIDERS` | 必選 | 填寫 `github`                            |
  | `AUTH_GITHUB_ID`     | 必選 | GitHub App 的 Client ID                 |
  | `AUTH_GITHUB_SECRET` | 必選 | GitHub App 的 Client Secret             |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variables/auth#github)
    可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功後，使用者將可以通過 GitHub 身分認證並使用 LobeHub。
</Callout>

## 常見問題

### email\_not\_found 錯誤

這通常是因為 GitHub App 沒有信箱讀取權限。前往應用程式設定，導航到 **Permissions & events** > **Account permissions** > **Email addresses**，設定為 **Read-only**。

### 沒有 Refresh Token

GitHub OAuth 不發放 refresh token。存取令牌在使用者撤銷、應用程式撤銷或一年未使用前會一直有效。
