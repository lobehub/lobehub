# 設定 Clerk 身分驗證服務

前往 [Clerk](https://clerk.com?utm_source=lobehub\&utm_medium=docs) 註冊並建立應用程式，獲取相應的 Public Key 和 Secret Key。

## 獲取環境變數

<Steps>
  ### 新增公、私鑰環境變數

  新增 `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` 和 `CLERK_SECRET_KEY` 環境變數。你可以在選單中點擊「API Keys」，然後複製對應的值獲取該環境變數。

  <Image alt={'在 Clerk 中找到對應的公私鑰環境變數'} src={'/blog/assets28616219/89883703-7a1a-4a11-b944-5d804544e57c.webp'} />

  此步驟所需的環境變數如下：

  ```shell
  NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_live_xxxxxxxxxxx
  CLERK_SECRET_KEY=sk_live_xxxxxxxxxxxxxxxxxxxxxx
  ```

  ### 在 Clerk 中建立並設定 Webhook

  由於我們讓 Clerk 完全接管使用者認證與管理，因此我們需要在 Clerk 使用者生命週期變更時（建立、更新、刪除）中通知我們的應用程式並儲存落庫。我們通過 Clerk 提供的 Webhook 來實現這一訴求。

  我們需要在 Clerk 的 Webhooks 中新增一個端點（Endpoint），告訴 Clerk 當使用者發生變更時，向這個端點發送通知。

  <Image alt={'Clerk 新增 Webhooks 端點'} src={'/blog/assets28616219/f50f47fb-5e8e-4930-bf4e-8cf6f5b8afb9.webp'} />

  在 endpoint 中填寫你的項目 URL，如 `https://your-project.com/api/webhooks/clerk`。然後在訂閱事件（Subscribe to events）中，勾選 user 的三個事件（`user.created` 、`user.deleted`、`user.updated`），然後點擊建立。

  <Callout type={'warning'}>URL 的`https://`不可缺失，須保持 URL 的完整性</Callout>

  <Image alt={'新增 Clerk Webhooks 時，設定 URL 和使用者事件'} src={'/blog/assets28616219/0249ea56-ab17-4aa9-a56c-9ebd556c2645.webp'} />

  ### 將 Webhook 秘鑰新增到環境變數

  建立完畢後，可以在右下角找到該 Webhook 的秘鑰：

  <Image alt={'查看 Clerk Webhooks 秘鑰'} src={'/blog/assets28616219/fab4abb2-584b-49de-9340-813382951635.webp'} />

  這個秘鑰所對應的環境變數名為 `CLERK_WEBHOOK_SECRET`：

  ```shell
  CLERK_WEBHOOK_SECRET=whsec_xxxxxxxxxxxxxxxxxxxxxx
  ```
</Steps>

這樣，你已經成功設定了 Clerk 身分驗證服務。
