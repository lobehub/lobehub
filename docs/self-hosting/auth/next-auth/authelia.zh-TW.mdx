# 設定 Authelia 身分驗證服務

## Authelia 設定流程

<Steps>
  ### 建立 Authelia 提供應用程式

  我們現在預設您已經瞭解瞭如何使用 Authelia。假設您的 LobeHub 實例部署在 `https://lobe.example.com/` 中。注意，目前只有 `localhost` 支援 HTTP 存取，其他域名需要啟用 TLS，否則 Authelia 預設將主動中斷身分認證。

  現在，我們開啟 Authelia 實例的組態檔進行編輯：

  在 `identity_providers`-> `oidc` 下新增一個 `lobe-chat` 的項目：

  ```yaml
  ...
  identity_providers:
    oidc:
      ...
      ## The other portions of the mandatory OpenID Connect 1.0 configuration go here.
      ## See: https://www.authelia.com/c/oidc
      - id: lobe-chat
        description: LobeHub
        secret: '$pbkdf2-sha512$310000$c8p78n7pUMln0jzvd4aK4Q$JNRBzwAo0ek5qKn50cFzzvE9RXV88h1wJn5KGiHrD0YKtZaR/nCb2CJPOsKaPK0hjf.9yHxzQGZziziccp6Yng'  # The digest of 'insecure_secret'.
        public: false
        authorization_policy: two_factor
        redirect_uris:
          - https://chat.example.com/api/auth/callback/authelia
        scopes:
          - openid
          - profile
          - email
        userinfo_signing_algorithm: none
  ```

  請您確保 `secret` 和 `redirect_urls` 替換成您自己的值。注意！Authelia 中設定 `secret` 是密文，即加鹽哈希值。其對應的明文稍後需要填寫在 LobeHub 中。

  儲存組態檔，然後重啟 Authelia 服務。現在我們完成了 Authelia 的設定工作。

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                      | 類型 | 描述                                                                                               |
  | ------------------------- | -- | ------------------------------------------------------------------------------------------------ |
  | `AUTH_SECRET`             | 必選 | 用於加密 Auth.js 會話令牌的密鑰。您可以使用以下命令生成秘鑰： `openssl rand -base64 32`                                    |
  | `NEXT_AUTH_SSO_PROVIDERS` | 必選 | 選擇 LoboChat 的單點登入提供商。使用 Authelia 請填寫 `authelia`。                                                 |
  | `AUTH_AUTHELIA_ID`        | 必選 | 剛剛在 Authelia 設定的 `id`，示例值是 `lobe-chat`                                                           |
  | `AUTH_AUTHELIA_SECRET`    | 必選 | 剛剛在 Authelia 設定的 `secret` 對應的明文，示例值是 `insecure_secret`                                           |
  | `AUTH_AUTHELIA_ISSUER`    | 必選 | 您的 Authelia 的網址，例如 `https://sso.example.com`                                                     |
  | `AUTH_URL`                | 必選 | 該 URL 用於指定 Auth.js 在執行 OAuth 驗證時的回調位址，當預設生成的重新導向位址發生不正確時才需要設定。`https://chat.example.com/api/auth` |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variable#Authelia) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功後，使用者將可以使用 Authelia 中設定的使用者通過身分認證並使用 LobeHub。
</Callout>
