# 設定 Cloudflare Zero Trust 身分驗證服務

## Cloudflare Zero Trust 設定流程

<Steps>
  ### 在 Cloudflare Zero Trust 中建立應用程式

  我們現在預設您已經瞭解瞭如何使用 Cloudflare Zero Trust 平臺且假設您的 LobeHub 實例部署在 `https://chat.example.com` 中。

  首先我們需要存取 `https://one.dash.cloudflare.com/` 並前往 `Access - Applications` 中。

  ![image](/blog/assetsc74cf5c8daee1515c37a85bce087f0d6.webp)

  現在，在所在頁面點擊 `Add an application` 並選擇 `SaaS`。

  ![image](/blog/assetse717764a3618df4e56212e447a6c20cd.webp)

  在 `Application` 文字框內填入應用程式名稱，如：`LobeHub SSO`，然後點擊 `Select OIDC` 後點擊 `Add applicaiton`

  ![image](/blog/assets0ceb7e446f9a850df283093563ba7803.webp)

  至此您已成功在 Clouflare Zero Trust 中建立了一個名為 `LobeHub SSO` 的 SaaS 應用程式。

  接下來我們需要在 `Redirect URLs` 中填入 `https://chat.example.com/api/auth/callback/cloudflare-zero-trust`（注意此處的 `chat.example.com` 需要替換為您的實例位址） ![image](/blog/assets4aaf8d5d092608b649230e0e6fc92df6.webp)

  最後我們將頁面往下滾動，您將需要記錄以下三個值 `Client secret`, `Client ID` 及 `Issuer` 以備後續部署 LobeHub 環境變數使用。

  ![image](/blog/assets66b0dfa56c1f5b3063b5ba740dd3ef8d.webp)

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                                | 類型 | 描述                                                                                                           |
  | ----------------------------------- | -- | ------------------------------------------------------------------------------------------------------------ |
  | `AUTH_SECRET`                       | 必選 | 用於加密 Auth.js 會話令牌的密鑰。您可以使用以下命令生成秘鑰： `openssl rand -base64 32`                                                |
  | `NEXT_AUTH_SSO_PROVIDERS`           | 必選 | 選擇 LoboChat 的單點登入提供商。使用 Cloudflare Zero Trust 請填寫 `cloudflare-zero-trust`。                                   |
  | `AUTH_CLOUDFLARE_ZERO_TRUST_ID`     | 必選 | 在 Cloudflare Zero Trust 生成的 `Client ID`，示例值是 `lobe-chat`                                                     |
  | `AUTH_CLOUDFLARE_ZERO_TRUST_SECRET` | 必選 | 在 Cloudflare Zero Trust 生成的 `Client secret`，示例值是 `insecure_secret`                                           |
  | `AUTH_CLOUDFLARE_ZERO_TRUST_ISSUER` | 必選 | 在 Cloudflare Zero Trust 生成的 `Issuer`，例如 `https://example.cloudflareaccess.com/cdn-cgi/access/sso/oidc/7db0f` |
  | `AUTH_URL`                          | 必選 | 該 URL 用於指定 Auth.js 在執行 OAuth 驗證時的回調位址，當預設生成的重新導向位址發生不正確時才需要設定。`https://chat.example.com/api/auth`             |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variable#Cloudflare%20Zero%20Trust) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功後，使用者將可以使用 Cloudflare Zero Trust 中設定的使用者通過身分認證並使用 LobeHub。
</Callout>
