# 設定 Authentik 身分驗證服務

## Authentik 設定流程

<Steps>
  ### 建立 Authentik 提供應用程式

  在你的 Authentik 實例中使用管理員帳號進入 管理員界面 -> 應用程式 -> 提供程式 建立一個新的提供程式。

  選擇 OAuth2/OpenID Provider 作為提供程式類型。填寫提供程式的名稱，選擇身分流程和授權流程。

  在 `重新導向 URL/Origin（正則）` 處填寫：

  ```bash
  https://your-domain/api/auth/callback/authentik
  ```

  <Callout type={'info'}>
    - 可以之後再填寫或修改 `重新導向 URL/Origin（正則）`，但是務必保證填寫的 URL 與部署的 URL 一致。 -
      your-domain 請替換為自己的域名
  </Callout>

  <Image alt="建立 Authentik 提供程式" inStep src="/blog/assets67304509/4244634e-5f68-48d5-aac0-e5f4b06d1c4b.webp" />

  點擊「完成」

  建立成功後，點擊左側的「應用程式」-> 建立，填寫名稱和 Slug ，提供程式選擇上一步建立的提供程式，點擊「建立」。

  提供程式建立成功後，點擊相應的提供程式，進入詳情頁，點擊「編輯」，將 `客戶端 ID` 和 `客戶端 Secret` 儲存下來。複製 `OpenID 設定頒發者` 的 URL，儲存下來。

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                      | 類型 | 描述                                                                                          |
  | ------------------------- | -- | ------------------------------------------------------------------------------------------- |
  | `AUTH_SECRET`             | 必選 | 用於加密 Auth.js 會話令牌的密鑰。您可以使用以下命令生成秘鑰： `openssl rand -base64 32`                               |
  | `NEXT_AUTH_SSO_PROVIDERS` | 必選 | 選擇 LoboChat 的單點登入提供商。使用 Authentik 請填寫 `authentik`。                                          |
  | `AUTH_AUTHENTIK_ID`       | 必選 | Authentik 提供程式詳情頁的 客戶端 ID                                                                   |
  | `AUTH_AUTHENTIK_SECRET`   | 必選 | Authentik 提供程式詳情頁的 客戶端 Secret                                                               |
  | `AUTH_AUTHENTIK_ISSUER`   | 必選 | Authentik 提供程式詳情頁的 OpenID 設定頒發者                                                             |
  | `AUTH_URL`                | 必選 | 該 URL 用於指定 Auth.js 在執行 OAuth 驗證時的回調位址，當預設生成的重新導向位址發生不正確時才需要設定。`https://example.com/api/auth` |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variable#Authentik) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功後，使用者將可以使用 Authentik 中設定的使用者通過身分認證並使用 LobeHub。
</Callout>
