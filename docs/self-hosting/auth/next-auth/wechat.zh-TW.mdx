# 設定微信身分驗證服務

## 微信設定流程

<Steps>
  ### 建立微信網站應用程式

  點擊 [這裡](https://open.weixin.qq.com/cgi-bin/index) 依次點擊 「管理中心」、「網站應用程式」、「建立網站應用程式」

  按照管網提示要求填寫資訊並提交審核。

  建立成功後，點擊 「應用程式詳情」，可獲知 AppID 和 AppSecret。

  ### 設定環境變數

  在部署 LobeHub 時，你需要設定以下環境變數：

  | 環境變數                      | 類型 | 描述                                                                                          |
  | ------------------------- | -- | ------------------------------------------------------------------------------------------- |
  | `AUTH_SECRET`             | 必選 | 用於加密 Auth.js 會話令牌的密鑰。您可以使用以下命令生成秘鑰： `openssl rand -base64 32`                               |
  | `NEXT_AUTH_SSO_PROVIDERS` | 必選 | 選擇 LoboChat 的單點登入提供商。使用 Github 請填寫 `github`。                                                |
  | `WECHAT_CLIENT_ID`        | 必選 | 微信網站應用程式詳情頁的 客戶端 ID                                                                           |
  | `WECHAT_CLIENT_SECRET`    | 必選 | 微信網站應用程式詳情頁的 客戶端 Secret                                                                       |
  | `AUTH_URL`                | 必選 | 該 URL 用於指定 Auth.js 在執行 OAuth 驗證時的回調位址，當預設生成的重新導向位址發生不正確時才需要設定。`https://example.com/api/auth` |

  <Callout type={'tip'}>
    前往 [📘 環境變數](/zh/docs/self-hosting/environment-variables/auth#wechat) 可查閱相關變數詳情。
  </Callout>
</Steps>

<Callout type={'info'}>部署成功後，使用者將可以通過微信開放平臺身分認證並使用 LobeHub。</Callout>
