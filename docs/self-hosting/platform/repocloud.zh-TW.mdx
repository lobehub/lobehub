# 在 RepoCloud 上部署 LobeHub 資料庫版

如果您想在 RepoCloud 上部署 LobeHub 資料庫版，可以按照以下步驟進行操作：

## RepoCloud 部署流程

<Steps>
  ### 準備您的 OpenAI API 密鑰

  請存取 [OpenAI API 密鑰](https://platform.openai.com/account/api-keys) 獲取您的 OpenAI API 密鑰。

  ### 一鍵部署

  [![部署到 RepoCloud](https://d16t0pc4846x52.cloudfront.net/deploy.svg)](https://repocloud.io/details/?app_id=248)

  ### 部署完成後，您可以開始使用

  ### 綁定自訂域名（可選）

  您可以使用 RepoCloud 提供的子域名，或選擇綁定自訂域名。目前，RepoCloud 提供的域名尚未被汙染，大多數地區可以直接連接。
</Steps>
