## 一句话

LobeHub 是开源的 AI Agent 工作空间：用户创建和组织 Agent，与 Agent / Agent 群组对话，让 Agent 跑任务、产出文档与作品，并管理模型、插件、技能、知识库与记忆。

## 平台

| 平台    | 主次                  | 入口                                                                                          | 交互前提                                                 |
| ------- | --------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| web     | 主                    | `src/spa/router/desktopRouter.*`，路由段在 `src/routes/(main)`                                | 鼠标 + 键盘，宽屏，多面板（侧栏 / 主区 / 右侧面板）      |
| desktop | 主（与 web 共用页面） | `apps/desktop`（Electron），`src/routes/(desktop)`、`src/features/Electron`、`Desktop*Bridge` | 同 web，另有窗口标题栏、系统菜单、本地文件与设备、快捷键 |
| mobile  | 次                    | `src/spa/router/mobileRouter.config.tsx`，路由段在 `src/routes/(mobile)`                      | **触控为主**，窄屏单栏，以点按为主，不依赖悬停           |
| popup   | 辅                    | `src/routes/(popup)`                                                                          | 独立小窗：单个 Agent / 群组 / 进程，信息只保留当前任务   |

平台：web, desktop, mobile

`project-scan` 只识别到 web；desktop 与 mobile 来自上表的目录，判断时以本表为准。**mobile 是同一套 DOM SPA 的移动入口**（`src/spa/entry.mobile.tsx`，原子层同样取自 `@lobehub/ui`），不是 React Native：RN 专属规则不适用，web 的组件与 lint 规则照常适用；C-20 这类「仅 mobile」的规则指的就是这个入口。web 与 desktop 共用 `desktopRouter.shared.tsx`，平台差异只放在 `desktopRouter.config*.tsx`（见 `spa-routes` skill）。

## 产品类型

消费级 AI 聊天 + 个人 / 团队 Agent 工作空间。主体是对话与内容生产界面，设置、资源和用量页面接近 SaaS 工具。不是企业后台，也不是营销站（本仓库不含官网页面）。

## 用户

| 角色                | 权限边界                                                   | 使用频率       |
| ------------------- | ---------------------------------------------------------- | -------------- |
| 个人用户            | 自己的 Agent、话题、文档、资源、记忆与设置                 | 高频，每天多次 |
| 工作区成员 / 管理者 | 工作区内共享的 Agent、项目、资源；管理者另有成员与权限设置 | 中高频         |
| 自部署管理员        | 部署、环境变量与模型提供商配置                             | 低频           |
| 分享访客            | 只看或使用被分享的 Agent / 话题 / 页面                     | 偶发           |

## 核心任务

1. 与 Agent 或 Agent 群组对话，查看流式回复、工具调用与产出。
2. 创建、配置和发现 Agent（角色、模型、插件、技能、知识库）。
3. 给 Agent 派任务，跟踪进度、审批与结果。
4. 编写和管理文档 / 页面，整理资源与知识库。
5. 选择和配置模型与服务商。
6. 管理记忆、偏好与工作区设置。

## 文案

copy-profile: consumer; /settings, /resource, /dashboard, /eval → saas

- 人称：**你**（现有 zh-CN 文案以「你」为主）；涉及企业采购、发票、合同的页面才用「您」，并在此登记。
- 用户的词优先：「对话」「助手 / Agent」「话题」「记忆」，不写实现词（会话实例、向量存储）。
- 可创建、命名、搜索、分享、迁移和删除的 Topic 实体统一称为 **topic /topics（话题）**；conversation（对话）仅用于聊天行为或消息内容，不作为 Topic 的同义名称。
- Channel 内承接某条消息的独立讨论统一称为 **thread（线程）**，不称「分支」或「分支讨论」；Git 分支、Topic 分支及其他产品概念不受此规则影响。
- i18n：默认文案写在 `packages/locales/src/default/*.ts`，手工同步 `locales/en-US` 与 `locales/zh-CN`，其余语言由 CI 翻译（见 `i18n` skill）。术语以已有 locale 为准。
