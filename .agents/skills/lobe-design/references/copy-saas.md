> 只在 75-copy 选中 `saas` 时加载。通用规则（T-01..T-09）照常适用。

## T-20 语气、人称与密度

- 人称：**你** 或无主语（二选一，记进 product.md）。面向企业采购、合同、发票的页面可以用「您」，但只限这些页面，并在 product.md 写明边界。
- 语气：专业、克制、可信。不夸张，不撒娇；用户是在工作，不是在娱乐。
- 密度：中等。标签是名词，说明一句话讲清用途或口径；复杂设置给「了解更多」，不在界面里写长段。

## T-21 术语

- 对象名词来自产品术语表：工作区、项目、成员、角色、席位……同一个对象全站一个词（W-03），首次出现的专有概念在 tooltip 里给一句定义。
- 权限与角色写清楚范围：`仅管理员可修改`，不写 `您没有权限`。
- 计费相关词严格区分：套餐 / 席位 / 用量 / 额度 / 账单 / 发票；不用「费用」笼统代替。

## T-22 空态、错误与确认

| 场景 | 推荐 | 避免 |
| --- | --- | --- |
| 首次空态 | `还没有项目。创建第一个项目来邀请成员` + 「新建项目」 | `暂无项目` |
| 权限不足 | `只有工作区管理员可以修改计费。联系 <管理员名> 申请` | `无权限` |
| 套餐限制 | `免费版最多 3 个项目。升级到团队版可创建更多` | `已达上限` |
| 邀请成功 | `已向 3 位成员发送邀请` | `操作成功` |
| 危险确认 | `移除成员「张三」？对方将无法访问该工作区的 12 个项目` · 按钮「移除成员」 | `确定移除吗？` |

- 失败时说清影响范围：`已保存 8 项，2 项因权限不足未保存`，并给「查看失败项」。

## T-23 表单说明与 tooltip

- 表单 help 写约束和默认值：`仅支持小写字母、数字和 -，最多 32 个字符`。
- tooltip 解释口径而不是复述标签：`席位：按当月最多同时在册的成员数计费`。
