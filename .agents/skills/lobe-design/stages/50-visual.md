# Stage 50 · 视觉取值打磨（visual）

> 只回答一个问题：**在结构和流程都已确定的前提下，这块界面的取值是否像一套系统，以及有没有 AI 味。**

## 聚焦

- 取值：颜色、圆角、阴影、字体都走 `cssVar`；状态色从基础 token 派生
- **主题色本身要改时**（换品牌 / primary、定制色板、重调状态色阶）：不要在本 stage 手改 hex——改去 lobe-ui 的 [`tuning-color-palettes`](https://github.com/lobehub/lobe-ui/tree/master/.agents/skills/tuning-color-palettes)（本机已安装则按名调用）。本 stage 只决定如何**用**已有 token（克制、对比、反 AI 味）
- 间距与对齐：4 的倍数；区块之间的间距要大于区块内部的间距；对齐线要少
- 排版：字阶、字重、中文排版、等宽数字
- 密度：按 brief 的「密度倾向」和页面类型定
- 视觉权重：按 brief 的「决定所需信息」分配，最重要的最显眼
- 明暗两种外观都成立；动效克制；反 AI 味

## 不负责（重要）

- **不评估组件选型，也不评估项目是否符合 LobeUI 架构。** 硬性架构规则由 `lint-lobe.mjs` 兜底，本 stage 只需要跑一下脚本，不需要把架构规范读进上下文。看到选型问题，记 `遗留 → 30`。
- 不改信息层级、区域顺序 → 40；不改文案措辞 → 75
- 不补状态和边界 → 70
- 不重新定方向（0→1 页面的方向卡由 20 产出，本 stage 只执行）

## 用格式塔原理判断分组（M-02）

**层级感来自分组，分组的第一手段是间距，第二是对齐，第三才是表面。**

| 原理 | 用户会怎么读 | 该用的手段 | 不该用的手段 |
| --- | --- | --- | --- |
| 接近性 | 挨得近的是一组 | 区块间距 ≥ 组内最大间距的 2 倍 | 用分隔线代替间距 |
| 相似性 | 长得像的是一类 | 同类用同一组件 / 同一 token | 同一分类换三种样式 |
| 共同区域 | 在同一个面里的是一组 | `Block` / `Surface` 的表面语义 | 无意义地卡中卡 |
| 闭合 | 缺一块也当成完整形状 | 保持规律（宫格不留孤卡） | 残缺的宫格 |
| 连续 | 沿同一条线的是相关的 | 对齐线 ≤ 3 条 | 每条边都对齐 |
| 图底 | 会先分出前景和背景 | 浮层用阴影 / 模糊分层 | 底色和表面同色 |
| 共同命运 | 一起动的是一组 | 同组一起进入视口 | 逐元素错峰入场 |

**核心判据：先分组，再画框。** 一个区域需要靠加边框才看得出是一组，说明间距不够。

**M-08 认知负荷**：一屏内能同时呈现的信息块有限。能减少同时呈现的信息量的一切手段（折叠、渐进披露、默认收起）都优于「做得更紧凑」。

## 机械检查（先跑脚本，再用眼睛看）

```bash
node scripts/lint-lobe.mjs <目标路径>     # 裸 hex/rgba、font-family、transition: all、弹跳曲线、>300ms 时长、紫蓝渐变、渐变文字、eyebrow……
```

FAIL 必须修；WARN 要么修，要么在该行加 `// lobe-design-ignore <RULE-ID>: <理由>`。

## 检查清单（脚本覆盖不到、需要看的部分）

1. 视觉权重和 brief 的信息优先级一致：最重要的一项最显眼，且不止一个手段（字号、位置、留白）。
2. 间距取自档位（4/8/12/16/24…），同一区域内一致；区块之间的间距明显大于区块内部的间距。
3. 字阶清楚：控制台 ≤ 4 档（标题 > 行标题 > 正文 > 辅助）；视觉页按方向卡，≤ 5 档。
4. 并排卡片同高，宫格里没有孤卡，指标在窄宽度下按规则换行。
5. 暗色下表面、描边、行线都看得见；没有为暗色单独写 hex 分支。
6. 品牌色 + 品牌渐变一屏 ≤ 3 处；`gradientAnimation` 一页 ≤ 2 处；模糊只用于浮层 / 贴顶表面（A-07）。
7. A-04 反 AI 味清单逐条过一遍。
8. 动效 ≤ 300ms，只动画 `transform` / `opacity`，每个动效都说得出目的。
9. **M-02**：分组是靠间距和对齐成立的，不是靠边框；对齐线 ≤ 3 条。

## 症状 → 规则

| 症状 | 规则 |

| 裸 hex、裸 rgba | D-01 / D-10（lint：`LOBE-RAW-COLOR`） |
| 状态色是新造的 | D-03 |
| 一眼是 AI 模板 | K-01 / A-04 |
| 字号太多、彼此太接近 | A-02 |
| 强调色到处都是 | A-03 / K-01 |

| 密度不对，像另一个品类的产品 | K-09 |
| 要换品牌主色 / 定制色板 / 重调状态色阶 | → lobe-ui `tuning-color-palettes`（非本 skill 规则） |
