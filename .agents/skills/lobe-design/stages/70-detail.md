# Stage 70 · 体验细节加固（detail）

> 只回答一个问题：**在非理想状态、极端输入、键盘操作和窄屏下，这个界面是否依然成立。**
> 吸收 Impeccable `harden` / `adapt` 的思路。逐项过 [detail-checklist.md](../references/detail-checklist.md)，能机械判定的部分交给脚本。

## 聚焦（七个维度，一个都不能少）

1. **状态**：空 / 加载 / 失败 / 部分失败 / 无权限 / 禁用 / 超时 / 刷新失败
2. **边界输入**：长文本、空值、特殊字符、超大数字、1000+ 条记录、多语言长度
3. **交互反馈**：hover / active / focus / 进行中 / 成功 / 失败，每个动作都有可见结果
4. **微文案**：空态、错误、确认、占位是否讲到要素（W-04 / W-05 / W-06）；最终措辞与中文排版交给 75
5. **可访问性**：可访问名、键盘可达、焦点环、对比度、不只靠颜色表达状态
6. **响应式**：1440 / 768 / 390 三个视口；触控目标；横向溢出
7. **一致性**：同一种状态在全页用同一种表达；空值占位全站统一

## 不负责

- 组件选型和架构 → 30（发现「这里应该用 `Empty` 组件」时，记 `遗留 → 30`）
- 页面层级、主路径、主文案 → 40
- 间距、颜色、字号的取值 → 50
- 措辞、语气、人称、中文排版 → 75
- 放行打分 → 80

## 输入

- 00 brief：危险操作、对象生命周期（决定必须覆盖哪些状态）（**必需**）
- 40 的 L5 状态清单（如果有）；10 的「截图未覆盖」清单（screenshot-restore 场景）
- 目标代码；能跑起来的页面

## 用启发式做诊断（M-03）

十项是一张**诊断清单**，不是设计目标：全满分不代表界面好，只代表没有明显坑。逐条过，命中的写进七维覆盖表。

| # | 启发式 | 对应本 stage | 检出 |
| --- | --- | --- | --- |
| 1 | 系统状态可见 | 加载 / 进行中 / 结果反馈 | `DETAIL-*` · X-1 · X-3 |
| 2 | 贴合现实世界 | 用产品的词，不用数据库的词 | X-7.4 |
| 3 | 用户可控可退出 | 取消、撤销、返回不丢数据 | X-3.4 · X-3.7 |
| 4 | 一致与标准 | 同一语义同一表达 | X-7 |

## 用旅程地图找跨页盲点（M-07）

单页看不出、跨页面才成立的三类问题，逐段检查「来路 → 本页 → 去路」：

- **掉状态**：上一步选的筛选、页码、tab 返回后没了
- **掉上下文**：返回后不知道从哪来，或重复问已经提供过的信息
- **重复问**：同一条信息在两个页面各填一次

只在 single-page 任务里免用；涉及流程 / 审批 / 向导时必用。

## 机械检查

```bash
node scripts/lint-lobe.mjs <目标路径>          # outline:none、div onClick 无 role、img 无 alt、icon 按钮无 aria-label、模糊错误文案……
node scripts/check-detail.mjs <目标路径>       # 状态覆盖启发式：数据请求有无 loading / error / empty 分支
```

## 步骤

1. 用 brief 的对象生命周期和危险操作，列出本页**必须**有的状态。
2. 跑两个脚本，把 FAIL / WARN 列进表。
3. 按 detail-checklist 七个维度逐项过：已覆盖打 ✓，缺失的写清楚怎么补，不适用的写 n/a 和理由。
4. 补齐状态、反馈和微文案；需要换组件的情况记遗留给 30。
5. 能拿到浏览器时，在 1440 / 768 / 390 各截一张图，并用 Tab 键走一遍主路径。

## 检查清单（摘要；完整版见 detail-checklist.md）

1. 每个数据区域都有 加载 / 空 / 失败 三种画面；失败不伪装成「0 条」；刷新失败不清空已有数据。
2. 空态给出第一个动作；错误说明原因和出路（W-04 / W-05）。
3. 长文本有截断策略，1000+ 条有分页或虚拟化，空值占位全站统一。
4. 每个动作都有可见反馈；危险操作有确认和结果提示。
5. 没有 `outline: none`；图标按钮有 `aria-label`；状态不只靠颜色表达；对比度达到 AA。
6. 390px 下没有横向溢出，触控目标 ≥ 44px。
7. 同一种状态在全页的表达方式一致。
8. **M-03**：十大启发式逐条过完，命中项已进入七维覆盖表。
9. **M-07**：涉及多步流程时，检查过「掉状态 / 掉上下文 / 重复问」三类跨页盲点（单页任务写 n/a）。
