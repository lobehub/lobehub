────────────────────────────────────────────────────────────────────────────
  Problem: Docker build fails
  → Check: docker build output for specific error
  → Action: Ensure sufficient disk space (10GB+ recommended)

  Problem: Container won't start
  → Check: docker compose logs app
  → Action: Verify DATABASE_URL and other env vars

  Problem: Application not responding
  → Check: curl -I http://localhost:3210
  → Action: Wait 2-3 minutes for initialization

  Problem: File uploads not working
  → Check: S3_* environment variables

  Problem: Audio generation not working
  → Check: SUNO_API_KEY in container
  → Action: Verify Suno API credentials
